---

## 1. Purpose

For **every study day**, determine whether Kwalitec’s educational decisions were worthy of student trust.

These seven questions are the mandatory Educational Trust Criteria (T1–T7). They audit **Kwalitec’s judgement**, not the Founder’s expertise and not subjective preference.

---

## 2. Daily trust questions (T1–T7)

Score each **0–10** immediately after wrap (or at end-of-day). For any score ≤ 5, write a one-line educational reason. Hard-fail flags (§4) override soft averages.

| ID | Validation question | Judgement focus | PASS signal (day) | FAIL signal (day) |
|----|---------------------|-----------------|-------------------|-------------------|
| **T1** | Was today’s mission the **correct educational choice**? | Sequencing / progression | Focus matches lawful next learning or justified revision; “why now” is educationally coherent | Wrong topic for history; checklist leap; mode mismatch without disclosed reason |
| **T2** | Was today’s **workload** educationally appropriate? | Workload / pacing / cognitive load | Achievable within scarce evening; intensity matches LO; no chronic overload or empty underload | Sprawl past stop; denser than evening budget can hold; theatrical thinness |
| **T3** | Did today’s guidance **optimise use of the CMP**? | CMP guidance | Clear locus, aim, and stop; CMP hour becomes intentional craft | Dump / paste; aimless “read the chapter”; product replaces CMP without craft |
| **T4** | Was **revision** introduced at the **correct time**? | Revision timing | Retrieval when memory needs protection; learning when new substance is due; no fake revision theatre | Premature revision with nothing to retrieve; overdue revision omitted; re-read masquerading as revision |
| **T5** | Was the **stopping point** educationally justified? | Stopping integrity | Stop protects learning and tomorrow; wrap matches authorised stop | Mid-fog abandon; forced next-LO sprawl; stop chrome contradicted by wrap |
| **T6** | Did the day’s design follow **established educational science**? | Science-aligned design | Deliberate practice, retrieval where due, guided reading, load-aware structure under frozen Excellence | Reread theatre; activity vanity; load-blind denseness; anti-science scaffolding |
| **T7** | Would an **educational expert** defend today’s learning pathway? | Professional defensibility | A competent IFoA-aware tutor would defend tonight’s pathway under Excellence / Operations | Pathway indefensible except as “the Founder liked it” or inventory convenience |

**Educational Trust day score (ET)** = mean(T1…T7).  
**Trust floor (day)** = min(T1…T7).

---

## 3. Scoring guidance (anti-bias)

### 3.1 Allowed grounds for scores

- Syllabus order and prerequisite honesty  
- Mission / Session educational coherence under frozen EA law  
- CMP craft quality (Guidance-Over-Content)  
- Workload vs stated evening budget  
- Revision vs Learning mode appropriateness  
- Stop / wrap integrity  
- Cognitive-load reasonableness for the LO  
- Confidence honesty (no false mastery)  
- Continuity with prior days (bridge, not reboot; cliff honesty at horizon tip)

### 3.2 Forbidden grounds for scores

| Forbidden | Why |
|-----------|-----|
| “I would have chosen a different LO” without educational defect | Substitutes Founder plan for Kwalitec judgement |
| “I prefer denser / lighter nights” as preference alone | Preference ≠ educational appropriateness (use T2 only with load evidence) |
| Coverage %, DSH, Approver, CE as ET proof | SV-001 / TV-001 separation |
| “Voice was charming” without judgement quality | Affinity ≠ trustworthiness |
| Soft-grading because DX was high | Editorial expectation ≠ lived judgement audit |
| Punishing honest cliff / missing next day | Continuity honesty is trust-preserving (FV-002 tip) |

### 3.3 Link to SV-001 dimensions (corroboration, not substitution)

| Trust criterion | Typical DEV corroboration |
|-----------------|---------------------------|
| T1 Mission choice | D1 direction; SS-02 plan invention |
| T2 Workload | D5 achievability; SS-04 budget honesty |
| T3 CMP craft | D3; SS-05 CMP open/stop |
| T4 Revision timing | Mode label + D3/D4 on Revision days |
| T5 Stopping point | D4; SS-06 correct stop |
| T6 Educational science | Cross-cut D1–D7; HT honesty |
| T7 Expert defence | Holistic; LT willingness only if grounded in quality |

DEV scores do **not** auto-fill T scores. A high-DEV pleasant day can still fail T7 if the pathway is educationally indefensible. A tutor-correct day can still fail DEV if the student cannot sustain it — both must be recorded.

## 4. Hard-fail flags (Educational Trust)

Tick if true. Any tick ⇒ day **does not** earn Educational Trust (still record T scores).

| Flag | Description |
|------|-------------|
| **TF-01** | Mission choice educationally indefensible for this student’s history / mode |
| **TF-02** | Workload educationally inappropriate (chronic overload or empty underload with guilt) |
| **TF-03** | Guidance failed CMP craft (dump, sprawl, or replace-without-aim) |
| **TF-04** | Revision timing wrong (premature / overdue / re-read theatre) |
| **TF-05** | Stopping point unjustified or contradicted |
| **TF-06** | Day design contradicts established educational science under frozen Excellence |
| **TF-07** | Educational expert could not defend the pathway without inventing excuses |
| **TF-08** | False confidence induced by progress / readiness / journey chrome (aligns HT) |

TF-08 is shared culture with SV-001 HT: honesty remains a gatekeeper for trust claims.

## 6. Run / pathway criteria

### 6.1 Founder Educational Trust run (minimum)

| ID | Metric | Target |
|----|--------|--------|
| **ET-01** | ET day score | ≥ 7.0 on ≥ 80% of walked days |
| **ET-02** | ET run score | Mean of ET day scores ≥ 7.5 |
| **ET-03** | Trust-floor mean | Mean of per-day min(T1…T7) ≥ 5.5 |
| **ET-04** | Dimension floor | No T-dimension mean < 6.0 across run |
| **ET-05** | Hard-fail rate | 0 days with TF-01…TF-08 |
| **ET-06** | Expert-defence rate | ≥ 80% of days with T7 ≥ 7 and a written one-line defence |

### 6.2 Dual-gate with SV-001 (companion / trust claims)

Claims that Educational Trust was earned **and** that the product may seek companion rights require:

| Gate | Source | Requirement |
|------|--------|-------------|
| Lived value | SV-001 | DEV / return-worthy / HT rules for the same run |
| Judgement trust | TV-001 | ET-01…ET-06 |
| Reachability honesty | CE / DSH / EO | Scope label correct; Validation-mode ≠ ordinary-path proof (FV-002 discipline) |

**PASS Educational Trust (scoped)** may be declared for Validation-mode inventory when ET criteria hold — must remain labelled non-reachable if DSH = 0.  
**PASS Educational Trust (student-reachable)** requires the released path.

FV-002 companion FAIL remains in force until ordinary-path conditions in `FV002_FINAL_RECOMMENDATION.md` are met. TV-001 does not overturn that FAIL; it clarifies the judgement standard for the next validation.

## 7. Defect vs preference (preserved discipline)

Classify residuals using FV-002 spirit:

| Class | Meaning | Effect on ET |
|-------|---------|--------------|
| **EDU-DEFECT** | Educational judgement failure (T/TF fail) | Blocks day trust |
| **OBS** | Observation / mild copy residual without judgement failure | Does not alone fail ET |
| **WATCH** | Load / density watch — monitor | May depress T2/T6 without TF if still defensible |
| **OPS** | Publication / reachability / inventory ops | Scope label — not ET score |
| **PREF** | Founder preference without educational defect | **Must not** fail ET |

## 8. What these criteria do not do

- Redesign Excellence, Operations, Runtime A/C, SCI, Twin, or recommendations  
- Author content or amend certification rubrics  
- Replace DEV scorecards  
- Convert Founder preference into educational law  
- Declare Version 1 production-ready or exam-pass proof  

---

## Closing

For every study day: correct mission, appropriate workload, optimised CMP use, correct revision timing, justified stop, science-aligned design, and expert-defensible pathway. That is Educational Trust. Anything less is affinity, inventory, or preference — not trustworthiness of judgement.
