### Summary

EA-002 establishes the permanent educational production system for Version 1: how every Mission, Learning Episode, Session, Revision plan, Tomorrow Preview, and Reflection is authored, reviewed, certified, published, and maintained. It delivers the definitive Tutor Voice Guide and Educational Style Guide so different authors produce one Sensei-quality house voice, and it binds a multi-stage certification pipeline (Educational → Tutor → Curriculum → Quality Gate → Publication Approval) where a single failed stage blocks publication.

This programme writes production process, not lessons. No CS1 missions, episodes, sessions, screens, Twin algorithms, or application code were changed. Live EV-001 FAIL remains until successor content programmes execute this Framework and pass EA-001 gates.
