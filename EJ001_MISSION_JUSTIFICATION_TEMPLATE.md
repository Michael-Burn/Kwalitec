# EJ-001 — Mission Justification Template

**Programme:** Educational Production Enhancement EJ-001  
**Artefact class:** Educational Justification (editorial — not student-facing)  
**Status:** Binding template for every authored Educational Mission  
**Effective:** 2026-08-01  
**Parent:** `EJ001_EDUCATIONAL_JUSTIFICATION_STANDARD.md`  
**Related:** `EJ001_AUTHORING_GUIDELINES.md` · `EA003_MISSION_SCHEMA.md` · `EA001_MISSION_PHILOSOPHY.md` · `TV001_VALIDATION_CRITERIA.md`  
**Nature:** Fillable production dossier — **not** application code, **not** student UI copy  

---

## How to use

1. Duplicate this template once per Mission (or equivalent pack path in the Volume Dossier).  
2. Fill identity first, then J1–J10 in any order — recommended order is J8 → J1 → J6 → J3 → J5 → J2 → J4 → J9 → J7 → J10.  
3. Cite concrete syllabus codes, CMP loci, prior Mission IDs, and EP IDs.  
4. Set status to `complete` only when all required fields are filled and Mission-unique.  
5. Attach to Educational Review / Certification evidence before Publication Approval.

**Do not** publish this artefact to students.  
**Do not** leave placeholders (`TBD`, `TODO`, lorem, “see Mission”) in J1–J10 at `complete` status.
