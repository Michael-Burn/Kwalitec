# EA-008 — Campaign Review Guide

**Programme:** Educational Excellence Programme EA-008 — Educational Campaign Architecture  
**Status:** Binding — Academic Board review protocol for Campaigns  
**Effective:** 2026-08-01  
**Parent:** `EA008_EDUCATIONAL_CAMPAIGN_ARCHITECTURE.md` · `EA008_CAMPAIGN_CERTIFICATION.md` · `EA008_CAMPAIGN_PUBLICATION_POLICY.md`  
**Related:** EA-007 Longitudinal Audit method · EA-002 Tutor Voice / Style Guides · EV-001 Trust Break classes  
**Nature:** Reviewer playbook — not educational content, not application code  

---

## 1. Purpose

Give Continuity Reviewers, Trust Reviewers, and the Academic Board an **objective, repeatable** method to accept or reject Educational Campaigns.

Reviewers think like a board designing an entire learning journey — not like editors polishing one lesson.

---

## 2. Review posture

| Do | Do not |
|----|--------|
| Read consecutive days as one student week | Score packages in isolation then average casually |
| Hunt stamp language across day boundaries | Accept syllabus order as continuity |
| Simulate Day-*N* trust | Excuse orphan excellence because one day is Golden |
| Require measurable CI scores | Pass on “generally coherent” prose |
| Reject artificial transitions | Soften gates to meet a release date |

**Superior tests:**

1. Would an IFoA tutor assign this **arc** as primary study for the claimed span?  
2. After the final day, would the student still open Kwalitec first tomorrow?  
3. Does quality hold on the boring middle days — not only the showcase?

---

## 3. Quality gates — reject Campaigns that…

Map to Architecture + Gate CG. Any one is sufficient for Continuity or Trust FAIL.

| Reject ID | Defect | Typical evidence |
|-----------|--------|------------------|
| RQ-01 | **Inconsistent Tutor Voice** | Sensei spike on one day; template collapse elsewhere; shared boilerplate tutor_intent |
| RQ-02 | **Unrelated Missions** | Purpose bag; no Campaign Objective; hinges absent |
| RQ-03 | **Broken educational continuity** | CI below threshold; missing reciprocal bridges; artificial continuity checklist hits |
| RQ-04 | **Generic reflections repeated** | Same residual prompt / stamp harvest across days |
| RQ-05 | **Lack of revision strategy** | No return targets; empty revision theatre; first-pass-only Chapter/Spine |
| RQ-06 | **Poor cognitive pacing** | Uniform thin days on heavy chapters; fatigue stretch without unique Tutor Intent |
| RQ-07 | **Artificial transitions** | Boilerplate Tomorrow / “building on today’s work” without named skill |
| RQ-08 | **Cannot sustain student trust** | Day-*N* simulation No; EA-007 pattern family open |

## 5. Continuity layer scoring protocol (CL-01…CL-08)

Score each layer **0–10**. Use half-points only when Board consensus requires. Record one evidence line per score.

### 5.1 Anchors

| Score | Meaning |
|------:|---------|
| 0–2 | Absent or theatrical only |
| 3–4 | Occasional authored quality; mostly template / artificial |
| 5–6 | Mixed; not yet reliable for weeks |
| 7–8 | Deliberate authored continuity with minor gaps |
| 9–10 | Tutor-grade journey; Board would endorse primary reliance for scope |

### 5.2 Layer guides

**CL-01 Syllabus order continuity**  
+ Lawful contiguous span; honest multi-day allocations.  
− Silent skips; contaminants; display_order worship without teaching.

**CL-02 Mission narrative continuity**  
+ Unique Purpose / why-now / prior_bridge daily; Campaign Objective visible in sequence.  
− Syllabus-paste Missions; identical why-now frames; unrelated day bag.

**CL-03 Session pedagogical continuity**  
+ EA-004 floor every Learning day; substance not shell.  
− Stable stage chrome with empty teaching; one premium Session only.

**CL-04 Tutor voice continuity**  
+ One Sensei; unique Tutor Intent; Style/Voice held on sample days.  
− Voice spike / collapse (EA-007 Day-13 pattern).

**CL-05 Reading Guidance continuity**  
+ open/stop/out-of-scope every Learning day; locus progresses.  
− Single Reading Guidance instance in a long arc.

**CL-06 Tomorrow / bridge continuity**  
+ Reciprocal skill-named pairs at 100% internal boundaries.  
− Boilerplate Tomorrow; orphan leap into prerequisite-heavy node.

**CL-07 Revision / memory continuity**  
+ Spaced return targets; Gate RV substance; visible in map.  
− No revision spine; empty revision surface.

**CL-08 Confidence / truth continuity**  
+ Progress/confidence language evidence-linked; EV-001 classes denied.  
− Scoreboard theatre; dual truth across surfaces.

### 5.3 Compute Continuity Index

```text
CI = mean(CL-01 … CL-08)
Floor = min(CL-02, CL-03, CL-04, CL-05, CL-07)
Bridge integrity = reciprocal skill-named boundaries / internal boundaries
```

Compare to Certification thresholds for scope class.

## 7. Component coordination audit

Walk the Campaign map day-by-day (or sample first / mid / last + any heavy-weight days):

| Component | Ask |
|-----------|-----|
| Mission sequence | Unique? Hinged? Mode honest? |
| Study Sessions | Certified substance? Load honest? |
| CMP Reading Guidance | Present daily? Locus advances? |
| Knowledge Checks | Topic-faithful? No future-skill dependency? |
| Reflection | Topic-specific? Feedable to revision? |
| Tomorrow Bridges | Reciprocal? Skill-named? |
| Revision | Placed? Targeted? Non-empty? |
| Confidence | Evidence-linked across arc? |
| Pacing | Weight-aware? Fatigue stretch absent? |
| Concept dependencies | Graph matches bridges? |

Record defects with day codes + Reject IDs.

## 8. Trust Review protocol

### 8.1 Pattern-family denial table

| Family | Status (DENIED / OPEN) | Evidence |
|--------|------------------------|----------|
| Stamp pedagogy | | |
| Orphan excellence | | |
| Missing memory system | | |
| Truth residuals | | |

OPEN on any family → CG-05 FAIL.

### 8.2 Day-*N* simulation

Use persona: diligent candidate; Kwalitec as intended primary system; CMP available as secondary.

| Horizon | Required for |
|---------|--------------|
| End of Pilot Arc | Pilot Arc certification |
| End of chapter | Chapter Campaign |
| Day 14 + Day 20 composite | First-pass Spine (EA-007 method) |

**Questions (all must be Yes for PASS):**

1. Would they still open Kwalitec first each morning for this scope?  
2. Would they trust Mission briefs as tutor-authored?  
3. Would they trust Sessions as teaching — not chrome?  
4. Would they trust revision return days?  
5. Would an IFoA tutor endorse primary reliance for this span?

Record a one-paragraph Board minute.

### 8.3 Fatigue inflection watch

Flag if template recognition / dual-track risk appears by **Day 4** of any Learning stretch. Pilot Arcs shorter than 4 days still require uniqueness across all days.

## 11. Review stages and independence

| Stage | Reviewer | Independence |
|-------|----------|--------------|
| Package certification | Per EA-002/003/004 | Already complete |
| Continuity Review | Continuity Reviewer | ≠ sole Campaign Author |
| Trust Review | Academic Board / Trust reviewer | May be same Board body; not sole Author |
| Gate CG | Quality Gate Owner | Signs evidence pack |
| Publication Approval | Publication Approver | Human; automation may not APPROVE |

For commercial packs, Educational Review and Tutor Review at package level remain mandatory before Continuity Review.

## 12. Sample review cadence

| Scope | Minimum sampling |
|-------|------------------|
| Pilot Arc (3–5 days) | 100% day read |
| Chapter (≈6–10 days) | 100% bridges; 100% Missions skim; deep-read ≥ 50% Sessions |
| First-pass Spine (≈14+ days) | 100% bridges; deep-read all chapter boundaries + fatigue stretch + any prior Golden days |

Always deep-read: first day, last day, heaviest syllabus-weight day, any previously orphan premium day.

---

## 13. Defect writing standard

Each defect states:

1. Day codes / boundary  
2. Reject ID (RQ-xx) or pattern family  
3. Principle / gate reference (EP / MG / SS / TP / CG / LTB)  
4. Required fix (authoring — not Runtime redesign)  
5. Whether it blocks Gate CG alone  

Do not prescribe application code changes under EA-008 authority.
