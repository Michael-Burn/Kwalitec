**Programme:** Student Value Programme SV-001 — Student Value Validation

**Status:** Binding — operational instrument for Founder Validation  
**Effective:** 2026-08-01  
**Authority:** `SV001_DAILY_EDUCATIONAL_VALUE.md` · `SV001_STUDENT_SUCCESS_METRICS.md`  
**Nature:** Scorecard / protocol only — **no** application code; **no** new content; **no** governance changes  

---

## 1. Purpose

Give the Founder a **practical scorecard** to measure **educational value** — not publication progress — during Founder Validation.

Use this when walking study days to decide:

> Does Kwalitec improve the quality of this study day enough that a serious candidate would return tomorrow?

Do **not** use this scorecard to celebrate Coverage %, Approver status, Gate CG, or DSH unless those appear only as **scope labels**.

## 6. Founder Validation pass / fail

### 6.1 Educational-value PASS (Founder Validation)

All required:

| # | Criterion | Threshold |
|---|-----------|-----------|
| V1 | DEV run score | ≥ **7.5** |
| V2 | Return-worthy rate | ≥ **80%** |
| V3 | No dimension mean | < **6.0** |
| V4 | False-confidence incidents (HT-01) | = **0** |
| V5 | Willingness-to-continue (LT-01) | ≥ **8** |
| V6 | Replacement test (LT-06) | Prefers **Kwalitec** (or Mixed with Kwalitec-majority nights) |
| V7 | Scope honesty | Reachability labelled; no ED metric cited as value proof |

**Result:** □ PASS · □ FAIL · □ INCOMPLETE (insufficient days / missing instrument)

### 6.2 What PASS means

> Founder Validation found that the walked study days **improved the study experience** under DEV / Student Success Metrics.

### 6.3 What PASS does not mean

- Private Beta proof  
- Exam readiness / pass probability  
- Full CS1 companion readiness  
- DSH > 0 or coverage claims  
- Version 1 production-ready / validated KSI ≥ 80  
- Licence to skip Approver, activation, or Continuity Front work  

### 6.4 FAIL / INCOMPLETE handling

| Outcome | Action |
|---------|--------|
| FAIL on D1/D2 | Investigate Mission clarity / Home dual-path / decision surfaces — **not** catalogue expansion first |
| FAIL on D3/D4 | Investigate Reading Guidance / stop conditions — Excellence already frozen; check delivery fidelity |
| FAIL on D5/D6 | Investigate load / bridges / motivation collapse |
| FAIL on D7 / HT | Investigate honesty / chrome — Constitution priority over cheer |
| INCOMPLETE | Extend run; do not claim value |

## 8. Protocol notes

1. Score **the same evening** — delayed recall inflates D6.  
2. Walk days in journey order when testing continuity (LT).  
3. If inventory is unreleased, stamp every page **Validation-mode — not student-reachable**.  
4. Do not “grade harder” to punish Editorial; do not “grade softer” because DX was 8.8.  
5. One bad chrome moment (HF-05) fails honesty even if the Mission brief was excellent.  
6. Keep raw journals; they are evidence for later Private Beta instrument tuning.

---

## 9. Handoff to Private Beta

When Founder Validation PASSes on a **student-reachable** path:

1. Freeze the D1–D7 wording (this document + Student Success Metrics).  
2. Convert daily scorecard to a lightweight beta form (same seven questions + HT probe).  
3. Apply Private Beta Stage 1 thresholds from `SV001_STUDENT_SUCCESS_METRICS.md` §8.2.  
4. Keep ED metrics on a separate ops board.

When Founder Validation PASSes only in Validation-mode inventory:

> Educational value is **promising on authored days** but **not yet student-proof**. Priority remains Approver + release + DSH > 0 — without calling that student-value success.
