# EA-004 — Session Scoring Rubric

**Programme:** Educational Excellence Programme EA-004  
**Status:** Binding — Study Session evaluation and publication threshold  
**Effective:** 2026-08-01  
**Parent:** `EA004_SESSION_BLUEPRINT.md` · `EA004_SESSION_CERTIFICATION.md`  
**Related:** EA-001 Session Philosophy §12 · Gate SS · Gate LE · EV-001 Learning Episode Audit · `EA004_STUDY_SESSION_FLOW.md` · `EA004_READING_GUIDANCE_ARCHITECTURE.md`  
**Nature:** Scoring law — not content generation, not application code  

---

## 1. Purpose

Provide an objective scoring system so different reviewers can evaluate Study Session quality consistently — and so unfit Sessions fail a numeric publication threshold, not only a vague taste test.

EV-001 proved structurally promising Session shells can still FAIL primary-study trust (placeholders, empty reading, stuck advances, weak continuity). This rubric is the permanent remedy specification for Session evaluation.

**Hard gate:** Reject classes in `EA004_SESSION_CERTIFICATION.md` §5 cause **automatic FAIL** regardless of numeric score. Rubric scoring proceeds only when no automatic reject class fires (or after defects are fixed).

---

## 2. Scoring model

| Property | Value |
|----------|-------|
| Dimensions | 9 (equal weight unless Board amends) |
| Scale per dimension | **0–10** integers |
| Overall score | Mean of nine dimension scores, rounded to 1 decimal |
| Publication threshold | **Overall ≥ 8.0** and **no dimension < 6** |
| Tutor Purpose override | If Tutor Purpose fails TR-S01 / SX-01 → overall **FAIL** (treat as 0 for publication) |
| Reviewer | Human for Version 1 commercial certification; second reviewer recommended when overall 7.5–8.4 |

### Score bands (overall)

| Band | Range | Meaning |
|------|-------|---------|
| Unfit | 0.0–4.9 | Must not certify |
| Weak | 5.0–6.9 | Must not publish; major rewrite |
| Borderline | 7.0–7.9 | Must not publish; targeted rewrite |
| **Publishable** | **8.0–8.9** | Certify if gates PASS and no dimension < 6 |
| Exemplary | 9.0–10.0 | Model pack for author training |

## 3. Dimensions

### D1 — Educational coherence

**Question:** Do Educational Purpose, Tutor Purpose, stage plan, Knowledge Checks, and success evidence tell one deliberate learning story that executes the parent Mission?

| Score | Anchor |
|------:|--------|
| 0–2 | Stages contradict Mission or collapse to placeholder/shell |
| 3–5 | Partial story; checks weak or purpose vague |
| 6–7 | Coherent but thin; some stages generic |
| 8–9 | Clear cognitive arc; stages reinforce Mission success criteria |
| 10 | Exemplary deliberate-study design; Head Tutor would assign unchanged |

**Fail signals:** Educationally purposeless; syllabus restatement as Session.  
**Principles:** EP-01, EP-03.

---

### D2 — Tutor quality & rhythm

**Question:** Does Tutor Purpose + stage prose pass the primary-block IFoA tutor test — and does the rhythm feel like an excellent tutor (guide → yield → return → reflect → tomorrow)?

| Score | Anchor |
|------:|--------|
| 0–2 | No Tutor Purpose; chatbot nagging; continuous interruption |
| 3–5 | Intent present but interchangeable; rhythm uneven |
| 6–7 | Acceptable tutor hour; minor voice or interruption defects |
| 8–9 | Specific coaching sequence; calm Sensei; silence designed |
| 10 | Indistinguishable from excellent human tutor session design |

**Fail signals:** Lacking Tutor Purpose; software-prompt feel during reading.  
**Principles:** EP-09 · RF-01–RF-06.  
**Hard rule:** Score ≤5 on D2 → cannot publish (dimension floor).

---

### D3 — Reading Guidance quality

**Question:** Does Guided Reading multiply CMP value with precise locus, objectives, misconceptions, attention directives, exit, and re-entry — without becoming a second textbook?

| Score | Anchor |
|------:|--------|
| 0–2 | Empty shell; no locus; or CMP paste |
| 3–5 | Vague “read the material”; weak stop/return |
| 6–7 | Named open/stop; leverage thin; pauses slightly heavy |
| 8–9 | Exit packet complete; selective attention; sparse pauses |
| 10 | Precision a senior tutor uses when directing scarce CMP hours |

**Fail signals:** TB-007 patterns; missing deliberate reading guidance.  
**Principles:** EP-01, EP-04 · Reading Guidance Architecture.

---

### D4 — Active cognition after reading

**Question:** Do Knowledge Checks convert exposure into retrieval/performance with feedback and lawful advance?

| Score | Anchor |
|------:|--------|
| 0–2 | No post-reading demand; Reflection-only “activity” |
| 3–5 | Token check; weak feedback; sticky advance |
| 6–7 | Real demand present; feedback adequate |
| 8–9 | Closed-book/reduced-cue checks tightly tied to success criteria |
| 10 | Exam-relevant cognition with exemplary feedback design |

**Fail signals:** TB-008; SS-03 fail; reading treated as proof of retention.  
**Principles:** EP-05 · EP-03.

---

### D5 — Reflection & confidence quality

**Question:** Does Reflection harvest topic-specific residual uncertainty, and does Confidence Assessment stay soft and warrant-aware?

| Score | Anchor |
|------:|--------|
| 0–2 | Missing/generic Reflection; confidence-as-mastery |
| 3–5 | Weak prompts; skippable close |
| 6–7 | Topic-specific; student-authored path present |
| 8–9 | Implements Mission Reflection Goal; confidence calibrated |
| 10 | Continuity-grade harvest a tutor would reuse tomorrow |

**Fail signals:** Reject class 5.7; mastery theatre.  
**Principles:** EP-07 · EP-06.

---

### D6 — Continuity & tomorrow

**Question:** Does the Session preserve yesterday → today → tomorrow and close without anxiety or contaminant previews?

| Score | Anchor |
|------:|--------|
| 0–2 | Broken handoff; fabricated/contaminant tomorrow; truth split |
| 3–5 | Tomorrow thin or inconsistent with Mission bridge |
| 6–7 | Lawful preview or honest absence; minor continuity gaps |
| 8–9 | Clear continuity line; Wrap-up + Tomorrow agree with Home |
| 10 | Exemplary educational story across the sitting boundary |

**Fail signals:** TB-003/005/010 patterns; EP-10 violations.  
**Principles:** EP-02 · EP-10 · Gate TP.

---

### D7 — Exam relevance & load honesty

**Question:** Is cognitive demand appropriate to exam preparation, and are duration/load claims honest relative to depth?

| Score | Anchor |
|------:|--------|
| 0–2 | Engagement bait; duration lie; chapter-scale work in 15 minutes |
| 3–5 | Weak exam link; load/time mismatch |
| 6–7 | Plausible exam relevance; mostly honest timing |
| 8–9 | Examiner-aware moves; time and depth aligned |
| 10 | Scarce-hour realism a sitting candidate would trust |

**Fail signals:** TB-009; EP-08 ignored; SS-06 fail.  
**Principles:** EP-08 · EP-03.

---

### D8 — Truth & evidence integrity

**Question:** Do success evidence, revision signals, and completion language respect Study Progress vs mastery — and One Educational Truth?

| Score | Anchor |
|------:|--------|
| 0–2 | Mastery theatre; designed truth splits; no evidence path |
| 3–5 | Soft evidence vague; revision signals silent on risk topics |
| 6–7 | Honest completion language; basic evidence paths |
| 8–9 | Clear success/reflection/revision evidence; no false mastery |
| 10 | Constitution-grade evidence hygiene |

**Fail signals:** Completion ≠ Mastery violated; EP-10 fail.  
**Principles:** EP-06 · EP-10 · Constitution VIII.

---

### D9 — Anti-EV-001 robustness

**Question:** Does the Session design explicitly deny EV-001 Session failure modes (placeholders, empty reading, stuck advance, duration split, meta hero)?

| Score | Anchor |
|------:|--------|
| 0–2 | Reproduces EV-001 Session defects |
| 3–5 | Partial denials; residual shell risk |
| 6–7 | Main TB-001/007/008 modes denied |
| 8–9 | Documented regression denials; unavailable policy solid |
| 10 | Model counter-example to EV-001 Session FAIL modes |

**Fail signals:** Any automatic reject class in Certification §5.8 related to EV-001.  
**Evidence:** EV-001 Trust Break Register; Episode Audit.

## 4. Scoring procedure

1. Confirm no automatic reject class (§5 Certification) — else FAIL, do not average into publishable.  
2. Score D1–D9 independently as integers 0–10.  
3. Compute mean → overall (1 decimal).  
4. Apply floors: any dimension < 6 → cannot publish.  
5. Apply Tutor Purpose override if SX-01 / TR-S01 failed.  
6. Record scores in certification evidence.  
7. For overall 7.5–8.4, recommend second reviewer before Publication Approval.

---

## 5. Mapping to gates

| Rubric outcome | Gate implication |
|----------------|------------------|
| Automatic reject class | Certification FAIL; Gate SS FAIL |
| Overall < 8.0 | SX-09 FAIL; must not publish |
| Any dimension < 6 | SX-09 FAIL; must not publish |
| Overall ≥ 8.0 and floors met | Rubric portion of SX-09 PASS (gates still required) |
| D3 ≤ 5 | Expect Reading Guidance / Gate LE special rule FAIL |
| D4 ≤ 5 | Expect SS-03 FAIL |
| D5 ≤ 5 | Expect SS-04 / reject 5.7 FAIL |

Rubric PASS does not waive Gate SS/LE checklist items.
