# Premium Experience Roadmap

**Programme:** PX-001 — Premium Experience (post–Version 1 Educational Completion)  
**Preparation:** PX-000 — Premium Experience Preparation  
**Status:** Binding plan for post-gate execution — **no implementation under PX-000**  
**Effective:** 2026-08-02  
**Authority:** `PX001_PROGRAMME_CHARTER.md` · EF-001 · EP-001 non-interference  
**Companions:** `PREMIUM_QUALITY_ATTRIBUTES.md` · `PREMIUM_BACKLOG.md`  

---

## 1. Purpose

Define the phased path from Version 1 educational completion to a certified premium student experience — so work can begin immediately when start gates PASS, without competing with Educational Production or reopening frozen Educational Law.

---

## 2. Start condition

```text
EP-001 → 72/72 Certified Coverage
       → Student Reliance to examination
       → End-to-end Progressive Confidence PASS
       → Version 1 educational certification
                    ↓
              PX-001 START
                    ↓
         Waves PX-W0 … PX-W5 (below)
```

Until the charter §4 gates PASS, this roadmap is **shelf-ready only**.

---

## 3. Wave overview

```text
PX-W0  Baseline & protect          → freeze reference surfaces; inventory residual debt
PX-W1  Emotional journey & microcopy → calm path language; reflection & empty/success states
PX-W2  Visual polish & interaction → tokens, density, CTAs, motion restraint
PX-W3  Accessibility & performance → WCAG-oriented presentation; perceived speed
PX-W4  Motivation, celebration, personalisation → diligence support without theatre
PX-W5  Long-term engagement & certification → retention craft + Premium Experience PASS
```

Waves are sequential by default. PX-W3 may overlap late PX-W2 only if capacity exists and PX-W1 exit is sealed (emotional honesty before decorative motion).

---

## 4. PX-W0 — Baseline and protect

| Field | Definition |
|-------|------------|
| **Scope** | Re-score current student surfaces against `PREMIUM_QUALITY_ATTRIBUTES.md`; protect Mission / Commitment-Defer / Study Session Feedback as reference standards; import still-open items from historical PX-001…PX-003 and RP-001.4 into live backlog IDs |
| **Prerequisites** | Charter start gates G-PX-A…D all PASS |
| **Must not** | Redesign recommendations; touch EP volumes; claim premium PASS |
| **Exit criteria** | Living scorecard baseline filed; protected-pattern list signed; backlog prioritised for W1–W2; no implementation beyond measurement hooks if already present |

**Educational trust objective:** Establish an honest “before” so polish claims are measurable.

---

## 5. PX-W1 — Student emotional journey and microcopy

| Field | Definition |
|-------|------------|
| **Scope** | End-to-end emotional arc: first touch → daily commitment → session → reflection → return tomorrow → exam-approach tone; unify verbs and value framing; calm empty/error/success language; remove residual internal/Alpha jargon from student paths |
| **Prerequisites** | PX-W0 exit |
| **Primary backlog themes** | Emotional journey · Microcopy (see `PREMIUM_BACKLOG.md` Tier A) |
| **Must not** | Invent new educational outcomes; shame missed days; promise pass rates |
| **Exit criteria** | Emotional + microcopy attributes meet Target on core path surfaces; reflection value framing present; terminology matrix closed for primary student verbs |

**Student outcome:** The product feels steady and respectful on every ordinary study day.

---

## 6. PX-W2 — Visual polish and premium interaction design

| Field | Definition |
|-------|------------|
| **Scope** | Token discipline; density control; one-composition home; interaction hierarchy; styled confirmations; loading/skeleton coherence; restrained motion; mobile nav consistency within sole runtime |
| **Prerequisites** | PX-W1 exit |
| **Primary backlog themes** | Visual polish · Premium interaction design |
| **Must not** | Dual-stack resurrection; card/dashboard theatre; decorative redesign of unfinished admin tools |
| **Exit criteria** | Visual + interaction attributes at Target on Included surfaces; consistency register residuals closed or waived with Founder sign-off |

**Student outcome:** Screens feel like one product, not a collage of eras.

---

## 7. PX-W3 — Accessibility and performance

| Field | Definition |
|-------|------------|
| **Scope** | Keyboard/focus discipline; labels and live regions; touch targets; contrast; reduced-motion respect; SSR-path perceived performance; eliminate silent interactive failures |
| **Prerequisites** | PX-W2 exit (or Founder-approved overlap after W1) |
| **Primary backlog themes** | Accessibility · Performance |
| **Must not** | Fake WCAG certification without audit evidence; performance “wins” that strip explainability |
| **Exit criteria** | Accessibility + performance attributes at Target; known blockers from historical PX-003 closed or explicitly deferred with risk owner |

**Student outcome:** Diligent students are not excluded by craft debt; the app feels immediate.

---

## 8. PX-W4 — Motivation, celebration, and personalisation

| Field | Definition |
|-------|------------|
| **Scope** | Non-coercive motivation systems; honest celebration moments (session complete, streak of real study, revision returns, Continuity Front milestones); personalisation of presentation (tone density, emphasis of already-authorised next action, exam-horizon framing) |
| **Prerequisites** | PX-W3 exit |
| **Primary backlog themes** | Motivation systems · Celebration moments · Personalisation |
| **Must not** | Points/leaderboards that undermine calm professionalism; personalisation that re-ranks or rewrites educational selection; preparedness theatre |
| **Exit criteria** | Motivation / celebration / personalisation attributes at Target; Editorial sign-off that Tutor voice and honesty hold |

**Student outcome:** Progress feels acknowledged; tomorrow still feels clear.

---

## 9. PX-W5 — Long-term engagement and Premium Experience certification

| Field | Definition |
|-------|------------|
| **Scope** | Multi-week / exam-horizon engagement craft (return rituals, honest progress narrative, help that answers real questions, settings that stay student-grade); full-path Premium Experience certification against quality attributes; Founder dogfood on completed educational journey |
| **Prerequisites** | PX-W4 exit; educational completion gates still held (no coverage regression) |
| **Primary backlog themes** | Long-term engagement · certification residual closure |
| **Must not** | Claim Version 1 *production-ready* solely from UX PASS; reopen EP production as “engagement content” without EO lifecycle |
| **Exit criteria** | Scorecard Target or Exemplary across focus areas; certification report filed; residual debt register empty or Board-accepted; PX-001 programme completion report |

**Student outcome:** Students can stay with Kwalitec through the examination without experience fatigue or trust erosion from chrome.
