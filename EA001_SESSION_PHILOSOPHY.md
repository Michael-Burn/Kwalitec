**Programme:** Educational Excellence Programme EA-001  
**Status:** Binding — premium study Session constitution  
**Effective:** 2026-08-01  
**Parent:** `EA001_EDUCATIONAL_FOUNDATION.md` · `EA001_EDUCATIONAL_PRINCIPLES.md`  
**Related:** `PRODUCT_EXPERIENCE_GUIDELINES.md` · Study Sensei Philosophy · Educational Constitution  

---

## 1. Purpose

Define exactly what happens during a premium Kwalitec study Session — and clarify what belongs inside Kwalitec versus inside the CMP.

A Session is the focused practice workflow in which the learner executes today’s Mission (Canonical Lexicon). It is not the Mission itself, not the textbook, and not a navigation shell.

**Premium standard:** An experienced IFoA tutor would be willing to assign this Session as the student’s primary study block for the hour.

EV-001 established that the live skeleton (Overview → Activity → Reflection → Summary) is the right shape. EA-001 defines the educational flesh that skeleton must carry.

---

## 2. Session outcomes (non-negotiable)

A completed Session must leave the student able to answer:

| Question | Owner |
|----------|--------|
| What did I study? | Real topic + objective (Kwalitec) |
| Where was the material? | CMP locus (Kwalitec points; CMP holds content) |
| What can I now explain or do? | Success criteria + recall/practice (Kwalitec) |
| What is still unclear? | Reflection (student + Kwalitec prompt) |
| What comes next? | Tomorrow Preview / Summary (Kwalitec) |

If any answer collapses to “Today’s topic,” the Session is **unfit for students**.

---

## 3. Division of labour — Kwalitec vs CMP

| Phase | Inside Kwalitec | Inside the CMP |
|-------|-----------------|----------------|
| Before Reading | Objective, focus questions, stop conditions, duration honesty, Begin CTA | — |
| During Reading | Guided prompts, annotation tasks, pacing cues, return instruction | Authoritative exposition, definitions, worked theory, full examples |
| After Reading | Active recall, short checks, feedback, stage advance | Reference if student re-opens a worked line |
| Reflection | Topic-specific prompts, capture, soft evidence | — |
| Preparation for Tomorrow | Continuity line, next focus, optional light prep cue | Optional “skim ahead” only if Kwalitec names a CMP locus |

**Hard rule:** Kwalitec never pretends the CMP chapter lives inside the Learning Episode.  
**Hard rule:** The CMP never decides today’s Mission, never holds Twin state, and never replaces Reflection.

---

## 4. Session arc

```text
Mission (Home)
    → Session Overview
        → Before Reading
            → During Reading (CMP open; Kwalitec guides)
                → After Reading (recall / example / practice)
                    → Reflection
                        → Summary + Tomorrow Preview
```

Stages may be composed as Learning Episodes (e.g. Guided Reading · Worked Example · Practice). Advertised stages must be reachable (EV-001 TB-008).

---

## 5. Before Reading

### Educational job

Prepare the mind. Create selective attention before the CMP opens.

### Must include

1. **Topic identity** — official topic code and human title (never placeholder).  
2. **One learning objective** — distinct from the syllabus heading paste; actionable verb.  
3. **Concept focus** — the one idea or skill that defines today’s block.  
4. **Why now** — bridge from prior topic / prerequisite / exam skill (Tutor Voice).  
5. **Focus questions** (2–4) — what to look for in the CMP.  
6. **Material locus** — chapter/section/LO reference when known; honest “open your CMP for [topic]” when fine locus unavailable.  
7. **Stop condition** — when to return to Kwalitec (e.g. after Example 2, or after writing the linear predictor).  
8. **Duration honesty** — claimed minutes match intended depth.

### Must not include

- CMP chapter dump  
- Platform philosophy or mastery disclaimers as the hero narrative  
- Restacked duplicate briefing already shown on Overview without progressive disclosure  
- Begin enabled when topic resolution failed

### Student experience

“I know what I’m hunting for before I open the notes.”

---

## 6. During Reading

### Educational job

Guided Reading (EP-04): the student works in the CMP under Kwalitec instruction.

### Must include

1. **Alive prompts** bound to today’s objective (not “read the material”).  
2. **Annotation / note task** — e.g. write one definition in own words; mark the least-clear sentence.  
3. **Pacing** — optional checkpoints (“After the mean-function paragraph, answer focus question 1”).  
4. **Return cue** — explicit instruction to come back for recall/practice.  
5. **Stage integrity** — if “Activity 1 of 3” is shown, activities 2 and 3 must exist and be reachable.

### Belongs in CMP

- Full prose, proofs, tables, extended worked solutions  
- Publisher diagrams and long examples  
- Depth beyond today’s stop condition

### Must not include

- Empty reading stage with only a free-text box (TB-007)  
- Raw syllabus/CMP dump language as episode body (V1 E1)  
- Mechanical concatenation of template fragments  
- Off-platform abandon without a return path

### Student experience

“I’m reading with a purpose, not drowning in the chapter.”

---

## 7. After Reading

### Educational job

Convert exposure into retrieval and performance (EP-05, EP-03).

### Typical episode types (compose as needed)

| Episode | Kwalitec does | CMP role |
|---------|---------------|----------|
| Active Recall | Closed-book prompt; capture attempt | Closed or set aside |
| Worked Example (guided) | Steps, pause points, “try before reveal” | Source example reference |
| Practice | Exam-style short item + feedback | Optional formula reference after attempt |
| Checkpoint | Countable success criteria check | — |

### Must include

1. At least one **active cognitive demand** without full notes.  
2. **Immediate feedback** where answers are objective; honest uncertainty where not.  
3. **Reliable advance** to the next stage after lawful completion.  
4. Success criteria verbs: explain / solve / identify / justify — not readiness-point theatre alone.

### Must not include

- “Answer recorded” with no feedback and no Continue (TB-008)  
- Practice that never names the skill  
- Declaring mastery from a single soft check

### Student experience

“I know whether today’s idea survived contact with my memory.”

---

## 8. Reflection

### Educational job

Metacognitive close (EP-07). Soft evidence. Continuity fuel.

### Must include

1. Prompts specific to **this topic and objective**.  
2. At least: what is clearer · what remains uncertain · what to carry forward.  
3. Student-authored text (or structured choices that are still student decisions).  
4. Completion required before educational close of the Session.

### Must not include

- Generic placeholder prompts  
- System-written reflection attributed to the student  
- Skipping Reflection while marking Session complete  
- Platform jargon (“evidence_creating”, “thin_warrant”)

### Student experience

“I named the gap while it’s fresh — tomorrow’s brief can use it.”

---

## 9. Preparation for Tomorrow

### Educational job

Educational Continuity (EP-02) and Exam Focus (EP-08) — close the loop.

### Must include (when next focus is known)

1. **Tomorrow Preview** — next topic title + continuity line from today.  
2. Optional **light prep cue** — e.g. “Skim CMP headings for Bayesian notation only; do not deep-read tonight.”  
3. Alignment with Summary: same next step as Home will show when the student returns.

### When next focus is unknown

Honest empty state: heading · one sentence · one action (Experience Guidelines §5). No fabricated topic. No contaminant nodes.

### Must not include

- Unlock theatre that contradicts Twin/plan state  
- Postal addresses or non-syllabus strings as tomorrow’s work  
- Heavy new teaching after Reflection (tomorrow’s Session owns that)

### Student experience

“I know how tonight’s work continues — I can stop without anxiety.”

---

## 10. Session Overview (entry gate)

**One purpose:** Am I ready to begin?

| Include | Exclude |
|---------|---------|
| Topic, objective, concept focus | Full CMP content |
| Structure of stages | Duplicate wall of Home briefing |
| Why now (one short paragraph) | Engineering / platform essays |
| Duration | Multiple competing CTAs |
| Begin Session | Placeholder topic strings |

If Overview cannot bind real topic data → **do not open** a fake Session. Show an honest recovery action.

---

## 11. Evidence and truth effects

| Session event | May update |
|---------------|------------|
| Guided Reading completion | Study Progress (when it is the defined study obligation); soft coverage/pace only for knowledge |
| Active Recall / Practice outcomes | Educational Evidence; Estimated Knowledge/Mastery only with warrant over time |
| Reflection | Soft evidence; continuity inputs; never sole mastery path |
| Session completion | Session history; journey progress inputs; Mission completion per constitutional rules |

**Completion ≠ Mastery.** Session finish completes the Session. Topic Complete and Estimated Mastery remain separately governed (Constitution; V2 P2 specialised).

---

## 12. Fitness test (Academic Board)

A Session is premium only if all are true:

1. An IFoA tutor would assign it as today’s primary block.  
2. CMP and Kwalitec roles are unmistakable.  
3. No placeholders, dumps, or stuck advances.  
4. Reflection and Tomorrow Preview preserve continuity.  
5. Surfaces agree on what was completed.

Fail any → fail `EA001_QUALITY_GATES.md` Session gate → must not reach students.
