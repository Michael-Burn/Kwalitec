# KWP-001 — Student Value Layer Roadmap

**Programme:** KWP-001 · Student Value Layer Audit  
**Phase:** Commercialisation  
**Date:** 2026-07-30  
**Nature:** Commercial product audit — **no runtime redesign**  
**Authority:** SR-001 · SR-001A · SR-003 · `PRODUCT_BLUEPRINT.md` · Student Digital Twin · Product Language Guide  

---

## Executive Summary

SR-001A has delivered a complete Student Runtime: Learning Session, Educational Evidence Authority, Student Digital Twin (observer), Progress Engine, Mission Runtime, Educational Flow, Evidence Before Completion, and Progress Singularity. Architecturally, the daily loop is lawful and singular.

Commercially, the product still reads as an **Internal Alpha operating system**, not a **premium exam-preparation companion**.

The gap is not missing engines. The gap is that student value is:

1. **Flag-gated** — session primary, substance flow, finish review, evidence gate, Twin daily loop, and progress singularity all default **OFF**.
2. **Under-surfaced** — Twin estimates, Study Progress projections, and readiness explainability exist in authorities but barely appear on Home.
3. **Epistemically worded** — learner copy still says “evidence”, “Twin”, “authorised”, “nodes · links”, and “Mark mission complete”.
4. **Missing premium moments** — completion celebration, weak-topic drills, exam-pace forecast, and Home explainability lag Revision and legacy dashboards.

**Verdict:** Convert the completed runtime into a paid product by surfacing what already exists, scrubbing internal language, and packaging the SR loop as one commercial experience — without new authorities or SR-001A violations.

**Phase 2 recommendation:** Execute a **Student Value Activation** programme (not another runtime singularity): enable the commercial loop, promote Home/Journey/Session copy to Product Language Guide standards, and expose Twin-informed Learning Insights and Progress narratives as presentation-only consumers of existing authorities.

## Current Product Strengths

These are real competitive assets if they are turned on and spoken in student language.

### 1. One clear daily decision

Home answers “What should I do next?” with a single primary CTA, calm empty/quiet/day-complete states, and a structured mission panel (title, learning objective, duration, why-now, expected outcome). That is rarer and more trustworthy than question-bank dashboards.

### 2. Syllabus-faithful study, not content spam

Certified curriculum + mission composition + session substance stages (Read → Worked example → Practice → Reflection) create an educational arc competitors typically fake with playlists. When `SR_SESSION_SUBSTANCE` is ON, the session feels like a coach, not a queue.

### 3. Honest completion culture

Finish Review (Yes / Partially / No) plus Evidence Before Completion separates “I showed up” from “I demonstrated learning.” That honesty is a premium differentiator against platforms that mint XP for opening a page.

### 4. Explainability infrastructure already exists

Revision’s explanation card, Tutor “why this mission”, Study Health, Decision Journal, and forbidden-learner-term guards show the product *can* speak professionally. The architecture supports Vision 2030’s explainability law; presentation just underuses it on Home.

### 5. Continuity and calm chrome

Unified EOS shell across Home and Session, resume/pause, auto-begin into activity, streak / countdown / progress signals, and defer copy that respects burnout — all reinforce sustainable professional study (Blueprint principle 4).

### 6. Invisible intelligence stack (latent premium)

Educational Evidence Authority, Twin knowledge/mastery estimates, Progress Engine coverage + weak-topic annotations, and readiness VMs are **already producing educational truth**. Competitors charge for thinner models. Kwalitec’s moat is depth — currently buried.

## Current Weaknesses

### 1. The commercial loop is off by default

| Flag | Student effect when OFF |
|---|---|
| `SR_SESSION_PRIMARY` | Home can fall back to pilot **“Mark mission complete”** |
| `SR_SESSION_SUBSTANCE` | Thin generic practice instead of educational flow |
| `SR_SESSION_COMPLETION_PRODUCT` | Weak finish / summary product |
| `SR_EVIDENCE_GATE` | Completion without accepted Educational+ evidence |
| `SR_TWIN_DAILY_LOOP` | No Twin learning from sessions |
| `SR_PROGRESS_SINGULARITY` | No singular Study Progress narrative for experience |

A paying student on defaults does not receive the product SR-001A built.

### 2. Internal mechanics leak into learner UI

Examples found in student surfaces:

- “Building evidence” / “educational evidence” / “practice evidence”
- “learning Twin” in Tutor errors
- “authorised recommendations” / “Certified curriculum” as primary chrome
- Knowledge Map: “N nodes · M links”
- Session “Technical details”: Session ID / Activity ID / Mission ID
- Login / footer: “Internal Alpha” / “Private Beta”
- Onboarding “Today’s Focus” vs Home “Today’s Mission” (and Product Language Guide requires **Today’s Session**)

These erode premium trust and violate the Product Language Guide.

### 3. Twin is activated but invisible

SDT-004 correctly makes Twin an observer of Accepted Educational+ evidence. Student chrome for Estimated Knowledge / Mastery is essentially absent. Settings expose a renamed “Personalised recommendations” status; Tutor is opt-in. Students cannot *feel* a Digital Twin of their journey.

### 4. Progress Engine is singular but silent

SR-003 owns coverage, current topic, projections, and weak-topic annotations for mission composition. Journey still frames coverage as “Overall mastery,” lists LOs without states, and “Next focus areas” as upcoming syllabus topics — not diagnosed weak areas. No post-session “what changed in your Journey” moment.

### 5. Readiness under-surfaced on the primary surface

Study Health is one calm line. The richer `readiness_card`, forecast drivers, and confidence disclosures live in VMs / Revision / legacy analytics — not Home. Exam countdown exists; exam-pace / pass-trajectory narrative does not.

### 6. Thin delight and retention mechanics

No completion celebration, no streak ritual, no “you’re on track for exam week” hero, no one-tap weak-topic drill, no mock-exam report surface on the sole-runtime path. Motivation is professional-calm to a fault — commercially flat.

### 7. Lexicon inconsistency with Blueprint / Language Guide

Blueprint and Language Guide: learner UI should say **Session / Today’s Session**, **Learning Insights**, **Exam Readiness**, **Journey**. Shipping UI still says Mission, Twin, evidence, mastery score semantics. Trust requires one voice.

## Commercial Opportunities

### Premium differentiators (vs typical exam-prep)

| Differentiator | Why students would pay | Runtime source (do not rebuild) |
|---|---|---|
| **Today’s Session as a defended decision** | Ends “what should I study?” anxiety | Mission Runtime + Home one-primary |
| **Honest finish + evidence gate** | Trust that progress means something | EV-001B + LXP-003 |
| **Syllabus-faithful Journey** | Official curriculum as truth, not random banks | Published Curriculum + Progress Engine |
| **Learning Insights with why** | Explainable guidance vs black-box AI tutor | Twin + Tutor + explanation cards |
| **Sustainable pace** | Professional exam prep without burnout theatre | Defer, Study Health, Blueprint principles |

### Features students would pay for

1. **Exam Readiness briefing** — plain-language readiness, confidence, drivers, and “what to do this week.”
2. **Personal weak-topic drill** — one primary from Progress/Twin weak annotations into Session.
3. **Post-session Learning Insights** — what changed (coverage, estimated strength, next Session teaser) without engine names.
4. **Mock / structured assessment reports** — when Educational+ assessment evidence exists.
5. **Exam-date pacing** — “At this pace, syllabus coverage by …” using Progress projections + calendar.

### Features that increase retention

- Session continuity (resume) + day-complete ritual that invites tomorrow.
- Streak + consistency framed as readiness substrate (not vanity XP).
- Visible Journey movement after every Accepted Educational+ sitting.
- Explainable “why this Session” on Home (reduce abandonment from distrust).

### Features that create word-of-mouth

- “It actually follows my syllabus.”
- “It won’t let me fake completion.”
- “It tells me *why* this topic today.”
- “After two weeks I could see where I was weak — not just how many hours I logged.”

### Competitive advantages (structural)

Typical platforms: content library + spaced repetition + leaderboards.  
Kwalitec: **curriculum authority → mission → session → evidence → twin estimate → progress singularity → tomorrow**. That pipeline is the product. The commercial task is to make the pipeline *felt* in 30 seconds of Home and 5 minutes of Session.

## Medium-term Roadmap (1–3 months)

Still presentation / experience consumers of existing authorities. May include adapters and view-model enrichment — **not** new educational engines.

### M1 — Learning Insights surface (Twin-visible without saying Twin)

- Journey topic cards show estimated strength bands when Twin is Active (`SR_TWIN_DAILY_LOOP`).
- Lawful silence when Twin Initialised-only or no Educational+ history.
- Home Study Health cites 1–2 plain drivers (“Recent practice on X was mixed”).
- Settings: “Learning Insights status: building / ready” — never Twin.

### M2 — Journey = Progress Singularity, humanised

- Rename “Overall mastery” → **Syllabus progress** (coverage honesty).
- Surface Progress Engine position + remaining topics in narrative form.
- “Up next” vs “Needs attention” (weak-topic annotations from Progress projections / Twin estimates).
- After Accepted Educational+ session: “You completed {topic}. Journey moved to {next}.”

### M3 — Exam Readiness on Home

- Mount readiness card under Study Health: label, trend, confidence, “why” disclosure.
- Exam countdown + pacing line from Progress remaining + study calendar.
- No marketed pass guarantee (Blueprint / Vision constraint).

### M4 — Practice feedback quality

- Correct / incorrect / model-answer reveal on activity surface (consume existing activity snapshots).
- Reflection stage copy that feels coach-like, not checklist-like.
- Finish Review retained as honesty ritual; soften defensive “not mastery” into “We’ll use today’s practice to update your Learning Insights.”

### M5 — Weak-topic Revision primary

- Revision / Home quick action: “Strengthen {weak topic}” → Session composed from existing mission/session path.
- Mission selection remains Mission AUTHORITY; experience only surfaces Progress/Twin hints already allowed for composition inputs.

### M6 — Alpha → Commercial chrome

- Soften/remove “Internal Alpha” from login for invite cohorts; keep founder diagnostics gated.
- Align onboarding lexicon with Home (**Today’s Session**).
- Extend explainability template scans to `app/templates/student/**` and `app/templates/session/**`.

## Long-term Vision

Aligned with `PRODUCT_BLUEPRINT.md` and Vision 2030 — student-value expression of the completed runtime:

> Every day, the student opens Home, sees one defended Session, understands why, completes a substantive educational flow, receives honest feedback, and watches Journey and Exam Readiness move only when learning was demonstrated.

Over an exam cycle:

1. **Week 1–2** — Trust forms: “It won’t let me cheat the system; it follows my syllabus.”
2. **Month 1** — Learning Insights become personal: weak topics are obvious; Sessions feel chosen, not random.
3. **Pre-exam** — Exam Briefing becomes the emotional product: calm, evidence-backed, actionable.
4. **Post-exam** — Word-of-mouth: pass probability narrative grounded in behaviour + evidence, not hype.

Institutional / multi-provider (Blueprint Epic 4) remains later. Commercialisation Phase 2 should perfect **one student, one subject, one runtime, one obvious value loop**.

## Risk Assessment

### Commercial risks

| Risk | Severity | Mitigation |
|---|---|---|
| **Selling the architecture while shipping the pilot** | Critical | Commercial Loop Bundle before any paid cohort |
| **Students misread coverage as understanding** | High | Rename Journey labels; teach Integrity Progress in copy |
| **Honesty (evidence gate) feels punitive** | High | Outcome-language flashes; celebration when Accepted; never shame Partially/No |
| **Twin silence read as “broken personalisation”** | Medium | Explicit “Learning Insights are building from your practice” empty states |
| **Over-gamification vs Blueprint** | Medium | Delight via clarity and completion ritual — not XP/leaderboards |
| **Competitor parity race (question banks)** | Medium | Do not out-bank them; out-decide them (Today’s Session + why) |
| **Language Guide drift after Quick Wins** | Medium | Extend EIP explainability / copy tests to student + session templates |
| **Flag sprawl confuses ops** | Medium | One named commercial profile env set; founder docs |

### Student trust risks

- Surfacing Twin estimates without confidence/silence rules → overclaim.
- Marketing “Exam Ready” as guarantee → Vision/Blueprint violation.
- Showing technical IDs or Authority jargon → product feels unfinished.

### Delivery risks

- Enabling all SR flags without content substance → empty educational flow.
- Journey rewrite without Progress singularity ON → dual-truth confusion returns in copy even if engines are singular.

## Recommendation for Phase 2

### Name

**KWP-002 — Student Value Activation** (working title)

### Mandate

Maximise educational value, trust, premium experience, and commercial differentiation **by surfacing and speaking the completed SR-001A runtime**. Explicit non-goals: new runtime authorities, Twin math changes, Evidence rule changes, Progress Engine redesign, Mission selection redesign.

### Phase 2 outcomes (definition of done)

1. A documented **Commercial Loop** profile with Session Primary, Substance, Completion Product, Evidence Gate enabled for the paid/alpha cohort; Twin + Progress singularity enabled when Educational+ path is live.
2. Learner UI passes Product Language Guide (Session, Learning Insights, Exam Readiness, Journey) — zero Twin/Mission-Engine/nodes copy on student surfaces.
3. Home shows: one Session primary, why-disclosure, Study Health with readiness card, no Mark-complete.
4. Session shows: topic title, substance flow, honest finish, outcome-language gates, completion moment with Journey/next teaser.
5. Journey shows: syllabus progress (coverage), optional Learning Insights strength, Needs attention vs Up next.

```
Week 1–2:  P0 Commercial Loop + language scrub + Mark-complete removal

Month 3:   P3 practice feedback + weak-topic CTA + pace-to-exam
```
