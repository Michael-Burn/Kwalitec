## 1. Purpose

This document is the **constitutional protocol** that governs **all future external educational-effectiveness validation** used for:

- Validated KSI re-scores under P-001.1  
- Version 1 Gate **G1** (especially G1.1 and G1.9)  
- EP-003 / EP-004 educational Go / No-Go verdicts  

It answers: *How may KSI evidence be collected, analysed, accepted, rejected, and used?*

It does **not** answer: *What is the current KSI?* (see KSI-001) or *Is Version 1 released?* (see P-002.1).

---

## 2. Constitutional rules (permanent)

These rules override optimism, marketing pressure, and programme estimation:

| # | Rule |
|---|------|
| C1 | **Estimated KSI never becomes validated KSI.** Programme ΔKSI is planning only. |
| C2 | **Premium PASS never increases KSI.** Craft / Conditional PASS is orthogonal to usefulness scoring. |
| C3 | **Educational correctness never implies usefulness.** PB Progressive Confidence, Content Freeze, and Approver inventory prove correctness confidence — not KSI. |
| C4 | **Educational confidence never implies effectiveness.** Simulation / diligence PASS ≠ sustained study behaviour. |
| C5 | **No marketing claims** from validation evidence until a separate, explicit marketing-lift authority exists (EP-001 O8 freeze held unless lifted). |
| C6 | **No pass-rate claims.** Exam pass probability remains Vision north star; not a KSI-002 outcome. |
| C7 | **No commercial claims.** Validation does not authorise pricing, conversion, or market-fit assertions. |
| C8 | **Prefer-lower** when evidence conflicts (PSF §5.1). |
| C9 | **External N = 0 caps Strong-band claimability** for categories that require behavioural corroboration. |
| C10 | **Do not sum overlapping programme estimates** into a composite “current KSI” (PSF §5.6). |
| C11 | Evidence for Gate G1 must be **≤ 90 days** old at declaration (G1.3 / PSF §5.4). |
| C12 | Independent re-score of the same package must agree within **±3 KSI** or escalate (G1.7 / PSF §5.5). |

## 3. Claim taxonomy — never mix

Every validation artefact **must** label exactly one primary claim class. Mixing classes in a single verdict sentence is forbidden.

### 3.1 Educational correctness

| Field | Definition |
|-------|------------|
| **Meaning** | Official syllabus structure, package content, CMP partnership, and educational law are followed without dual truth or false readiness. |
| **Typical evidence** | Content Freeze; Approver inventory; LIVE package audits; EF-001 compliance; curriculum V1/V2 load. |
| **May support** | Trust that content is legitimate to study. |
| **Must not be used as** | Validated KSI lift; effectiveness GO; usefulness proof. |

### 3.2 Educational usefulness

| Field | Definition |
|-------|------------|
| **Meaning** | For a serious exam candidate, the product helps learning decisions and study quality across K1–K8 (PSF). |
| **Typical evidence** | Validated category scores; Tier B / Stage 1 interviews coded to KSI categories; behavioural proxies mapped to K1–K8. |
| **May support** | Validated KSI (G1.1); V1-K1…V1-K4, V1-K6, V1-K7. |
| **Must not be used as** | Exam pass-rate proof; marketing effectiveness claims without authority. |

### 3.3 Educational effectiveness

| Field | Definition |
|-------|------------|
| **Meaning** | Over a defined observation window, students show sustained study behaviour and perceived educational benefit consistent with EP-003 Go / No-Go (Q1–Q5). |
| **Typical evidence** | Stage 1/2 M1–M9 scorecards; structured interviews; recovery / consistency patterns. |
| **May support** | G1.9 (effectiveness not NO-GO); claimability for Strong-band usefulness. |
| **Must not be used as** | Automatic KSI ≥ 80; pass-rate claims. |

### 3.4 Educational confidence

| Field | Definition |
|-------|------------|
| **Meaning** | Diligent students can complete LIVE-certified packages with CMP partnership under Progressive Confidence / private-beta simulation rules. |
| **Typical evidence** | PB Progressive Confidence reports; persona simulations. |
| **May support** | Completeness / delivery confidence for Approver inventory. |
| **Must not be used as** | Validated KSI; multi-week usefulness; G1 PASS. |

### 3.5 Recommendation usefulness

| Field | Definition |
|-------|------------|
| **Meaning** | Subset of educational usefulness specific to **K2**: next-action guidance is trusted, non-conflicting, and (when instrumented) followed. |
| **Typical evidence** | Recommendation Review checklist Pass; Tier B trust codes; observational acceptance / commitment / completion rates under privacy bounds. |
| **May support** | K2 category score; G4 residual context. |
| **Must not be used as** | Recommendation-effectiveness **marketing**; proof that ranking algorithms changed (KSI-002 does not authorise ranking changes). |

**Separation rule:** A document may *reference* multiple classes, but each **verdict, score change, or gate decision** must cite one primary class and refuse silent substitution.

## 4. Research question (canonical)

### 4.1 Primary research question (educational effectiveness)

> For invite-only external students studying an in-scope professional exam subject on **W-PROD** sole-runtime production defaults, over a protocol-compliant observation window, does consistent use of Kwalitec produce **measurable study behaviour** and **perceived educational usefulness** sufficient to move educational effectiveness away from **NO-GO / PENDING EVIDENCE** and to support an honest **validated KSI** re-score under P-001.1?

### 4.2 Secondary research questions (by claim class)

| ID | Class | Question |
|----|-------|----------|
| RQ-U | Usefulness | What are the evidence-bound K1–K8 scores and composite validated KSI for the declared claim window? |
| RQ-E | Effectiveness | Do M1–M9 and interview codes satisfy EP-003 Q1–Q5 for the cohort window? |
| RQ-R | Recommendation usefulness | Are observational recommendation follow-through rates and trust codes sufficient to discuss Strong-band K2 (prefer-lower still applies)? |
| RQ-C | Correctness | *(Out of scope for KSI-002 ops)* Held by Content Freeze / PB chain — referenced, not re-tested as effectiveness. |
| RQ-F | Confidence | *(Out of scope for KSI-002 ops)* Held by Progressive Confidence — referenced, not substituted for RQ-E. |

### 4.3 Explicit non-questions

KSI-002 protocol **forbids** treating the following as research questions for Gate G1:

- Does Premium UX PASS raise KSI?  
- Does PB-017 PASS prove effectiveness?  
- What is the exam pass-rate lift?  
- Should we rebuild Runtime / Twin / Recommendation Engine / Educational Framework?

## 9. Per-category measurement protocol (K1–K8)

Each category score requires: evidence paths, rationale, confidence (High/Medium/Low), limitations (PSF §5.3). Scale: 0–100 bands per PSF §5.1.

| ID | Measurement (what is judged) | Collection method | Scale | Acceptance threshold (for *claim discussion*) | Confidence requirement |
|----|------------------------------|-------------------|-------|-----------------------------------------------|------------------------|
| **K1** Planning usefulness | Student can decide what to study now; plan coherence; duration / dual-home integrity | Interviews (planning codes); M2/M4 plan-adherence proxies; Session start from plan surfaces | 0–100 | Partial ≥50; Strong-band discussion ≥70 with behavioural corroboration | Medium min for validated publish; Low → do not publish lift |
| **K2** Recommendation usefulness | Trust, non-conflict, follow-through on next action | Tier B / Stage 1 trust codes; observational accept / defer / complete / follow-through rates | 0–100 | Partial upper possible on perception alone; **Strong ≥75 requires rates** (prefer-lower) | Medium min; Strong-band needs Medium+ with rates |
| **K3** Readiness usefulness | Unpackability; multi-week preparedness without false certainty | Interviews over ≥4 weeks preferred; single-session unpackability = Partial ceiling unless corroborated | 0–100 | ≥50 floor (V1-K2); Strong discussion ≥70 with multi-week codes | Medium min |
| **K4** Personalisation | “My plan” adaptation under the **actual** flag matrix | Only score ON posture; flag-OFF → validated absence of lift (Δ=0) is honest | 0–100 | Do not credit gated capability to W-PROD | High confidence acceptable for Δ=0 when flags OFF |
| **K5** Motivation | Consistent return; honest tone; recovery after miss | M6/M7; miss/return tallies; tone-trust interview codes | 0–100 | ≥50 floor; Strong needs consistency evidence | Medium min |
| **K6** Learning analytics | Decision-grade progress understanding (one-sentence test) | Interview + observed use of Journey/analytics; founder scorecard N; no invented educational scores | 0–100 | ≥50 V1 floor; lifts require student-facing decision use | Medium min for lifts; High OK for floor hold |
| **K7** Revision support | Revision changes practice; adherence proxies | Interviews; revision completion / return-to-weak-topic proxies | 0–100 | Continuity chrome alone ≠ Strong | Medium min |
| **K8** Explainability | Plain-language why; MES unpackability; honesty incidents = 0 material | Interview trust-why codes; P-001.2 checklist Pass linkage; incident log | 0–100 | **≥70 required for G1.5 / V1-K3** | Medium min |

**Composite acceptance for G1.1:** Validated KSI ≥ **80**, confidence Medium or High, prefer-lower applied, package ≤90 days.

## 10. Behavioural metrics (binding definitions)

Canonical formulae live in `EDUCATIONAL_METRICS.md`. This protocol binds **how they are used for effectiveness validation**.

| Metric | Protocol use | Notes |
|--------|--------------|-------|
| **Mission / Session completion (M4)** | Primary completion signal | Report abandon separately; no auto-complete theatre |
| **Return rate** | Share of accepted participants with ≥1 productive Session in week *t+1* after week *t* activity | Distinct from M7; report both |
| **Study consistency (M6)** | Primary sustained-behaviour signal for RQ-E | Rolling 4-week mean |
| **Revision usage** | Count / rate of revision-surface productive uses in window | Maps to K7; not vanity page views |
| **Recommendation acceptance** | Observational: primary next-action followed within defined TTL | Marketing freeze held; rates for K2 scoring only |
| **Session completion** | Synonym governance: learner-facing Session = Mission domain | Use Session in student reports |
| **Time-to-next-session** | Hours/days from completion (or abandon) to next start | Exploratory; report median + IQR |
| **Drop-off** | Accepted → never productive; or WAL loss after activation | Exclude from “survivorship-only” success narratives |
| **Abandonment** | Started Session without educational completion | Mandatory companion to M4 |

Additional operational definitions (dropout, inactive, duplicates): `KSI002_PARTICIPANT_PROTOCOL.md`.
