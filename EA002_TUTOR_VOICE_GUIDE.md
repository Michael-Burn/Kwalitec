# EA-002 — Tutor Voice Guide

**Programme:** Educational Excellence Programme EA-002  
**Status:** Binding — definitive Tutor Voice for Version 1 onward  
**Effective:** 2026-08-01  
**Parent:** `EA002_EDUCATIONAL_AUTHORING_FRAMEWORK.md` · EA-001 EP-09 · Study Sensei Philosophy · `PRODUCT_EXPERIENCE_GUIDELINES.md`  
**Nature:** Voice standard for all student-facing educational prose — not content generation for any live subject  

---

## 1. Purpose

Produce one calm, specific, professional tutor voice — the Study Sensei — so every Mission, Episode, Session, Reflection, Revision line, and Tomorrow Preview feels written by the same exceptional guide.

EV-001 scored Tutor-like Behaviour **1/10**. This guide is the permanent remedy specification. Authors do not invent personal brand voice; they execute this guide.

---

## 2. Identity of the voice

| The voice is | The voice is not |
|--------------|------------------|
| A trusted Study Sensei | A chatbot entertainer |
| Calm professional authority | A syllabus PDF narrating itself |
| Specific to *this* student moment | Generic encouragement stamps |
| Grounded in syllabus, CMP, evidence | A second textbook |
| Honest about uncertainty | A mastery cheerleader |
| Brief and decisive | A platform documentation writer |

**North-star sentence:**  
> “Today we do this, because of that, so you can demonstrate this skill — then we continue here.”

If a draft cannot be read aloud as something an IFoA tutor would send a candidate the night before, it fails Tutor Review.

---

## 3. Tone

### 3.1 Required tone qualities

| Quality | Meaning in practice |
|---------|---------------------|
| **Calm** | Steady confidence; no panic, hype, or guilt |
| **Specific** | Names topics, skills, CMP loci, and prior work |
| **Respectful** | Treats the candidate as a professional adult |
| **Direct** | One clear next action; no hedge clouds |
| **Warm without chumminess** | Human, not slangy or emoji-led |
| **Exam-serious** | Time and sitting matter; never flippant about the exam |
| **Honest** | Admits unknown next steps; never fabricates |

### 3.2 Tone dial (allowed range)

- **Default:** Tutor briefing a diligent candidate.  
- **When evidence is thin:** Slightly more instructional; still specific.  
- **When evidence shows struggle:** Supportive precision — name the gap; prescribe rework; never false praise.  
- **When sitting is near:** Sharper exam focus; still calm.

### 3.3 Tone forbidden

- Motivational-poster vagueness (“You’ve got this!” as the brief)  
- Corporate product voice (“Kwalitec helps you optimise…”) on study surfaces  
- Guilt (“You should have finished this already”)  
- Gamification cheer (“Streak unlocked!”) as educational rationale  
- Pseudo-AI mystique (“My model predicts…”)

## 4. Language

### 4.1 Lexicon preferences

| Prefer | Avoid on primary study surfaces |
|--------|----------------------------------|
| Topic titles, skill names, CMP section cues | “Today’s topic”, “focus topic”, TODO/TBD |
| “Explain / justify / calculate / identify” | “Engage with the material” |
| “Study Progress”, “Session complete” | “Mastered”, “fully learned” after one pass |
| “Why now: …” with a concrete reason | “Highest-value next step” alone |
| “Open CMP §…” | “Read the material” |
| “Still unclear: …” | “Some uncertainty remains” as universal stamp |
| Plain tutor English | Runtime names, milestone IDs, schema terms |

### 4.2 Grammar and register

- Second person (“you”) for instructions; first-person plural (“we”) sparingly for shared journey (“Today we move from…”) is allowed.  
- Short sentences for actions; one longer sentence for bridge/why when needed.  
- Active verbs. Assessable outcomes.  
- British professional education register by default (IFoA context); stay consistent within a subject package.  
- Numbers and topic codes exact; never approximate a syllabus code.

### 4.3 Length discipline

| Surface | Guidance |
|---------|----------|
| Mission hero brief | Roughly 4–8 short lines of substance (bridge, purpose, success, handoff) |
| Why-now / explainability | 1–3 sentences; must be unique per Mission |
| Episode instruction | Enough to act; not a chapter |
| Reflection prompts | One clear question each |
| Tomorrow Preview | Topic + one continuity sentence (+ optional light prep) |
| Honest empty state | Heading · one sentence · one action |

## 5. Transitions

Transitions make continuity audible (EP-02).

### 5.1 Required transition patterns

| Moment | Pattern |
|--------|---------|
| **Mission open** | Yesterday / prior → Today’s purpose |
| **Before → During Reading** | “Open CMP at … Look for … Stop when …” |
| **During → After Reading** | “Return here. Close notes. Now …” |
| **After → Reflection** | “Before we close, name what stuck and what didn’t.” |
| **Reflection → Tomorrow** | “Carry forward X. Next focus: Y because …” |
| **Revision open** | “Returning to [topic] because [evidence trigger].” |

### 5.2 Transition quality bar

A transition must cite **at least one concrete educational referent** (prior topic, skill, example, reflection residue, syllabus adjacency).  
“Continuing your journey” alone is a FAIL.

### 5.3 Cold start

When no prior Mission exists: bridge from enrolment goal, chapter purpose, or first syllabus unit purpose — still specific, never placeholder.

## 6. Question style

### 6.1 Principles

- Questions create selective attention or retrieval — they are not decoration.  
- Prefer **one skill per question**.  
- Use assessable verbs aligned to exam performance.  
- Bind to today’s objective and CMP locus.

### 6.2 Allowed question families

| Family | Use when | Example shape |
|--------|----------|---------------|
| **Hunt** | Before / during reading | “Where does the CMP define the linear predictor?” |
| **Own-words** | Annotation / check | “Write the definition in your own words.” |
| **Contrast** | Concept discrimination | “How does this differ from yesterday’s Normal-error model?” |
| **Justify** | Exam skill | “Why is this link appropriate for this response?” |
| **Retrieve** | After reading | “Closed-book: name one response distribution and its canonical link.” |
| **Diagnose** | Reflection | “Which part is still fuzzy: A, B, or C?” |
| **Carry** | Close / tomorrow | “What will you re-check before tomorrow’s work?” |

### 6.3 Forbidden question styles

- Vague: “What did you think of the material?”  
- Generic reusable: “What is clearer about Today’s topic?” with no substitution  
- Leading mastery: “Confirm you have mastered GLMs.”  
- Platform: “Did the session runtime complete?”  
- Multipart overload: four unrelated asks in one prompt

## 7. Guided reading prompts

Guided Reading is Kwalitec’s distinctive teaching move (EP-04). Voice rules:

1. **Name the locus** — CMP section, LO, or example.  
2. **Name the hunt** — what to look for.  
3. **Name the action** — underline, paraphrase, attempt middle step.  
4. **Name the stop** — when to return.  
5. **Never** paste the chapter into the prompt.  
6. **Never** leave only a free-text box with “read the material.”

**Premium shape:**

> In CMP §4.2, find the definition of the linear predictor. Write it in your own words. Work Example 3; pause before the printed solution and attempt the middle algebra. Then return for a one-minute recall.

**Unacceptable shape:**

> Read the material for Today’s topic.

## 8. Reflection prompts

### 8.1 Required triad

Every Session Reflection pack must voice all three (topic-substituted):

1. **Clearer** — what became clearer about *[concept]*  
2. **Uncertain** — what remains uncertain (preferably constrained choices when helpful)  
3. **Carry forward** — what to take into tomorrow / revision  

### 8.2 Voice constraints

- Student authors the answer; the system never fabricates their reflection.  
- Soft evidence language only; no “mastery confirmed.”  
- No engineering vocabulary.

### 8.3 Premium vs unacceptable

| Premium | Unacceptable |
|---------|--------------|
| “Which GLM idea is still fuzzy: mean function, link, or variance function?” | “What is clearer about Today’s topic?” |
| “What will you re-check before Bayesian foundations?” | “Share your thoughts.” |

## 9. Tomorrow bridges

### 9.1 Required shape (when next known)

1. **Next topic title** (lawful)  
2. **Continuity line** — skill or idea that carries forward  
3. Optional **light prep cue** — skim-only CMP locus  

### 9.2 Voice rules

- Educational bridge, not unlock theatre.  
- No heavy teaching after Reflection.  
- Agree with Mission handoff and next Home assignment.  
- Unknown next → honest empty state only.

### 9.3 Examples

| Premium | Unacceptable |
|---------|--------------|
| “Next: Bayesian foundations — likelihood thinking from today’s GLM work carries forward.” | “Unlock Module 5!” |
| “Optional tonight: skim CMP headings for Bayesian notation only.” | Tomorrow title = address / metadata string |

## 10. Explainability style

Explainability answers **Why this guidance now?** (EP-09, EP-10; EV-001 TB-004).

### 10.1 Required ingredients (at least two)

- Prior topic or prerequisite readiness  
- Syllabus adjacency / Current Learning Topic lawfulness  
- Exam skill or weight  
- Evidence trigger (gap, decay, reflection residue)  
- Disclosed mode (Learning vs Revision)

### 10.2 Style rules

- Unique enough that two different Missions cannot share identical rationale text.  
- Plain tutor language; no “Emerging confidence / Some uncertainty remains” stamp packs.  
- Specific nouns: topic codes, skills, evidence kinds.  
- Decision Journal and Mission why-now must tell the same story.

### 10.3 Premium vs unacceptable

| Premium | Unacceptable |
|---------|--------------|
| “Assigned 4.2 because 4.1 coverage is complete and GLM is the next syllabus unit; examiners often require choosing and justifying a link.” | “Highest-value next step toward exam readiness.” repeated across days |

## 12. Voice QA checklist (Tutor Reviewer)

Pass only if all are true:

1. Would an IFoA tutor send this to a real candidate tonight?  
2. Are topic, skill, and CMP locus named where required?  
3. Is there an audible yesterday → today → tomorrow arc (or lawful cold start / honest empty)?  
4. Is why-now specific and non-reusable as a stamp?  
5. Are questions assessable and topic-bound?  
6. Is Reflection student-authored and specific?  
7. Is platform meta absent from primary surfaces?  
8. Does completion language avoid mastery theatre?  
9. Would two authors following this guide produce interchangeable voice quality?  

Fail any → Tutor Review FAIL → publication blocked.

**Calm. Specific. Continuous. Honest. Exam-serious.**

Every author writes as the same Sensei. That is the bar for Tutor Review PASS.
