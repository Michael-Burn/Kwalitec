# EA-001 — Educational Quality Gates

**Programme:** Educational Excellence Programme EA-001  
**Status:** Binding — mandatory certification gates before student exposure  
**Effective:** 2026-08-01  
**Parent:** `EA001_EDUCATIONAL_FOUNDATION.md` · Principles · Session Philosophy · Mission Philosophy  
**Consumers:** EVF · curriculum publication · educational authoring · Founder certification · successor rewrite programmes  

---

## 1. Governing rule

> **Nothing reaches students unless it passes.**

Lifecycle green (publish workflow, RF-002 consistency, schema validity) is **necessary but not sufficient**. Educational certification under EA-001 is a separate gate.

EV-001 proved that structurally promising shells can still FAIL primary-study trust. These gates encode that lesson permanently.

---

## 2. Gate model

| Result | Meaning |
|--------|---------|
| **PASS** | Artefact may reach students for the scoped subject/version. |
| **FAIL** | Artefact must not reach students; defects listed with principle IDs. |
| **HOLD** | Temporary block pending evidence (e.g. CMP locus TBD with Founder waiver expiry). HOLD is not a silent PASS. |

**Certifier:** Human Academic Board / Founder Educational Gate Owner (or designated educational reviewer). Automation may **pre-fail** obvious defects; automation alone may not **PASS** Tutor Voice or continuity judgement without human sign-off for Version 1.

**Evidence:** Each PASS records reviewer, date, subject/package version, artefact IDs, and checklist outcomes.

---

## 3. Universal preconditions (all gates)

Fail any → overall FAIL:

| ID | Precondition |
|----|--------------|
| U1 | Topic identity resolves to a lawful syllabus node (no addresses, metadata, empty titles). |
| U2 | No placeholder lexicon: “Today’s topic”, “TODO”, “TBD”, lorem, unfilled template tokens. |
| U3 | No raw CMP/syllabus dump as the primary teaching body (V1 E1). |
| U4 | No platform/engineering jargon on primary student study surfaces. |
| U5 | One Educational Truth: artefact does not contradict Home / History / Journey / Revision for the same facts. |
| U6 | Completion language does not claim mastery. |
| U7 | Cited EA-001 principles EP-01–EP-10 respected for the artefact class. |

## 9. Certification package (minimum)

For a subject version to expose Missions/Sessions to students:

1. Curriculum package free of contaminant topics (U1).  
2. Sample Mission set (≥5 across journey positions) Gate MG PASS.  
3. Sample Session set covering those Missions Gate SS PASS.  
4. At least one Revision path Gate RV PASS **or** documented HOLD with student-visible honesty if revision not yet warranted.  
5. Tomorrow Preview spots Gate TP PASS on those samples.  
6. Cross-surface truth audit (Home ↔ History ↔ Journal ↔ Revision) with no dual-truth defects.  
7. Written sign-off referencing EV-001 failure classes as regression checks.

Spot-check sizes may increase for commercial cohorts; they must not decrease below this floor without Board amendment of EA-001.

---

## 10. Automation assist (non-authoritative)

Recommended pre-fail detectors (implementation programmes may build later — **not in EA-001**):

- Placeholder token scan  
- Title == objective equality  
- `looks_like_cmp_dump` / address-like topic linter  
- Boilerplate rationale similarity threshold  
- Episode empty-body detector  
- Stage count vs reachable activities  

Human PASS remains mandatory for Tutor Voice, continuity quality, and exam-focus judgement in Version 1.
