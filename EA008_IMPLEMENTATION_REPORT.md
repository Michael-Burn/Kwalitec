### Summary

EA-008 defines the **Educational Campaign** as Kwalitec’s primary educational publication unit. Consecutive Missions are coordinated as one coherent journey — with purpose, objective, scope, entry/completion criteria, continuity layers, revision strategy, certification (Gate CG), and publication policy.

The publication policy **prohibits isolated Golden Day commercial publication** after the effective date, requiring certified Campaign (or Pilot Arc) membership. Continuity is made objectively measurable via Continuity Index (CI), bridge integrity, floor rules, and Day-*N* trust simulation. EA-007’s continuity FAIL remains the standing live result; EA-008 supplies the architecture to remediate it in successor programmes without touching application code or Runtime/SCI.

#### 1. Student problem

Students experience study as a continuous journey. Publishing one Golden day inside a template semester trains them to distrust the product after the relapse day. Without Campaign-level publication law, Educational Excellence can still ship spikes that photograph well and journeys that fail.

#### 2. Student benefit

| Design question | Helped? | How |
|---|---|---|
| What should I do now? | Indirect | Future pathways must ship contiguous arcs, not orphan days |
| How am I progressing? | Indirect | Completion criteria require evidence-honest exit language |
| What is stopping me? | Yes (governance) | Names continuity, revision, voice, and orphan excellence as publication blockers |
| What happens next? | Yes (governance) | Requires certified Campaign membership before commercial package publish |

**Student benefit summary:** No direct UX change. Protective benefit: blocks isolated premium-day publication as a false maturity signal.

### Lessons learned for student value

1. **The publication unit must match the trust horizon** — days create sittings; Campaigns create reliance.  
2. **Package PASS without Campaign law recreates EA-007** — orphan excellence is a process failure, not only a content gap.  
3. **Continuity must be scored** — otherwise “feels continuous” rubber-stamps artificial syllabus order.  
4. **Revision Strategy is Campaign-mandatory** — memory cannot be a post-semester afterthought.  
5. **Protective architecture creates student value at ΔKSI = 0** by refusing premature scale claims.
