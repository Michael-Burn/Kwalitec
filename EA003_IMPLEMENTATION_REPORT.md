### Lessons learned for student value

1. **Gates without a Mission Blueprint still leave “tutor-grade” subjective** — authors need field-level architecture, not only MG checklists.  
2. **Tutor Intent is the missing centre** — EV-001 briefs failed because no coaching move was specified before student copy.  
3. **Continuity must be a bundle, not a garnish** — yesterday/today/tomorrow as first-class schema prevents disconnected days.  
4. **Numeric publication threshold prevents taste-test drift** — ≥8.0 with dimension floors stops borderline checkbox Missions shipping as “good enough.”
