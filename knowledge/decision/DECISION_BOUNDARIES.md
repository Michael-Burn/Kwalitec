## 1. Purpose

A Decision Architecture that silently becomes a second constitution — re-executing rules under the label “decision,” reinterpreting EIP in “notes,” amending specifications so a preferred disposition appears, or inventing governance outside published authority because a badge was needed — destroys student trust and educational integrity.

This document draws a bright line between **lawful constitutional decision production** (Programme X / WS3 / MS001) and **constitutional execution / legislation / independent interpretation / independent governance** (Constitution / EIP / Programmes VI–IX / WS2 / permitted writers).

---

## 2. Boundary Principles

1. **Decide, do not execute.** The Decision Architecture transforms completed outcomes; it does not perform constitutional rule execution.
2. **Completed outcomes only.** Incomplete or unpublished execution is a hard stop.
3. **Published decision rules only.** Unpublished customs and “main as law” are hard stops as decision-rule sources.
4. **Published components only.** Unpublished CDA customs are unlawful.
5. **Exactly as published.** Successful decision production never rewrites specification meaning.
6. **Authority first.** Published corpora remain the sole constitutional standard.
7. **EIP intact.** Educational Interpretation Principles are never reinterpreted or replaced by decision prose.
8. **Implementation independence.** No stack, vendor, or reference implementation becomes law by proximity.
9. **Decisions ≠ legislation.** Published constitutional decisions never amend constitutional specifications.
10. **No rule re-execution.** Applying decision rules is not WS2 constitutional rule execution.
11. **No meaning redefinition.** Decision prose never redefines Constitution / EIP / Programme VI–IX meaning.
12. **No independent governance.** Decision production never determines governance outside published constitutional authority.
13. **No authority substitution.** A published decision never replaces the corpus for the next act.
14. **No bypass.** Product urgency never waives required decision components or completed-outcome prerequisites.
15. **Determinism and repeatability.** Race-dependent or operator-dependent decision production is a defect.
16. **Explain the stop.** Students, developers, and auditors should hear when decision production must refuse.
17. **No emergency exemption.** Deadlines and demos never mint constitutional amendment power via the Decision Architecture.
18. **Validate before publish.** Invalid constructions must not be published as constitutionally valid.
19. **Upstream honesty.** Execution outcomes remain execution outcomes; decision production never rewrites them into new law.

## 3. What the Decision Architecture May Do (Lawful)

| Lawful action | Constitutional meaning |
|---------------|------------------------|
| **Evaluate execution outcomes** | Admit and assess completed WS2 outcomes under CDA-01 / CDA-02 |
| **Apply published constitutional decision rules** | Evaluate decision rules exactly as published via CDA-02 |
| **Produce constitutional decisions** | Construct and validate dispositions via CDA-03 / CDA-04 |
| **Publish constitutional decisions** | Make validated decisions available for audit and explainability via CDA-05 |
| **Manage decision state** | Record speakable Decision Architecture progress via CDA-06 |
| **Refuse incomplete decision production** | Prefer honest refuse / invalid over improvisation |
| **Cite constitutional authority** | Name governing published corpora without replacing them |
| **Remain deterministic and repeatable** | Same completed outcomes + same decision rules ⇒ same disposition |
| **Remain implementation-neutral** | Honour decision law across lawful equivalent stacks |
| **Explain decisions** | Answer outcomes / decision rules / decisions / authority / boundaries without rewriting meaning |
| **Compose required components** | Bind published CDA conjunctions without collapsing missing components |
| **Propose corpus amendments upstream** | Recommend (not enact) amendments when law itself must change before a lawful decision can be produced |

## 4. What the Decision Architecture Must Never Do (Unlawful)

| Unlawful action | Why it is forbidden |
|-----------------|---------------------|
| **Execute constitutional rules** | Rule execution belongs to WS2 Constitutional Execution Engine; decision production consumes outcomes |
| **Redefine constitutional meaning** | Meaning remains owned by Constitution / EIP / Programmes VI–IX |
| **Reinterpret Educational Interpretation Principles** | EIP is referenced as published; decision notes never author new interpretation |
| **Amend constitutional specifications** | Decisions never soft-amend published law |
| **Modify constitutional specifications** | Clarifying notes must not rewrite published text |
| **Replace constitutional authority** | Decision machinery never becomes the standard for the next act |
| **Determine governance outside constitutional authority** | Governance judgements remain bound to published Programme IX (and related) authority; CDA is not an independent producer |
| **Begin against incomplete outcomes** | Incomplete WS2 execution is a hard stop |
| **Invent unpublished decision rules** | Closed published decision-rule sources only |
| **Invent unpublished CDA components** | Closed CDA-01…CDA-06 catalogue only |
| **Publish invalid candidates as valid** | CDA-04 must validate before CDA-05 publication |
| **Mint educational recommendations / tips as CDA decisions** | Programme VII owns recommendation / ownership meanings |
| **Re-prepare or re-resolve execution context** | WS1 owns preparation; CDA consumes completed outcomes |
| **Complete unfinished execution** | WS2 owns execution completion; CDA never finishes the mark sheet under a decision label |
| **Freeze a stack as law** | Implementation neutrality forbids stack elevation by decision proximity |
| **Claim educational quality from publication** | Decision ≠ mastery, readiness, or learning success |
| **Suppress lawful refuse** | Honesty requires speakable stops |

## 6. Hard Stops

Decision production **must stop** (refuse / invalid) when any of the following hold:

1. Required execution outcomes are incomplete, unpublished, or non-reconstructable.
2. Required constitutional decision rules are unpublished or cannot be identified without invention.
3. Applying the only available “custom” would require executing constitutional rules, reinterpreting EIP, or amending specifications.
4. The candidate decision would replace constitutional authority or determine governance outside constitutional authority.
5. Validation (CDA-04) fails and no lawful repair exists without violating boundaries.
6. Required CDA components cannot be applied without inventing unpublished component identities.
7. Determinism or repeatability cannot be preserved for the material concern.
8. Explainability questions cannot be answered honestly without fabricating traces.

Product urgency, demo schedules, CI pressure, and founder preference never waive these hard stops.
