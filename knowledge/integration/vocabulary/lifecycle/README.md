## Purpose

This folder defines **the permanent constitutional lifecycle coordinating vocabulary integrity assessments** from initiation through vocabulary discovery, canonical definition validation, semantic consistency validation (including terminology reuse honesty), ambiguity validation, definition stability validation, finding construction, and publication of vocabulary integrity findings.

It answers *what the lifecycle must optimise*, *which recognised stages organise vocabulary assessment*, *what the lifecycle may and must never do*, and *how lifecycle progress is constitutionally explained* — without implementing Runtime A, testing frameworks, CI/CD, redefining constitutional terminology, reinterpreting constitutional meaning, amending constitutional specifications, creating constitutional authority, or elevating lifecycle machinery into a constitutional authority.

It does **not** implement Runtime A, test runners, CI/CD pipelines, GitHub Actions, Python, Flask, SQLAlchemy, REST, OpenAPI, infrastructure, databases, or application services.

> **The constitutional vocabulary integrity lifecycle coordinates vocabulary assessment activities.  
> It validates canonical terminology, evaluates semantic consistency and terminology reuse, validates ambiguity avoidance and definition stability, and publishes findings.  
> It never redefines constitutional terminology, reinterprets constitutional meaning, amends constitutional specifications, or creates constitutional authority.**

## Architectural requirement

The constitutional vocabulary integrity lifecycle coordinates **vocabulary assessment activities**.
