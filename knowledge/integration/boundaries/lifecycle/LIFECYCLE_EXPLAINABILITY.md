## 1. Purpose

An expert IFoA tutor who cannot say *which boundaries* were assessed — which authority and responsibility boundaries were validated, which constitutional constraints were evaluated, which findings were produced, and which limits remained intact — is not coaching; they are performing.

After Programmes VI–X have made meaning, ownership, tips, context, contracts, evidence, runtime, governance, and execution speech speakable, after Programme XI / WS1–WS2 have made dependency and catalogue integrity speech speakable, and after WS3 / MS001 has made boundary integrity speech speakable, Programme XI still needs one lifecycle-speech answer:

> **“Which boundaries were assessed, which authority boundaries were validated, which responsibility boundaries were validated, which constitutional constraints were evaluated, which findings were produced, and which constitutional boundaries remained intact?”**

That answer must cover every material boundary integrity lifecycle without inventing educational meaning, transferring authority, minting tips, inventing state, rewriting specifications, redefining responsibilities, softening constraints, creating constitutional authority, freezing a stack as law, inventing unpublished CBI or CBIL types, replacing MS001 validation meaning, or presenting publication as educational quality.

## 2. What Lifecycle Explainability Is

**Constitutional Boundary Integrity Lifecycle Explainability** is the constitutional obligation to narrate **coordination of named boundary assessments through published CBIL stages** — discovering published boundary statements, validating authority and responsibility boundaries, evaluating behavioural / consumption / production constraints, validating layering, applying published CBI types, and producing / publishing findings — not to invent a second tutor voice from string scanners, not to grade the student, and not to replace constitutional authority.

| Concept | Definition | Primary question |
|---------|------------|------------------|
| **Boundaries assessed** | Named published corpus identities and boundary statements under assessment | Which boundaries were assessed? |
| **Authority boundaries validated** | Reconstructable published who-may-define / own / decide limits confirmed at CBIL-03 | Which authority boundaries were validated? |
| **Responsibility boundaries validated** | Reconstructable published duty allocations confirmed at CBIL-04 | Which responsibility boundaries were validated? |
| **Constitutional constraints evaluated** | Behavioural may / must / must-not and consumption / production rights evaluated at CBIL-05 | Which constitutional constraints were evaluated? |
| **Findings produced** | intact / violated / deferred / escalated (with stage binding and composition notes) | Which findings were produced? |
| **Boundaries remaining intact** | Explicit confirmation that forbidden legislation / mutation / reinterpretation / responsibility redefinition / constraint alteration / authority-creation / substitution did not occur | Which constitutional boundaries remained intact? |

Lifecycle Explainability is:

- **coordination-centred** — it narrates boundaries → authority → responsibility → constraints → layering → findings under law;
- **catalogue-bound** — every justification cites published CBIL and CBI identities;
- **corpus-bound** — every justification cites published corpora and boundary statements;
- **discovery-honest** — every material justification cites identifiable published boundaries assessed (or names the hard stop when none exist);
- **authority-honest** — every material justification cites validated authority boundaries (or names the hard stop when unmet);
- **responsibility-honest** — every material justification cites validated responsibility boundaries (or names the hard stop when unmet);
- **constraint-honest** — every material justification cites evaluated constraints without hiding softening;
- **finding-honest** — every material finding is bound to the producing lifecycle stages;
- **record-honest** — every material lifecycle cites which assessment records were preserved / published;
- **non-legislative** — explanation never becomes a back door to amend corpora;
- **non-authoritative** — publication is never narrated as a freeze of stack authority or a substitute for published corpora;
- **quality-honest** — intact status is never narrated as mastery, readiness theatre, or educational quality;
- **mutation-honest** — explanation never hides boundary / responsibility / constraint changes performed “so the lifecycle could proceed”;
- **technology-honest** — explanation never presents a stack preference as constitutional law;
- **audience-aware** — student speech and developer/auditor traces differ in vocabulary, not in truth;
- **layer-honest** — it does not replace Programme VI tip warrant speech, Programme VII ownership / workflow / state speech, EIP-002 evidence meaning speech, Programme VIII contract / evidence / validation speech, Programme IX governance speech, Programme X activity speech, WS1 / WS2 dependency / catalogue speech, or WS3 / MS001 boundary integrity speech;
- **audit-aligned** — explanation components match CBILO-05 reconstruction needs;
- **repeatability-honest** — explanations must not paper over race-dependent dispositions or private stage shortcuts.

Lifecycle Explainability is **not**:

- a rewrite of Constitution / EIP / Programme VI–X / WS1 / WS2 / WS3 / MS001 meaning;
- a quality report on learning, coaching, or exam readiness;
- a substitute for CBI findings speech, CT lineage speech, CDI / CCI speech, or Programme IX–X evaluative / execution speech;
- a CI status page, coverage report, string-scanner summary, or linter summary presented as constitutional coordination;
- a freeze of implementations, stacks, vendors, or releases as constitutional law;
- a licence to narrate invented boundaries, redefined responsibilities, or softened constraints as if they were lawful inputs.

## 3. Mandatory Explainability Questions

Every material constitutional boundary integrity lifecycle must be able to answer:

### CBILEQ-01 — Which boundaries were assessed?

**Required content**

- Named published corpus identities and boundary statement identities discovered at CBIL-02
- Binding between boundary identities and intended / applied CBI types
- Confirmation that unpublished customs, invented boundaries, or scanner noise were not used as constitutional boundaries

**Defect if**

- “Boundaries are fine” with no boundary references
- Anonymous “the docs” or “the may/must text” without identifiable published boundary statements
- Boundaries invented, softened, redefined, or deleted as assessment without disclosure and hard stop

---

### CBILEQ-02 — Which authority boundaries were validated?

**Required content**

- Named authority boundaries confirmed at CBIL-03 (who may define, own, or decide under published owning corpora)
- Explicit refuse-validate disposition when authority boundaries were unmet
- Confirmation that authority statements were not invented or silently absorbed into subordinates

**Defect if**

- Assessment proceeds with “authority assumed”
- Authority boundaries invented mid-lifecycle to force intact status
- Silent omission of mandatory superior authority identities

---

### CBILEQ-03 — Which responsibility boundaries were validated?

**Required content**

- Named responsibility boundaries confirmed at CBIL-04 (published duty allocations and non-absorption)
- Explicit refuse-validate disposition when responsibility boundaries were unmet
- Confirmation that responsibilities were not redefined or silently transferred

**Defect if**

- Assessment proceeds with “responsibilities assumed”
- Responsibilities redefined mid-lifecycle to force intact status
- Silent dual exclusive ownership without published warrant

---

### CBILEQ-04 — Which constitutional constraints were evaluated?

**Required content**

- Named behavioural may / must / must-not and consumption / production constraints evaluated at CBIL-05
- Constraint disposition: preserved / violated / deferred / escalated (or refuse-validate)
- Confirmation that constraints were not softened or rights invented under lifecycle pretence

**Defect if**

- Constraint status omitted when findings are claimed
- Softened constraints quietly dropped from publication speech
- Narration that contradictions were “resolved” by rewriting constraints under lifecycle pretence

---

### CBILEQ-05 — Which findings were produced?

**Required content**

- Named boundary integrity findings from CBIL-07 (intact / violated / deferred / escalated)
- Binding of each finding to producing CBIL stages (especially CBIL-03…CBIL-07)
- Publication artefacts from CBIL-08 where material (or refuse-publish identity)
- Continuity sufficient to reconstruct corpora, boundaries, authority / responsibility validations, constraints, CBI types, stages, findings, and intact limits

**Defect if**

- “Intact” with no reconstructable finding identity
- Findings that drop stage-to-finding binding or boundary identity
- Silent erasure of prior lawful assessment / lifecycle history
- Publication that invents intact status or hides violated dispositions

---

### CBILEQ-06 — Which constitutional boundaries remained intact?

**Required content**

- Explicit confirmation against `LIFECYCLE_BOUNDARIES.md` checks material to the concern (especially non-legislation, non-reinterpretation, non-mutation, non-responsibility-redefinition, non-constraint-alteration, non-authority-creation, non-substitution)
- Disclosure of any hard stop that prevented progress or publication
- Explicit confirmation that assessed published boundaries that remained lawful were not rewritten by coordination

**Defect if**

- Intact limits are implied, not speakable
- Publication speech smuggles authority creation, responsibility redefinition, constraint softening, meaning reinterpretation, or law rewrites
- Artefact / boundary mutation or invented statements are hidden

|----------|---------------------|------------|

Projections differ in vocabulary. They must not differ in constitutional facts.

## 5. Forbidden Explainability Moves

| Forbidden narration | Why | Lawful alternative |
|---------------------|-----|--------------------|
| “Lifecycle published ⇒ new constitutional law” | Legislation via publication | “Findings recorded; corpora unchanged” |
| “Lifecycle published ⇒ responsibilities redefined” | Responsibility mutation | “Duty allocations assessed as found; responsibilities unchanged” |
| “Lifecycle published ⇒ constraints softened” | Constraint alteration | “Constraints assessed as found; may / must / must-not unchanged” |
| “Lifecycle published ⇒ authority created” | Authority creation | “Assessment coordinated; published corpora remain the standard” |
| “Intact ⇒ student ready / mastered” | Quality / mastery out of scope | Keep boundary speech distinct from educational claim classes |
| “We invented the missing authority so validation passed” | Invented authority | Refuse-validate; propose lawful amendment upstream |
| “We adjusted the must-not so the lifecycle could finish” | Constraint / specification mutation | Refuse-validate / violated; propose lawful change outside lifecycle pretence |
| “Stage skipped because the scanner was green” | Unpublished stage customs | Apply CBIL-01…CBIL-08 or refuse |
| “This stack is now the standard” | Authority substitution / neutrality breach | Keep implementation as assessed subject |
| “Findings update the constitution” | Legislation via explanation | Propose amendment upstream; leave corpora unchanged |
| “Linked in CT ⇒ boundary intact forever” | CT / CBI conflation | Compose with CT; keep boundary integrity speech distinct |
| “Dependency / catalogue intact ⇒ boundary intact” | Horizon conflation | Compose with CDI / CCI; keep boundary speech distinct |

## 7. Audit Alignment

Lifecycle explainability records must support reconstruction of:

1. Boundaries assessed (CBILEQ-01)
2. Authority boundaries validated (CBILEQ-02)
3. Responsibility boundaries validated (CBILEQ-03)
4. Constitutional constraints evaluated (CBILEQ-04)
5. Findings produced and records / publication artefacts preserved (CBILEQ-05)
6. Constitutional boundaries / limits remaining intact (CBILEQ-06)
7. Applied CBI-01…CBI-07 identities (from WS3 / MS001 speech)
8. Finding dispositions (intact / violated / deferred / escalated / refuse-*)
9. Continuity of prior lawful lifecycle history (EIP-005)

Missing any material element is an explainability defect under CBILO-05.
