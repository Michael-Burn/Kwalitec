## 1. Purpose

A lifecycle that silently becomes a second constitution — rewriting responsibilities so stages “complete,” softening “must not” into “may” in “findings,” licensing a preferred documentation topology under a published badge, inventing boundaries to force CBIL-07, treating a preferred implementation as the new standard, mutating corpora mid-lifecycle, or freezing a stack as law — destroys student trust and educational integrity.

This document draws a bright line between **lawful constitutional boundary integrity lifecycle coordination** (Programme XI / WS3 / MS002) and **constitutional authorship / educational judgement / responsibility redefinition / constraint alteration / authority creation / meaning reinterpretation / specification amendment** (Constitution / EIP / Programmes VI–X / WS1 / WS2 / WS3 / MS001 / permitted writers).

---

## 2. Boundary Principles

1. **Coordinate, do not legislate.** The lifecycle organises boundary assessment; it does not create law.
2. **Published specifications only.** Unpublished customs and “main as boundary” are hard stops as standards.
3. **Published stages only.** Unpublished CBIL customs are unlawful.
4. **Published boundary categories only.** Stages apply CBI-01…CBI-07 only.
5. **Published boundaries only.** Lifecycles without identifiable published boundary statements are theatre.
6. **Exactly as published.** Successful progress never rewrites specification meaning, responsibilities, or constraints.
7. **Authority first.** Published corpora remain the sole constitutional standard.
8. **Implementation independence.** No stack, vendor, or reference implementation becomes law by proximity to publication.
9. **Published ≠ quality.** Lifecycle publication never grades learning, mastery, readiness, or product success.
10. **Published ≠ rewritten boundaries.** The lifecycle never mutates boundaries so findings look intact.
11. **Published ≠ new authority.** The lifecycle never elevates Programme XI into foundational law by coordinating others.
12. **No reinterpretation.** Programme VI–X meanings, EIP claim classes, and CBI criteria survive coordination intact.
13. **No authority substitution.** A published finding never replaces the corpus for the next judgement.
14. **No responsibility mutation.** Coordination never redefines, invents, or soft-transfers constitutional responsibilities.
15. **No constraint alteration.** Coordination never softens, invents, or deletes may / must / must-not or consumption / production rights.
16. **No bypass.** Product urgency never waives constitutional lifecycle requirements.
17. **Repeatability / consistency.** Race-dependent or private stage shortcuts are defects.
18. **Explain the stop.** Students, developers, and auditors should hear when the lifecycle must refuse progress or publication.
19. **No emergency exemption.** Deadlines and demos never mint constitutional amendment power or authority creation via lifecycle publication.
20. **Layering honesty.** Lower horizons never absorb superior authority via lifecycle prose.

## 3. What the Lifecycle May Do (Lawful)

| Lawful action | Constitutional meaning |
|---------------|------------------------|
| **Coordinate boundary assessment** | Organise activities through CBIL-01…CBIL-08 |
| **Validate constitutional boundaries** | Apply published CBI / CBIR law to discovered published boundary statements |
| **Validate authority boundaries** | Confirm reconstructable who-may-decide limits at CBIL-03 |
| **Validate responsibility boundaries** | Confirm published duty allocations and non-absorption at CBIL-04 |
| **Validate behavioural constraints** | Confirm may / must / must-not fidelity at CBIL-05 |
| **Validate consumption / production boundaries** | Confirm lawful consume / produce rights at CBIL-05 |
| **Validate constitutional layer separation** | Confirm published programme / workstream order at CBIL-06 |
| **Identify integrity findings** | Emit intact / violated / deferred / escalated under published criteria |
| **Publish assessment findings** | Communicate findings and records under published honesty rules |
| **Consume constitutional specifications** | Use published Constitution / EIP / Programme VI–XI corpora as assessment standards |
| **Preserve established traceability in records** | Carry established CT-01…CT-07 relationships into assessment records; never invent them |
| **Apply boundary categories** | Across stages, apply published CBI-01…CBI-07 only |
| **Refuse unlawful progress** | Prefer honest refuse / defer / escalate / violated over improvisation |
| **Remain repeatable and consistent** | Same published inputs → same stage outcomes and dispositions |
| **Remain implementation-neutral** | Honour lifecycle law across lawful equivalent stacks |
| **Support governance integrity** | Strengthen corpus-boundary honesty without becoming educational readiness or constitutional authority |
| **Explain lifecycle progress** | Answer boundaries / authority / responsibility / constraints / findings / intact limits without rewriting meaning |
| **Propose corpus amendments upstream** | Recommend (not enact) amendments when law itself must change |

These actions **coordinate boundary assessment**. They do **not** publish a new Constitution, invent coach warrants, mint tips, author ownership maps, invent CBI or CBIL types, invent CT links, author runtime behaviour, judge educational quality, create constitutional authority, redefine responsibilities, alter constraints, reinterpret meaning, or amend specifications under coordination pretext.

## 4. What the Lifecycle Must NEVER Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Redefine constitutional authority** | Published corpora alone own who may define, own, or decide | Cite published authority boundaries only; refuse unpublished standards; never elevate lifecycle progress into authority |
| **Modify constitutional responsibilities** | Duties are published corpus facts, not lifecycle outputs | Report responsibility structure as found; refuse redefinition theatre |
| **Alter constitutional constraints** | May / must / must-not and consumption / production rights are published | Report constraints as found; refuse softening or inventing rights |
| **Amend constitutional specifications** | Only corpus governance may amend law | Leave specs unchanged; propose amendment upstream or mark violated / refuse |
| **Create constitutional authority** | Published corpora alone own constitutional meaning | Never elevate findings or stages into foundational law |
| **Invent boundary statements** | Discovery organises published boundaries | Refuse-discover when boundaries are missing |
| **Invent authority or responsibility allocations** | Fidelity requires real published statements | Refuse-validate when allocations cannot be reconstructed |
| **Soften constraints in situ** | Constraint honesty | Report violated; never rewrite may / must / must-not under assessment pretence |
| **Absorb superior layers** | Layering honesty | Report layer violations; never soft-absorb superiors |
| **Invent boundary categories** | CBI catalogue is closed under WS3 / MS001 | Apply CBI-01…CBI-07 only |
| **Invent lifecycle stages** | CBIL catalogue is closed under this corpus | Apply CBIL-01…CBIL-08 only |
| **Invent traceability** | CT owns lawful lineage | Preserve established relationships in records; refuse invented links |
| **Bypass lifecycle requirements** | Requirements are educational care, not optional polish | Prefer understatement / refuse over invented green |
| **Privilege a technology as constitutional** | Implementation neutrality | Coordinate assessment, not Flask / SQLAlchemy / REST / OpenAPI fashion |
| **Determine educational quality** | No CBIL stage is a quality rubric | Keep coordination speech distinct from quality speech |
| **Determine constitutional truth** | Constitution / EIP own truth | Obey published law; do not adjudicate truth in lifecycle machinery |
| **Transfer authority** | Programme VII WS2 owns ownership, permission, and conflict disposition | Apply Authority corpora; refuse domain absorption via stages |
| **Invent educational state** | Programme VII WS4 owns EST/CST context law | Assess against published postures only |
| **Generate unpublished recommendations** | Programme VII WS3 + Programme VI owners own tip warrant | Surface integrity findings, not new tips |
| **Treat Twin / Adaptive / UI / CI / scanners as constitutional producers** | They are subjects / delivery surfaces | Require published corpus mapping or refuse |
| **Present scores / coverage / acks / scanner greens as constitutional integrity or publication** | Operational proxies are not lifecycle law | Cite published corpora, CBI types, and CBIL stages |
| **Become irreplaceable by coordination topology** | Replaceability | Keep lifecycle law implementation-independent |
| **Freeze stack authority via publication** | Neutrality / authority preservation | Publish findings; never make the stack the next standard |
| **Replace MS001 boundary meaning** | CBI owns validation meaning | Sequence assessments; never rewrite CBI criteria |
| **Replace Programme XI WS1 / WS2** | CDI / CCI own dependency / catalogue integrity | Compose with those horizons; never absorb them |
| **Replace Programme IX CT** | CT owns lineage | Compose with CT; never treat “linked” as “boundary intact forever” |
| **Reinterpret constitutional meaning** | Programme VI–X and EIP own meaning | Assess against published meaning; never redefine it |

## 6. Boundary Checks (Pre-Publication)

Before a material constitutional boundary integrity lifecycle is treated as lawfully published, coordination requires affirmative answers:

| Check | Question |
|-------|----------|
| **CBILB-01 Specification / corpus identity** | Are assessment standards published Constitution / EIP / Programme VI–XI corpora (not unpublished customs)? |
| **CBILB-02 Stage class** | Are required CBIL-01…CBIL-08 stages being applied (not unpublished customs)? |
| **CBILB-03 Boundary class** | Are required CBI-01…CBI-07 categories applied (not unpublished customs)? |
| **CBILB-04 Boundary identity** | Which named boundary statements were assessed? |
| **CBILB-05 Authority-boundary identity** | Which authority boundaries were validated (none invented)? |
| **CBILB-06 Responsibility-boundary identity** | Which responsibility boundaries were validated (none redefined)? |
| **CBILB-07 Constraint status** | Which behavioural / consumption / production constraints were evaluated (none softened; none invented)? |
| **CBILB-08 Layering status** | Was published constitutional layering confirmed or honestly reported violated? |
| **CBILB-09 Finding binding** | Which lifecycle stages produced the boundary integrity findings (especially CBIL-03…CBIL-07)? |
| **CBILB-10 Record identity** | Which assessment records were preserved? |
| **CBILB-11 Non-legislation** | Does the lifecycle avoid creating or amending constitutional specifications? |
| **CBILB-12 Non-reinterpretation** | Does the lifecycle avoid redefining Programme VI–X educational / constitutional meaning? |
| **CBILB-13 Non-mutation** | Were boundary statements, responsibilities, and constraints left unmodified by lifecycle coordination? |
| **CBILB-14 Non-authority-creation** | Does the lifecycle avoid creating constitutional authority or treating findings as new law? |
| **CBILB-15 Non-substitution** | Does the lifecycle avoid treating the implementation or lifecycle machinery as the next constitutional standard? |
| **CBILB-16 Non-MS001-replacement** | Is publication framed as assessment coordination complete — not a rewrite of CBI meaning? |
| **CBILB-17 Neutrality** | Does the lifecycle avoid privileging a language, framework, protocol, or CI vendor as law? |
| **CBILB-18 Publication ≠ quality** | Is the outcome framed as lifecycle coordination / boundary integrity — not educational quality? |
| **CBILB-19 Repeatability / audit** | Are stage outcomes reproducible; do explainability records preserve boundaries, authority / responsibility validations, constraints, findings, and intact limits? |

Any failed check → refuse-publish / deferred / escalated / violated as published. Do not “best-effort” invent lifecycle law, invent boundaries, soft-amend specifications, redefine responsibilities, alter constraints, create constitutional authority, or replace constitutional authority in situ.
