## Purpose

This folder defines **the permanent constitutional lifecycle coordinating boundary integrity assessments** from initiation through boundary discovery, authority validation, responsibility validation, constraint validation (behavioural, consumption, and production), layer validation, finding construction, and publication of boundary integrity findings.

It answers *what the lifecycle must optimise*, *which recognised stages organise boundary assessment*, *what the lifecycle may and must never do*, and *how lifecycle progress is constitutionally explained* — without implementing Runtime A, testing frameworks, CI/CD, creating constitutional authority, redefining constitutional responsibilities, reinterpreting constitutional meaning, amending constitutional specifications, or elevating lifecycle machinery into a constitutional authority.

It does **not** implement Runtime A, test runners, CI/CD pipelines, GitHub Actions, Python, Flask, SQLAlchemy, REST, OpenAPI, infrastructure, databases, or application services.

> **The constitutional boundary integrity lifecycle coordinates boundary assessment activities.  
> It validates authority boundaries, responsibility boundaries, behavioural constraints, consumption and production boundaries, and constitutional layer separation, and publishes findings.  
> It never creates constitutional authority, redefines responsibilities, reinterprets meaning, or amends constitutional specifications.**
