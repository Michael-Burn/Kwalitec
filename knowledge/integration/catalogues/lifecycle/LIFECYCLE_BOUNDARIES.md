## 1. Purpose

A lifecycle that silently becomes a second constitution — renumbering catalogues so stages “complete,” inventing uniqueness in “findings,” licensing a preferred vocabulary topology under a published badge, inventing catalogues to force CCIL-06, treating a preferred implementation as the new standard, mutating corpora mid-lifecycle, or freezing a stack as law — destroys student trust and educational integrity.

This document draws a bright line between **lawful constitutional catalogue integrity lifecycle coordination** (Programme XI / WS2 / MS002) and **constitutional authorship / educational judgement / identifier creation / renumbering / authority creation / meaning redefinition / specification amendment** (Constitution / EIP / Programmes VI–X / WS1 / WS2 / MS001 / permitted writers).

## 2. Boundary Principles

1. **Coordinate, do not legislate.** The lifecycle organises catalogue assessment; it does not create law.
2. **Published specifications only.** Unpublished customs and “main as vocabulary” are hard stops as standards.
3. **Published stages only.** Unpublished CCIL customs are unlawful.
4. **Published catalogue integrity categories only.** Stages apply CCI-01…CCI-07 only.
5. **Published catalogue families only.** Stages classify under CCF-01…CCF-07 only.
6. **Published catalogues only.** Lifecycles without identifiable published catalogues are theatre.
7. **Exactly as published.** Successful progress never rewrites specification meaning or identifier numbering.
8. **Authority first.** Published corpora remain the sole constitutional standard.
9. **Implementation independence.** No stack, vendor, or reference implementation becomes law by proximity to publication.
10. **Published ≠ quality.** Lifecycle publication never grades learning, mastery, readiness, or product success.
11. **Published ≠ renumbered catalogue.** The lifecycle never creates or renumbers identifiers so findings look intact.
12. **Published ≠ new authority.** The lifecycle never elevates Programme XI into foundational law by coordinating others.
13. **No meaning redefinition.** Programme VI–X meanings, EIP claim classes, and CCI / CCF criteria survive coordination intact.
14. **No authority substitution.** A published finding never replaces the corpus for the next judgement.
15. **No catalogue mutation.** Coordination never creates, deletes, renames, renumbers, or soft-amends constitutional catalogue identifiers.
16. **No bypass.** Product urgency never waives constitutional lifecycle requirements.
17. **Repeatability / consistency.** Race-dependent or private stage shortcuts are defects.
18. **Explain the stop.** Students, developers, and auditors should hear when the lifecycle must refuse progress or publication.
19. **No emergency exemption.** Deadlines and demos never mint constitutional amendment power or authority creation via lifecycle publication.
20. **Namespace honesty.** Collisions that confuse vocabulary are reported, not “fixed” by renumbering in situ.
21. **Extensibility honesty.** Growth remains amendment-only; invent-in-place is forbidden.

## 3. What the Lifecycle May Do (Lawful)

| Lawful action | Constitutional meaning |
|---------------|------------------------|
| **Coordinate catalogue assessment** | Organise activities through CCIL-01…CCIL-07 |
| **Validate catalogue structures** | Apply published CCF / CCI / CCIR law to discovered published catalogues |
| **Validate catalogue families** | Classify and confirm membership under CCF-01…CCF-07 at CCIL-02 |
| **Validate namespace separation** | Confirm family / prefix separation and collision honesty at CCIL-03 |
| **Validate identifier consistency / uniqueness** | Confirm CCI-01 / CCI-02 honesty at CCIL-04 |
| **Validate numbering integrity** | Confirm published ranges / succession at CCIL-05 |
| **Validate extensibility posture** | Confirm amendment-only growth rules at CCIL-05 |
| **Identify integrity findings** | Emit intact / violated / deferred / escalated under published criteria |
| **Publish assessment findings** | Communicate findings and records under published honesty rules |
| **Consume constitutional specifications** | Use published Constitution / EIP / Programme VI–XI corpora as assessment standards |
| **Preserve established traceability in records** | Carry established CT-01…CT-07 relationships into assessment records; never invent them |
| **Apply catalogue integrity categories** | Across stages, apply published CCI-01…CCI-07 only |
| **Refuse unlawful progress** | Prefer honest refuse / defer / escalate / violated over improvisation |
| **Remain repeatable and consistent** | Same published inputs → same stage outcomes and dispositions |
| **Remain implementation-neutral** | Honour lifecycle law across lawful equivalent stacks |
| **Support readiness honesty** | Strengthen catalogue-structure honesty without becoming educational readiness or constitutional authority |
| **Explain lifecycle progress** | Answer families / namespace rules / identifier validations / findings / boundaries without rewriting meaning |
| **Propose corpus amendments upstream** | Recommend (not enact) amendments when law itself must change |

These actions **coordinate catalogue assessment**. They do **not** publish a new Constitution, invent coach warrants, mint tips, author ownership maps, invent CCI / CCF / CCIL types, invent CT links, author runtime behaviour, judge educational quality, create catalogue identifiers, renumber catalogues, create constitutional authority, redefine meanings, or amend specifications under coordination pretext.

## 4. What the Lifecycle Must NEVER Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Create catalogue identifiers** | Identifiers are published corpus facts, not lifecycle outputs | Report structure as found; refuse invent-in-place |
| **Renumber constitutional catalogues** | Numbering is published ownership; silent renumbering destroys continuity | Report numbering defects; propose amendment upstream |
| **Redefine catalogue meanings** | Owning corpora alone define what IDs mean | Assess against published meanings; never redefine them |
| **Amend constitutional specifications** | Only corpus governance may amend law | Leave specs unchanged; propose amendment upstream or mark violated / refuse |
| **Create constitutional authority** | Published corpora alone own constitutional meaning | Cite published law only; refuse unpublished standards; never elevate lifecycle progress into authority |
| **Invent catalogue identities** | Discovery organises published catalogues | Refuse-discover when catalogues are missing |
| **Invent family membership** | CCF catalogue is closed under WS2 / MS001 | Classify under CCF-01…CCF-07 only |
| **Invent uniqueness / namespace separation** | Honesty requires real published structure | Refuse-validate when uniqueness or separation cannot be reconstructed |
| **Erase collisions in situ** | Namespace honesty | Report collisions; never renumber under assessment pretence |
| **Invent catalogue integrity categories** | CCI catalogue is closed under WS2 / MS001 | Apply CCI-01…CCI-07 only |
| **Invent lifecycle stages** | CCIL catalogue is closed under this corpus | Apply CCIL-01…CCIL-07 only |
| **Invent traceability** | CT owns lawful lineage | Preserve established relationships in records; refuse invented links |
| **Bypass lifecycle requirements** | Requirements are educational care, not optional polish | Prefer understatement / refuse over invented green |
| **Privilege a technology as constitutional** | Implementation neutrality | Coordinate assessment, not Flask / SQLAlchemy / REST / OpenAPI fashion |
| **Determine educational quality** | No CCIL stage is a quality rubric | Keep coordination speech distinct from quality speech |
| **Determine constitutional truth** | Constitution / EIP own truth | Obey published law; do not adjudicate truth in lifecycle machinery |
| **Transfer authority** | Programme VII WS2 owns ownership, permission, and conflict disposition | Apply Authority corpora; refuse domain absorption via stages |
| **Invent educational state** | Programme VII WS4 owns EST/CST context law | Assess against published postures only |
| **Generate unpublished recommendations** | Programme VII WS3 + Programme VI owners own tip warrant | Surface integrity findings, not new tips |
| **Treat Twin / Adaptive / UI / CI / scanners as constitutional producers** | They are subjects / delivery surfaces | Require published corpus mapping or refuse |
| **Present scores / coverage / acks / scanner greens as constitutional integrity or publication** | Operational proxies are not lifecycle law | Cite published corpora, CCF / CCI types, and CCIL stages |
| **Become irreplaceable by coordination topology** | Replaceability | Keep lifecycle law implementation-independent |
| **Freeze stack authority via publication** | Neutrality / authority preservation | Publish findings; never make the stack the next standard |
| **Replace MS001 catalogue integrity meaning** | CCI / CCF own validation meaning | Sequence assessments; never rewrite CCI / CCF criteria |
| **Replace Programme XI / WS1 CDI / CDIL** | Dependency integrity owns corpus edge structure | Compose with CDI / CDIL; never treat “catalogue intact” as “dependency intact forever” |
| **Replace Programme IX CT** | CT owns lineage | Compose with CT; never treat “linked” as “catalogue intact forever” |

## 6. Boundary Checks (Pre-Publication)

Before a material constitutional catalogue integrity lifecycle is treated as lawfully published, coordination requires affirmative answers:

| Check | Question |
|-------|----------|
| **CCILB-01 Specification / corpus identity** | Are assessment standards published Constitution / EIP / Programme VI–XI corpora (not unpublished customs)? |
| **CCILB-02 Stage class** | Are required CCIL-01…CCIL-07 stages being applied (not unpublished customs)? |
| **CCILB-03 Integrity class** | Are required CCI-01…CCI-07 categories applied (not unpublished customs)? |
| **CCILB-04 Family class** | Are required CCF-01…CCF-07 families applied (not unpublished customs)? |
| **CCILB-05 Catalogue identity** | Which named catalogues / families were assessed? |
| **CCILB-06 Namespace-rule identity** | Which namespace rules / disambiguation tables were applied (none invented)? |
| **CCILB-07 Identifier-validation status** | Which uniqueness / consistency validations were performed (none hidden; none “fixed” by renumbering)? |
| **CCILB-08 Numbering / extensibility status** | Was published numbering and amendment-only growth confirmed or honestly reported violated? |
| **CCILB-09 Finding binding** | Which lifecycle stages produced the catalogue integrity findings (especially CCIL-03…CCIL-06)? |
| **CCILB-10 Record identity** | Which assessment records were preserved? |
| **CCILB-11 Non-identifier-creation** | Does the lifecycle avoid creating catalogue identifiers? |
| **CCILB-12 Non-renumbering** | Were catalogue identifiers left unrenumbered by lifecycle coordination? |
| **CCILB-13 Non-legislation** | Does the lifecycle avoid creating or amending constitutional specifications? |
| **CCILB-14 Non-redefinition** | Does the lifecycle avoid redefining catalogue meanings or Programme VI–X educational / constitutional meaning? |
| **CCILB-15 Non-authority-creation** | Does the lifecycle avoid creating constitutional authority or treating findings as new law? |
| **CCILB-16 Non-substitution** | Does the lifecycle avoid treating the implementation or lifecycle machinery as the next constitutional standard? |
| **CCILB-17 Non-MS001-replacement** | Is publication framed as assessment coordination complete — not a rewrite of CCI / CCF meaning? |
| **CCILB-18 Neutrality / publication ≠ quality / repeatability / audit** | Does the lifecycle avoid privileging a stack as law; frame outcomes as lifecycle coordination / structure integrity — not educational quality; keep stage outcomes reproducible with explainability records preserving families, namespace rules, identifier validations, findings, and boundaries? |

Any failed check → refuse-publish / deferred / escalated / violated as published. Do not “best-effort” invent lifecycle law, invent catalogues, soft-amend specifications, renumber identifiers, create constitutional authority, or replace constitutional authority in situ.
