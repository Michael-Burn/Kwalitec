## 1. Purpose

Assessment that silently becomes a second constitution — renumbering catalogues so scans look unique, inventing identifiers in “findings,” elevating Programme XI into an authorship layer, or treating a preferred labelling topology as the new standard — destroys student trust and educational integrity.

This document draws a bright line between **lawful constitutional catalogue integrity** (Programme XI / WS2 / MS001) and **constitutional authorship / educational judgement / catalogue mutation** (Constitution / EIP / Programmes VI–XI / permitted writers).

---

## 2. Boundary Principles

1. **Validate, do not legislate.** Catalogue integrity measures catalogue consistency; it does not create law.
2. **Published catalogues only.** Unpublished customs and “main as vocabulary” are hard stops as standards.
3. **Published families and integrity categories only.** Unpublished CCF / CCI customs are unlawful.
4. **Named catalogue identities only.** Assessments without identifiable constitutional subjects are theatre.
5. **Exactly as published.** Successful intact status never rewrites specification meaning or identifier numbering.
6. **Authority first.** Published corpora remain the sole constitutional standard.
7. **No identifier mutation.** Findings never create, rename, renumber, delete, or soft-amend catalogue identifiers.
8. **No meaning redefinition.** Catalogue meanings remain with their owning corpora.
9. **No new authority.** Programme XI never becomes foundational law by validating others.
10. **No specification amendment.** Soft-amendment via findings destroys integrity.
11. **Collision honesty.** Overlaps are reported, not “fixed” in situ by renumbering.
12. **Intact ≠ quality.** Catalogue integrity never grades learning, mastery, readiness, or product success.
13. **Implementation independence.** No stack, vendor, or scanner becomes law by proximity.
14. **No bypass.** Product urgency never waives constitutional catalogue integrity requirements.
15. **Repeatability.** Race-dependent dispositions are a defect.
16. **Explain the stop.** Students, developers, and auditors should hear when assessment must refuse intact status.
17. **No emergency exemption.** Deadlines and demos never mint constitutional amendment power via findings.

## 3. What Catalogue Integrity May Do (Lawful)

| Lawful action | Constitutional meaning |
|---------------|------------------------|
| **Analyse catalogue structures** | Inspect published catalogue identities, entries, prefixes, and family membership under CCF-01…CCF-07 |
| **Validate uniqueness** | Confirm identifier uniqueness under CCI-01 / CCIR-01 |
| **Validate consistency** | Confirm one published meaning per ID within namespace under CCI-02 / CCIR-02 |
| **Validate namespace separation** | Confirm family / prefix separation under CCI-03 / CCIR-03 |
| **Detect collisions** | Apply CCI-04 / CCIR-04 and report collision status |
| **Validate numbering integrity** | Confirm published ranges / succession under CCI-05 / CCIR-05 |
| **Validate extensibility posture** | Confirm amendment-only growth rules under CCI-06 / CCIR-06 |
| **Report integrity findings** | Emit intact / violated / deferred / escalated under published criteria |
| **Identify integrity observations** | Name uniqueness, consistency, namespace, collision, numbering, or extensibility defects |
| **Preserve audit records** | Keep reconstructable trails under CCI-07 |
| **Refuse unlawful intact claims** | Prefer honest violated / deferred / escalated over improvisation |
| **Compose required categories** | Apply published CCI / CCF conjunctions without collapsing failed checks |
| **Remain repeatable and neutral** | Same published inputs → same disposition; no stack privilege |
| **Explain catalogue integrity** | Answer families / namespace rules / collisions / findings / boundaries without rewriting meaning |
| **Propose corpus amendments upstream** | Recommend (not enact) amendments when published catalogues themselves must change |

These actions **validate catalogue consistency**. They do **not** publish a new Constitution, invent coach warrants, mint tips, author ownership maps, invent CCI types, amend programme law, rename IDs, renumber catalogues, redefine meanings, or judge educational quality.

## 4. What Catalogue Integrity Must NEVER Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Rename identifiers** | Only catalogue owners may change published IDs | Leave IDs unchanged; report collisions; propose amendment upstream |
| **Alter catalogue numbering** | Silent renumbering destroys continuity and auditability | Leave numbering unchanged; report numbering defects |
| **Create catalogue identifiers** | Integrity is validation, not authorship | Cite published IDs only; refuse invent-in-place |
| **Redefine catalogue meanings** | Meaning owners own claim classes and warrants | Confirm published meaning; never rewrite it in findings |
| **Amend constitutional specifications** | Soft-amendment via findings destroys integrity | Leave specs unchanged; mark violated / deferred / escalated |
| **Create constitutional authority** | Findings are not legislation; Programme XI is not foundational law | Cite published authority only; refuse unpublished standards |
| **Create constitutional law** | Catalogue integrity is validation, not authorship | Cite published law only |
| **Reinterpret constitutional law** | EIP and programme owners own interpretation boundaries | Obey published law; do not reinterpret under catalogue pretext |
| **Substitute constitutional authority** | Published corpora remain the standard after any finding | Keep assessed corpora as subjects, never as next-cycle law |
| **Bypass catalogue integrity requirements** | Requirements are educational care, not optional polish | Prefer understatement / violated over invented green |
| **Privilege a technology as constitutional** | Implementation neutrality | Evaluate catalogues, not Flask / npm / scanner fashion |
| **Determine educational quality** | No CCI is a quality rubric | Keep integrity speech distinct from quality speech |
| **Determine constitutional truth** | Constitution / EIP own truth | Obey published law; do not adjudicate truth in catalogue machinery |
| **Replace Programme IX CT / CC / CV / CCM / CRT** | Distinct governance horizons | Compose; do not conflate or absorb |
| **Replace Programme XI / WS1 CDI** | Distinct assurance horizon | Validate catalogues; never rewrite dependency structure |
| **Replace Programme X execution / decision / audit / explainability** | Distinct activity horizons | Validate catalogues; never execute those activities |
| **Transfer authority** | Programme VII WS2 owns ownership, permission, and conflict disposition | Apply Authority corpora; refuse domain absorption via findings |
| **Invent educational state** | Programme VII WS4 owns EST/CST context law | Evaluate against published postures only |
| **Generate unpublished recommendations** | Programme VII WS3 + Programme VI owners own tip warrant | Surface integrity findings, not new tips |
| **Treat Twin / Adaptive / UI / CI / string scans as constitutional producers** | They are subjects / delivery surfaces | Require published catalogue mapping or refuse |
| **Present scanner greens / grep uniqueness / coverage as constitutional integrity** | Operational proxies are not catalogue law | Cite published corpora and CCI / CCF types |
| **Become irreplaceable by assessment topology** | Replaceability | Keep catalogue law implementation-independent |

## 6. Boundary Checks (Pre-Finding)

Before material constitutional catalogue integrity is treated as established, assessment requires affirmative answers:

| Check | Question |
|-------|----------|
| **CCIB-01 Corpus identity** | Are assessed subjects published Constitution / EIP / Programme VI–XI corpus identities (not unpublished customs)? |
| **CCIB-02 Family class** | Are required CCF-01…CCF-07 families being applied (not unpublished customs)? |
| **CCIB-03 Integrity class** | Are required CCI-01…CCI-07 categories being applied (not unpublished customs)? |
| **CCIB-04 Catalogue identity** | Which named catalogues / identifier sets are under assessment? |
| **CCIB-05 Uniqueness** | Is identifier uniqueness confirmed or honestly reported missing / collided? |
| **CCIB-06 Consistency** | Is one published meaning per ID within namespace confirmed or honestly reported broken? |
| **CCIB-07 Namespace** | Does the assessment preserve published family / prefix separation? |
| **CCIB-08 Collision status** | Have collisions been detected and classified (none / disambiguated / collided / inconclusive)? |
| **CCIB-09 Numbering** | Does numbering remain as published (no silent renumbering)? |
| **CCIB-10 Extensibility** | Are amendment-only growth rules intact (no invent-in-place claims)? |
| **CCIB-11 Non-legislation** | Does the assessment avoid creating constitutional authority or amending specifications? |
| **CCIB-12 Non-mutation** | Does the assessment avoid renaming, renumbering, inventing, or deleting catalogue identifiers? |
| **CCIB-13 Non-redefinition** | Does the assessment avoid redefining catalogue meanings or Programme VI–X / EIP meaning? |
| **CCIB-14 Neutrality / intact ≠ quality** | Does the assessment avoid stack privilege and quality / student-readiness conflation? |
| **CCIB-15 Repeatability / audit** | Is disposition reproducible; will CCI-07 / explainability records preserve families, namespace rules, collisions, findings, and boundaries? |

Any failed check → violated / deferred / escalated. Do not “best-effort” invent catalogue law, renumber identifiers, or soft-amend specifications in situ.
