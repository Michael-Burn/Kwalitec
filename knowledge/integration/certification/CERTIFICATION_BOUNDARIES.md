## 1. Purpose

Assessment that silently becomes a second constitution — rewriting artefacts in “findings,” inventing preferred certification maps, elevating Programme XI into an authorship layer, executing Runtime A under a certified badge, collapsing into Programme IX CRT seals, or treating a deployment gate as the new standard — destroys student trust and educational integrity.

This document draws a bright line between **lawful constitutional corpus certification** (Programme XI / WS7 / MS001) and **constitutional authorship / educational judgement / runtime execution / artefact mutation / implementation certification** (Constitution / EIP / Programmes VI–XI / permitted writers / Programme VIII runtime law / Programme IX CRT).

---

## 2. Boundary Principles

1. **Evaluate evidence, do not legislate.** Certification measures corpus certification status from completed assurance and readiness; it does not create law.
2. **Completed evidence only.** Unpublished “we’re done enough” and invented completion / readiness are hard stops as certified bases.
3. **Published dimensions only.** Unpublished CXCD customs are unlawful.
4. **Named corpus identities only.** Assessments without identifiable constitutional subjects and evidence inputs are theatre.
5. **Exactly as published.** Successful certified status never rewrites specification meaning or assurance / readiness findings.
6. **Authority first.** Published corpora remain the sole constitutional standard.
7. **No artefact mutation.** Findings never create, redefine, reorder, invent, delete, or soft-amend constitutional artefacts.
8. **No meaning rewrite.** Constitutional meaning remains with owning corpora as published.
9. **No new authority.** Programme XI never becomes foundational law by certifying the corpus.
10. **No specification amendment.** Soft-amendment via findings destroys integrity.
11. **No runtime execution.** Certified status never executes, simulates, or ships Runtime A / product behaviour.
12. **No re-authorship of WS1–WS6.** Aggregation consumes completed findings; it never invents intact / ready status they did not publish.
13. **Certified ≠ quality.** Corpus certification never grades learning, mastery, student exam readiness, or product success.
14. **Certified ≠ Programme IX CRT.** Corpus certification never substitutes for Programme IX implementation certification.
15. **Certified ≠ conformity / verification / compliance.** Corpus certification never substitutes for Programme IX determinations.
16. **Implementation independence.** No stack, vendor, or scanner becomes law by proximity.
17. **No bypass of certification requirements.** Product urgency never waives constitutional corpus certification requirements.
18. **Repeatability.** Race-dependent dispositions are a defect.
19. **Explain the stop.** Students, developers, and auditors should hear when assessment must refuse certified status.
20. **No emergency exemption.** Deadlines and demos never mint constitutional amendment power or runtime execution power via findings.

## 3. What Certification May Do (Lawful)

| Lawful action | Constitutional meaning |
|---------------|------------------------|
| **Evaluate certification evidence** | Apply CXCD-01…CXCD-05 to a published certification concern using completed WS1–WS6 evidence |
| **Determine certification status** | Emit certified / not-certified / deferred / escalated under published criteria |
| **Publish certification findings** | Publish findings and certification decisions with reconstructable evidence identity |
| **Record certification findings** | Keep reconstructable trails under CXCI / CXCEQ obligations |
| **Evaluate assurance completeness** | Confirm required WS1–WS5 completion under CXCD-01 |
| **Evaluate runtime readiness achievement** | Confirm WS6 readiness under CXCD-02 |
| **Evaluate architectural coherence** | Confirm coherence under CXCD-03 |
| **Evaluate constitutional consistency** | Confirm consistency under CXCD-04 |
| **Evaluate overall certification status** | Aggregate required dimensions under CXCD-05 |
| **Refuse unlawful certified claims** | Prefer honest not-certified / deferred / escalated over improvisation |
| **Compose required dimensions** | Apply published CXCD conjunctions without collapsing failed checks |
| **Remain repeatable and neutral** | Same published inputs → same disposition; no stack privilege |
| **Explain corpus certification** | Answer workstreams / readiness / prerequisites / status / evidence without rewriting meaning |
| **Propose corpus amendments upstream** | Recommend (not enact) amendments when published law itself must change before certification can be honest |

These actions **evaluate evidence and determine status**. They do **not** publish a new Constitution, invent coach warrants, mint tips, author ownership maps, invent CXCD types, amend programme law, execute Runtime A, modify artefacts, redefine meaning, perform Programme IX CRT recognition, or judge educational quality.

## 4. What Certification Must NEVER Do

| Forbidden action | Why forbidden | Lawful alternative |
|------------------|---------------|--------------------|
| **Create constitutional authority** | Programme XI is assurance / readiness / corpus certification, not foundation | Preserve subordination; refuse overclaim |
| **Modify constitutional artefacts** | Findings are not writers | Propose upstream amendment; refuse certified if law blocks honesty |
| **Redefine constitutional meaning** | Meaning stays with Constitution / EIP / Programmes VI–X / WS1–WS6 | Cite published meaning; escalate conflicts |
| **Execute runtime behaviour** | Certification is evaluation, not Runtime A | Leave execution to Programme VIII implementations after lawful gates |
| **Amend constitutional specifications** | Soft-amendment destroys integrity | Recommend amendment; do not enact via findings |
| **Implement Runtime A / services / adapters** | Out of MS001 scope; not constitutional law | Separate implementation work under published law |
| **Invent unfinished assurance / readiness as complete** | Completeness / readiness honesty is mandatory | Name gaps; not-certified / deferred |
| **Rewrite WS1–WS6 findings** | Aggregation must not become re-authorship | Consume published dispositions as published |
| **Treat certified as student exam readiness** | Orthogonal educational claim | Separate Programme VI / EIP educational speech |
| **Treat certified as Programme IX CRT success** | Programme IX owns *implementation* certification | Compose; do not conflate |
| **Treat certified as conformity / verification / compliance** | Programme IX owns those judgements | Compose; do not conflate |
| **Treat certified as product success** | Quality / delivery remain distinct | Educational Validation Framework / delivery process |
| **Privilege a stack as law** | Implementation neutrality | Speak to constitutional identities only |
| **Skip certification under demo pressure** | Urgency never waives constitutional requirements | Defer / escalate honestly |
| **Hide certification gaps** | Gap honesty is mandatory | Publish gaps with findings |
| **Use CI / CD / GitHub Actions as constitutional proof** | Tool greens are not law | Tools may *assist* evaluation; they never *are* the standard |
| **Collapse Programme VIII runtime law into certification** | Path adjacency under `knowledge/runtime/` must not erase meaning | Compose Programme VIII *how* with CXC *whether certified* |
| **Collapse Programme IX CRT into CXC** | Shared English “certification” must not erase horizon difference | Keep corpus vs implementation certification distinct |

## 5. Boundary Check Catalogue (CXCB)

| ID | Check | Question |
|----|-------|----------|
| **CXCB-01 Evaluate ≠ legislate** | Does the assessment evaluate evidence without creating law? |
| **CXCB-02 Completed evidence only** | Are certified bases limited to identifiable completed WS1–WS6 inputs (or lawful scope-outs)? |
| **CXCB-03 Published dimensions only** | Are only CXCD-01…CXCD-05 applied? |
| **CXCB-04 Named identities** | Are corpus subjects and evidence inputs identifiable? |
| **CXCB-05 No artefact mutation** | Does the path avoid modifying constitutional artefacts? |
| **CXCB-06 No meaning rewrite** | Does published meaning survive evaluation intact? |
| **CXCB-07 No new authority** | Does Programme XI remain subordinate? |
| **CXCB-08 No specification amendment** | Are findings free of soft-amendment? |
| **CXCB-09 No runtime execution** | Does certified status avoid executing / shipping Runtime A? |
| **CXCB-10 No WS1–WS6 re-authorship** | Are completed findings consumed, not rewritten? |
| **CXCB-11 Certified ≠ quality / exam readiness** | Is educational conflation avoided? |
| **CXCB-12 Certified ≠ Programme IX success** | Are conformity / verification / compliance / CRT kept distinct? |
| **CXCB-13 Neutrality** | Is stack privilege avoided? |
| **CXCB-14 Gap honesty** | Are certification gaps named when present? |
| **CXCB-15 Repeatability** | Would identical published inputs yield the same disposition? |
| **CXCB-16 Explain the stop** | Are refusals of certified status speakable? |

Any failed CXCB check voids lawful certified status for the affected concern regardless of CI polish.

## 6. Ownership Separation

| Concern | Owner | Corpus certification role |
|---------|-------|---------------------------|
| Educational truth / meaning | Constitution / EIP / Programme VI | Cite presence; never redefine |
| Orchestration / ownership / tips / context | Programme VII | Cite presence; never redefine |
| Runtime contracts / evidence / services / interfaces | Programme VIII | Never execute or rewrite; certification is not runtime law |
| Conformance / verification / compliance / *implementation* certification / evolution | Programme IX | Preserve lineage; never substitute CXC for those determinations |
| Execution / decision / audit / explainability activity | Programme X | Never execute in their place |
| Dependency / catalogue / boundary / vocabulary / layer integrity | Programme XI WS1–WS5 | Consume completed outcomes; never re-author |
| Runtime readiness | Programme XI WS6 | Consume readiness findings; never re-author or execute |
| Constitutional corpus certification | **This corpus** | Determine corpus certification status from completed evidence |
| Educational quality / mastery / student exam readiness | Programme VI + EIP claim honesty | **Out of CXC scope** |
| Runtime A / product implementation | Delivery / engineering under published law | **Out of CXC scope** — assessed subject, not certification law |
