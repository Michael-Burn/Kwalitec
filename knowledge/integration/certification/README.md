## Purpose

This folder defines **the permanent constitutional mechanism for determining the certification status of the constitutional corpus**.

It answers *what certification must optimise*, *which recognised certification dimensions exist and which evidence they require*, *what certification assessment may and must never do*, and *how constitutional certification is constitutionally explained* — without implementing Runtime A, testing frameworks, CI/CD, creating constitutional authority, modifying constitutional artefacts, executing runtime behaviour, amending constitutional specifications, or elevating certification machinery into a constitutional authority.

It does **not** implement Runtime A, test runners, CI/CD pipelines, GitHub Actions, Python, Flask, SQLAlchemy, REST, OpenAPI, infrastructure, databases, or application services.

> **Constitutional Certification evaluates evidence only.  
> It consumes completed assurance from Workstreams 1–6 and determines the certification status of the constitutional corpus.  
> It never creates constitutional authority, modifies constitutional artefacts, executes runtime behaviour, or amends constitutional specifications.**

## Architectural requirement

Constitutional Certification evaluates only whether **the constitutional corpus is formally certified from completed constitutional assurance and runtime readiness**.

| Lawful | Unlawful |
|--------|----------|
| Evaluate certification evidence | Create constitutional authority |
| Determine certification status | Modify constitutional artefacts |
| Publish certification findings | Redefine constitutional meaning |
| Record certification findings | Execute runtime behaviour |
| Preserve evidence traceability | Amend constitutional specifications |
| Preserve certification repeatability | Freeze a stack as law via “certified” |
| Explain workstreams / readiness / prerequisites / status / evidence | Imply educational success, Programme IX CRT success, or executed Runtime A |
| Consume WS1–WS6 completion honestly | Re-author WS1–WS6 findings under certification pretext |

**Constitutional Certification confirms only that the constitutional corpus is formally certified according to completed constitutional assurance and runtime readiness.  
It never creates constitutional authority, modifies constitutional artefacts, executes runtime behaviour, or amends constitutional specifications.**
