## Purpose

This folder defines **the permanent constitutional lifecycle coordinating dependency integrity assessments** from initiation through discovery, authority validation, cycle detection, layer validation, finding construction, and publication of dependency integrity findings.

It answers *what the lifecycle must optimise*, *which recognised stages organise dependency assessment*, *what the lifecycle may and must never do*, and *how lifecycle progress is constitutionally explained* — without implementing Runtime A, testing frameworks, CI/CD, creating constitutional authority, reinterpreting constitutional law, amending constitutional specifications, modifying constitutional dependencies, or elevating lifecycle machinery into a constitutional authority.

It does **not** implement Runtime A, test runners, CI/CD pipelines, GitHub Actions, Python, Flask, SQLAlchemy, REST, OpenAPI, infrastructure, databases, or application services.

> **The constitutional dependency integrity lifecycle coordinates dependency assessment activities.  
> It validates authority chains, evaluates dependency direction, detects cycles, validates layering, and publishes findings.  
> It never creates constitutional authority, reinterprets law, amends specifications, or modifies dependencies.**

## Architectural requirement

The constitutional dependency integrity lifecycle coordinates **dependency assessment activities**.

| Lawful | Unlawful |
|--------|----------|
| Coordinate dependency assessment through recognised stages | Create constitutional authority |
| Validate dependency relationships under published CDI / CDIR law | Alter / invent / reverse / delete dependency relationships |
| Identify integrity findings | Reinterpret constitutional meaning |
| Publish assessment findings | Amend constitutional specifications |
| Preserve repeatability, neutrality, explainability, auditability | Become constitutional authority |
| Explain dependencies / authority chains / cycles / findings / boundaries | Elevate lifecycle machinery into a constitutional producer |

**The constitutional dependency integrity lifecycle coordinates dependency assessments. It validates corpus structure without altering constitutional law or rewriting dependencies.**
