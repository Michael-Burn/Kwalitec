## 1. Purpose

An expert IFoA tutor who cannot say *which dependency* was checked — which authority chain supported it, whether cycles were detected, what finding resulted, and which limits were preserved — is not coaching; they are performing.

After Programmes VI–X have made meaning, ownership, tips, context, contracts, evidence, runtime, governance, and execution speech speakable, Programme XI still needs one dependency-speech answer:

> **“Which dependency was assessed, which authority chain supports it, were any cycles detected, which integrity findings were produced, and which constitutional boundaries were preserved?”**

That answer must cover every material dependency integrity assessment without inventing educational meaning, transferring authority, minting tips, inventing state, rewriting specifications, mutating edges, freezing a stack as law, inventing unpublished CDI types, or presenting intact status as educational quality or student readiness.

## 2. What Dependency Explainability Is

**Constitutional Dependency Integrity Explainability** is the constitutional obligation to narrate **validation of named constitutional dependencies under published CDI categories** — not to invent a second tutor voice from package scanners, and not to grade the student.

| Concept | Definition | Primary question |
|---------|------------|------------------|
| **Dependency assessed** | Named published corpus identities and the relationship under validation | Which dependency was assessed? |
| **Authority chain** | Reconstructable path from Constitution / EIP through programme layers to the edge | Which authority chain supports it? |
| **Cycle status** | none detected / cycle detected / inconclusive | Were any cycles detected? |
| **Integrity findings** | intact / violated / deferred / escalated (with composition notes) | Which integrity findings were produced? |
| **Boundaries preserved** | Explicit confirmation that forbidden legislation / mutation / reinterpretation / substitution did not occur | Which constitutional boundaries were preserved? |

Dependency Explainability is:

- **validation-centred** — it narrates dependency → authority chain → cycle status → findings under law;
- **catalogue-bound** — every justification cites published CDI identities;
- **corpus-bound** — every justification cites published specifications and edges;
- **non-legislative** — explanation never becomes a back door to amend corpora or rewrite edges;
- **quality-honest** — intact status is never narrated as mastery, readiness, or educational quality;
- **technology-honest** — explanation never presents a stack preference or scanner green as constitutional law;
- **audience-aware** — student speech and developer/auditor traces differ in vocabulary, not in truth;
- **layer-honest** — it does not replace Programme VI tip warrant speech, Programme VII ownership / workflow / state speech, EIP-002 evidence meaning speech, Programme VIII contract / evidence speech, Programme IX governance speech, or Programme X execution / decision / audit / explanation speech;
- **audit-aligned** — explanation components match CDI-07 reconstruction needs;
- **repeatability-honest** — explanations must not paper over race-dependent dispositions.

Dependency Explainability is **not**:

- a rewrite of Constitution / EIP / Programme VI–X meaning;
- a quality report on learning, coaching, or exam readiness;
- a substitute for Programme IX CT explainability or Programme X explainability architecture corpora;
- a rendering system, UI template, CI badge, log shipper, dependency-visualisation product, or analytics dashboard;
- a claim that clear dependency speech guarantees learning or a pass;
- a licence to present package-graph greens, import acyclicity, or pipeline badges as constitutional proof or educational quality;
- a licence to narrate edge rewrites as “integrity repairs.”

## 3. Mandatory Explanation Questions

Every material constitutional dependency integrity assessment should answer all five questions:

### CDIEQ-01 — Which dependency was assessed?

Name the primary published corpus identities and the relationship under validation (for example Programme VIII evidence completion → Programme IX compliance consumption; Programme IX WS4 / MS002 lifecycle → WS4 / MS001 certification types; Programme XI / WS1 / MS001 → Programme VI–X subjects). Unpublished tribal adjacency and “neighbouring folders” are not constitutional dependencies.

### CDIEQ-02 — Which authority chain supports it?

Name the reconstructable authority chain from Constitution / EIP through relevant Programme / workstream / milestone intermediates to the assessed edge. Missing links are defects to disclose — not gaps to invent. “Supported by ticket #1234” or “supported by import edge” is not an authority chain.

### CDIEQ-03 — Were any cycles detected?

Distinguish:

- **None detected** — no closed path among the assessed identities confuses or inverts constitutional authority under published criteria.
- **Cycle detected** — name the cycle path at constitutional identity granularity (not only package names).
- **Inconclusive** — identities or edges incomplete; disposition must be deferred / escalated, not silently intact.

Peer composition that is published as composition is not automatically a cycle; undeclared mutual authorship is.

### CDIEQ-04 — Which integrity findings were produced?

Distinguish:

- **intact** — published relationships satisfy applicable CDI categories and CDIR rules for the assessment scope;
- **violated** — direction, authority chain, acyclicity, layering, or catalogue rules failed;
- **deferred** — lawful pause pending identifiable missing published inputs;
- **escalated** — requires corpus governance / human constitutional review beyond ordinary assessment.

Composition notes must name which CDI-01…CDI-07 categories bound the finding. “Graph looks fine” is not a finding.

### CDIEQ-05 — Which constitutional boundaries were preserved?

Confirm explicitly that the assessment did **not**:

- create constitutional authority or new constitutional law;
- redefine or reinterpret constitutional / educational meaning;
- amend constitutional specifications;
- alter, invent, reverse, or delete constitutional dependencies;
- substitute Programme XI or any assessed corpus for upstream authority;
- narrate intact status as educational quality, mastery, or student exam readiness;
- privilege a technology, scanner, or CI vendor as constitutional law.

Failed boundary confirmation → the explanation is constitutionally defective even if a disposition string exists.

## 4. Audience Projections (One Truth)

| Audience | Vocabulary focus | Must still include |
|----------|------------------|--------------------|
| **Student-facing** | Plain language that the study system’s rules still point the right way and do not chase their own tail | CDIEQ-01…CDIEQ-05 truth; no mastery / pass claims from intact status |
| **Developer-facing** | Corpus paths, CDI IDs, edge orientation, cycle paths, disposition | Same constitutional truth; no stack-as-law narration |
| **Auditor-facing** | Authority chains, CDIR rule IDs, CDI-07 record identity, boundary checklist | Reconstructability; continuity with prior findings |

Projections may simplify vocabulary. They may **not** simplify away cycle status, authority-chain gaps, or boundary failures.

## 5. Explanation Anti-Patterns

| Anti-pattern | Why defective | Lawful alternative |
|--------------|---------------|--------------------|
| “Dependencies are fine because CI is green” | Proxy theatre | Cite CDI categories, corpus identities, and findings |
| “We fixed integrity by reversing the edge” | Mutation under explanation pretext | Report violation; propose upstream amendment |
| “Intact means the student is ready” | Quality conflation | Keep corpus integrity distinct from student readiness |
| “Authority chain is the Jira epic” | Non-constitutional origin | Cite Constitution / EIP / programme paths |
| “No cycles in npm / pip graph” | Wrong subject horizon | Map to published corpus identities or refuse |
| “Programme XI now defines Programme VI” | Authority substitution | Preserve VI meaning; XI validates only |
| “Temporary cycle for the demo” | Emergency exemption | Deferred / escalated / violated — never demo law |
| “Trust us — the graph is obvious” | Opacity | Answer CDIEQ-01…CDIEQ-05 explicitly |
