## Purpose

This folder defines **the permanent constitutional framework governing lawful evolution of the constitutional corpus**.

It answers *what evolution governance must optimise*, *which recognised evolution categories exist*, *what evolution governance may and must never do*, and *how constitutional evolution is constitutionally explained* — without implementing Runtime A, testing frameworks, CI/CD, directly amending constitutional specifications, redefining educational meaning outside lawful amendment processes, replacing constitutional authority, or performing implementation governance.

It does **not** implement Runtime A, test runners, CI/CD pipelines, GitHub Actions, Python, Flask, SQLAlchemy, REST, OpenAPI, infrastructure, or application services.

> **Constitutional evolution governance governs lawful change of the constitutional corpus.  
> It preserves constitutional continuity, integrity, authority, and historical traceability.  
> It never directly amends constitutional specifications.  
> It never replaces constitutional authority.  
> It never governs implementation details.**

## Architectural requirement

Evolution governance defines the **lawful framework for constitutional change**.

| Lawful | Unlawful |
|--------|----------|
| Govern lawful constitutional evolution | Directly amend constitutional specifications under the label “governance” |
| Preserve constitutional history | Alter constitutional history retrospectively |
| Preserve provenance and continuity | Bypass constitutional authority |
| Preserve constitutional integrity and authority | Redefine educational meaning outside lawful amendment processes |
| Preserve governance transparency and explainability | Replace governance workstreams (WS1–WS4) |
| Classify under CEG-01…CEG-07 | Invent unpublished evolution customs |
| Require historical relationship preservation | Redefine implementation behaviour as constitutional law |
| Explain artefacts / category / justification / history / boundaries | Elevate evolution machinery into a silent second constitution |

**Evolution governance preserves constitutional authority rather than replacing it.**

## How to use this corpus

1. Confirm the published constitutional artefacts proposed for evolution exist — refuse evolution theatre against unpublished customs.
2. Confirm a recognised CEG-01…CEG-07 category applies — refuse invented evolution kinds.
3. Read `CONSTITUTIONAL_EVOLUTION_GOVERNANCE_MODEL.md` for stack position and integrity rules.
4. Optimise under `EVOLUTION_OBJECTIVES.md`.
5. Classify under `EVOLUTION_TYPES.md` (CEG-01…CEG-07 only).
6. Enforce hard stops under `EVOLUTION_BOUNDARIES.md`.
7. Require explainability contracts from `EVOLUTION_EXPLAINABILITY.md` before student-, developer-, or auditor-facing evolution narration.
8. Do not implement evolution machinery that contradicts this corpus without amending it first under its own rules.
