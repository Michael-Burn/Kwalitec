## Purpose

This folder defines **the permanent constitutional lifecycle coordinating evolution activities** from proposal through classification, assessment, disposition, provenance recording, publication preparation, and closure.

It answers *what the lifecycle must optimise*, *which recognised stages organise evolution*, *what the lifecycle may and must never do*, and *how lifecycle progress is constitutionally explained* — without implementing Runtime A, testing frameworks, CI/CD, directly amending constitutional specifications, redefining constitutional meaning, replacing constitutional authority, governing implementation behaviour, or elevating lifecycle machinery into a constitutional authority.

It does **not** implement Runtime A, test runners, CI/CD pipelines, GitHub Actions, Python, Flask, SQLAlchemy, REST, OpenAPI, infrastructure, or application services.

> **The constitutional evolution lifecycle coordinates constitutional evolution activities.  
> It consumes evolution governance principles and produces evolution dispositions without directly amending constitutional specifications or replacing constitutional authority.  
> It never becomes constitutional authority.**

## Architectural requirement

The constitutional evolution lifecycle coordinates **constitutional evolution activities**.

| Lawful | Unlawful |
|--------|----------|
| Coordinate evolution through recognised stages | Directly amend constitutional specifications |
| Classify proposals under CEG-01…CEG-07 | Redefine constitutional meaning |
| Consume evolution governance principles | Replace constitutional authority |
| Produce evolution dispositions | Govern implementation details |
| Preserve historical provenance | Become constitutional authority |
| Preserve continuity, transparency, repeatability, explainability | Elevate lifecycle machinery into a constitutional producer |
| Explain artefacts / category / stages / provenance / boundaries | Treat dispositions as silent soft amendments |

**The constitutional evolution lifecycle coordinates lawful constitutional evolution. It governs the process surrounding constitutional change without directly performing constitutional change.**
