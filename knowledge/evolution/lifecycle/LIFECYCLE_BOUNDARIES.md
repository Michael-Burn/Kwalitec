## 1. Purpose

A lifecycle that silently becomes a second constitution — rewriting specs so stages “complete,” inventing educational meaning in “decisions,” licensing runtime redesign under a closed seal, inventing CEG types mid-pipeline, erasing superseded history so today’s product looks always-correct, treating certification seals as amendment authority, replacing WS1–WS4 with evolution theatre, or freezing a preferred stack as next-cycle law — destroys student trust and educational integrity.

This document draws a bright line between **lawful constitutional evolution lifecycle coordination** (Programme IX / WS5 / MS002) and **corpus authorship / educational judgement / runtime authorship / assessment authorship / evolution-type authorship / implementation governance / authority substitution** (Constitution / EIP / Programmes VI–VIII / WS1–WS4 / WS5 MS001 / permitted writers / delivery owners).

---

## 2. Boundary Principles

1. **Coordinate, do not enact.** The lifecycle organises evolution; it does not itself rewrite corpus text.
2. **Published artefacts only.** Unpublished customs and “main as law” are hard stops as evolution subjects.
3. **Published stages only.** Unpublished CEL customs are unlawful.
4. **Published evolution types only.** CEL-02 / CEL-03 apply CEG-01…CEG-07 only.
5. **Governance principles only.** Lifecycles without published WS5 / MS001 principles are theatre.
6. **Exactly as published.** Successful progress never rewrites specification meaning in stage prose.
7. **Authority first.** Published corpora remain the sole constitutional standard.
8. **Implementation independence.** No stack, vendor, or reference implementation becomes law by proximity to closure.
9. **Closed ≠ quality.** Lifecycle closure never grades learning, mastery, readiness, or product success.
10. **Closed ≠ amended.** Closure never itself amends constitutional specifications.
11. **Closed ≠ assessment waiver.** The lifecycle never replaces WS1–WS4.
12. **No redefinition.** Programme VI questions, EIP claim classes, CC / CT / CV / CCM / CRT / CEG meanings survive coordination intact.
13. **No authority substitution.** A closed lifecycle never replaces the corpus for the next judgement.
14. **No implementation governance.** Coordination never redesigns delivery under constitutional colour.
15. **No history rewrite.** Retrospective alteration of constitutional history is a hard stop.
16. **No bypass.** Product urgency never waives constitutional lifecycle requirements.
17. **Repeatability / consistency.** Race-dependent or private stage shortcuts are defects.
18. **Explain the stop.** Students, developers, and auditors should hear when the lifecycle must refuse progress or closure.
19. **No emergency exemption.** Deadlines and demos never mint constitutional amendment power or authority replacement via lifecycle closure.

## 3. What the Lifecycle May Do (Lawful)

| Lawful action | Constitutional meaning |
|---------------|------------------------|
| **Coordinate constitutional evolution** | Organise activities through CEL-01…CEL-07 |
| **Consume evolution governance principles** | Bind named CEG types, CEGO objectives, and WS5 / MS001 boundaries without inventing or rewriting them |
| **Classify proposals** | At CEL-02, apply published CEG-01…CEG-07 only |
| **Assess under published constraints** | At CEL-03, evaluate continuity / integrity / authority / provenance as published |
| **Produce evolution decisions** | Emit permitted / refused / deferred / escalated under published criteria |
| **Preserve provenance** | Keep reconstructable trails of artefacts, category, stages, dispositions, and boundaries |
| **Prepare publication artefacts** | Assemble honest disposition / provenance packages under published honesty rules |
| **Consume constitutional specifications** | Use published Constitution / EIP / Programme VI / VII / VIII / IX corpora as evolution subjects / standards |
| **Preserve established traceability in provenance** | Carry established CT-01…CT-07 relationships into provenance; never invent them |
| **Refuse unlawful progress** | Prefer honest refuse / defer / escalate over improvisation |
| **Remain repeatable and consistent** | Same published inputs → same stage outcomes and dispositions |
| **Remain implementation-neutral** | Honour lifecycle law across lawful equivalent stacks |
| **Support constitutional evolution honesty** | Strengthen change honesty without replacing CEG meaning or becoming constitutional authority |
| **Explain lifecycle progress** | Answer artefacts / category / stages / provenance / boundaries without rewriting meaning |
| **Propose corpus amendments upstream** | Recommend (not enact) textual amendments when a *permitted* disposition later requires writer action |

These actions **coordinate evolution**. They do **not** publish a new Constitution, invent coach warrants, mint tips, author ownership maps, invent CEG or CEL types, invent CT links, author runtime behaviour, judge educational quality, perform verification, determine compliance, mint certifications, or redesign implementations under coordination pretext.

## 4. What the Lifecycle Must NEVER Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Directly amend constitutional specifications** | Only permitted corpus writers under lawful amendment processes may enact text | Leave specs unchanged; disposition may *permit* later writer action — never enact it |
| **Redefine constitutional meaning** | Programme VI and sibling corpora own meaning | Assess against published meaning; never redefine it |
| **Replace constitutional authority** | Published corpora remain the standard after any closure | Keep artefacts as subjects, never as next-cycle law |
| **Govern implementation details** | Evolution coordinates *law* change organisation, not delivery fashion | Refuse implementation redesign under constitutional colour |
| **Create constitutional law** | Decisions and stage progress are not legislation | Cite published law only; refuse unpublished standards |
| **Invent evolution types** | CEG catalogue is closed under WS5 / MS001 | Apply CEG-01…CEG-07 only |
| **Invent lifecycle stages** | CEL catalogue is closed under this corpus | Apply CEL-01…CEL-07 only |
| **Alter constitutional history retrospectively** | EIP-005 / CEGO / CELO continuity | Preserve prior versions; refuse erasure theatre |
| **Bypass constitutional authority** | Authority maps remain binding | Obey published corpora; refuse authority absorption |
| **Replace WS1–WS4 workstreams** | Assessment horizons remain assessment owners | Never narrate closure as waiver of CC / CT / CV / CCM / CRT |
| **Perform verification** | CV owns evidence evaluation | Never narrate closure as a verification re-run |
| **Determine compliance** | CCM owns obligation status | Never narrate closure as compliance determination |
| **Mint certifications** | CRT owns recognition | Never treat seals as evolution authority or lifecycle fulfilment |
| **Invent traceability** | CT owns lawful lineage | Preserve established relationships in provenance; refuse invented links |
| **Privilege a technology as constitutional** | Implementation neutrality | Coordinate evolution organisation, not Flask / SQLAlchemy / REST / OpenAPI fashion |
| **Determine educational quality** | No CEL stage is a quality rubric | Keep coordination speech distinct from quality speech |
| **Determine constitutional truth** | Constitution / EIP own truth | Obey published law; do not adjudicate truth in lifecycle machinery |
| **Transfer authority** | Programme VII WS2 owns ownership, permission, and conflict disposition | Apply Authority corpora; refuse domain absorption via stages |
| **Invent educational state** | Programme VII WS4 owns EST/CST context law | Assess against published postures only |
| **Generate unpublished recommendations** | Programme VII WS3 + Programme VI owners own tip warrant | Surface evolution findings, not new tips |
| **Treat Twin / Adaptive / UI / CI noise as constitutional producers** | They are subjects / delivery surfaces | Require published corpus mapping or refuse |
| **Present scores / coverage / acks / cache hits as constitutional evolution or closure** | Operational proxies are not lifecycle law | Cite published corpora, CEG types, and CEL stages |
| **Become irreplaceable by coordination topology** | Replaceability | Keep lifecycle law implementation-independent |
| **Freeze stack authority via publication or closure** | Neutrality / authority preservation | Publish dispositions; never make the stack the next standard |

## 6. Boundary Checks (Pre-Closure)

Before a material constitutional evolution lifecycle is treated as closed, coordination requires affirmative answers:

| Check | Question |
|-------|----------|
| **CELB-01 Artefact identity** | Are evolution subjects published Constitution / EIP / Programme VI / VII / VIII / IX artefacts (not unpublished customs)? |
| **CELB-02 Stage class** | Are required CEL-01…CEL-07 stages being applied (not unpublished customs)? |
| **CELB-03 Evolution class** | Are required CEG-01…CEG-07 types applied at CEL-02 / CEL-03 (not unpublished customs)? |
| **CELB-04 Governance principles** | Were published WS5 / MS001 evolution governance principles consumed (not invented)? |
| **CELB-05 Decision binding** | Which lifecycle stage produced the evolution decision (especially CEL-03 / CEL-04)? |
| **CELB-06 Provenance identity** | Which historical provenance records were preserved? |
| **CELB-07 Non-enactment** | Does the lifecycle avoid directly amending constitutional specifications? |
| **CELB-08 Non-redefinition** | Does the lifecycle avoid redefining Programme VI educational meaning or sibling constitutional meaning? |
| **CELB-09 Non-substitution** | Does the lifecycle avoid treating the implementation or lifecycle machinery as the next constitutional standard? |
| **CELB-10 Non-implementation-governance** | Is closure framed as evolution coordination complete — not delivery redesign authority? |
| **CELB-11 Non-history-rewrite** | Was constitutional history left unaltered retrospectively? |
| **CELB-12 Non-workstream-replacement** | Is closure framed as evolution coordination complete — not a waiver of WS1–WS4? |
| **CELB-13 Neutrality** | Does the lifecycle avoid privileging a language, framework, protocol, or CI vendor as law? |
| **CELB-14 Closure ≠ quality** | Is the outcome framed as lifecycle coordination — not educational quality? |
| **CELB-15 Spec immutability by lifecycle** | Are constitutional corpora left unchanged by the lifecycle act itself? |
| **CELB-16 Repeatability / audit** | Are stage outcomes reproducible; do explainability records preserve artefacts, category, stages, provenance, and boundaries? |

Any failed check → refuse-close / deferred / escalated / refused as published. Do not “best-effort” invent lifecycle law, soft-amend specifications, erase history, redesign implementations, or replace constitutional authority in situ.
