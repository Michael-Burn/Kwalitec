## Purpose

Catalogue **reusable Study Sensei phrases** for common learner-facing moments.

These are **patterns and defaults**, not a mandate to hard-code strings outside existing registries. Adaptive Assessment production copy remains owned by `copy_registry` / ILE-001A. Implementation programmes should converge toward this voice when adding or revising copy.

Placeholders use `{braces}`.

## Mission

| Intent | Phrase |
|---|---|
| Today’s focus | “Today’s Mission focuses on {topic}.” |
| Why | “It’s the highest-value next step given your plan and recent evidence.” |
| Duration honesty | “About {n} minutes within your available time.” |
| Start | “Start Mission” / “Continue Mission” |
| Complete | “Mission complete — evidence from today’s loop is recorded.” |
| Incomplete | “Mission paused. You can return to the same focus when ready.” |
| Protect mid-focus | “No extra tip right now — your Mission is the focus.” |

## Tutor

Tutor narration **explains authorised decisions**; it does not invent ranking or mastery.

| Intent | Phrase |
|---|---|
| Frame | “Here’s why this focus now.” |
| Arc opener | “We observed {observation}.” |
| Meaning | “For your syllabus position, that means {meaning}.” |
| Action | “So the suggested step is {action}.” |
| Benefit | “That should help {benefit}.” |
| Uncertainty | “We’re still unsure about {gap}.” |
| Scope | “I can explain the guidance — I don’t replace your textbooks or tutor.” |
| Refuse invent | “I don’t have enough to guide further on that yet.” |

## Readiness

| Intent | Phrase |
|---|---|
| Estimated label | “Estimated readiness (provisional).” |
| Basis | “Based on recorded practice and syllabus progress.” |
| Non-guarantee | “This guides what to study next. It does not predict your result.” |
| Unavailable | “Estimated readiness isn’t available yet — more practice evidence is needed.” |
| Implication | “Evidence supports focusing on {topic} to strengthen preparation.” |

Never: “You will pass” / “Exam ready” as guarantee.

## Revision

| Intent | Phrase |
|---|---|
| Warrant | “Revision on {topic} is warranted — recent practice looks fragile.” |
| Spacing | “It’s been a while since you practised {topic} — a short revisit will test durability.” |
| Exam proximity (calm) | “With the exam date closer, reinforcing covered, high-weight topics is useful.” |
| Not theatrical | Avoid “cram everything now” panic. |
| Never unstudied “revision” | Do not label first-touch learning as revision. |

## Confidence

| Intent | Phrase |
|---|---|
| System limited | “Evidence is limited.” |
| System mixed | “Evidence is mixed.” |
| System stronger | “Evidence is stronger here.” |
| Emerging tip | “Early signals suggest… — still provisional.” |
| Reliable tip | “Evidence supports this as the next step.” |
| High tip | “This should be today’s focus.” |
| Student prompt (optional) | “How sure do you feel about this?” — skip without penalty |

Avoid pseudo-precise confidence percentages for tips.

## Usage rules

1. Prefer library phrases over inventing a new personality per feature.  
2. Adapt placeholders; keep tone attributes (calm, precise, warm).  
3. Do not paste challenge language into encouragement slots or vice versa.  
4. Production AA strings: update via copy registry, then keep this library in sync as patterns.  
5. When in doubt, shorten — then add why.
