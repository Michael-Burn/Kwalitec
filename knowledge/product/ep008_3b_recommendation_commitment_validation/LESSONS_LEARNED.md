# EP-008.3B — Lessons Learned

**Programme:** EP-008.3B — Recommendation Commitment Validation (Tier B)  
**Date:** 2026-07-26  

---

## 1. Student value

1. **Execution chrome can be educational without new ranking.** Commit / defer / reflection / history improved perceived agency and continuity while Runtime A and RecommendationService maths stayed frozen.  
2. **Honesty is the commitment product.** Near-universal preference for calm defer over fake Start — shame UX would have falsified H2.  
3. **Pattern A trades explicitness for load.** Single Start Session protects DR-050 and H5; it also leaves a soft-agency residual some students name as click-through risk.  
4. **Reflection closes “what next” more reliably than “what changed.”** Continuity lines carry more meaning than thin review-point reuse.  
5. **Perception ≠ follow-through.** Tier B can clear H1–H3 without proving completion rates — Strong-band K2 still requires observational floors.

---

## 2. Measurement

1. Prefer-lower correctly **held K2 at 68** despite positive agency themes — VALIDATION_PLAN §6 rate requirement is load-bearing.  
2. Continuity / History themes justified a small **K7 +2** without inventing revision-engine claims.  
3. Instrumentation-live is necessary but not sufficient; dogfood checklist Pass ≠ rate baseline.  
4. Commitment-focused cohort (motivation / load / bounded-commitment personas) complements the trust pack without overwriting it.
