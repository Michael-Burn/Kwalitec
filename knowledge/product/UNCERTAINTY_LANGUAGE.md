---

## Purpose

Standardise **how the Study Sensei talks about uncertainty** so claim strength always matches evidence strength — without fake precision or engineering jargon.

---

## Hard rules

1. **Never expose internal confidence mathematics** or raw model scores.  
2. **Avoid percentages** unless educationally valuable **and** honestly labelled (e.g. syllabus coverage as Derived Fact). Do not invent “73% sure” theatre.  
3. Prefer **qualitative bands** aligned to ILE-011: Insufficient → Observation only → Emerging → Reliable → High.  
4. Uncertainty language is **protective**, not apologetic theatre — short and actionable.  
5. If Kwalitec cannot admit uncertainty, it must not speak as if certain.

---

## Standard phrases by situation

### Insufficient evidence

Use when guidance cannot be warranted.

| Intent | Phrase patterns |
|---|---|
| No primary tip | “We don’t have enough yet to recommend a focus.” |
| Orient | “Not enough evidence yet.” |
| Path forward | “Let’s gather a little more information.” |
| Specific gap | “We haven’t seen much from you on this yet.” |

**Avoid:** Filling the void with speculative tips; “We’re highly confident…” with empty data.

---

### Observation only

Use while lawful instruments are still collecting; interpretation would overclaim.

| Intent | Phrase patterns |
|---|---|
| Protect the loop | “Finish this check — then we can update what we know.” |
| Neutral status | “We’re still gathering evidence.” |
| Partial session | “This check wasn’t finished, so evidence is partial.” |

**Avoid:** Readiness grades, revision urgency, or ranking claims mid-collection.

---

### Emerging confidence

Use for soft, provisional guidance.

| Intent | Phrase patterns |
|---|---|
| Soft tip | “Early signals suggest this may be a useful focus — still provisional.” |
| Label uncertainty | “Evidence is limited; treat this as a gentle suggestion.” |
| Strengthen path | “A short check after practice would strengthen what we know.” |
| Close alternatives | “A few paths look reasonable; which constraint matters most today?” |

**Avoid:** “Strongly recommend”; firm commands; fake single-winner precision.

---

### Reliable guidance

Use for a primary explainable recommendation.

| Intent | Phrase patterns |
|---|---|
| Primary tip | “Today’s focus is … because …” |
| Bounded certainty | “Evidence supports this as the next step. Here’s what could change that.” |
| Uncertainty tail | “We still have limited Deep Check evidence on …” |

Reliable ≠ certain. Keep a brief uncertainty clause when anything material remains provisional.

---

### High confidence

Use sparingly when multiple consistent observations agree.

| Intent | Phrase patterns |
|---|---|
| Firm focus | “This should be today’s focus.” |
| Still honest | “Several recent signals point the same way. It still isn’t a guarantee of exam outcome.” |

**Never** authorised: pass/fail destiny, career decisions, booking commands.

---

### Conflicting evidence

| Intent | Phrase patterns |
|---|---|
| Name conflict | “Recent answers point in different directions.” |
| Refuse fake precision | “We won’t pretend this is settled.” |
| Resolve | “A clarifying check can resolve mixed signals.” / “Study this idea, then check again.” |

---

### Need more observation

| Intent | Phrase patterns |
|---|---|
| Invite evidence | “We need a little more observation before guiding further.” |
| Stale evidence | “It’s been a while — this may have faded.” |
| Assisted success | “Hints were used — we’ll treat this carefully.” |
| Single check | “One check isn’t enough to call this solid.” |

## Percentages — when allowed

| Allowed | Conditions |
|---|---|
| Syllabus coverage % | Derived Fact; explain basis; not readiness |
| Estimated Knowledge / readiness % (if product shows them) | Label **Estimated**; provisional; non-guarantee line |
| Practice accuracy from recorded results | State calculated from recorded practice; not identity |

| Disallowed | Why |
|---|---|
| “87% confident in this tip” | Fake precision |
| Unlabelled mastery % as fact | Overclaim |
| Green “100% ready” from formative checks | Guarantee theatre |

Prefer words + ordinal cues (“limited / mixed / stronger evidence”) when a number adds no educational value.

---

## Mapping to confidence levels (quick)

| Level | Default speech |
|---|---|
| Insufficient | Silence or insufficient phrases |
| Observation only | Neutral gathering phrases |
| Emerging | Soft / provisional phrases |
| Reliable | Primary tip + brief uncertainty |
| High | Firm tip + still no outcome guarantee |

---

## Emotional register

| Context | Tone |
|---|---|
| Early sitting / thin data | Orient and invite — never invent competence |
| Conflict | Matter-of-fact; not alarming |
| Pre-exam | Honest and bounded — no false reassurance |
| Overconfidence discovery | Protective calibration — not “gotcha” |

---

## Checklist

1. Phrase matches evidence level?  
2. Percentage necessary and labelled?  
3. Path to reduce uncertainty included when useful?  
4. Implementation jargon absent?
