# Founder User Guide — Curriculum Studio

**Programme:** PR-001A  
**Who this is for:** Founders publishing subjects without developer help  

---

## What Curriculum Studio is

Curriculum Studio is the Command Centre workflow for turning official syllabus materials into a **published curriculum** students can study against.

You will:

1. Create a subject.
2. Open a workspace.
3. Attach CMP and syllabus references.
4. Validate and review.
5. Approve and publish.

## Before you start

- You can sign in with a founder-authorised account.
- You have CMP and official syllabus **references** ready (paths/URIs your organisation uses — not PDF file contents pasted into the form).
- You know the subject code you want students to recognise (example: `CS1`).

## Step-by-step

### 1. Sign in

Open Kwalitec → Log in → Command Centre → **Curriculum Studio**.

### 2. Create a subject

1. Under **Create Subject**, enter the subject code.
2. Optionally add a display title.
3. Click **Create Subject**.
4. Confirm the success message.

If the code already exists, open the existing workspace instead of creating a duplicate.

### 3. Open a workspace

1. Under **Open Workspace**, enter the same subject code.
2. Click **Open Workspace**.
3. Read the **Next step** panel — it tells you what to do now.

### 4. Assign a version

1. In **Version history**, enter a label such as `2027.1` or `1.0.0`.
2. Click **Assign Version**.
3. Keep labels unique per material change.

### 5. Upload sources

1. Enter a **CMP reference**.
2. Enter a **Syllabus reference**.
3. Click **Upload Sources**.

Do not paste raw PDF bytes. References only.

### 6. Validate

1. Click **Validate Curriculum**.
2. Check the Validation readiness card.
3. If **Validation findings** appear, read each:
   - what is wrong,
   - why it matters for students,
   - what to do next.
4. Fix sources and validate again until findings are clear (or only acceptable warnings remain).

### 7. Preview and approve

1. Click **Build Preview**.
2. Review the readiness summary.
3. Optionally add an approval note.
4. Click **Approve Curriculum**.

### 8. Publish

1. Confirm checklist readiness.
2. Click **Publish Curriculum**.
3. Confirm the success message.

### 9. Verify availability

Return to the Studio dashboard. **Published** count should increase. The subject/version is now the published authority for students on the Runtime C / published-package path.

## Everyday tips

- Follow **Next step** — primary buttons highlight the recommended action for the current stage.
- Prefer one workspace per subject.
- Never reuse a published version label for a different curriculum.
