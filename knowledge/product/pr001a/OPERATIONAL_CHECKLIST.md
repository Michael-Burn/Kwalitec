# Operational Checklist — Founder Publishing

**Programme:** PR-001A  
**Use:** Print or keep open while publishing a subject  

---

## Pre-flight

- [ ] Founder account can open Command Centre
- [ ] Subject code agreed
- [ ] CMP reference ready
- [ ] Syllabus reference ready
- [ ] Version label chosen (unique)

## Create & open

- [ ] Create Subject (or confirm existing)
- [ ] Open Workspace
- [ ] Confirm **Next step** panel is visible

## Sources & version

- [ ] Assign Version
- [ ] Upload CMP reference
- [ ] Upload syllabus reference
- [ ] Success flash for sources

## Validate & review

- [ ] Run Validate Curriculum
- [ ] No blocking findings remain
- [ ] Build Preview
- [ ] Structure looks correct vs official syllabus
- [ ] Approve Curriculum

## Publish & verify

- [ ] Checklist shows ready (or acceptable remaining items understood)
- [ ] Publish Curriculum
- [ ] Success flash received
- [ ] Dashboard published count / version history updated
- [ ] Subject available on published authority path

## If anything failed

- [ ] Read flash warning (issue → why → recovery)
- [ ] Read Validation findings panel if present
- [ ] Apply recovery from [Troubleshooting Guide](TROUBLESHOOTING_GUIDE.md)
- [ ] Re-run the failed step
- [ ] Escalate to platform support only if service-unavailable persists
