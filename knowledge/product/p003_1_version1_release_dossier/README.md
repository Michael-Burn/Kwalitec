# P-003.1 — Version 1 Release Dossier

**Programme:** P-003.1 — Version 1 Release Dossier  
**Status:** Complete — documentation and governance only  
**Date:** 2026-07-26  
**Audience:** Product Board  
**Authority:** Board-level release reference (does not amend constitutions or declare Version 1)

This folder is the **definitive board-level release dossier** for Kwalitec Version 1. It summarises the programme from inception to the current evidence state so a board member unfamiliar with the repository can understand what Kwalitec is, what has been validated, what has not, and why Version 1 has not yet been declared production-ready.

**This programme does not implement features.** Runtime code, educational reasoning, Runtime A, recommendations, planning, readiness, UI, and services were intentionally untouched.

## Board recommendation (evidence-bound)

# NO GO

Version 1 **production-ready** declaration is **not** permitted under P-002.1 while Gate **G1 FAIL** (validated KSI **62** &lt; 80; educational effectiveness **NO-GO / PENDING EVIDENCE** / G1.9 **FAIL**) and the full G1–G12 evidence package remains incomplete.

Full rationale: [`Version_1_RELEASE_DOSSIER.md`](Version_1_RELEASE_DOSSIER.md) §11.
