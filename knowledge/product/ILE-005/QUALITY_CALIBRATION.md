# Quality Calibration

**Programme:** ILE-005 — Educational Feedback Loop  

---

## Purpose

Describe how Sensei self-reflection improves **educational quality governance** without becoming a second recommendation authority.

---

## Calibration loop

```
Significant recommendation (journal)
    → learner response / outcome
    → optional student reflection
    → evidence quality band
    → recommendation review state
    → Sensei educational review record
    → future learning note (governance only)
```

Calibration is about honesty and usefulness — not optimisation for engagement.

---

## Sensei educational review record

| Field | Role |
|---|---|
| Observation | What was seen at recommendation time |
| Original recommendation | Guidance offered (immutable snapshot reference) |
| Later evidence | Outcome, reflection, appended evidence |
| Educational assessment | Review-state rationale in calm language |
| Future learning | What governance should remember next time |
| Review state / evidence quality | Structured calibration labels |
| `learner_visible=false` | Hard invariant — never student UI |

---

## Lawful uses of future learning

- Prefer clearer timing or explainability on similar future guidance
- Keep confidence humble when evidence was insufficient
- Remember that support does not licence overclaim

## Unlawful uses

- Auto-rewriting ranking weights from engagement
- Silent Twin mutation
- Hiding honest refusal behind “calibration”
- Surfacing governance language as learner scores

---

## Relationship to KSI

| Category | Intended contribution |
|---|---|
| K1 Learning / metacognition | Optional reflection invites professional judgement |
| K2 Recommendation quality | Outcome review without changing selection |
| K8 Explainability / trust | Humble, evidence-bound assessment language |

Deltas remain **estimated** until cohort validation.

---

## Quality bar

A calibration episode is successful when the Study Sensei can state — from journal evidence — whether guidance was useful, partially useful, inconclusive, insufficient, or still awaiting observation — **without** compromising learner agency or educational honesty.
