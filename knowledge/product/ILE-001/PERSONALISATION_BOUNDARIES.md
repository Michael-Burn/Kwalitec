# Personalisation Boundaries — Adaptive Assessment

**Programme:** ILE-001 — Adaptive Assessment Experience  
**Version:** 1.0  
**Status:** Design  
**Effective:** 2026-07-28  

---

## Purpose

State clearly **what Adaptive Assessment personalises** and **what it deliberately does not**, to protect fairness, predictability, and educational honesty.

Personalisation adapts *within* lawful curriculum and deterministic educational rules. It does not invent a private syllabus or an opaque “AI that knows you.”

---

## Guiding constraints

From ILE-000 / Constitution:

- Curriculum first  
- Evidence before inference  
- Deterministic cores  
- One educational truth  
- Student trust first  
- Never optimise engagement over learning  

---

## What Kwalitec personalises

| Dimension | Personalised how | Bound by |
|---|---|---|
| **Whether a check appears** | Mission eligibility from Twin need, density, pacing | Burnout / over-assessment gates |
| **Why the check exists** | Intent from Educational State (thin, conflict, revision due, …) | Explainable intents only |
| **Session type** | Quick / Deep / Recovery / Confidence / Revision / Readiness | Time budget + journey |
| **Syllabus focus** | Objectives tied to plan position, gaps, revision due | Official curriculum identity |
| **Confirmation vs exploration mix** | Policy based on intent and evidence density | `QUESTION_SELECTION_POLICY.md` |
| **Length / early stop** | Fit available study time; stop when intent met | Mission duration realism |
| **Feedback narrative** | Evidence themes + decided next action for *this* student | Reasoning / Twin outputs; Tutor narrates only |
| **Confidence prompts** | Shown when calibration intent warrants | Optional; non-forced |
| **Recovery after gap** | Gentle Recovery Check vs aggressive batteries | Motivation + honesty |
| **Deferral** | Allow skip/defer when policy permits | Mission still offers a lawful Next |

Personalisation must remain **reproducible**: same educational inputs → same session construction decisions.

---

## What Kwalitec deliberately does not personalise

| Non-personalised | Rationale |
|---|---|
| **Official syllabus structure** | No private reordering that invents a new curriculum |
| **Educational law / Constitution** | Same honesty rules for every student |
| **Authority boundaries** | Assessment never becomes a second Twin; Tutor never grades |
| **Pass/fail identity scores** | No personalised “grade culture” |
| **Peer comparison / ranking** | Fairness and motivation; not a social product |
| **Engagement dark patterns** | No personalised notification pressure or FOMO quizzes |
| **Random difficulty punishment** | Predictability and trust |
| **Demographic / stereotype inference** | Evidence before inference; no profiling theatre |
| **Hidden LLM item authority** | Deterministic cores; explainability |
| **Marketing claims per persona** | Educational honesty is universal |
| **Shadow recommendations** | Home remains one story |
| **Mastery language beyond Twin support** | Never overstate confidence |
| **High-stakes exam simulation defaults** | Separate consented programme if ever built |

## Fairness and predictability

Students should be able to form a stable mental model:

> “When Kwalitec is unsure about me on a topic, it may offer a framed learning check. It will explain why. It will not surprise-test me or rank me.”

| Fairness rule | Meaning |
|---|---|
| **Same rules** | Selection policy and honesty language do not secretly differ by “engagement cohort” |
| **Explainable difference** | If two students see different checks, the difference traces to educational evidence / plan state, not opaque scores |
| **Appeal to understanding** | Student can understand why *their* check appeared |
| **No trap variance** | Item “gotcha” culture is not a personalisation lever |

## Personal Learning Profile boundary

Where a Personal Learning Profile exists (EP-004 family), Adaptive Assessment may use **declared preferences** only within these limits:

| Allowed | Not allowed |
|---|---|
| Prefer shorter checks when time preference is low | Override Twin uncertainty honesty to “feel nicer” |
| Prefer fewer confidence prompts if anxiety preference set | Disable evidence collection required for safe guidance |
| Presentation comfort (pace of chrome) | Different mastery standards or softer educational law |

Profile never outranks curriculum identity or Reasoning conclusions.

## Commercial and cohort boundaries

| Context | Rule |
|---|---|
| Free vs paid | Monetise depth/integrity of experience — not harsher or softer educational truth |
| Institution / mentor views (future ILE-007) | Same Educational State; no dual assessment truth |
| Founder analytics | Evidence-density health — never student league tables |

---

## Decision test

Before adding a personalisation:

1. Does it reduce decisions and increase learning?  
2. Can we explain it in one student sentence?  
3. Does it preserve fairness and predictability?  
4. Does it avoid engagement-at-all-costs?  
5. Does it leave authorities unchanged (observe → reason → Twin → mission → tutor)?  

If any answer is no, do not ship it.
