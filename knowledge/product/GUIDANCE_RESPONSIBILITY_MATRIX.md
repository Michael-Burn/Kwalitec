# Guidance Responsibility Matrix

**Programme:** ILE-011 — Student Decision Framework  
**Version:** 1.0  
**Status:** Active — permanent responsibility classification  
**Effective:** 2026-07-28  
**Companion:** [`STUDENT_DECISION_FRAMEWORK.md`](STUDENT_DECISION_FRAMEWORK.md), [`DECISION_CATALOGUE.md`](DECISION_CATALOGUE.md)  

---

## Purpose

Classify every major learner decision by **how far Kwalitec may go** as Study Sensei.

This matrix makes boundaries explicit so future capabilities cannot quietly expand into decisions the product must never own.

---

## Responsibility classes

| Class | Meaning | Product behaviour |
|---|---|---|
| **Student only** | Learner decides entirely; Sensei does not recommend a choice | Provide neutral tools/context at most; prefer silence on the *choice* |
| **Sensei recommends** | Sensei may propose a lawful next action; student freely accepts/defers/dismisses | Single explainable recommendation when confidence allows |
| **Sensei strongly recommends** | Evidence and stakes warrant firm, calm urgency — still not a command | Strong language allowed (“this should be today’s focus”) with full explainability; dismissal still respected |
| **Sensei never decides** | Outside educational responsibility or high-stakes personal agency | Do not choose, book, diagnose, or prescribe outcomes |

**Shared responsibility** (from the Framework) maps primarily to **Sensei recommends** or **Sensei strongly recommends**, with the student always owning the final act.

## Illustrative examples (product language)

| Situation | Class | Why |
|---|---|---|
| Exam booking | **Student only** / **Sensei never decides** | High-stakes administration; Kwalitec is not the exam body |
| Topic revision order | **Sensei recommends** | Core Sensei craft; evidence + weights + spacing |
| Career decisions | **Sensei never decides** | Outside educational responsibility |
| Daily Mission | **Sensei recommends** (often strongly) — **shared responsibility** | Sensei proposes; student owns execution |
| Pass/fail guarantee | **Sensei never decides** | Honesty forbids outcome guarantees |
| Shorten today’s session under overload | **Sensei strongly recommends** | Trust requires protecting sustainable intensity |
| Accept or dismiss a tip | **Student only** | Agency preserved; journal records choice |

---

## Escalation rules

1. **Never upgrade class silently.** A feature must not move a decision from “recommends” to “decides.”
2. **Strongly recommend** requires Reliable confidence or higher, plus explainability (see Confidence Model).
3. **Student only** and **Sensei never decides** default to silence on the *choice*, even if educational context is shown nearby.
4. When in doubt, classify **down** (more student ownership), not up.
