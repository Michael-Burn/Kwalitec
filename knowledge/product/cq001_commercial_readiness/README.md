## Purpose

From this point onwards, **all Version 1 work must optimise the Commercial Readiness Index (CRI)**.

CQ-001 establishes:

- the permanent **Commercial Readiness Framework** (CRI domains, weights, scoring, priority order);
- a **baseline CRI of 43%** (provisional domain board);
- the living **Commercial Readiness Board**;
- Version 1 intake / deferral rules (non-CRI work → Version 2 backlog);
- milestone tag discipline (`cri-45` … `v1.0.0`).

**CRI does not replace Vision 2030, KSI, or P-002.1 gates.** It is the operational index that asks whether the founder can trust Kwalitec as a **premium daily study operating system** worth running every day — and whether Version 1 scope is commercially ready enough to keep investing.
