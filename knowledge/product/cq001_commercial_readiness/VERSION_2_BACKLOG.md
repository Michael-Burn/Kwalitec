# Version 2 Backlog (CRI deferrals)

**Programme:** CQ-001 — Commercial Readiness First  
**Status:** Active — living deferral register  
**Rule:** If a Version 1 task does **not** measurably improve current CRI, record it here and do not start it as V1 work.  
**Exception:** Version 2 capabilities may enter V1 only when they **directly** improve current CRI (document intake + Founder Review).

---

## 1. Purpose

Protect Version 1 scope discipline. Interesting, strategic, or architecturally elegant work that does not raise CRI waits here until:

- a higher-priority CRI domain is Strong enough to skip down the priority ladder, **or**
- the item is explicitly shown to raise current CRI, **or**
- Version 1 commercial thresholds no longer require capacity.

## 3. Intake → backlog workflow

1. Fill [`TASK_INTAKE_TEMPLATE.md`](TASK_INTAKE_TEMPLATE.md).  
2. If expected ΔCRI is **none / not measurable** → add row here; stop.  
3. If ΔCRI measurable but domain is below current priority target → schedule after higher domains unless Founder Review authorises.  
4. If item claims “direct CRI improvement via V2 capability” → Founder Review before start; cite domains and evidence plan.
