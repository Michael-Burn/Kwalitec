---

## 1. Purpose

Rank experience issues that keep validated KSI at **59** (gap **21** to ≥80) by:

1. Estimated **validated** KSI impact (not optimistic estimate stacks)  
2. Implementation effort  
3. Evidence confidence  

Produce a **Version 1 Gate G1 remediation strategy** that Product can execute as subsequent programmes.

---

## 2. Scoring rubric used here

| Dimension | Scale |
|---|---|
| Est. validated KSI impact | H ≥ +2.0 / M +0.8–1.9 / L &lt; +0.8 composite points if successful |
| Effort | S (≤1 focused programme) / M (1–2 programmes or cross-surface) / L (multi-programme / cohort ops) |
| Evidence confidence | High / Medium / Low that the issue is real and the fix would help |
| Priority score | Impact×Confidence first; then prefer lower effort; constitutional safety always gates |

### 5.2 Phased path (recommended)

```
Phase A — Inspectability & single path (unblocks G1.5 trajectory)
  REM-01 MES rendering
  REM-02 one home/start
  REM-03 one duration
  REM-05 readiness drivers (can parallelise with REM-01)
        ↓
Phase B — Prove perception (makes lifts validated)
  REM-04 Tier B blind re-review / interviews
  Re-run validated KSI (successor to EP-005.1)
        ↓
Phase C — Trust & measurement
  REM-06 recommendation trust + acceptance instrumentation (approved PRD)
  REM-07 Stage 1 cohort / M1–M9 (clears G1.9 trajectory)
        ↓
Phase D — Activate gated value carefully
  REM-08 dogfood → soak → intentional G12 defaults
  REM-09 / REM-10 / REM-11 portfolio fillers toward ≥80
        ↓
Phase E — Declaration hygiene
  REM-12 second assessor
  Full P-002.1 package G2–G12 (out of scope here but mandatory for production-ready)
```

### 5.3 Success thresholds (validated, not estimated)

| Milestone | Validated signal | Still not allowed |
|---|---|---|
| A done | Dogfood: why visible without expand on Home/Mission; no dual duration on smoke pack | Claiming K8 ≥ 70 |
| B done | Tier B clears Coach opacity theme; re-validated K8 ≥ 70; K1/K2/K3 non-regression | Claiming KSI ≥ 80 |
| C done | Acceptance KPI under PRD; Stage 1 scorecard directional | Effectiveness marketing without O8 lift |
| D done | W-GATED personalisation validated then promoted only with flag matrix | Silent default ON |
| G1 PASS | KSI ≥ 80; K8 ≥ 70; no category &lt; 50; G1.9 cleared; confidence Med/High | Skipping G2–G12 for “production-ready” |

### 5.4 Ordering rule (PSF §8.1)

Prefer remediations that raise the **lowest material blockers** first: **K8 floor (G1.5)**, then large-weight weak pillars (**K2**, then **K3/K4/K6**), while fixing K1 experiential caps that already have Partial credit.
