# Recommendation Quality Standard

**Programme:** P-001.3 — Recommendation Quality Standard  
**Version:** 1.0  
**Status:** Active — permanent product quality authority for student-facing recommendations  
**Effective:** 2026-07-26  
**Authority:** Product recommendation-quality law  
**Does not:** Change runtime behaviour, Twin algorithms, UI, or APIs  

---

## 1. Purpose

This standard defines **what constitutes a high-quality student-facing recommendation** in Kwalitec.

It exists so that:

- recommendation usefulness is judged by educational value, not tip volume or engagement;
- competing guidance can be prioritised with a shared decision frame;
- every recommendation change can be reviewed against one permanent quality contract;
- Version 1 can close the K2 Recommendation usefulness gap (baseline **48** → immediate floor **≥ 50**, then **≥ 70**).

**Recommendation quality maximises educational usefulness of guidance already lawfully authorised.  
It never invents educational meaning, mastery, or a second educational brain.**

---

## 2. Product objectives

Recommendation quality serves learning, not theatre.

| Objective | Student outcome |
|---|---|
| Right next action | The student knows the highest-value lawful thing to do *now* within scarce study time. |
| Educational usefulness | Following the recommendation improves coverage, weak-topic repair, revision timing, readiness honesty, or recovery — not vanity activity. |
| Trustworthy prioritisation | When multiple tips compete, the winner is proportionate, evidence-backed, and non-conflicting with Learning Mode / Today’s Mission. |
| Honest confidence | Thin evidence produces humble suggestions or lawful refusal — never fabricated certainty. |
| Explainable acceptance | Students can accept, defer, or reject guidance with enough context (via the Explainability Standard). |
| Measurable improvement | Quality is scoreable (precision, acceptance, completion, effectiveness, satisfaction, explainability compliance) so K2 can move with evidence. |

**Final Test alignment:** Recommendations that help students become better professionals pass. Recommendations that inflate confidence, invent certainty, overwhelm with low-value tips, or fight the authorised plan fail.

## 4. Relationship to Explainability Standard

| Concern | Owner |
|---|---|
| Is this the right recommendation / priority? | **This standard** + Decision Framework |
| Can the student see why, with honest confidence and a next action? | **Explainability Standard** (P-001.2) |

**Joint rule:** A recommendation that cannot satisfy the Mandatory Explanation Schema at the declared level is **not ready to show**, even if prioritisation ranks it highly. Quality without explainability fails K2 *and* K8. Explainability without educational quality fails K2 while inflating trust theatre.

Both review checklists apply when an EP/P programme changes student-facing recommendations:

1. [Recommendation Review Checklist](RECOMMENDATION_REVIEW_CHECKLIST.md) — quality / problem / proportionality / benefit

## 6. Recommendation Quality Principles

Every student-facing recommendation must satisfy these principles. Principles are pass/fail acceptance criteria for product review; algorithms may implement numerical proxies but must not invert the order.

| # | Principle | Rule |
|---|---|---|
| Q1 | **Relevance** | The recommendation matches where the student actually is (syllabus position, recent study, exam posture) — not a generic tip catalogue. |
| Q2 | **Educational value** | Following it should improve learning outcomes (coverage, understanding signals, weak-topic repair, revision timing, readiness honesty, recovery). Activity vanity is non-compliant. |
| Q3 | **Personalisation** | Guidance reflects *this* student’s evidence and constraints (available time, weak topics, missed sessions, plan state) — not cohort averages alone. |
| Q4 | **Actionability** | Exactly one primary next action the student can take now without reverse-engineering the system. |
| Q5 | **Timeliness** | Right work *now* — not premature depth, stale catch-up theatre, or revision before first learning without warrant. |
| Q6 | **Proportionality** | Effort asked matches available session time and evidence strength. Overwhelming catch-up dumps and trivial busywork both fail. |
| Q7 | **Evidence-based reasoning** | Supporting inputs are identifiable (practice results, syllabus position, missed sessions, time-to-exam, plan authority). Vague “learning evidence says so” is non-compliant. |
| Q8 | **Explainability alignment** | Satisfies P-001.2 Mandatory Explanation Schema at the surface’s default level; confidence honesty required. |
| Q9 | **Plan coherence** | Does not silently fight Learning Mode / Today’s Mission / Canonical Study Plan. Advice that diverges must be labelled as advice. |
| Q10 | **Honest refusal** | Prefer “no recommendation yet” / deferral over fabricated tips when warrants or evidence are insufficient (ERO-01). |

## 7. Recommendation Quality Dimensions

Evaluate every material student-facing recommendation on these dimensions before ship / re-score. Use the Decision Framework when dimensions compete across candidates.

| Dimension | Question | Strong | Weak / fail |
|---|---|---|---|
| **Correctness** | Is this lawful and factually aligned with syllabus / plan / evidence? | Matches authorised educational state and coach warrant | Wrong topic family, invents meaning, or contradicts plan authority |
| **Priority** | Is this the highest-value lawful action among competitors *now*? | Wins Decision Framework comparison with clear trade-off | Lower-value tip shown as primary while a higher educational need is ignored |
| **Personal relevance** | Is this about *this* student’s situation? | Uses student-specific evidence and constraints | Generic restatement that any peer could receive unchanged |
| **Expected educational impact** | What learning outcome should improve if followed? | Named benefit (weak-topic repair, revision timing, recovery, readiness honesty) | No clear benefit, or benefit is engagement / streak theatre |
| **Student effort required** | Is the implied effort honest and doable? | Scope fits available window; effort stated or obvious | Silent marathon, impossible load, or trivial filler |
| **Confidence** | How strong is the evidence for this judgement? | Confidence label matches evidence density (per P-001.2 §7.1) | False precision or silent high confidence on thin history |
| **Review trigger** | When should this judgement be reconsidered? | Explicit review point (after N sessions, next practice, plan refresh) | Eternal tip with no reassessment; stale guidance persists |

### 7.1 Dimension usage rules

1. Record at least one concrete evidence sentence for each dimension that is material to the decision.
2. Do not average dimensions into a single opaque “quality %” for student speech.
3. **Correctness** and **Plan coherence (Q9)** are hard gates — fail either → do not show as primary recommendation.
4. **Confidence** and **Review trigger** travel with the explanation (P-001.2 schema).
5. Scorecard metrics (§ companions) measure portfolio quality over time; dimensions judge individual recommendations.

## 9. Explicit non-goals

This standard does **not**:

- change Twin, Adaptive, planning, or recommendation algorithms;
- authorise new educational scores or effectiveness marketing;
- require UI or API implementation in this programme;
- replace the Educational Recommendation Model or Recommendation Objectives;
- replace the Explainability Standard;
- lift EP-001 / EP-003 recommendation-effectiveness marketing freezes.
