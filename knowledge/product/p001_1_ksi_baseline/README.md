**Programme ID:** P-001.1

**Started:** 2026-07-26  
**Authority:** Product (subordinate to Vision 2030 + Product Blueprint + Educational Constitution)  
**Constraints:** Documentation and governance only — no runtime, UI, or API changes  

---

## Mission

Establish a permanent, measurable framework that governs future product work and aligns development with the Version 1 target of **KSI ≥ 80** (educational usefulness).

Previous product evaluation estimated educational usefulness at approximately **58%**. This programme defines how that baseline is interpreted, how progress is scored, and how every future EP/P programme must account for student value.
