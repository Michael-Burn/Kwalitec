**Programme:** GP-001 — Founder Governance Model  
**Date:** 2026-07-26  
**Status:** Complete — documentation only  
**Runtime / UI / API / educational algorithm / architecture changes:** None  

---

## Purpose

Refactor permanent governance documentation so approval authority truthfully reflects a **founder-operated** organisation, without weakening evidence standards, claim standards, or Product Board release authority.

---

## Operating reality

Kwalitec is operated by a **single founder**. Multi-person organisational roles in prior governance text described **capacities**, not separate staff. Independent separation of duties is **deferred** until organisational scale justifies it.
