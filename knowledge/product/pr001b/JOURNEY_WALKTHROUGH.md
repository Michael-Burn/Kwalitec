# Journey Walkthrough — First Week

**Programme:** PR-001B  
**Companion:** [STUDENT_PILOT_GUIDE.md](STUDENT_PILOT_GUIDE.md)

---

## Walkthrough map

```text
Invite account
    → Sign in
    → (Alpha onboarding once)
    → Study plan wizard → Published Curriculum → subject
    → Enrol (Runtime C)
    → Home: understand mission
    → Study materials
    → Mark mission complete
    → Journey: see progress
    → Next day → new mission
    → Repeat through the week
```

---

## Day 1 — First mission (≈ 45–90 minutes)

1. Sign in.  
2. Complete onboarding if shown.  
3. In the wizard, open **Published Curriculum** and select your subject.  
4. Finish wizard steps; confirm enrolment.  
5. On Home, read Why / Why now / Done when / What comes next.  
6. Study the topic.  
7. Click **Mark mission complete**.  
8. Open **Journey** — confirm the topic appears completed (or progress increased).

**Checkpoint:** You can answer: What did I study? Why today? What comes next?

---

## Day 2 — Consecutive session

1. Sign in → Home (not wizard).  
2. Confirm the mission topic is **different** from Day 1.  
3. Study → Mark complete.  
4. Journey shows two completed topics (or higher coverage).

**Checkpoint:** Returning did not force re-enrolment.

---

## Day 3 — Interrupted session

1. Sign in; note the mission title.  
2. Start studying, then leave (close browser).  
3. Return later the same day.  
4. Confirm the **same** mission is still open.  
5. Finish and mark complete.

**Checkpoint:** Leaving mid-day does not lose the mission.

---

## Day 4 — Missed day return

1. Skip a planned study day.  
2. Return the following day.  
3. Home still targets the unfinished syllabus topic (new daily mission instance for the current topic if yesterday was not completed).  
4. Complete when ready.

**Checkpoint:** Gaps do not scramble your place in the syllabus.

---

## Days 5–7 — Multiple missions

1. Complete one mission per day.  
2. Each morning, skim Educational context before studying.  
3. Use Journey mid-week to see coverage % and upcoming topics.  
4. If exam pacing warnings appear, treat them as planning signals — not blockers.

**Checkpoint:** A full first week is possible using only the product + student docs.

---

## End-of-week self-check

| Question | Expected |
|---|---|
| Can I find today’s mission without help? | Yes — Home |
| Do I understand why it was selected? | Yes — Why / Why now |
| Can I complete and see progress? | Yes — Mark complete + Journey |
| Can I return without confusion? | Yes — login → Home |
