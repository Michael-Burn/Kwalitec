## Purpose

This folder defines **the permanent constitutional lifecycle coordinating compliance activities** from initiation through production and recording of compliance determinations.

It answers *what the lifecycle must optimise*, *which recognised stages organise compliance*, *what the lifecycle may and must never do*, and *how lifecycle progress is constitutionally explained* — without implementing Runtime A, testing frameworks, CI/CD, creating constitutional law, modifying constitutional specifications, redefining constitutional meaning, replacing constitutional authority, certifying implementations, replacing verification, or elevating lifecycle machinery into a constitutional authority.

It does **not** implement Runtime A, test runners, CI/CD pipelines, GitHub Actions, Python, Flask, SQLAlchemy, REST, OpenAPI, infrastructure, or application services.

> **The constitutional compliance lifecycle coordinates compliance activities.  
> It produces compliance determinations without certifying implementations or altering constitutional law.  
> It never becomes constitutional authority.**

## Architectural requirement

The constitutional compliance lifecycle coordinates **compliance activities**.

| Lawful | Unlawful |
|--------|----------|
| Coordinate compliance through recognised stages | Certify implementations |
| Consume constitutional specifications | Modify constitutional specifications |
| Consume verification findings | Replace verification or re-author findings |
| Consume established traceability | Invent lineage to force progress |
| Produce compliance determinations | Redefine constitutional / educational meaning |
| Preserve audit records | Become constitutional authority |
| Preserve repeatability, neutrality, explainability | Modify implementation artefacts under lifecycle pretext |
| Explain obligations / findings / relationships / stages / boundaries | Elevate lifecycle machinery into a constitutional producer |

**The constitutional compliance lifecycle coordinates compliance activities. It produces compliance determinations without certifying implementations or altering constitutional law.**

6. Enforce hard stops under `LIFECYCLE_BOUNDARIES.md`.
7. Require explainability contracts from `LIFECYCLE_EXPLAINABILITY.md` before student-, developer-, or auditor-facing lifecycle narration.
8. Do not implement lifecycle machinery that contradicts this corpus without amending it first.
