# Kwalitec V1 Blind Review Package

**Audience:** Independent simulated IFoA student reviewers (private beta)  
**Rule for reviewers:** Evaluate only what a student can see and do. Ignore how the product is built.

This package documents the **current** student-facing application. It does not propose redesigns or invent features.

---

## Package contents

| Document | What it contains |
|---|---|
| [APPLICATION_OVERVIEW.md](APPLICATION_OVERVIEW.md) | Purpose, supported IFoA subjects, intended users, problems claimed, value proposition |
| [FEATURE_INVENTORY.md](FEATURE_INVENTORY.md) | Every student-visible capability: purpose, access, workflow, dependencies |
| [USER_JOURNEYS.md](USER_JOURNEYS.md) | Numbered journeys: first visit, registration (absent), login, dashboard, session, mission, reflection, journey, coach, history, settings, logout |
| [SCREEN_INVENTORY.md](SCREEN_INVENTORY.md) | Every screen with route, title, purpose, actions, navigation; screenshot index |

| [APPLICATION_WALKTHROUGH.md](APPLICATION_WALKTHROUGH.md) | Realistic ~one-hour student session narrative |
| [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md) | Student-visible gaps, empty states, broken paths, placeholders |
| [BETA_EXPECTATIONS.md](BETA_EXPECTATIONS.md) | What should work, what is experimental, feedback we want |
| [REVIEW_PACKAGE_REPORT.md](REVIEW_PACKAGE_REPORT.md) | Coverage assessment for package authors / facilitators |
| [screens/](screens/) | Desktop screenshots of student-visible screens |

---

## How to use this package (reviewer)

1. Read **APPLICATION_OVERVIEW** and **BETA_EXPECTATIONS** first.
2. Skim **FEATURE_INVENTORY** and **USER_JOURNEYS**.
3. Use **screens/** as a visual reference while you explore the live app (preferred) or if you cannot sign in yet.
4. Follow **CLICK_PATHS** / **APPLICATION_WALKTHROUGH** for a structured hour.
5. Log issues against **KNOWN_LIMITATIONS** (is it already known?) and everything else as new feedback.

---

## Access note

Kwalitec Internal Alpha has **no public registration**. Reviewers receive credentials from a Kwalitec coordinator.
