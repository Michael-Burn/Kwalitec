## Purpose

Map every audited educational concept to its **canonical term**, surface family, and student journey placement — so implementers and copy authors know *which word belongs where*.

This map does not change product behaviour.

## 3. Daily-focus map (ED-02 resolution)

| Concept | Canonical | Student question answered | Typical surfaces | Not to be confused with |
|---------|-----------|---------------------------|------------------|-------------------------|
| Authorised daily educational focus | **Mission** | What deserves attention today? | Home Mission Intelligence, Journal, Timeline | Session, tip |

## 4. Reflection map (ED-03 resolution)

| Kind | Records? | Scores learner? | Where | Teach as |
|------|----------|-----------------|-------|----------|
| Session reflection | Workflow-dependent | No | Session end | Close practice |
| Commitment reflection | Ack / continuity | No | Home after complete | Close commitment |
| Sensei reflection | Yes — Journal | No | Decision Journal optional form | Calibrate guidance |
| Timeline reflection | Narrative prompts | No | Educational Timeline | Interpret story |
| Guided Reflection preview | **No** | No | Home preview | Orient only + honesty |
| Product Check-in | Research | N/A | Research | **Not** reflection |

**Student map sentence (future Help):**  
> Reflection after a Session closes practice. Optional reflection in the Decision Journal helps the Study Sensei learn whether guidance was useful. The Educational Timeline asks deeper questions about your learning story. Product Check-in is feedback for the product team — not educational reflection.

## 6. Honesty grammar map

| Term | Use when | Student phrase |
|------|----------|----------------|

| Progress | Plan / practice movement | Journey / History |
| Mastery | Twin estimate (prefer soft student wording) | Understanding / completed topics |
| Calibration | Declared coverage | Starting position — not mastery |

## 7. Journey placement (first introduction)

```
Auth (Kwalitec)
  → Onboarding (Calibration, Study Plan, Study Sensei handoff)
    → Home (Mission, Mission Intelligence, Commitment)
      → Session (practice)
        → Session reflection / Commitment reflection
          → Decision Journal (memory + Sensei reflection)
            → Educational Timeline (story)
              → History / Journey / Revision / Readiness (context)
                → Help (glossary reinforcing all)
```

## 10. How to use this map

1. Before writing student-facing educational copy, find the concept here.  
2. Use only the canonical term (or approved synonym).  
3. If tempted to invent a synonym, stop — update DG-001.1 docs via Board process.  
4. Implementation programmes remediating ED-01–ED-04 must cite this map in their completion reports.
