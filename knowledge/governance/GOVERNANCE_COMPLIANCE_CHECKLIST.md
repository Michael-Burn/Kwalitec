## 1. Purpose

Define how future work packages demonstrate compliance with educational governance law.

Every educational implementation (and every material educational copy / Help / narrator / reflection programme) must identify:

1. affected governance documents  
2. affected constitutional principles  
3. compliance statement  
4. exceptions  
5. rationale  

**Governance-only packages** still complete a lightweight compliance block (documents touched = DG-001; student-facing change = No).

---

## 2. When this checklist is mandatory

| Work type | Required? |
|-----------|-----------|
| Student-facing educational capability | **Yes** — full checklist |
| Copy / Help / onboarding / narrator remediation | **Yes** — full or targeted |
| Reflection / Journal / Timeline / Feedback Loop changes | **Yes** — include reflection section |
| Recommendation / Mission Intelligence *presentation* | **Yes** — vocabulary + authority + honesty |
| Recommendation *ranking* / educational algorithms | **Yes** — plus P-001.3 / EGI as applicable |
| Pure infra / security / migrations with no educational speech | Lightweight — state N/A with rationale |
| Docs-only governance (DG-*) | Lightweight compliance + Decision Log |

## 4. Standard governance review checklist

Reviewers mark each item **Pass / Fail / N/A / Residual**.

### 4.1 Vocabulary compliance (DG-001.1)

| # | Check | Pass criteria |
|---|-------|---------------|
| V1 | Canonical terms used for educational concepts | Mission, Session, Study Sensei, Decision Journal, etc. match lexicon |
| V2 | No silent synonyms | Deprecated terms not reintroduced as primary nouns |
| V3 | Tip not used as primary educational CTA noun | Per DEP register |
| V4 | Mission ≠ Session in student language | Distinct concepts preserved |
| V5 | Reflection family qualifiers correct | No unqualified “reflection” collision with Check-in |
| V6 | First-introduction ownership respected | Journal / Timeline / MI introduced per D04 |
| V7 | PX / Product Language conflicts handled | Educational meaning follows lexicon; residuals named |

### 4.2 Authority compliance (DG-001.2)

| # | Check | Pass criteria |
|---|-------|---------------|
| A1 | Exactly one primary authority per interaction | Study Sensei / Kwalitec / System |
| A2 | Study Sensei owns educational judgement speech | Recommendations, memory, guidance reflection |
| A3 | Kwalitec never acts as second tutor | No brand-as-mentor on educational surfaces |
| A4 | System has zero educational judgement | Status / errors only |
| A5 | Onboarding handoff present when claiming ED-01 closure | KW → SS sentence |
| A6 | Flags / ops notices never Study Sensei | D07 |

### 4.3 Reflection compliance (DG-001.3)

## 5. Outcomes

| Overall | Meaning |
|---------|---------|
| **Pass** | All applicable checks Pass or justified N/A |
| **Conditional Pass** | Governance intent met; named residuals block unqualified closure claims |
| **Fail** | One or more mandatory checks Fail without approved exception |
| **Hold** | Evidence insufficient to rate |

**Rule:** Conditional Pass is the correct outcome when governance law is clear but student-facing remediation remains open — same pattern as DG-001.1–3 certifications.

---

## 6. Exceptions

Exceptions require:

1. Written rationale  
2. Affected principle IDs  
3. Risk to student trust  
4. Expiry date or follow-up programme ID  
5. Educational Gate Owner approval (Founder Review)

Exceptions **may not** waive CP-06, CP-07, CP-08, or CP-10 without amending the Constitution under `GOVERNANCE_AMENDMENT_PROCESS.md`.
