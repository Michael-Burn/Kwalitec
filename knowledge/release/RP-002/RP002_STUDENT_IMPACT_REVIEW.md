## 9. Lessons learned for student value

1. **Remediation ≠ certification** — RR-001 could close assigned NCRs; only independent re-measurement answers whether the product still complies.  
2. **Sole-runtime Contained latent chrome still matters** — students never see dual-run defects until configuration fails; then educational trust collapses quickly.  
3. **Small vocabulary fractures (Share Feedback vs Product Check-in) still matter** — Help can teach the right map while chrome quietly undoes it.  
4. **String FC ≠ validated student perception** — cohort validation remains required for KSI claims.
