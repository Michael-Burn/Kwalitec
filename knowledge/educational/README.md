# Educational

## Purpose

Educational law, integrity governance, and related Educational Integrity / Governance Initiative artefacts (EGI / EIP).

This folder answers: **what is educationally lawful, and does implementation tell educational truth?**

## Educational quality release (sibling)

For **whether educational quality is sufficient to release to students**, see the Educational Validation Framework:

→ [`knowledge/educational_validation/`](../educational_validation/)

EVF consumes Blind Review and does not replace Educational Constitution authority in this folder.
