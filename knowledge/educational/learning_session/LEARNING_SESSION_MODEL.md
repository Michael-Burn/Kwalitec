# Learning Session Model

**Programme:** VI — Workstream 2 — Daily Coach  
**Milestone:** MS002 — Learning Session Model  
**Classification:** Highest educational authority for individual study-session meaning within Programme VI Workstream 2 / MS002  
**Status:** APPROVED — governing for Learning Session educational contract  
**Version:** 1.0  
**Date:** 2026-07-25  

---

## Authority

This document is the constitutional overview of the **Learning Session** for Kwalitec.

It is subordinate to the Educational Constitution and to the Daily Coach Model (MS001). It governs **how an authorised Daily Coach objective becomes the educational anatomy of one study session**. It does not authorise implementation shortcuts that contradict the Constitution, and it does not redefine today’s educational objective.

Authority order for learning sessions:

> Constitution defines educational truth and curriculum primacy.  
> Knowledge & Mastery defines coverage ≠ understanding ≠ mastery.  
> Evidence Model defines what may warrant understanding claims.  
> Canonical Study Plan publishes the long-term preparation contract.  
> Daily Coach (MS001) selects *what is most educationally valuable to do today*.  
> **This Learning Session Model (Workstream 2 / MS002) defines how that day’s objective is studied in one session.**  
> Downstream activity, mission, runtime, and narration surfaces must consume this educational reasoning — never redesign today’s objective while structuring the session.

---

## 1. Purpose

Kwalitec coaches students preparing for demanding professional examinations (especially IFoA syllabi such as CM1/CS1 and peers).

An expert IFoA tutor, having already decided *what* matters today, still faces a second living question for each study sitting:

> **“How should this student study this topic today?”**

That answer must remain faithful to the Daily Coach’s educational objective while arranging preparation, focused learning, retrieval, practice, reflection, and review so that the session builds durable competence — not theatre.

This document records that tutor posture so every future session, activity, and narration surface has a single educational reference for *how a study session is structured*.

> **The Learning Session Model describes educational reasoning.  
> It does not implement Runtime A logic, mission generation, timers, or UI.**

---

## 2. What a Learning Session Is

A **Learning Session** is the educational unit in which the student pursues **today’s Daily Coach primary objective** (DCO-01) through a coherent sequence of educational phases.

| Input family | Role |
|--------------|------|
| **Daily Coach primary objective (DCO-01)** | The day’s educational job — non-negotiable session warrant |
| **Recommended study blocks / practice focus (DCO-02 / DCO-03)** | Authorised emphasis and capacity envelopes from Daily Coach |
| **Topic / syllabus / mode authority** | What content the session may lawfully address |
| **Student Educational Profile (relevant slice)** | How the student tends to learn — not a licence to change the day |
| **Session-local progress signals** | Emerging difficulty, fluency, fatigue, interruption during the session |

into:

| Output family | Role |
|---------------|------|
| **Session educational structure** | Ordered phases and aims that serve today’s objective |
| **Phase transition posture** | When and why phases change |
| **Local adaptation posture** | How the tutor adjusts *within* the session |
| **Escalation signal (when needed)** | When the day’s objective itself must be revisited by Daily Coach |
| **Session explainability** | Why this structure, order, and contribution to long-term learning |

It answers:

| Question | Educational answer |
|----------|-------------------|
| What is this session for? | Today’s Daily Coach objective — preserved intact |
| How should we study it? | A principle-led sequence of educational phases |
| When do we move on? | When educational progress (not the clock alone) warrants |
| What if things go wrong? | Local adaptation; escalate if the day’s job must change |
| Why this shape? | Plain educational rationale tied to objective + learning science for IFoA prep |

A Learning Session is:

- **objective-faithful** — every material phase serves today’s Daily Coach objective;
- **tutor-shaped** — reflects how an expert IFoA tutor runs one coaching sitting;
- **principle-led** — phases derive from educational purpose, not a single fixed template;
- **progress-sensitive** — transitions follow educational readiness, not elapsed time alone;
- **locally adaptive** — may change pace, scaffolding, and activity mix inside the session;
- **non-redefining** — never silently replaces today’s educational job;
- **evidence-honest** — session completion is not narrated as mastery;
- **explainable** — students can understand why the session is structured this way;
- **escalation-aware** — returns to Daily Coach when the day’s objective cannot be honestly served.

A Learning Session is **not**:

- a second Daily Coach, Master Planner, or Strategy selector;
- a licence to invent a new day’s priority “because the session is going poorly / well”;
- ownership of Study Progress, Educational Evidence, or Twin understanding;
- a timer, UI flow, mission-generation algorithm, or Runtime A service;
- a claim that finishing the session guarantees understanding or a pass.

## 3. Educational Purpose

The Learning Session Model exists so that:

1. **Today’s objective becomes livable study work** — not a slogan left without educational method.
2. **IFoA-grade study habits are encoded** — preparation, active engagement, retrieval, deliberate practice, and reflection — rather than passive reading theatre.
3. **Session integrity survives friction** — difficulty, fatigue, and interruptions adjust *how* work proceeds without rewriting *what* the day asked for.
4. **Long-term learning is visible in the short arc** — each activity’s contribution to durable competence can be explained.
5. **Authority stays layered** — Session optimises method; Daily Coach owns the day’s job; Master Planner owns the journey contract.

---

## 4. Core Responsibilities

The Learning Session is educationally responsible for:

| Responsibility | Meaning |
|----------------|---------|
| **Preserve today’s objective** | Treat DCO-01 (and disclosed mode/authority posture) as the session’s constitutional warrant |
| **Compose educational phases** | Arrange preparation, learning, retrieval, practice, reflection, and review as the objective requires |
| **Govern transitions** | Move between phases when educational progress warrants — not by clock alone |
| **Adapt locally** | Adjust scaffolding, depth, pace, and activity mix while the day’s job remains intact |
| **Protect honesty** | Separate coverage, practice attempts, confidence, and understanding claims |
| **Escalate upward** | Return to Daily Coach when honest service of today’s objective is no longer possible |
| **Explain the session** | Make structure, order, and learning contribution intelligible |

### 4.1 Binding non-responsibility

The Learning Session must **not**:

- redefine, replace, or invent today’s Daily Coach primary objective;
- redesign the Canonical Study Plan or re-select Educational Strategy;
- mint Estimated Knowledge / Mastery from phase completion alone;
- treat elapsed time as sufficient educational law for phase change;
- convert recovery / revision / rest days into undeclared first-pass ambition;
- absorb Daily Coach or Master Planner authority when envelopes break.

---

## 5. Educational Guarantees

A lawful Learning Session posture **guarantees** the following educational properties — not exam outcomes.

| Guarantee | Meaning |
|-----------|---------|
| **Objective fidelity** | Material session structure is warranted by an authorised Daily Coach primary objective (or honestly refuses to invent one) |
| **Purpose before template** | Phases are selected because they serve the session’s educational aims — not because a fixed script demands them |
| **Progress-led transitions** | Phase changes cite educational readiness / completion signals, not minutes alone |
| **Local adaptation envelope** | In-session adjustments stay within today’s objective and Daily Coach capacity envelopes |
| **Honest escalation** | When the day’s job must change, the session identifies Daily Coach escalation — it does not silently rewrite the day |
| **Evidence honesty** | Understanding and readiness claims remain claim-typed under Evidence Model / Explainability Standard |
| **Explainability** | Every material structure decision can answer the session explainability questions |
| **Continuity** | Session adaptation does not erase learner-owned educational history (EIP-005) |
| **Non-redefinition** | The Learning Session never silently redefines what the student was expected to accomplish today |

### 5.1 What the Learning Session does *not* guarantee

- That the student will pass the examination.
- That every planned phase will be completed.
- That completing the session equals understanding or mastery.
- That a longer session is a better session.
- That local adaptation may invent a new day’s educational job.

## 6. Tutor Posture (Binding Metaphor)

When structuring a study session, the system must behave as an expert IFoA tutor would:

1. **Keep the day’s brief.** Do not abandon today’s objective because a shinier topic appears mid-session.
2. **Start with orientation.** Brief preparation beats diving into undifferentiated content.
3. **Prefer active over passive.** Retrieval, worked reasoning, and deliberate practice outrank rereading theatre when the objective allows.
4. **Check understanding, don’t assume it.** Move forward when educational signals warrant — not when the page count looks impressive.
5. **Scaffold then release.** Support difficulty; withdraw support as fluency grows — without inventing mastery.
6. **Protect reflection.** Honest close is part of learning, not optional garnish.
7. **Respect human limits.** Fatigue and interruption change pace and depth — they do not automatically invent a new syllabus job.
8. **Adapt locally first.** Change method before changing the day’s objective.
9. **Escalate honestly.** When today’s job cannot be served, say the coach must revisit the day — do not silently rewrite it.
10. **Explain in educational language.** Students hear why *this* structure serves *today’s* objective and long-term learning.
11. **Leave internal machinery invisible.** No Twin facets, optimiser scores, or registry IDs in student speech.

## 8. Relationship to Daily Coach Outputs

| Daily Coach output | Learning Session duty |
|--------------------|----------------------|
| **DCO-01 Today’s primary objective** | Constitutional warrant — preserved; never redefined |
| **DCO-02 Recommended study blocks** | Capacity and emphasis envelopes for phase composition |
| **DCO-03 Practice focus** | Constrains practice / retrieval emphasis when present |
| **DCO-04 Reflection prompts** | Informs reflection / session-review phase content |
| **DCO-06 Educational rationale** | Parent rationale; session explainability specialises *how* |
| **DCO-08 Escalation notice** | Session may *raise* escalation; may not *consume* Master Planner authority |
| **DCO-10 Mode / authority disclosure** | Session narration must stay consistent with disclosed day posture |

The Learning Session **consumes** Daily Coach outputs. It does not compete with them.

## 9. Relationship to Learning Mode and Today’s Mission

Under Learning Mode Version 1.0 (EL-009 / EL-003):

- When today’s Daily Coach job is first-pass learning, session content must **align** with Learning Mode / Today’s Mission topic authority.
- When today’s job is revision, recovery, practice emphasis, checkpoint, or rest, session structure must **disclose and honour** that posture — not smuggle undeclared first-pass coverage.
- Session phases may vary method (e.g. more retrieval on a practice day); they may not silently replace Mission topic authority with advisory preference.

---

## 10. Educational Integrity

Educational integrity for the Learning Session means:

1. **One story with the day.** Session speech and Daily Coach speech must not contradict without disclosed local adaptation or escalation.
2. **Claim-type honesty.** Observed Facts, Derived Facts, Estimates, and Advice remain distinguishable (EIP-003).
3. **No mastery minting.** Completing phases advances honest study; it does not create understanding claims.
4. **No punishment pedagogy.** Unexpected difficulty triggers scaffolding or lawful scope reduction — not shame intensity.
5. **No silent day rewrite.** Material change to today’s educational job requires Daily Coach — not session improvisation.
6. **Continuity of history.** Adapting the session never erases rightful learner history.

---

## 11. Determinism (Educational)

Given the same:

- Daily Coach primary objective and disclosed day posture,
- authorised capacity / practice envelopes,
- topic / mode authority,
- relevant Profile slice,
- session-local progress signals summarised equivalently,

the Learning Session must present the same educational structure posture (same primary session aims, same phase family emphasis, same escalation posture).

Variation is allowed only when those inputs change, or when lawful local adaptation triggers fire mid-session.

Numeric scoring schemes and timer policies are out of scope for this milestone. Educational determinism here means **reproducible educational posture**, not a mandated formula.
