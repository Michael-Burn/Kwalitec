## 1. Purpose

Interventions that silently become calendars, strategies, or mastery claims destroy educational trust and constitutional layering.

This document draws a bright line between **local educational coaching change** (lawful for Learning Coach) and **structural / authority change** (must escalate).

---

## 2. Boundary Principles

1. **Recommend, do not commandeer.** Interventions guide emphasis; they are not Mission law unless Daily Coach / plan authority makes them so.
2. **Smallest sufficient local change.** Method and emphasis before structural replan.
3. **Plan faithfulness.** Canonical Study Plan remains the authorised preparation contract.
4. **Day faithfulness.** Daily Coach retains *what is most educationally valuable today*.
5. **Mastery honesty.** Interventions never redefine EIP-006 ladder meanings.
6. **Strategy stability.** Long-term educational strategy changes through Master Planner Strategy pathways.
7. **Explicit escalation.** When envelopes break, select LI-12 — do not mutate silently.
8. **Continuity respect.** Recovery and interruption handling remain Continuity-governed.
9. **Explain the limit.** When escalation is needed, say so supportively — do not hide behind a fake tip.

## 3. What the Learning Coach May Change (Local)

The Learning Coach may recommend changes to **how learning is pursued** inside existing plan and day envelopes:

| Lawful local change | Educational meaning | Typical LI |
|---------------------|---------------------|------------|
| **Study method** | How the student works the objective (retrieval vs re-read; worked-example fading; notation discipline) | LI-08, LI-08a, LI-03 |
| **Practice emphasis** | What kind of practice to prioritise on current scope (targeted questions; deliberate practice on a named weakness) | LI-02, LI-13, LI-01 |
| **Retrieval frequency / design** | Cue-light production emphasis within lawful sessions | LI-03 |
| **Reinforcement recommendations** | Consolidate same-scope understanding before new coverage theatre | LI-01, LI-09 |
| **Spacing recommendations** | Advise return timing / retention checks that fit protected revision intent | LI-06 |
| **Confidence framing** | Align coaching tone with performance evidence | LI-11 |
| **Misconception repair focus** | Name and correct a specific wrong idea before volume | LI-07 |
| **Prerequisite focus (local)** | Emphasise earlier foundations *within* plan-allowed repair windows | LI-04 |
| **Revision design advice** | Reshape how revision sessions use their allotted educational job | LI-14 |
| **Evidence-gathering design** | Distinguishing observations when diagnosis is unclear | LI-00 |
| **Recovery-light rebuild advice** | Gentle return after interruption inside Continuity posture | LI-10 |

These changes **inform** Daily Coach emphasis and session design. They do **not** by themselves publish a new study plan or cancel today’s lawful Daily Coach objective.

---

## 4. What the Learning Coach Must NOT Change

| Forbidden change | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Rewrite the Canonical Study Plan** | Plan is Master Planner / Scheduling educational contract | **LI-12** → reschedule / replan pathways |
| **Change long-term educational strategy** | Strategy is Master Planner MS003 authority | Profile / Strategy re-consultation pathways |
| **Override Daily Coach authority** | Daily Coach owns *today’s* educational priority under the plan | Offer intervention meaning as input; Daily Coach decides today’s objective |
| **Redefine mastery / exam readiness** | EIP-006 and Learning Objectives own meanings | Refuse unlawful LPS-7 / mastery speech; recommend evidence-building LIs |
| **Mutate protected revision / phase meaning silently** | Protections are plan-constitutional | LI-14 only within allotted revision jobs; else LI-12 |
| **Invent syllabus content or unofficial shortcuts** | Curriculum primacy | Syllabus-faithful LI-04 / LI-08 only |
| **Absorb Scheduling Engine authority** | Allocation is MS006 | LI-12 |
| **Write Twin estimates as intervention success** | Evidence / Twin law separate | Future evidence observed honestly |
| **Convert interventions into sanctions** | Non-punitive coaching | Supportive explainability |
| **Skip diagnosis to tip** | Layer separation | Obstacle Model first; LI-00 if under-warranted |

## 5. Authority Map

```
Canonical Study Plan (MS007)
        │  contract for the sitting
        ▼
Daily Coach (WS2)
        │  today’s educational objective under the contract
        ▼
Learning Session / Reflection
        │  how today was studied; what one sitting meant
        ▼
Learning Progression (MS001) → Obstacles (MS002) → Interventions (MS003)
        │  whether learning grows; why not; what response
        │
        ├─ local LI (method / emphasis / retrieval / reinforcement / …)
        │     → informs Daily Coach emphasis & session design
        │
        └─ LI-12 escalation
              → Master Planner / Strategy / Rescheduling pathways
              → may yield a revised Canonical Study Plan
              → Daily Coach then coaches under the new contract
```

Hard rule:

> **Learning Coach interventions never invalidate Canonical Study Plan authority.  
> They never replace Daily Coach day-priority authority.  
> Long-term changes escalate through existing planning pathways.**

## 6. Envelope Tests (Before Local Recommendation)

Before treating an LI as local, the tutor asks:

| Test | If “no” |
|------|---------|
| Can this response be pursued without changing plan phase meaning? | Escalate (LI-12) |
| Can today’s Daily Coach still own the day’s primary objective? | Do not override; offer as emphasis input |
| Does Profile capacity sustain the response? | Narrow (LI-09/LI-10) or escalate intensity envelopes |
| Does Continuity require recovery-light treatment? | Prefer LI-10; forbid challenge theatre |
| Would success require redefining mastery speech? | Refuse; choose evidence-building LI instead |
| Would revision protections be silently consumed by first-pass? | Forbid; LI-09/LI-14 within intent or LI-12 |

---

## 7. Escalation Triggers (Must Use LI-12 Pathway)

Escalate when any of the following hold:

1. Persistent LPS-S / named LOB despite repeated lawful local interventions.
2. Sitting ambition / LO-07 trajectory impossible under remaining calendar honestly.
3. Required repair (e.g. deep prerequisite rebuild) consumes protected revision or phase meaning.
4. Intensity required exceeds Profile capacity and cannot be narrowed locally.
5. Strategy posture (foundation / rescue / revision-intensive, etc.) no longer matches the educational picture.
6. Plan protections repeatedly conflict with necessary educational repair.
7. Material contradiction with Student Educational Profile that needs Profile re-consultation before further tips.

Escalation speech remains supportive and specific — see Explainability. Escalation is not abandonment.

## 8. Interaction with Neighbouring Authorities

| Authority | Learning Coach may | Learning Coach may not |
|-----------|--------------------|------------------------|
| **Daily Coach** | Inform emphasis with LI meaning | Replace today’s primary objective decision |
| **Learning Session** | Recommend method/adaptation cues | Absorb day-priority when session needs a different educational job (session escalates to Daily Coach) |
| **Educational Reflection** | Consume session-level continuation / reinforcement signals | Treat one sitting’s tip as longitudinal law |
| **Canonical Study Plan** | Coach inside the contract | Publish or silently edit the contract |
| **Educational Strategy** | Signal mismatch via LI-12 | Switch strategy labels unilaterally |
| **Scheduling / Rescheduling** | Request lawful reallocation via escalation | Reallocate dates as a coaching tip |
| **Knowledge & Mastery** | Respect ladder when judging success | Collapse coverage into mastery via intervention compliance |
| **Student Educational Profile** | Respect capacity / recovery constraints | Overwrite Profile diagnosis by tip |

---

## 9. Boundary Anti-Patterns (Forbidden)

| Anti-pattern | Educational harm |
|--------------|------------------|
| “We’ll just rewrite your timetable” inside Learning Coach tip | Silent plan mutation |
| “Forget today’s mission — do this instead” without Daily Coach | Authority override |
| “You’re at mastery now that you followed advice” | Mastery redefined by compliance |
| “Switch to rescue strategy” without Strategy pathway | Strategy fiat |
| Local LI that requires calendar surgery presented as “spacing tip” | Envelope laundering |
| Escalation used as first tip for mild provisional stalls | Escalation theatre |
