Catalogue entries are educational meanings — not database enums, UI badges, optimiser modes, or numeric priority bands. Implementations may map storage labels onto these meanings; they may not redefine the meanings in code.

> **Interventions are educational responses.  
> They are developed from educational principles, not implementation convenience.  
> Listing an intervention does not author a diagnosis — and no intervention may fire without one.**

---

## 1. Purpose

An expert IFoA tutor carries a mental catalogue of *what to change* once a barrier is named: rebuild foundations, correct a misconception, emphasise retrieval, add targeted practice, fade worked examples into deliberate practice, adjust spacing, recalibrate confidence, restructure revision, or gather clearer evidence when the cause is still unclear.

This catalogue records those educational responses so Learning Coach selection, boundaries, and explainability share one vocabulary.

---

## 2. Catalogue Principles

1. **Educational first.** Categories come from learning science and IFoA tutoring practice — not from which mission template is easiest to wire.
2. **Diagnosis-gated.** Every entry (except evidence gathering under insufficient warrant) requires a named LOB.
3. **Objective-aware.** Each intervention advances specific Learning Objectives (LO-01…LO-07); it must not collapse the ladder.
4. **Cause-matched.** Volume does not cure misconception; retrieval design does not rebuild missing prerequisites.
5. **Non-exclusive.** Supporting interventions may accompany a primary; student speech prefers one primary.
6. **Reversible.** Interventions are provisional; they clear or change as future evidence evolves.
7. **Non-punitive.** Names describe educational moves — never character.
8. **Syllabus-faithful.** Prerequisite rebuilding respects official curriculum order; folk shortcuts that invent syllabus content are unlawful.
9. **No priority scores.** Qualitative selection language only — never numeric ranks as educational law.
10. **Boundary-aware.** Local coaching interventions stay distinct from escalation to planning pathways.

---

## 3. Framework Logic (Before Labels)

Before naming an intervention, the tutor asks, in order:

| Order | Tutor question | If unclear |
|-------|----------------|------------|
| 1 | Is there an explicit diagnosis (or explicit insufficient warrant)? | Stop — no tip without gate |
| 2 | Which learning objective should this response advance? | Withhold strong recommendation; gather evidence |
| 3 | What is the smallest change that matches the cause? | Prefer method/emphasis over structural replan |
| 4 | Can this be enacted inside Daily Coach / plan envelopes? | Escalate rather than silently rewrite |
| 5 | What future evidence would show the response worked? | Do not recommend if success is unobservable in principle |

Examples such as “Prerequisite Rebuilding” are **illustrative names** for responses produced by this logic. Binding meanings are the definitions below.

## 4. Intervention Catalogue

Each entry records: educational meaning, required diagnosis family, educational objective, expected evidence of improvement, non-use cases, and a supportive speech cue.

IDs (`LI-XX`) exist for audit and cross-reference. They must not appear as student-facing jargon.

Mission-named educational moves map into this catalogue as follows:

### LI-00 — Evidence Gathering

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Deliberately collect clearer educational observations that distinguish rival causes — when diagnostic warrant is insufficient or conflicting — without pretending a cure. |
| **Required diagnosis** | Explicit **Insufficient warrant** or **Conflicting** posture (MS002) — *not* a named LOB cure. |
| **Educational objective** | Improve diagnostic honesty so a lawful LOB (and later LI) becomes possible; protect claim integrity. |
| **Expected evidence of improvement** | Distinguishing observations appear (e.g. closed-book vs open-book contrast; earlier-scope probe; patterned vs random errors; cadence clarity). |
| **Must not / do not use when** | A Supported primary LOB already exists and a matched response is available; used as a euphemism for “do random questions” without a distinguishing question; used to delay honest escalation when envelopes are already broken. |
| **Speech cue** | “It’s too early to name the barrier confidently — we’ll gather clearer evidence first.” |

**Educational principle.** Honest tutoring withholds cures when causes are unclear. Evidence gathering is a first-class educational response, not a product failure.

---

### LI-01 — Retrieval Reinforcement / Consolidation Practice

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Strengthen recently emerging understanding or application with additional supportive practice on the **same** scope — consolidation without new first-pass theatre. |
| **Required diagnosis** | Typically LOB-08 (thin but emerging practice), mild LOB-02 after repair begins, post–LOB-03 repair fragility, or LOB-12 after coverage pause begins — when consolidation (not volume theatre) is the need. |
| **Educational objective** | Stabilise LO-03 Understanding; early LO-05 Application stability. |
| **Expected evidence of improvement** | Confirming EC-C on the same scope; fewer fragile same-day collapses; Reflection notes growing command without new coverage. |
| **Must not / do not use when** | Primary barrier is LOB-01 (missing foundations) or LOB-03 (stable wrong model) still unrepaired; used to invent mastery from more completions; skips retrieval testing forever; silently consumes protected revision windows without plan authority. |
| **Speech cue** | “We’ll reinforce what you’re starting to understand before moving on.” |

**Educational principle.** Emerging competence consolidates through focused return on the same ideas — not through racing ahead.

---

### LI-02 — Targeted Question Practice

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Increase volume or variety of **attributable** practice on a named syllabus scope so application evidence can accumulate — focused question work, not undirected homework theatre. |
| **Required diagnosis** | Primarily LOB-08 Insufficient Practice; may support LOB-07 (as performance anchors) once structural rivals are weakened. |
| **Educational objective** | Advance LO-05 Application; thicken warrant for LO-03. |
| **Expected evidence of improvement** | Growing EC-C density and variety on the target scope; reduced “I understand when I read” without question trails. |
| **Must not / do not use when** | LOB-01/LOB-03 patterns suggest structure first; LOB-05 overload is primary (narrow before adding volume); LOB-06 (wrong method) needs strategy change more than more of the same; equates set completion with competence; ignores fatigue / recovery. |
| **Speech cue** | “You’ve covered the ideas — we’ll add focused question practice so application evidence can build.” |

**Educational principle.** Actuarial competence is shown in performance. Reading alone rarely authorises application claims.

---

### LI-03 — Retrieval Reinforcement (Cue-Light Production)

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Shift study design toward cue-light recall, reconstruction, and closed-book production rather than re-reading or recognition review. |
| **Required diagnosis** | Primarily LOB-02 Weak Retrieval; often co-selected with LI-06 for LOB-11 Fragile Durability. |
| **Educational objective** | Advance LO-04 Retrieval ability; support later LO-06. |
| **Expected evidence of improvement** | Narrowing of prompt-vs-production gap across sessions; stronger unaided reconstruction on the same scope. |
| **Must not / do not use when** | Student has never been taught the idea (LOB-01/LOB-12 first-pass need); LOB-03 wrong schema is being fluently retrieved (repair first); flashcard theatre substitutes for exam application; durable knowledge claimed without spaced success. |
| **Speech cue** | “We’ll emphasise retrieving this without notes — recognition isn’t enough for the exam.” |

**Educational principle.** Exams reward production under reduced cues. Recognition theatre is not retrieval.

---

### LI-04 — Prerequisite Rebuilding

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Step back to earlier syllabus foundations that block current understanding or application — rebuild lawfully ordered prerequisites before advancing the blocked scope. |
| **Required diagnosis** | Primarily LOB-01 Prerequisite Gap; occasionally LOB-03 when the wrong model is rooted in an earlier missing idea (diagnose carefully). |
| **Educational objective** | Restore LO-01/LO-03 on prerequisites so current LO-05 can become lawful. |
| **Expected evidence of improvement** | Earlier-scope checks strengthen; current-scope items that previously could not begin become approachable; patterned foundation errors reduce. |
| **Must not / do not use when** | Errors are current-topic misconception with sound foundations (LOB-03); practice is simply thin (LOB-08); shame narrative of “going backwards”; invents prerequisites absent from official syllabus structure; erases rightful coverage honesty on current topics. |
| **Speech cue** | “This topic depends on earlier ideas — we’ll rebuild those foundations first.” |

**Educational principle.** Professional syllabi are ordered. Teaching advanced technique on missing foundations manufactures false struggle.

---

### LI-05 — Increased Challenge

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Raise educational demand: harder items, less scaffolding, mixed topics, or timed conditions — when warrant supports acceleration without skipping foundations. |
| **Required diagnosis** | Not a “stall cure.” Used when progression shows **acceleration** with confirming evidence, or when LOB-10 Exam Technique is primary *and* content warrant is fair enough for exam-form stretch. |
| **Educational objective** | Strengthen LO-05; contribute honestly toward LO-07 readiness work. |
| **Expected evidence of improvement** | Stable performance under higher demand; improved timed/mixed-item trails without collapse into overload. |
| **Must not / do not use when** | Soft confidence alone; LOB-01/03/05 unresolved; recovery days; thin warrant / false readiness risk; challenge used to paper over LOB-12 coverage theatre. |
| **Speech cue** | “Evidence supports raising the challenge — we’ll stretch application carefully.” |

**Educational principle.** Desirable difficulty advances learning when foundations and method can bear it — not as motivational theatre.

---

### LI-06 — Spacing Adjustment

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Deliberately redesign return timing to prior scope — introduce, restore, or adjust spaced returns to test and build durable retention. |
| **Required diagnosis** | LOB-09 Revision Neglect (returns absent); LOB-11 Fragile Durability (returns weak); may support LOB-02 when cue-light return is needed. |
| **Educational objective** | Advance LO-06 Durable retention; honesty about decay. |
| **Expected evidence of improvement** | Stronger EC-E on return; reduced immediate-vs-spaced inconsistency; revision contact appears in the trail. |
| **Must not / do not use when** | Same-day retests are mislabelled as spacing; all first-pass time stolen if plan forbids (escalate); one return treated as permanent mastery; used instead of LOB-01 rebuild when foundations never existed. |
| **Speech cue** | “We’ll adjust how we return to this after a gap so knowledge can hold for the exam.” |

**Educational principle.** Durability is tested by return. Spacing is a design choice, not a hope.

---

### LI-07 — Misconception Correction

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Target a named misunderstanding revealed by practice or reflection — conceptual correction before more volume rehearses the error. |
| **Required diagnosis** | Primarily LOB-03 Misconception (Supported or strong Provisional with a namable wrong idea). |
| **Educational objective** | Repair LO-03 Understanding quality; unlock lawful LO-05. |
| **Expected evidence of improvement** | The false rule stops recurring across item forms; performance flips after explicit correction; student can state the corrected idea. |
| **Must not / do not use when** | Errors are heterogeneous/random; tutor cannot name the putative misconception; LOB-01 missing foundation misread as wrong current rule; buried inside unexplained “do more questions”; invented without evidence. |
| **Speech cue** | “There’s a specific misunderstanding to correct before more practice will help.” |

**Educational principle.** Volume on a wrong schema strengthens the wrong schema. Repair precedes rehearsal.

---

### LI-08 — Study Method / Strategy Coaching

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Change *how* the student studies the objective — including **worked-example emphasis** with fading, exam technique craft, time allocation, and notation discipline — without changing the syllabus target. |
| **Required diagnosis** | Primarily LOB-06 Ineffective Study Strategies; LOB-10 Exam Technique Deficiencies; may support LOB-05 when demand shaping is methodological rather than pure volume cut. |
| **Educational objective** | Improve efficiency of LO-04/LO-05 growth; support LO-07 process quality. |
| **Expected evidence of improvement** | Production-shaped sessions appear; EC-C gains rise for comparable effort; timed/method-mark trails improve when LOB-10 was primary. |
| **Must not / do not use when** | LOB-01/03 block any method; LOB-08 needs attributable practice first (not method sermons); folk shortcuts invent syllabus content; generic productivity advice divorced from educational evidence. |
| **Speech cue** | “Your effort is there — we’ll change the study method so the learning the exam needs can form.” |

#### LI-08a — Worked-Example Emphasis (specialisation)

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Emphasise carefully studied worked examples with progressive fading into independent problem solving — especially early in application growth or after misconception repair. |
| **Required diagnosis** | LOB-06 when passive re-reading dominates; post–LI-07 consolidation into application; LOB-05 when scaffolding must be redesigned rather than removed abruptly. |
| **Must not** | Eternal example-watching without fading; examples that rehearse a still-uncorrected misconception. |
| **Speech cue** | “We’ll study worked examples carefully, then fade the support as you take over the method.” |

**Educational principle.** Desirable difficulties outperform comfort strategies — but early application often needs worked-example scaffolding before full independence.

---

### LI-09 — Consolidation Before Progression (Coverage Pause)

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Pause or slow new first-pass coverage to consolidate current scope when the trail shows thin understanding beneath rising coverage. |
| **Required diagnosis** | Primarily LOB-12 Coverage Ahead of Understanding; may support LOB-05 Cognitive Overload when narrowing includes deferring novelty. |
| **Educational objective** | Convert LO-01 into LO-03/LO-05 before more coverage theatre; protect false LO-07 risk. |
| **Expected evidence of improvement** | EC-C/understanding signals catch up to coverage; soft “I’ve seen it all” confidence cools toward evidence; fewer unfinished novelty threads. |
| **Must not / do not use when** | Permanently freezes the Canonical Study Plan without escalation; punishes coverage honesty; ignores plan phase protections that require Master Planner pathways; used when LOB-01 requires rebuild of *earlier* scope (that is LI-04, not a vague pause). |
| **Speech cue** | “Coverage is ahead of understanding — we’ll consolidate before covering more.” |

**Educational principle.** Finishing the CMP is not finishing the learning. Pace must serve understanding.

---

### LI-10 — Recovery-Respecting Rebuild

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | After interruption, rebuild lightly and honestly — restore retrieval and confidence without heroic catch-up intensity. |
| **Required diagnosis** | LOB-04 when recovering into rhythm; LOB-11 rust after lawful break; Continuity / Profile Recovering postures that invite lighter rebuild (often alongside spacing/retrieval). |
| **Educational objective** | Safe return to LO-04/LO-05; protect sustainability. |
| **Expected evidence of improvement** | Gentle re-emergence of retrieval/application without overload collapse; cadence stabilises; despair narrative softens with evidence. |
| **Must not / do not use when** | Converts recovery into punishment catch-up; narrates the break as moral failure; invents that nothing was ever known; used as excuse to avoid LI-12 when sitting runway is already broken. |
| **Speech cue** | “After the break, we’ll rebuild gently and re-check what still holds.” |

**Educational principle.** Continuity respects interruption. Heroic catch-up theatre often destroys the recovery it pretends to save.

---

### LI-11 — Confidence Recalibration

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Adjust coaching tone and evidence anchors when felt confidence systematically diverges from performance — raise warranted confidence or cool overconfidence. |
| **Required diagnosis** | Primarily LOB-07 Confidence Mismatch. |
| **Educational objective** | Honest self-regulation toward LO-03–LO-07; protect false readiness speech. |
| **Expected evidence of improvement** | Soft self-story moves toward EC-C reality across sessions; overconfidence cools before exam-readiness claims; underconfidence yields to attributable successes without invented mastery. |
| **Must not / do not use when** | Authors understanding from confidence; demoralises with absolute language; ignores soft signals entirely; used instead of LOB-02/11 content work when confidence is correctly low; shames overconfidence. |
| **Speech cue** | “Your confidence and your practice results don’t match yet — we’ll align them with evidence.” |

**Educational principle.** Calibration protects exam decisions. Confidence is not competence; despair is not incapacity.

---

### LI-12 — Escalation for Replan / Reschedule

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Signal that educational envelopes, phase meaning, intensity, or sitting ambition no longer fit — Master Planner / Daily Coach rescheduling or replanning pathways must decide. |
| **Required diagnosis** | Persistent obstacle(s) despite lawful local interventions; LOB-04/05/09/12 (or stacked barriers) that cannot be repaired inside remaining plan envelopes; LO-07 impossible under remaining calendar. |
| **Educational objective** | Lawful long-term correction without silent rewrite. |
| **Expected evidence of improvement** | (Indirect) A revised plan/strategy that restores educational honesty — Learning Coach does not itself publish the new plan. |
| **Must not / do not use when** | Used as first tip for every stall; silently redesigns Canonical Study Plan inside Learning Coach speech; invents new phases; absorbs Scheduling Engine or Strategy authority; demoralising “you’re behind” without a pathway. |
| **Speech cue** | “Local coaching isn’t enough — we need to adjust the longer-term plan honestly.” |

**Educational principle.** Some problems are planning problems. Tutors escalate; they do not pretend calendar surgery is a study tip.

---

### LI-13 — Deliberate Practice

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Structure practice on a **narrow, named weakness** with clear success criteria, immediate educational feedback, and progressive difficulty — deeper than undirected question volume. |
| **Required diagnosis** | LOB-08 when practice exists but is unfocused; LOB-10 when technique elements need isolated craft; post–LI-07 when corrected ideas need controlled application; LOB-06 when method change must be practised, not merely advised. |
| **Educational objective** | Accelerate quality of LO-05 (and LO-07 process elements) on a scoped target. |
| **Expected evidence of improvement** | Named weakness shrinks across sessions; feedback-informed adjustments appear; transfer to slightly varied items without collapse. |
| **Must not / do not use when** | LOB-01/03 still primary; LOB-05 overload (narrow demand first); confuses deliberate practice with marathon question dumps; success criteria undefined; used to claim mastery from one focused block. |
| **Speech cue** | “We’ll practise one specific weakness deliberately — with clear aims and feedback — not just more questions in general.” |

**Educational principle.** Deliberate practice is focused improvement on a diagnosed weakness, not time-on-task theatre.

---

### LI-14 — Revision Restructuring

| Aspect | Provision |
|--------|-----------|
| **Educational meaning** | Redesign how revision is organised across prior scope — what returns, in what order, with what mix of retrieval and application — when revision contact exists but is educationally mis-shaped. |
| **Required diagnosis** | LOB-09 when returns are absent or chronically deferred (often with LI-06); LOB-11 when returns occur but are poorly designed; LOB-12 when first-pass still crowds out revision design; LOB-10 when revision lacks exam-form elements near sitting. |
| **Educational objective** | Make LO-06 (and late LO-07 contributions) structurally achievable inside coaching emphasis — without rewriting the plan unilaterally. |
| **Expected evidence of improvement** | Revision sessions show clearer scope mix; EC-E improves; protected revision intent is actually inhabited rather than skipped or filled with new coverage. |
| **Must not / do not use when** | Silently reallocates Canonical Study Plan protections (escalate via LI-12); replaces LI-04 when foundations are missing; treats “revise everything” as a structure; invents mastery from a revised checklist alone. |
| **Speech cue** | “We’ll restructure how we revise — what we return to, and how — so retention can build for the exam.” |

**Educational principle.** Revision is a designed educational system. Neglect and poor structure are different problems; both need response.

## 6. Primary Obstacle → First-Line Intervention Map

Traceability guidance only — not automatic selection maths. Selection rules live in `INTERVENTION_SELECTION.md`.

| Primary obstacle | Typical first-line interventions |
|------------------|----------------------------------|
| Insufficient warrant / Conflicting | **LI-00** Evidence Gathering |
| LOB-01 Prerequisite Gap | **LI-04**; sometimes LI-07 if wrong model is foundation-rooted |
| LOB-02 Weak Retrieval | **LI-03**; LI-06 as support |
| LOB-03 Misconception | **LI-07**; then LI-01 / LI-13 |
| LOB-04 Inconsistent Study | LI-10 when recovering; cadence via Daily Coach; **LI-12** if envelopes break |
| LOB-05 Cognitive Overload | **LI-09** / narrower session design; LI-10 if recovery; LI-08 when method is the demand shape |
| LOB-06 Ineffective Strategies | **LI-08** (incl. LI-08a); LI-13 to enact the new method |
| LOB-07 Confidence Mismatch | **LI-11**; LI-02/LI-03 as evidence anchors |
| LOB-08 Insufficient Practice | **LI-02**; LI-01 as support; LI-13 when focus is needed |
| LOB-09 Revision Neglect | **LI-06** + **LI-14**; LI-09 if first-pass must pause |
| LOB-10 Exam Technique | **LI-08**; LI-13; LI-05 careful exam-form stretch |
| LOB-11 Fragile Durability | **LI-06** + **LI-03**; LI-14 if return design is poor |
| LOB-12 Coverage Ahead | **LI-09**; LI-01/LI-03 as consolidation tools |

If no LOB can be named, the lawful response is **LI-00** — not picking an LI “because something must be recommended.”

---

## 7. What This Catalogue Explicitly Excludes

Not educational interventions in this Framework’s sense:

- character judgements or motivational shaming;
- opaque “boost engagement” tips without diagnosis;
- silent Canonical Study Plan mutation presented as coaching;
- mastery certificates, streak rewards, or score theatre as educational response;
- product UX fixes (operational — escalate separately);
- inventing syllabus content or unofficial “shortcuts” that contradict curriculum order.
