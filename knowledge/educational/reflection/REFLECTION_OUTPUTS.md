## 1. Purpose

An expert IFoA tutor, after reviewing a sitting, leaves a clear educational residue:

- what we now provisionally understand about today’s learning;
- whether tomorrow should continue, reinforce, or escalate;
- how confidently we may speak;
- what the next coach (including Kwalitec’s Daily Coach) should remember.

This catalogue names those outcomes so downstream coaching and narration consume a shared reflection contract.

Identifiers (EROut-XX) exist for traceability. Educational meaning is binding; widgets and schemas are out of scope.

---

## 2. Output Principles

1. **Warrant-traceable.** Material outputs cite today’s DCO-01 / session aims.
2. **Claim-typed.** Facts, estimates, and advice remain distinguishable.
3. **Non-mastery-minting.** No output implies understanding proof from completion alone.
4. **Non-rewriting.** Outputs must not silently redefine Canonical Study Plan commitments.
5. **Actionable for coaching.** Tomorrow implications are usable by Daily Coach input meanings.
6. **Escalation-explicit.** Structural needs are named as escalation — not hidden as local advice.
7. **Explainable.** Material outputs carry rationale (`REFLECTION_EXPLAINABILITY.md`).
8. **Field-free.** This catalogue defines meaning — not serialisation.

## 4. Output Specifications

### EROut-01 — Objective attainment summary

| Aspect | Specification |
|--------|----------------|
| **What** | Attainment class for today’s DCO-01 (served / partially served / attempted not served / deferred-escalated / rest-recovery fulfilled) |
| **Must include** | Reference to today’s work type and warrant; effect of interruptions/incompletes when material |
| **Must not** | Equate UI completion with “served”; invent attainment without ERI-01 |

### EROut-02 — Learning evidence summary

| Aspect | Specification |
|--------|----------------|
| **What** | Plain educational summary of qualifying observations (retrieval, practice, demonstrated repair) and explicit note when evidence was soft-only or absent |
| **Must include** | Quality band language (stronger / moderate / soft / thin) without mandatory scores |
| **Must not** | Invent observations; list product metrics as learning evidence |

### EROut-03 — Updated understanding posture

| Aspect | Specification |
|--------|----------------|
| **What** | Provisional posture for Estimated Knowledge / related understanding claims *as educational meaning* |
| **Must include** | Provisionality; evidence basis; coverage ≠ understanding ≠ mastery discipline |
| **Must not** | Declare mastery from one sitting; bypass Evidence Model succession; act as a silent Twin write specification |
| **Note** | Lawful persistence of this posture is owned by Evidence / Twin authority elsewhere |

### EROut-04 — Misconception register

| Aspect | Specification |
|--------|----------------|
| **What** | Zero or more named misconceptions / method errors tied to syllabus or skill targets |
| **Must include** | Specificity sufficient for future reinforcement |
| **Must not** | Vague stigma labels; invent errors from missing data |

### EROut-05 — Residual uncertainty statement

| Aspect | Specification |
|--------|----------------|
| **What** | Explicit statement of what remains uncertain after today’s sitting |
| **Must include** | Thin history, conflicts, incompletes, or unchecked first-pass material when applicable |
| **Must not** | Be omitted to preserve motivational theatre |

### EROut-06 — Confidence adjustment

| Aspect | Specification |
|--------|----------------|
| **What** | Educational advice on claim strength and student-facing confidence calibration |
| **Must include** | Alignment with evidence band; over/under-confidence handling when both confidence and performance exist |
| **Must not** | Inflate confidence contrary to evidence |

### EROut-07 — Reinforcement recommendation

| Aspect | Specification |
|--------|----------------|
| **What** | Advice to return to retrieval, practice, or misconception repair for today’s material |
| **Must include** | Educational target; plan/mode warrant or explicit “subject to Daily Coach envelope check” |
| **Must not** | Invent new first-pass ambition; steal protected revision; become undeclared Study Plan mutation |
| **Feeds** | Subsequent Daily Coach DCD-05 modulation and optional DCO-03 practice focus |

### EROut-08 — Continuation recommendation

| Aspect | Specification |
|--------|----------------|
| **What** | Advice that the plan’s next authorised educational rhythm remains appropriate |
| **Must include** | Honesty that Daily Coach still selects tomorrow under full DCD pipeline |
| **Must not** | Guarantee tomorrow’s DCO-01; ignore new capacity shocks tomorrow |

### EROut-09 — Escalation notice

| Aspect | Specification |
|--------|----------------|
| **What** | Notice that rescheduling and/or replanning is required |
| **Must include** | Educational reason (capacity collapse, repeated miss, envelope breach, phase/intent no longer fits); recommended pathway class (reschedule vs replan) |
| **Must not** | Quietly rewrite the Canonical Study Plan instead of escalating |
| **Pathway** | Daily Coach escalation outputs / Rescheduling Policy / Master Planner — as already established |

### EROut-10 — Coaching notes

| Aspect | Specification |
|--------|----------------|
| **What** | Concise tutor-facing notes: resume points, misconception targets, interruption context, confidence calibration hints |
| **Must include** | Claim-type labels when mixing fact and advice |
| **Must not** | Become a shadow Study Plan; store product-survey content as educational law |

### EROut-11 — Reflection rationale

| Aspect | Specification |
|--------|----------------|
| **What** | Plain-language educational explanation of material reflection conclusions |
| **Must include** | Links from warrant → evidence → conclusion → tomorrow implication |
| **Detail** | See `REFLECTION_EXPLAINABILITY.md` |

## 5. Output Combinatorics

| Situation | Typical output bundle |
|-----------|----------------------|
| Clean served sitting | EROut-01 Served + EROut-02 + EROut-05 (low) + EROut-08 + EROut-11; optional light EROut-03 |
| Soft-only completion | EROut-01 Partial / journey-complete + EROut-02 soft/thin + EROut-05 strong + EROut-06 understated + EROut-07 when plan allows + EROut-11 |
| Named misconceptions | EROut-04 + EROut-07 + EROut-10 + EROut-11 |
| Interrupted partial | EROut-01 Partial + EROut-05 + EROut-10 resume note + EROut-08 or EROut-09 as envelopes demand |
| Structural breach | EROut-09 mandatory; do not emit fake EROut-08 “business as usual” |

**Binding rule:** EROut-07 and EROut-08 may both appear only when ranked and non-contradictory (e.g. continue plan rhythm *and* reinforce a sub-skill inside envelopes). If they conflict with protections, escalate (EROut-09).

---

## 6. Architectural Boundary — Study Plan

| Output | May touch Canonical Study Plan? |
|--------|----------------------------------|
| EROut-01…EROut-06, EROut-10, EROut-11 | Read / interpret only |
| EROut-07, EROut-08 | Recommend within existing plan law |
| EROut-09 | Requests change via lawful pathways — does not itself rewrite the plan |

> **Reflection may update educational understanding and recommendations.  
> It must never directly rewrite the Canonical Study Plan.**

---

## 7. Relationship to Daily Coach Outputs

Reflection outputs are **not** a substitute for DCO-01…DCO-10 on the next day. They inform:

| Reflection output | Downstream Daily Coach use |
|-------------------|----------------------------|
| EROut-02 / EROut-03 | DCI-06 recent learning evidence / estimate humility |
| EROut-01 / incompletes | DCI-07 session completion history |
| EROut-07 / EROut-08 | DCD-05 modulation inputs |
| EROut-09 | DCO-08 escalation posture / DCI-12 flags |
| EROut-06 | Aligns with DCO-05 confidence honesty |
| EROut-10 | Coach memory for explainability and continuity |

Tomorrow’s primary objective remains a **Daily Coach** output under plan authority.
