## 1. Purpose

Interpretation is the tutor’s disciplined reading of the sitting:

1. What was asked today?
2. What was observed?
3. What may we provisionally believe?
4. What must remain uncertain?
5. What should tomorrow’s coaching do *within law*?

This document records that reasoning without prescribing algorithms, weights, thresholds, or code.

Identifiers (ERIJ-XX) exist for traceability (“interpretation judgement”). Educational meaning is binding; implementation formulae are out of scope.

---

## 2. Interpretation Principles

These refine Evidence Model principles for the post-session setting; they do not amend them.

1. **Warrant first.** Read all evidence against DCO-01 / session aims (ERI-01 / ERI-02).
2. **Succession law.** Activity → Evidence → Inference → Understanding posture. Do not skip steps.
3. **Quality before certainty.** Soft inputs inform; they do not outvote qualifying performance when conflict exists.
4. **Accumulation humility.** One sitting revises belief cautiously; it does not constitutionalise lasting mastery.
5. **Conflict → understatement.** Conflicting observations require honest provisional speech, not selective theatre.
6. **Absence is uncertainty.** Missing retrieval/practice evidence is not proof of weakness-as-fact.
7. **Misconceptions are targets.** Name them for reinforcement; do not moralise.
8. **Envelopes bound recommendations.** Tomorrow implications stay inside plan envelopes or escalate.
9. **No scores required.** Educational conclusions may be categorical and narrative; numerical proxies are optional later and never redefine meaning here.
10. **Deterministic posture.** Same warrant + same inputs → same attainment class, confidence band, and escalation posture.

## 3. Interpretation Pipeline (Educational)

```
ERIJ-01  Warrant lock (today’s objective + session aims)
   ↓
ERIJ-02  Separate journey facts from learning evidence
   ↓
ERIJ-03  Rank evidence quality (educational bands, not scores)
   ↓
ERIJ-04  Attainment judgement (ERO-01)
   ↓
ERIJ-05  Misconception & uncertainty extraction (ERO-03 / ERO-04)
   ↓
ERIJ-06  Confidence calibration (ERO-05)
   ↓
ERIJ-07  Understanding posture update (provisional)
   ↓
ERIJ-08  Tomorrow implication (continue / reinforce / escalate)
   ↓
ERIJ-09  Explainability attachment
```

### ERIJ-01 — Warrant lock

| Aspect | Rule |
|--------|------|
| **Require** | ERI-01 (DCO-01); refuse reflection theatre if absent |
| **Include** | Day posture / mode disclosure; session aims |
| **Must not** | Re-author the day’s job to flatter outcomes |

### ERIJ-02 — Separate journey facts from learning evidence

| Aspect | Rule |
|--------|------|
| **Journey facts** | Session completion posture, interruptions, incomplete activities, time context |
| **Learning evidence candidates** | Retrieval performance, practice performance, clearly demonstrated method repair, well-specified misconception corrections |
| **Soft signals** | Self-reflection, confidence statements — retained as soft |
| **Must not** | Promote journey facts to understanding claims |

### ERIJ-03 — Rank evidence quality (educational bands)

Use educational quality language consistent with the Evidence Model — **without defining a numerical score**:

| Band | Typical sources in a sitting | What it may support |
|------|------------------------------|---------------------|
| **Stronger observational** | Clear retrieval / practice outcomes on authorised work | Provisional understanding estimates with cautious confidence |
| **Moderate observational** | Mixed practice; partial retrieval; method use with support | Tentative estimates; reinforcement likely |
| **Soft / declarative** | Self-reflection, felt confidence, unvalidated clarity claims | Calibration, coaching notes, uncertainty leads — not high-certainty mastery |
| **Absent / thin** | Completion only; interrupted with no performance | Coverage / continuity speech only; withhold understanding certainty |

When bands conflict, **prefer understatement** and name the conflict.

### ERIJ-04 — Attainment judgement

| Attainment class | Educational meaning |
|------------------|---------------------|
| **Served** | Today’s authorised job was honestly pursued and educationally realised within scope (not merely ticked) |
| **Partially served** | Material progress on the job, but incompletes, interruptions, or skipped warranted phases limit the claim |
| **Attempted, not served** | Sitting occurred but did not educationally realise DCO-01 |
| **Deferred / escalated** | Day’s job was paused or returned to Daily Coach; do not narrate as success |
| **Rest / recovery fulfilled** | If today’s job was rest or recovery, fulfilment means honouring that posture — not inventing study theatre |

**Must not.** Treat “all UI steps done” as **Served** when retrieval/practice central to the aim was empty without warrant.

### ERIJ-05 — Misconception & uncertainty extraction

| Aspect | Rule |
|--------|------|
| **Misconceptions** | Extract only when performance or clear articulation warrants; prefer specific syllabus/method targets |
| **Uncertainty** | Always state residual uncertainty when evidence is soft, thin, conflicting, or incomplete |
| **First-pass struggle** | Normal difficulty on new material is not automatically a durable misconception |
| **Recurrence** | Use ERI-12 prior posture when judging pattern vs one-off slip |

### ERIJ-06 — Confidence calibration

| Aspect | Rule |
|--------|------|
| **Align** | Narrated confidence ≤ evidence band |
| **Over-confidence** | If ERI-08 is high but ERI-04/05 show struggle, prefer performance; coach calibration |
| **Under-confidence** | If performance is solid but confidence is low, acknowledge progress without minting mastery |
| **Must not** | Inflate confidence for motivation (DCO-05 honesty spirit) |

### ERIJ-07 — Understanding posture update (provisional)

| Aspect | Rule |
|--------|------|
| **May** | Propose a provisional update to educational understanding posture *subject to Evidence Model succession and Twin write authority elsewhere* |
| **Must** | Keep updates provisional; cite evidence band; preserve coverage ≠ understanding ≠ mastery |
| **Must not** | Claim Estimated Mastery from one sitting; invent evidence to justify an update; treat this document as a scoring engine |

This step is **educational meaning**, not an implementation write path.

### ERIJ-08 — Tomorrow implication

| Implication class | When it fits | Bound |
|-------------------|--------------|-------|
| **Continuation** | Job served (or rest fulfilled); no material misconception forcing return; plan’s next authorised job remains appropriate | Stay inside envelopes; Daily Coach still selects tomorrow under DCD law |
| **Reinforcement** | Weak retrieval/practice, partial attainment, or named misconceptions warrant return emphasis | Must be authorised by plan practice/consolidation/revision pathways or lawful Daily Coach modulation (DCD-05) — not invented first-pass ambition |
| **Confidence adjustment** | Over/under-confidence relative to evidence | Advice + narration calibration; not plan rewrite |
| **Escalation — reschedule** | Capacity collapse, repeated miss, incomplete backlog that cannot fit without breaching protections | Via Daily Coach → Rescheduling Policy |
| **Escalation — replan** | Educational envelopes / phase meaning / sitting ambition no longer fit | Via Daily Coach → Master Planner pathways |

**Hard rule:** If the honest implication requires long-term change, choose escalation — never silent Canonical Study Plan rewrite.

### ERIJ-09 — Explainability attachment

Material judgements (attainment, misconceptions, understanding posture, tomorrow implication) must carry rationale under `REFLECTION_EXPLAINABILITY.md`.

## 4. Worked Tutor Patterns (Non-Algorithmic)

These patterns illustrate interpretation posture. They are not scorecards.

### 4.1 Clean practice day

- Warrant: practise Topic T.  
- Retrieval/practice: solid on authorised items; one slip corrected.  
- Soft confidence: moderate.  
→ Attainment **Served**; mild coaching note; **Continuation** with optional light reinforcement if plan already places practice return; confidence honest and calm.

### 4.2 Completed first-pass with soft-only close

- Warrant: learn Topic T.  
- Completion: yes.  
- Retrieval: not run / empty.  
- Self-reflection: “I understand it.”  
→ Journey fact: completed. Understanding: **thin / soft only**. Attainment at most **Partially served** educationally if sense-making unchecked. **Reinforcement** toward retrieval when plan allows; **must not** mint knowledge from confidence.

### 4.3 Interrupted sitting

- Warrant: consolidate Topic T.  
- Interruption mid-practice; activities incomplete.  
→ Attainment **Partially served** or **Attempted**; high uncertainty; coaching note records resume point; tomorrow may continue same authorised job if Daily Coach / plan allow — or escalate if capacity pattern repeats.

### 4.4 Recurring misconception

- Prior posture shows same method error; today’s practice repeats it.  
→ Name misconception; prefer **Reinforcement** inside envelopes; if reinforcement would cannibalise protected revision or explode intensity, **Escalate**.

### 4.5 Escalation already raised in-session

- Session adaptation escalated because day’s job could not be served.  
→ Reflection **confirms** deferred/escalated posture; does not rewrite as success; may enrich escalation reason with evidence summary.

## 5. Forbidden Interpretations

| Forbidden move | Why |
|----------------|-----|
| Completion → mastery | Violates Evidence Model and Knowledge & Mastery distinctions |
| Soft confidence → high-certainty knowledge | Soft signals stay soft |
| Missing data → “student is weak” as fact | Absence is uncertainty |
| Product survey → learning evidence | Domain boundary (RIP-001) |
| Reflection → silent plan rewrite | Architectural requirement |
| Reflection → invent tomorrow’s DCO-01 alone | Daily Coach decision law owns tomorrow’s primary |
| Selective quoting of only favourable items | Conflict requires understatement |
| Punishment catch-up after a hard day | Recovery / envelope honesty; no heroics |

---

## 6. Relationship to Daily Coach Evidence Modulation

Subsequent Daily Coach days may use reflection outcomes under **DCD-05**:

- Prefer authorised consolidation / practice return after weak recent practice when evidence quality permits and envelopes allow.  
- Prefer continuing planned next job after solid authorised work.  
- Must not treat mission/session completion as mastery.  
- Thin evidence → plan-led provisional speech.

Reflection **supplies** the educational reading; Daily Coach **applies** modulation inside its decision pipeline.
