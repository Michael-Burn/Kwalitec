## 1. Purpose

An expert IFoA tutor faced with previously learned material does not grab a familiar “do past papers” mode. The tutor asks what consolidating need the evidence shows, which revision goods must lead, whether Learning Coach evidence suggests a deeper problem, what success would look like, and when another strategy — or Learning Coach escalation — would be wiser.

This document records that selection discipline so Revision Coach strategy recommendations remain educationally honest.

For each strategy, selection cards state:

- educational purpose,
- suitable evidence profile,
- expected educational outcome,
- situations where another strategy (or handoff) is preferable.

---

## 2. Selection Principles

1. **Warrant first.** No RVS without an explicit revision warrant and prior exposure (`REVISION_TRIGGERS.md`).
2. **Match consolidating need, not calendar guilt.** Phase labels alone never select RVS-06 or intensive RVS-01–RVS-03.
3. **One primary in speech.** Supporting strategies may exist; students hear one primary consolidating approach.
4. **Smallest sufficient approach.** Prefer RVS-07 when light maintenance suffices.
5. **Learning Coach humility.** If evidence shows a deeper learning problem on “covered” material, escalate rather than force a strategy.
6. **Objective specificity.** Name which RVO-XX goods the strategy advances.
7. **Envelope awareness.** Strategy informs emphasis within Canonical Study Plan / Daily Coach authority; escalate structural change honestly.
8. **Evidence honesty.** Fragility / forgetting / integration claims require Educational Evidence warrant — never absence inference alone.
9. **Recovery humility.** If meaningful disruption is primary, defer to Recovery Coach — do not open a revision strategy as catch-up disguise.
10. **No numerical scoring.** No weights, ranks, fitness scores, or priority maths as educational law.

---

## 3. Selection Procedure (Educational)

The tutor follows this order. Implementations may later encode equivalents; they may not skip educational steps.

| Step | Action | Output |
|------|--------|--------|
| 1 | Confirm **prior exposure** and **revision warrant** | RVT-XX + wrong-mode rejected |
| 2 | If first learning or Recovery-primary | **No strategy** — hand off |
| 3 | Confirm **material emphasis** under MS001 priority (RVP) | Target known unit(s) |
| 4 | Name **evidence profile** in educational language | Durability / retrieval / fragility / prerequisite / integration / exam-facing / maintenance |
| 5 | Consult **Learning Coach posture** | Proceed / escalate if deeper learning problem |
| 6 | Name **RVO-XX goods** that must lead | Priority among RVO-01…RVO-05 |
| 7 | List **candidate strategies** from Catalogue matched to the profile | Shortlist of RVS-XX |
| 8 | Eliminate candidates that **must not be used** given evidence, Profile, envelopes, Learning Coach posture | Reduced shortlist |
| 9 | Prefer **smallest sufficient** primary strategy | Primary RVS |
| 10 | State **expected educational outcome** and **success recognition** | Outcome + success cues |
| 11 | If revision alone cannot honestly help | Transition to **Learning Coach escalation** (`STRATEGY_TRANSITIONS.md`) — do not invent endless revision |
| 12 | Produce **explainability** under `STRATEGY_EXPLAINABILITY.md` | Student-facing account |

Skipping from “revision phase” directly to a strategy is unlawful.

## 4. Preferential Reading Order (Qualitative)

When multiple strategies fit, apply this qualitative order — **not** a numeric rank:

1. **Escalate to Learning Coach** if deeper learning problem / obstacle diagnosis is required (no RVS as compensation)  
2. **RVS-04** if prerequisite fragility of studied foundations blocks safe onward work  
3. **RVS-03** if brittle / falsely ready / thin grip is the leading consolidating problem (and Learning Coach still allows consolidating frame)  
4. **RVS-02** if weak retrieval / production on known material leads  
5. **RVS-01** if durability across spacing is the leading need (with prior demonstrated understanding)  
6. **RVS-05** if related known topics must cohere for exam / curriculum use  
7. **RVS-06** when exam proximity makes exam-facing consolidation of *already known* material the leading story — may intensify form of the above without inventing coverage  
8. **RVS-07** when the trail is healthy and only light keep-alive return is warranted  

Envelope breakage or Recovery-primary disruption at any point → hand off rather than force a local strategy.

## 5. Per-Strategy Selection Cards

Each card below is binding educational selection law for that RVS.

---

### RVS-01 — Durability Reinforcement

| Aspect | Provision |
|--------|-----------|
| **Educational purpose** | Strengthen lasting retention of previously demonstrated understanding across spacing |
| **Suitable evidence profile** | Prior success or workable understanding exists; spacing / return trail shows durability risk **or** authorised spaced return is the honest job; not primarily a misconception / obstacle case |
| **Expected educational outcome** | Knowledge remains usable after intentional spacing; student experiences consolidating return as protection of what was learned |
| **Prefer another approach when** | Retrieval production is the acute failure → RVS-02; brittleness / false readiness dominates → RVS-03; trail is already healthy → RVS-07; understanding never formed → Learning Coach; disruption primary → Recovery Coach |

---

### RVS-02 — Retrieval Strengthening

| Aspect | Provision |
|--------|-----------|
| **Educational purpose** | Improve active recall and production of previously learned methods and results |
| **Suitable evidence profile** | Weak, effortful, or failed retrieval on return; passive familiarity without production; exam-facing need to *find* known material under pressure |
| **Expected educational outcome** | Methods and results become more findable with less scaffolding than on recent weak return |
| **Prefer another approach when** | Understanding is brittle beyond mere retrieval → RVS-03; only light keep-alive needed → RVS-07; unlearned content → first learning; obstacle diagnosis required → Learning Coach |

---

### RVS-03 — Fragile Knowledge Stabilisation

| Aspect | Provision |
|--------|-----------|
| **Educational purpose** | Steady brittle previously learned understanding so it holds under variation and pressure |
| **Suitable evidence profile** | Covered / same-day success without durable grip; pattern-matching; thin practice depth; Learning Coach thin / falsely ready posture where consolidating frame remains honest |
| **Expected educational outcome** | Understanding becomes less brittle; explanation and varied application improve without inventing mastery |
| **Prefer another approach when** | Learning Coach diagnoses an obstacle requiring intervention (do not loop RVS-03 endlessly) → Learning Coach; acute retrieval-only weakness with solid explanation → RVS-02; prerequisite for next work is the issue → RVS-04; healthy trail → RVS-07 |

---

### RVS-04 — Prerequisite Refresh

| Aspect | Provision |
|--------|-----------|
| **Educational purpose** | Refresh studied foundations that later authorised work depends on |
| **Suitable evidence profile** | Prior exposure to foundation; dependency from current / imminent authorised work; weak return or fragility on that foundation |
| **Expected educational outcome** | Foundations firm enough for safe onward learning; later first learning remains first learning |
| **Prefer another approach when** | Foundation was never studied → first learning; no onward dependency (ordinary decay only) → RVS-01 / RVS-02 / RVS-03 as profile fits; exam consolidation of unrelated known topics → RVS-06; deeper conceptual barrier → Learning Coach |

---

### RVS-05 — Concept Integration

| Aspect | Provision |
|--------|-----------|
| **Educational purpose** | Connect previously learned related topics into a usable network |
| **Suitable evidence profile** | Prior exposure for each linked unit; isolation on return; curriculum / exam interdependence warrants joint consolidation |
| **Expected educational outcome** | Student can use related known ideas together with evidence-honest integration speech |
| **Prefer another approach when** | One linked topic lacks prior exposure → first learning for that unit + refuse joint “integration”; single-topic durability / retrieval need → RVS-01 / RVS-02; brittle single-topic understanding → RVS-03 before integration theatre |

---

### RVS-06 — Examination Consolidation

| Aspect | Provision |
|--------|-----------|
| **Educational purpose** | Sharpen exam-usable strength of already learned material as the sitting approaches |
| **Suitable evidence profile** | Prior exposure for target scope; lawful exam proximity / plan exam-facing emphasis; protected revision used for consolidating substance |
| **Expected educational outcome** | Known material becomes more usable under authentic exam conditions; readiness remains provisional |
| **Prefer another approach when** | Target scope unlearned → first learning (never RVS-06 as coverage theatre); acute fragility / forgetting on known material still needs repair before exam polish → RVS-03 / RVS-01 / RVS-02 first; Recovery-primary return → Recovery Coach; deeper learning problem → Learning Coach |

---

### RVS-07 — Maintenance Revision

| Aspect | Provision |
|--------|-----------|
| **Educational purpose** | Light protective return that keeps healthy known material available without inventing crisis |
| **Suitable evidence profile** | Reasonably durable known material; authorised keep-alive spacing; no acute forgetting / fragility warrant |
| **Expected educational outcome** | Healthy knowledge stays available; student hears protection, not failure |
| **Prefer another approach when** | Clear forgetting / weak retrieval → RVS-01 / RVS-02; brittle / false readiness → RVS-03; prerequisite / integration / exam-facing needs dominate → RVS-04 / RVS-05 / RVS-06; Learning Coach posture contradicts “healthy” reading → consume / escalate |

## 6. Stacked Needs and Supporting Strategies

When needs stack (e.g. exam proximity + fragile known topic):

1. Name **one primary** strategy in student speech (usually the leading educational risk).  
2. Allow a **supporting** strategy only when it does not contradict the primary story.  
3. Example: primary **RVS-03** with exam-facing *form* (RVS-06 intensifies conditions) — speech still leads with stabilising fragile knowledge, not “you are exam ready.”  
4. Never stack a revision strategy with Recovery-primary or first-learning needs as if they were the same mode.

---

## 7. Learning Coach Gate (Before Selection Completes)

Before locking a primary RVS, the tutor asks:

| Gate question | If “yes” |
|---------------|----------|
| Does Learning Coach evidence show an obstacle / thin genuine progression that revision cannot honestly repair? | **Escalate** — do not select RVS as compensation |
| Is an intervention already the lawful educational response? | Defer to Learning Coach; revision strategy only if explicitly subordinate and honest |
| Would success of this strategy require redefining mastery? | Refuse; keep RVO speech evidence-honest |

Hard rule:

> **Repeated revision is not a lawful substitute for Learning Coach authority  
> when evidence indicates a deeper learning problem.**

## 8. Lawful vs Unlawful Selection Examples

| Situation | Lawful | Unlawful |
|-----------|--------|----------|
| Protected revision window; healthy known chapter | RVS-07 maintenance | Open RVS-06 panic because the window is labelled “revision” |
| Spaced return weak on retrieval of known methods | RVS-02 | Teach next unread chapter as “retrieval practice” |
| Covered topic; same-day success; fails on variation | RVS-03 if consolidating frame honest; else Learning Coach | Endless RVS-03 loops ignoring obstacle diagnosis |
| Next topic depends on brittle studied foundation | RVS-04 | Teach foundation for the first time as revision |
| Exam in three weeks; two topics never studied | First learning for unlearned; RVS-06 only for known | RVS-06 over the whole syllabus |
| Learning Coach diagnoses misconception on covered topic | Learning Coach intervention primary | Select RVS-02 “just do more questions” to override diagnosis |
| Student returns after two-week illness | Recovery Coach primary | Open RVS-01 as if disruption were ordinary spacing |
