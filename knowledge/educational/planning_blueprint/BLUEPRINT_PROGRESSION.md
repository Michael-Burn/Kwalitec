This document defines **how students move through a Planning Blueprint** — entry, progression, pause, recovery insertion, revision entry, and completion — using **educational criteria only**.

Progression rules **organise package decisions into movement law**. They introduce **no new educational reasoning**, **no date calculations**, and **no mastery thresholds invented for scheduling convenience**.

---

## 1. Purpose

A blueprint without progression rules is a static diagram. An expert IFoA tutor also decides:

- when the student may enter the journey structure;
- when first-pass work may advance;
- when study should pause rather than grind;
- when recovery must be inserted;
- when revision becomes the primary mission;
- when the journey for this sitting is educationally complete.

This document records those criteria so scheduling engines move students through authorised structure — not invent advancement rules in calendar code.

---

## 2. Progression Principles

1. **Educational criteria only.** Movement depends on coverage honesty, package postures, feasibility, recovery needs, and mode authority — not on “enough days filled.”
2. **Package is law.** Progression never contradicts PD-01…PD-16 postures.
3. **Understatement.** Thin evidence → cautious advancement; no invented readiness.
4. **Pause is lawful.** Stopping is sometimes the educationally correct move.
5. **Recovery before heroics.** After disruption, insert recovery / lawful catch-up options before impossible compression.
6. **Revision entry is explicit.** Crossing into Protected Revision requires the PD-04 boundary — not silent relabelling of leftover topics.
7. **Completion ≠ mastery.** Finishing the blueprint for a sitting means the structured journey reached its educational end; it does not mint a pass claim.
8. **Re-blueprint when package changes.** Material Profile / strategy / sitting shocks require a new package (and thus a new blueprint), not silent progression theatre on stale structure.

## 3. Entry Criteria

### 3.1 Entry into a published blueprint (BP-00 → active journey)

The student may enter an active Planning Blueprint when **all** of the following hold:

| Criterion | Educational meaning | Package warrant |
|-----------|---------------------|-----------------|
| **Anchors exist** | Examination and sitting are bound | D1 / package identity |
| **Package complete** | Mandatory decisions present, including capacity, revision reservation, sequencing, intensity band, feasibility, explainability | MS004 §6.2–6.3 |
| **Feasibility posture honest** | Either “fits” or explicit infeasibility / triage counsel — never hidden | PD-13 / D8 |
| **Strategy bound** | Primary strategy ID and meaning attached | Package strategy binding |
| **Forbidden decisions absent** | No F1–F14 structures encoded | Decision Model §5 |

**Refuse entry (publish no complete journey)** when the package is incomplete or silently infeasible.

**Triage entry:** Under ES-09 / ES-10 (or equivalent package triage), the student may enter a *reduced* blueprint that names what remains educationally possible — still package-derived, still honest.

### 3.2 Entry into Foundation & Knowledge Building (BP-01)

| Criterion | Educational meaning |
|-----------|---------------------|
| Blueprint entry satisfied | §3.1 |
| Starting coverage position known | PD-02 |
| Sequencing policy fixed | PD-01 |
| Intensity envelope set | PD-06 / BC-12 |
| Protected revision region reserved in structure | PD-03 (even if far from sitting in calendar terms later) |

Cold-start students enter with cautious defaults already present in the package — never with invented weakness theatre.

## 4. Progression Criteria

Progression means advancing educational mission within or across phases **without** violating sequencing, intensity, or revision protection.

### 4.1 Within BP-01 (first-pass advancement)

Advance to the next learning block when:

| Criterion | Educational meaning |
|-----------|---------------------|
| Current unit’s Study Progress / coverage advance is lawful | Continuity of educational history |
| Prerequisites for the next unit are satisfied under curriculum law | PD-01 / C6–C8 |
| Intensity remains inside BC-12 | PD-06 |
| Revision region remains structurally protected | PD-03 not consumed by default |

Do **not** advance by:

- shuffling order for engagement;
- skipping foundations silently;
- accelerating via punishment load after missed days.

### 4.2 Interleaved BP-02 / BP-03 during first-pass

Insert or emphasise practice / consolidation components when the package postures warrant (PD-05, PD-14), typically when:

- the relevant material has already been studied (practice); and/or
- retention risk / syllabus length warrants spaced return (consolidation).

Interleaving is **progression of emphasis**, not abandonment of BP-01.

### 4.3 Toward milestones and checkpoints

Reach BC-08 / BC-09 when the educational event the package named has occurred (e.g. section coverage complete, revision start). Milestones are legibility devices — not automatic mastery certificates.

### 4.4 Strategy-coloured pace (not new law)

Strategy may privilege steadier or more cautious advancement (e.g. Steady Progression, Confidence Restoration, Recovery) or earlier freeze (Rescue / Late Starter). Pace colouring must already exist in the package intensity / risk / confidence decisions — progression does not invent a second strategy engine.

## 5. Pause Conditions

Pause means temporarily suspending progressive first-pass or dense practice **without** treating the student as failed.

Pause when **any** of the following educational conditions hold:

| Condition | Educational reason | Typical package link |
|-----------|--------------------|----------------------|
| **Declared leave / known interruption** | Capacity truth changes | Capacity / leave in package; PD-12 |
| **Burnout or soft-signal distress** | Sustainability outranks coverage theatre | PD-06 moderated; PD-07; ES-07/ES-08 |
| **Feasibility break** | Remaining work no longer fits envelopes | PD-13 escalation |
| **Evidence shock** | Mock or practice outcomes invalidate current emphasis | Feeds re-package; may pause dense work |
| **Student-declared need to stop** | Adherence and honesty beat coerced grind | Preference fit within constraints; recovery law |
| **Final freshness protection** | Cognitive freshness before sitting | BP-06 / BC-11 |

During pause:

- do not invent punishment catch-up plans;
- preserve learner history;
- prefer BC-06 / BC-07 / BC-11 over silent impossible compression (PD-16).

Pause is educationally distinct from **abandonment**. Abandonment without replan leaves the sitting at risk; lawful pause leads to recovery insertion or re-blueprint.

## 6. Recovery Insertion

### 6.1 When to insert BP-07 / BC-06 / BC-07

Insert recovery structure when the package (or a required re-run that produces an updated package) warrants PD-07 / PD-08 / PD-16, especially after:

- mocks (BC-05) when recovery was decided;
- dense intensity peaks;
- illness, leave, or missed-study shock;
- abandoned intensity / consistency collapse;
- Confidence Restoration / Recovery strategies.

### 6.2 Lawful recovery responses (from package — not invented)

Per PD-16 / D18, choose among lawful options already authorised:

1. Use buffer periods (BC-07)
2. Reduce intensity elsewhere (tighten BC-12 posture)
3. Defer low-priority consolidation (shrink non-critical BC-03)
4. Escalate infeasibility / triage counsel (PD-13)

**Forbidden default:** silent impossible compression; punishment pacing; borrowing protected revision for first-pass without surfacing trade-off (F1, F2, F9).

### 6.3 Re-entry after recovery

Re-enter BP-01…BP-04 only when:

- intensity is again inside a sustainable envelope;
- sequencing and starting position remain honest (no history erasure);
- revision region remains protected;
- feasibility posture is re-checked if capacity truth changed.

If capacity truth changed materially, **re-run the Decision Engine** and rebuild the blueprint — do not “progress” on obsolete structure.

## 7. Revision Entry

### 7.1 Crossing into Protected Revision (BP-04)

Enter primary revision emphasis when the package’s **PD-04 first-pass vs revision boundary** is reached educationally.

Educational signals that the boundary is live (as already decided in the package — not newly invented here):

| Signal | Meaning |
|--------|---------|
| **Reserved revision region begins as primary mission** | PD-03 capacity becomes the active phase home for BC-04 |
| **Coverage posture supports revision emphasis** | First-pass complete *or* remaining first-pass fits only under explicit triage — never silent borrow |
| **Strategy Approach / Rescue / Revision Intensive freeze** | Package already privileged earlier freeze |
| **BC-10 transition point** | Mission change is explicit and explainable |

### 7.2 What revision entry is not

- Relabelling unfinished first-pass topics as “revision” without PD-04
- Practising never-studied material under a revision banner as coverage substitute
- Automatic mastery claims because revision started
- Calendar proximity alone without package boundary (dates are scheduling’s concern; boundary *intent* is package’s)

### 7.3 Within revision progression

Advance revision blocks according to D16 emphasis mix in the package (breadth vs evidenced weak-area depth), with estimates labelled and cold-start invention forbidden (F6).

Mocks (BP-05) may occur adjacent to or within revision per PD-15 without ending revision early unless Final Preparation freeze requires it.

## 8. Completion Conditions

### 8.1 Educational completion of the blueprint for this sitting

The journey structure is educationally complete when **all** applicable conditions hold:

| Condition | Meaning |
|-----------|---------|
| **Active phases fulfilled or honestly triage-closed** | BP-01…BP-06 missions met relative to package — or explicitly reduced under triage with student-visible truth |
| **Protected revision mission honoured** | BC-04 region was not silently consumed; revision emphasis executed per package |
| **Mock intent resolved** | PD-15 satisfied or deferred honestly |
| **Final Preparation posture reached** | BP-06 freeze / freshness structure in place when package required it |
| **Sitting boundary** | Study after the sitting does not count toward this sitting (F13) |

### 8.2 What completion does not mean

- Mastery of the syllabus
- A predicted pass
- Permission to erase history for the next sitting
- Automatic readiness claims for concurrent subjects

### 8.3 Early closure / infeasibility closure

If PD-13 marks the sitting infeasible, “completion” may mean **honest closure of the fantasy journey** — counselling scope, hours, or sitting change — not drawing remaining phases as if they still fit.

### 8.4 Replan completion vs sitting completion

Finishing a recovery/replan cycle (BP-07 exit) restores lawful progression; it is not sitting completion. Sitting completion awaits §8.1.

## 9. Progression State Summary

```
ENTER blueprint (§3)
   → PROGRESS within/across phases (§4)
        ↕ PAUSE when required (§5)
        ↕ INSERT recovery (§6) → re-enter or re-blueprint
   → ENTER revision at PD-04 (§7)
   → FINAL PREPARATION
   → COMPLETE for sitting (§8)
```

All arrows are educational. Calendar placement of these states is the Scheduling Engine’s job ([`../scheduling/`](../scheduling/)).

## 10. Interaction With Daily Modes

| Progression event | Daily-mode implication |
|-------------------|------------------------|
| BP-01 learning advancement | Constrains Learning Mode topic advancement envelopes; does not silently replace Current Learning Topic authority |
| BP-04 revision entry | Authorises Revision Mode *emphasis timing* per package boundary; modes remain constitutionally governed |
| Pause / recovery | Informs lighter missions; forbids punishment pacing |
| Completion | Ends this sitting’s blueprint mission; does not invent post-exam credit |
