## Purpose

This folder defines **the permanent constitutional process by which relevant constitutional information is selected and assembled from an available Execution Context for a specific constitutional execution**.

It answers *how resolution consumes the Execution Context*, *what resolution must optimise*, *which recognised stages organise resolution*, *what resolution may and must never do*, and *how resolution is constitutionally explained* — without implementing Runtime A, executing constitutional logic, interpreting constitutional law independently, producing constitutional decisions, modifying constitutional specifications, or replacing constitutional authority.

It does **not** implement Runtime A, test runners, CI/CD pipelines, GitHub Actions, Python, Flask, SQLAlchemy, REST, OpenAPI, infrastructure, or application services.

> **Constitutional Execution Context Resolution assembles constitutional information for execution.  
> It never performs constitutional execution itself.  
> It never interprets constitutional law independently.  
> It never produces constitutional decisions.**

## Architectural requirement

Constitutional Execution Context Resolution assembles **constitutional information for execution**.

| Lawful | Unlawful |
|--------|----------|
| Consume the Execution Context | Execute constitutional logic |
| Select constitutional artefacts | Interpret constitutional law independently |
| Assemble a resolved execution context | Produce constitutional decisions |
| Validate consistency of the resolved view | Determine compliance |
| Preserve constitutional authority and neutrality | Certify implementations |
| Explain selection, exclusion, dependencies, checks, and boundaries | Amend constitutional law / replace constitutional authority |

**Resolution assembles constitutional information for execution.  
It never performs constitutional execution or constitutional interpretation independently.**

## How to use this corpus

1. Confirm a lawful Constitutional Execution Context exists under MS001 — refuse resolution theatre assembled from an unpublished or incomplete information environment.
2. Read `CONSTITUTIONAL_EXECUTION_CONTEXT_RESOLUTION_MODEL.md` for stack position and integrity rules.
3. Optimise under `RESOLUTION_OBJECTIVES.md`.
4. Sequence under `RESOLUTION_STAGES.md` (CECR-01…CECR-06 only).
5. Enforce hard stops under `RESOLUTION_BOUNDARIES.md`.
6. Require explainability contracts from `RESOLUTION_EXPLAINABILITY.md` before student-, developer-, or auditor-facing resolution narration.
7. Do not implement resolution machinery that contradicts this corpus without amending it first — and do not treat resolution as execution, interpretation, or decision.
