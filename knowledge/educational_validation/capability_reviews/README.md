# Capability Reviews

Layer 1 Educational Capability Validation reports.

## Purpose

One independently reviewable report per educational capability (EC-ID) per candidate version.

## Naming

```
EC-<NN>_<capability_slug>_<version>_<YYYYMMDD>.md
```

Examples:

- `EC-01_master_planner_v1.0_20260725.md`  
- `EC-02_daily_coach_v1.0_20260725.md`

## Required Version 1.0 IDs

- EC-01 Master Planner  
- EC-02 Daily Coach  
- EC-03 Learning Coach  
- EC-04 Recovery Coach  
- EC-05 Revision Coach  
- EC-06 Exam Coach  

## Template

Use the template in [`../CAPABILITY_VALIDATION_GUIDE.md`](../CAPABILITY_VALIDATION_GUIDE.md) §8.

## Rules

- Do not combine multiple EC-IDs in one file.  
- Cite Blind Review evidence; do not mutate Blind Review outputs.  
- Include a full Educational Dimensions table.
