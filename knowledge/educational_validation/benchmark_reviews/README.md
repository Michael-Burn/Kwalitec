# Benchmark Reviews

Standing benchmark profiles and post-unblinding comparison records.

## Purpose

Support Layer 2 Blind Comparative Review with durable descriptions of educational benchmarks and dated results after sealed comparisons.

## Naming

| Artefact | Pattern |
|---|---|
| Benchmark profile | `BM-<NN>_<slug>_profile.md` |
| Dated comparison | `BM-<NN>_<slug>_vs_<version>_<YYYYMMDD>.md` |
