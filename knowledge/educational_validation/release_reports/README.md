# Release Reports

Official Version Approval Reports issued by the Educational Release Gate (Layer 4).

## Purpose

Each file in this folder is an **official educational approval artefact** for a Kwalitec version candidate.

## Naming

```
VAR_<version>_<YYYYMMDD>.md
```

Example: `VAR_1.0_20260801.md`

## Template

Copy from [`../RELEASE_DECISION_TEMPLATE.md`](../RELEASE_DECISION_TEMPLATE.md).

## Authority

Only reports in this folder (completed and signed per template) constitute EVF educational release decisions.

Working papers belong in [`../reports/`](../reports/). Capability evidence belongs in [`../capability_reviews/`](../capability_reviews/).
