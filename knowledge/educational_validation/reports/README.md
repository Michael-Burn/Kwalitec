# EVF Reports

Working papers and cross-cutting validation reports for the Educational Validation Framework.

## Purpose

Store comparative reports, mapping notes, and other EVF working artefacts that are not yet (or not only) official Version Approval Reports.

## Naming

| Artefact | Pattern |
|---|---|
| Sealed blind comparative report | `COMPARATIVE_<version>_<YYYYMMDD>.md` |
| Corpus mapping note | `COMPARATIVE_MAPPING_<version>_<YYYYMMDD>.md` |
| Cross-cutting analysis | `EVF_REPORT_<topic>_<YYYYMMDD>.md` |

## Official release decisions

Do **not** file Version Approval Reports here. Use [`../release_reports/`](../release_reports/).
