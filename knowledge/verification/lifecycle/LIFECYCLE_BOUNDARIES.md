## 1. Purpose

A lifecycle that silently becomes a second constitution — rewriting specs so stages “complete,” inventing educational meaning in “findings,” licensing runtime behaviour under a closed badge, inventing lineage to force CVL-04, treating a preferred implementation as the new standard, mutating artefacts mid-lifecycle, or issuing certificates that freeze a stack as law — destroys student trust and educational integrity.

This document draws a bright line between **lawful constitutional verification lifecycle coordination** (Programme IX / WS2 / MS002) and **constitutional authorship / educational judgement / runtime authorship / conformance meaning / lineage authorship / verification-type authorship / certification / artefact mutation** (Constitution / EIP / Programmes VI–VIII / WS1 / WS2 MS001 / permitted writers).

---

## 2. Boundary Principles

1. **Coordinate, do not legislate.** The lifecycle organises verification; it does not create law.
2. **Published specifications only.** Unpublished customs and “main as law” are hard stops as standards.
3. **Published stages only.** Unpublished CVL customs are unlawful.
4. **Published verification types only.** CVL-04 applies CV-01…CV-07 only.
5. **Named evidence only.** Lifecycles without identifiable implementation evidence are theatre.
6. **Established traceability only.** Invented CT relationships are hard stops as lifecycle inputs.
7. **Exactly as published.** Successful progress never rewrites specification meaning.
8. **Authority first.** Published corpora remain the sole constitutional standard.
9. **Implementation independence.** No stack, vendor, or reference implementation becomes law by proximity to closure.
10. **Closed ≠ quality.** Lifecycle closure never grades learning, mastery, readiness, or product success.
11. **Closed ≠ certified.** The lifecycle never issues certificates for implementations, stacks, vendors, or releases.
12. **Closed ≠ permanently conformant.** The lifecycle supports fidelity honesty; it never replaces MS001 meaning or freezes conformity.
13. **No redefinition.** Programme VI questions, EIP claim classes, CC criteria, CT lineage meaning, and CV type meaning survive coordination intact.
14. **No authority substitution.** A closed lifecycle never replaces the corpus for the next judgement.
15. **No artefact mutation.** Coordination never rewrites implementation artefacts to manufacture passable evidence.
16. **No bypass.** Product urgency never waives constitutional lifecycle requirements.
17. **Repeatability / consistency.** Race-dependent or private stage shortcuts are defects.
18. **Explain the stop.** Students, developers, and auditors should hear when the lifecycle must refuse progress or closure.
19. **No emergency exemption.** Deadlines and demos never mint constitutional amendment power or certificates via lifecycle closure.

## 3. What the Lifecycle May Do (Lawful)

| Lawful action | Constitutional meaning |
|---------------|------------------------|
| **Coordinate verification** | Organise activities through CVL-01…CVL-07 |
| **Consume constitutional specifications** | Use published Constitution / EIP / Programme VI / VII / VIII corpora as evaluation standards |
| **Consume implementation evidence** | Bind named evidence for evaluation without mutating it |
| **Consume established traceability** | Use established CT-01…CT-07 relationships as inputs; never invent them |
| **Consume conformance artefacts** | Reference identifiable WS1 / MS001 assessment records as inputs without rewriting them |
| **Apply verification types** | At CVL-04, apply published CV-01…CV-07 only |
| **Produce verification findings** | Emit satisfied / not-satisfied / deferred / escalated under published criteria |
| **Preserve audit records** | Keep reconstructable trails of specs, evidence, relationships, stages, findings, and boundaries |
| **Refuse unlawful progress** | Prefer honest refuse / defer / escalate / not-satisfied over improvisation |
| **Remain repeatable and consistent** | Same published inputs → same stage outcomes and dispositions |
| **Remain implementation-neutral** | Honour lifecycle law across lawful equivalent stacks |
| **Support constitutional conformance** | Strengthen fidelity honesty without replacing CC meaning or certifying conformity |
| **Explain lifecycle progress** | Answer specs / evidence / relationships / stages / findings / boundaries without rewriting meaning |
| **Propose corpus amendments upstream** | Recommend (not enact) amendments when law itself must change |

These actions **coordinate verification**. They do **not** publish a new Constitution, invent coach warrants, mint tips, author ownership maps, invent CV or CVL types, invent CT links, author runtime behaviour, judge educational quality, certify implementations, or modify artefacts under coordination pretext.

## 4. What the Lifecycle Must NEVER Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Certify implementations** | Lifecycle is coordinative / evaluative, not a certification bureau | Emit findings; never issue certificates for code, stacks, vendors, or releases |
| **Replace conformance** | CC owns when conformity may be claimed | Support fidelity honesty; never narrate closure as certified conformity |
| **Redefine constitutional law** | Published corpora own meaning | Confirm published meaning; never rewrite it in stage prose or findings |
| **Modify constitutional specifications** | Only corpus governance may amend law | Leave specs unchanged; propose amendment upstream or mark not-satisfied / refuse |
| **Modify implementation artefacts** | Coordination is not a mutation licence | Prepare and evaluate evidence as found; refuse when identity is insufficient |
| **Create constitutional law** | Findings and stage progress are not legislation | Cite published law only; refuse unpublished standards |
| **Redefine educational meaning** | Programme VI owns coach / planner questions | Evaluate evidence of fidelity to published meaning; never redefine it |
| **Substitute constitutional authority** | Published corpora remain the standard after any closure | Keep artefacts as assessed subjects, never as next-cycle law |
| **Invent traceability** | CT owns lawful lineage | Consume established relationships; refuse invented links |
| **Rewrite conformance findings** | CC owns conformity meaning | Consume CC artefacts as inputs; never amend them to force satisfaction |
| **Invent verification types** | CV catalogue is closed under WS2 / MS001 | Apply CV-01…CV-07 only |
| **Invent lifecycle stages** | CVL catalogue is closed under this corpus | Apply CVL-01…CVL-07 only |
| **Bypass lifecycle requirements** | Requirements are educational care, not optional polish | Prefer understatement / refuse over invented green |
| **Privilege a technology as constitutional** | Implementation neutrality | Coordinate obligations, not Flask / SQLAlchemy / REST / OpenAPI fashion |
| **Determine educational quality** | No CVL stage is a quality rubric | Keep coordination speech distinct from quality speech |
| **Determine constitutional truth** | Constitution / EIP own truth | Obey published law; do not adjudicate truth in lifecycle machinery |
| **Transfer authority** | Programme VII WS2 owns ownership, permission, and conflict disposition | Apply Authority corpora; refuse domain absorption via stages |
| **Invent educational state** | Programme VII WS4 owns EST/CST context law | Evaluate against published postures only |
| **Generate unpublished recommendations** | Programme VII WS3 + Programme VI owners own tip warrant | Surface fidelity findings, not new tips |
| **Treat Twin / Adaptive / UI / CI noise as constitutional producers** | They are subjects / delivery surfaces | Require published corpus mapping or refuse |
| **Present scores / coverage / acks / cache hits as constitutional satisfaction or closure** | Operational proxies are not lifecycle law | Cite published corpora, CV types, and CVL stages |
| **Become irreplaceable by coordination topology** | Replaceability | Keep lifecycle law implementation-independent |

## 6. Boundary Checks (Pre-Closure)

Before a material constitutional verification lifecycle is treated as closed, coordination requires affirmative answers:

| Check | Question |
|-------|----------|
| **CVLB-01 Specification identity** | Are evaluation standards published Constitution / EIP / Programme VI / VII / VIII specifications (not unpublished customs)? |
| **CVLB-02 Stage class** | Are required CVL-01…CVL-07 stages being applied (not unpublished customs)? |
| **CVLB-03 Verification class** | Are required CV-01…CV-07 types applied at CVL-04 (not unpublished customs)? |
| **CVLB-04 Evidence identity** | Which named implementation evidence was consumed? |
| **CVLB-05 Traceability identity** | Which established CT relationships were used (none invented)? |
| **CVLB-06 Findings binding** | Which lifecycle stage produced each finding (especially CVL-04 / CVL-05)? |
| **CVLB-07 Non-legislation** | Does the lifecycle avoid creating or modifying constitutional specifications? |
| **CVLB-08 Non-redefinition** | Does the lifecycle avoid redefining Programme VI educational meaning or sibling constitutional meaning? |
| **CVLB-09 Non-substitution** | Does the lifecycle avoid treating the implementation or lifecycle machinery as the next constitutional standard? |
| **CVLB-10 Non-certification** | Does the lifecycle avoid issuing certificates for implementations, stacks, vendors, or releases? |
| **CVLB-11 Non-conformance-replacement** | Is closure framed as coordination complete — not certified conformity or permanent conformance? |
| **CVLB-12 Non-mutation** | Were implementation artefacts left unmodified by lifecycle coordination? |
| **CVLB-13 Neutrality** | Does the lifecycle avoid privileging a language, framework, protocol, or CI vendor as law? |
| **CVLB-14 Closure ≠ quality** | Is the outcome framed as lifecycle coordination / evidence satisfaction — not educational quality? |
| **CVLB-15 Spec immutability** | Are constitutional corpora left unchanged by the lifecycle act? |
| **CVLB-16 Repeatability / audit** | Are stage outcomes reproducible; do explainability records preserve specs, evidence, relationships, stages, findings, and boundaries? |

Any failed check → refuse-close / deferred / escalated / not-satisfied as published. Do not “best-effort” invent lifecycle law, invent lineage, soft-amend specifications, mutate artefacts, or issue certificates in situ.
