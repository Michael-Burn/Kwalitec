Kwalitec coaches students preparing for demanding professional examinations (especially IFoA syllabi such as CM1/CS1 and peers).

An expert IFoA tutor does not collapse two specialist conversations into one undifferentiated voice because a calendar widget is convenient, nor hand a colleague their professional identity because two questions arrived in sequence. That answer must ensure composition coordinates interaction under published contracts; exchanges only authorised constitutional artefacts; preserves each interface’s identity and responsibilities; remains auditable, explainable, and technology-neutral — without merging interface identities, redefining constitutional capabilities, bypassing runtime contracts, or elevating implementation technologies into constitutional architecture.

This document records that posture so every future Runtime A (and successor) subsystem has a single constitutional reference for *how named RI interaction contracts may lawfully work together*.

## 2. What Runtime Interface Composition Is

**Runtime interface composition** is a named **coordination relationship** among **recognised constitutional runtime interfaces** (RI-01…RI-07) that **coordinates constitutional interaction** — without becoming a source of educational truth, collapsing distinct interaction contracts into one mega-interface, or transferring constitutional responsibilities between interfaces.

| Concept | Definition | Primary question |
|---------|------------|------------------|
| **Participating interfaces** | Named RI-01…RI-07 interaction contracts that take part | Which interfaces participated? |
| **Composition pattern** | A recognised RIC-01…RIC-07 coordination form | How do they compose? |
| **Exchanged artefacts** | Authorised constitutional artefacts passed between participating interfaces | What was exchanged? |
| **Preserved identities** | Each participant’s MS001 interface identity remains intact and speakable | Did anyone become a mega-interface? |
| **Preserved responsibilities** | Each participant’s permitted / prohibited exposures remain intact | Did anyone absorb another’s duty? |
| **Composition outputs** | Authorised constitutional outputs produced by the coordinated interactions | What resulted? |
| **Technology silence** | Composition patterns name coordination forms, not transports or SDKs | Is composition law, or merely wiring? |

Runtime interface composition is:

- **coordination-only** — it sequences, parallels, conditions, nests, or specialises interaction; it does not author law;
- **identity-preserving** — each RI participant keeps its MS001 catalogue identity;
- **responsibility-preserving** — composition never transfers or merges constitutional duties between interfaces;
- **artefact-honest** — only authorised constitutional artefacts are exchanged;
- **capability-non-redefining** — composition never invents new RI or RS types by aggregation;
- **contract-honouring** — every material composed interaction remains under published RC bindings;
- **implementation-independent** — patterns name coordination forms, not REST, gRPC, queues, or SDKs;
- **integrity-preserving** — composition never quietly rewrites meaning, ownership, tips, evidence, or specifications;
- **audit-capable** — composed interactions leave reconstructable constitutional traces;
- **explainable** — students and developers can answer which interfaces composed and under which pattern.

Runtime interface composition is **not**:

- a second Educational Constitution, EIP, or Runtime Interface Model;
- a merger of RI-01…RI-07 into a single undifferentiated interaction contract;
- a transfer of constitutional responsibilities between interfaces or components;
- a licence to invent unpublished composition patterns, capabilities, tips, mastery, or educational context;
- a REST facade, GraphQL schema stitch, gRPC gateway, HTTP aggregator, SDK client, auth middleware, or network topology;
- a claim that successful composition guarantees learning or a pass;
- an amendment to MS001 interface identities by proximity or convenience;
- a substitute for WS3 service collaboration (RSC-*) — composition coordinates interfaces; collaboration coordinates services.
