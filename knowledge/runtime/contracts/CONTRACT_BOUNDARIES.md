## 1. Purpose

Runtime that silently becomes a second constitution — rewriting meaning in services, inventing tips in adapters, or skipping orchestration because a button was pressed — destroys student trust and educational integrity.

This document draws a bright line between **lawful execution** (Programme VIII) and **constitutional authorship** (Constitution / EIP / Programmes VI–VII).

---

## 2. Boundary Principles

1. **Execute, do not author.** Runtime applies published law; it does not write it.
2. **Consume Programmes VI and VII intact.** Meaning and orchestration survive delivery.
3. **Published conditions only.** Unpublished customs are hard stops.
4. **Published workflows only.** Stage skipping is not optimisation.
5. **Published events only.** Event invention is law invention.
6. **Evidence non-reinterpretation.** Classifications stay with the Evidence Model.
7. **Authority non-absorption.** Ownership stays with the Authority Model.
8. **Recommendation non-invention.** Tips stay with WS3 + Programme VI owners.
9. **State non-invention.** Context postures stay with WS4 EST/CST law.
10. **Specification immutability at runtime.** Code never amends constitutional corpora by side effect.
11. **Explain the stop.** Students and developers should hear when execution must refuse.
12. **No emergency exemption.** Load, deadlines, and demos never mint constitutional power.

## 3. What Runtime May Do (Lawful)

| Lawful action | Constitutional meaning |
|---------------|------------------------|
| **Consume Programme VI** | Read and apply published educational meaning and authorised guidance artefacts |
| **Consume Programme VII** | Read and apply published workflow, authority, recommendation, and state law |
| **Evaluate published constitutional conditions** | Test documented entry/exit, transition, permission, and completion conditions against learner circumstances |
| **Execute published constitutional workflows** | Initiate, advance, hand off, and conclude under WS1 law (RC-03) |
| **Generate published constitutional events** | Emit only event classes already named by constitutional corpora |
| **Preserve audit records** | Retain reconstructable RC-07 trails for material acts |
| **Refuse unlawfully requested acts** | Prefer honest stop / defer / escalate over improvisation |
| **Remain replaceable** | Honour contracts in any compliant implementation (RCO-06) |
| **Explain execution** | Answer contract / corpus / evidence / outputs / boundaries without rewriting meaning |

These actions **execute**. They do **not** publish a new Constitution, invent coach questions, mint tips, or author ownership maps.

## 4. What Runtime Must NEVER Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Redefine educational meaning** | Programme VI owns coach / planner questions and envelopes | Consume published meaning; escalate for corpus amendment |
| **Redefine authority** | Programme VII WS2 owns ownership, permission, and conflict disposition | Apply Authority / Conflict corpora; refuse domain absorption |
| **Invent recommendations** | Programme VII WS3 + Programme VI owners own tip warrant | Surface lawful artefacts or no-recommendation |
| **Bypass workflow law** | Programme VII WS1 owns orchestration | Require published events, stages, transitions, and completion |
| **Invent educational state** | Programme VII WS4 owns EST/CST context law | Apply published postures / transitions only |
| **Reinterpret constitutional evidence** | EIP-002 / EIP-006 / EIP-001 writers own observational truth and claim honesty | Consume classifications; leave writers to permitted paths |
| **Modify constitutional specifications** | Constitution / EIP / Programmes VI–VII are amended only under their governance | Change code to obey law, or propose a corpus amendment — never patch law in runtime |
| **Mint mastery / readiness from convenience** | Knowledge & Mastery and Evidence authorities own estimates | Preserve claim ladder; refuse overclaim |
| **Erase educational history** | EIP-005 Continuity | Preserve lawful history across retries and replacements |
| **Treat Twin / Adaptive / UI as constitutional authors** | They are consumers / delivery surfaces | Keep them subordinate to Runtime Contract + upstream corpora |
| **Present scores as constitutional warrant** | Scores are operational proxies | Cite published corpora and evidence classes |
| **Become irreplaceable by design** | RCO-06 replaceability | Keep contracts implementation-independent |

## 6. Boundary Checks (Pre-Execution)

Before a material educational runtime act, constitutional execution requires affirmative answers:

| Check | Question |
|-------|----------|
| **BC-01 Producer** | Which published corpus authorises this act? |
| **BC-02 Contract** | Which RC-01…RC-07 contract(s) bind this act? |
| **BC-03 Meaning** | Does this act avoid redefining Programme VI meaning? |
| **BC-04 Governance** | Does this act preserve ownership / permission / conflict law? |
| **BC-05 Evidence** | Does this act avoid reinterpreting Evidence classifications? |
| **BC-06 Workflow** | If orchestration is involved, is WS1 law followed without bypass? |
| **BC-07 Tip honesty** | If guidance is surfaced, is it a lawful recommendation (not invented)? |
| **BC-08 State honesty** | If context is represented, is it a published EST/CST posture? |
| **BC-09 Spec immutability** | Does this act avoid modifying constitutional specifications? |
| **BC-10 Audit** | Will RC-07 records preserve contract, corpus, evidence, outputs, and boundaries? |

Any failed check → refuse / defer / escalate. Do not “best-effort” invent law.
