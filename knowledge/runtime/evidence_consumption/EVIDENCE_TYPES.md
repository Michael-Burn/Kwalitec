## 1. Purpose

Runtime without a closed evidence catalogue invents law by proximity: whichever row, payload, or estimate is nearest becomes the tutor’s “proof.”

This catalogue names the only lawful constitutional evidence categories a runtime may receive, validate, and consume — and binds each category to producers, consumers, purpose, and permitted / prohibited consumption.

---

## 2. Catalogue Overview

| ID | Evidence category | Primary producer class | Primary consumer | Primary RC binding |
|----|-------------------|------------------------|------------------|--------------------|
| **EC-01** | Learning Evidence | EIP-002 + Programme VI learning owners + EIP-001 permitted writers | Runtime A | RC-02 (+ RC-01, RC-07) |
| **EC-02** | Assessment Evidence | EIP-002 + Programme VI assessment / exam owners + EIP-001 permitted writers | Runtime A | RC-02 (+ RC-01, RC-07) |
| **EC-03** | Workflow Evidence | Programme VII Workstream 1 | Runtime A | RC-03 (+ RC-02 when learning warrants cited; RC-07) |
| **EC-04** | Authority Evidence | Programme VII Workstream 2 | Runtime A | RC-04 (+ RC-07) |
| **EC-05** | Recommendation Evidence | Programme VII Workstream 3 (+ Programme VI owners) | Runtime A | RC-05 (+ RC-02 when tip warrant cites Educational Evidence; RC-07) |
| **EC-06** | State Evidence | Programme VII Workstream 4 | Runtime A | RC-06 (+ RC-07) |
| **EC-07** | Runtime Evidence | Programme VIII WS1 Contract / Event / Completion Models (+ producer of audited act) | Runtime A | RC-01 + RC-07 (never mint VI/VII/EIP-002 meaning) |

Material consumed evidence must map to one of these categories. Cross-cutting situations may bind multiple EC categories; none may invent a category outside this catalogue.

**Relation to EIP-002:** Educational Evidence of understanding remains defined solely by EIP-002. **EC-01** and **EC-02** classify how runtime *consumes* learning- and assessment-facing published warrants under that law. They do not create a rival Evidence Model.

**Relation to Programme VII completion evidence:** Orchestration completion trails published under Programme VII are consumed under **EC-03**. This catalogue does not redefine orchestration fulfilment; it binds how runtime consumes those published artefacts.

**Relation to CE-01:** Evidence Events (WS1 / MS002) may deliver evidence-facing stimuli. Consumption of the underlying warrant still maps to the applicable EC-01…EC-07 category.

## 3. EC-01 — Learning Evidence

### Constitutional producer

[`../../educational/EDUCATIONAL_EVIDENCE_MODEL.md`](../../educational/EDUCATIONAL_EVIDENCE_MODEL.md) (EIP-002), Knowledge & Mastery (EIP-006), Programme VI learning / daily / recovery / revision corpora that publish lawful learning warrants, and permitted writers under the State Authority Matrix (EIP-001).

### Constitutional consumer

Runtime A (and lawful successors) when reading or applying observational warrants about learning activity outcomes and understanding-adjacent observations as classified.

### Purpose

Ensure runtime **consumes published learning warrants as classified observational inputs**, supporting honest educational execution — never inventing learning proof from coverage, time-on-task, confidence, or engagement alone.

### Permitted consumption

- Read published learning evidence artefacts and claim types exactly as classified under EIP-002 / Programme VI.
- Apply published claim-ladder honesty in downstream speech and decisions.
- Pass learning evidence to authorised constitutional processes (e.g. Twin succession under EIP-001; coach envelopes under Programme VI; RC-02-bound execution).
- Surface honest understatement when learning evidence is incomplete or conflicting.
- Preserve continuity of learning evidence history (EIP-005).
- Emit RC-07 audit records for material learning-evidence consumption.

### Prohibited consumption

- Invent learning evidence or reclassify activity / coverage / session completion as understanding or mastery.
- Alter learning evidence meaning in transit (e.g. soft-upgrade claim class for UX).
- Fabricate provenance for learning warrants.
- Treat Twin / Adaptive estimates as primary EIP-002 observations when they are not.
- Bypass Evidence Model succession rules with “temporary” learning certainty.
- Use EC-01 to invent tips, transfer ownership, or advance workflows without WS1 / RC-03 law.

- Pass assessment evidence to authorised constitutional processes under EIP-001 / Programme VI / RC-02.

## 9. EC-07 — Runtime Evidence

### Constitutional producer

Programme VIII Workstream 1 Runtime Contract, Event Processing, and Execution Completion Models — limited to **published execution, processing, and completion trails** required for replaceable, continuous, auditable execution — plus the producer corpora of the audited act (EC-01…EC-06 as applicable).

### Constitutional consumer

Runtime A (and lawful successors) when reading or applying published execution records, event-processing trails, and execution-completion dispositions as evidence *of runtime fulfilment*, not of learning.

### Purpose

Ensure runtime **consumes published runtime trails as execution warrants**, supporting audit, replaceability, and lawful completion speech — never treating handler success, latency, or acks as Educational Evidence or Programme VII workflow completion.

### Permitted consumption

- Read published RC-07 / CE-06 / REC execution and audit trails exactly as Programme VIII WS1 classifies them.
- Validate runtime-evidence integrity and provenance before affirming execution completion or audit reconstruction.
- Pass runtime evidence to authorised audit / completion / replaceability processes under RC-01 / RC-07.
- Reference which upstream EC-01…EC-06 evidence was consumed during the audited act — without rewriting those warrants.
- Emit further RC-07 records for material runtime-evidence consumption when law requires.

### Prohibited consumption

- Invent runtime evidence or treat broker acks / timers / queue-empty as constitutional execution fulfilment.
- Reinterpret runtime evidence as learning, mastery, workflow completion, or constitutional amendment.
- Alter runtime trails to hide failed boundary checks or missing provenance.
- Fabricate provenance for execution / audit records.
- Use EC-07 to mint Programme VI meaning, Programme VII ownership/tips/state, or EIP-002 observations.
- Make a particular runtime topology irreplaceable by treating its private logs as constitutional law.

## 10. Catalogue Rules

1. **Closed catalogue.** New EC types require a Programme VIII constitutional amendment — not a silent schema invention.
2. **Producer required.** Every material EC instance must identify a published constitutional producer.
3. **Consumer bound.** Runtime consumes; it does not become the producer by holding the bytes.
4. **RC binding required.** Material consumption without RC identity is unlawful.
5. **No silent collapse.** EC categories may compose; they must not be collapsed to hide missing warrants.
6. **Claim honesty.** EC-01 / EC-02 never license coverage → understanding → mastery upgrades in runtime.
7. **Orchestration ≠ learning.** EC-03 never becomes EC-01 / EC-02 by naming convenience.
8. **Exactly as published.** Consumption preserves published meaning, classification, and provenance.

---

## 11. Closing Statement

> **If runtime cannot name which EC-01…EC-07 category was consumed, under which producer and RC binding, the artefact is not yet constitutional evidence — and must not be treated as educational law.**
