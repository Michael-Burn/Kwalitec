## 1. Purpose

An expert IFoA tutor who cannot say *which warrant* supported a study action — which contract authorised consumption, which provenance was preserved, what outputs relied on it, and which limits were maintained — is not coaching; they are performing.

After Programmes VI and VII have made meaning, ownership, tips, and context speakable, and after Programme VIII WS1 has made contract / event / completion speech speakable, Programme VIII still needs one evidence-speech answer:

> **“Which constitutional evidence was consumed, under which contract, with which provenance preserved, producing which reliant outputs, while maintaining which boundaries?”**

That answer must cover every material evidence consumption without inventing educational meaning, transferring authority, minting tips, inventing state, rewriting evidence, fabricating provenance, or inventing unpublished EC types.

---

## 2. What Evidence Consumption Explainability Is

**Constitutional Evidence Consumption Explainability** is the constitutional obligation to narrate **consumption of published evidence under published contracts** — not to invent a second tutor voice from storage machinery.

| Concept | Definition | Primary question |
|---------|------------|------------------|
| **Evidence consumed** | Named EC-01…EC-07 category (and upstream warrant / artefact ID when applicable) | Which constitutional evidence was consumed? |
| **Authorising contract** | Named RC-01…RC-07 binding(s) that authorised consumption | Which constitutional contract authorised consumption? |
| **Provenance preserved** | Producer, corpus path, claim class, succession / continuity refs | Which constitutional provenance was preserved? |
| **Outputs relied** | Published execution paths’ results that depended on the evidence | Which constitutional outputs relied on the evidence? |
| **Boundaries maintained** | Explicit confirmation that forbidden inventions / alterations / reclassifications / fabrications / bypasses did not occur | Which constitutional boundaries were maintained? |

Evidence Consumption Explainability is:

- **consumption-centred** — it narrates receive → validate → consume / hand off under law;
- **catalogue-bound** — every justification cites published EC and RC identities;
- **corpus-bound** — every justification cites published producers;
- **provenance-honest** — origin and succession are speakable or the explanation is incomplete;
- **audience-aware** — student speech and developer/auditor traces differ in vocabulary, not in truth;
- **layer-honest** — it does not replace Programme VI tip warrant speech, Programme VII ownership / workflow / state speech, EIP-002 evidence meaning speech, or WS1 contract / event / completion speech;
- **non-inventive** — explanation never becomes a back door to mint meaning, tips, EC types, or mastery;
- **audit-aligned** — explanation components match RC-07 reconstruction needs;
- **determinism-honest** — explanations must not paper over race-dependent dispositions.

Evidence Consumption Explainability is **not**:

- a rewrite of EIP-002 Educational Evidence meaning;
- a substitute for workflow, authority, recommendation, state, or WS1 contract / event / completion explainability corpora;
- a rendering system, UI template, log shipper, storage console, or analytics dashboard;
- a claim that clear consumption speech guarantees learning or a pass;
- a licence to present scores, acks, cache hits, or optimiser confidence as constitutional proof.

## 3. Mandatory Explanation Questions

Every material constitutional evidence consumption should answer all five questions:

### ECEQ-01 — Which constitutional evidence was consumed?

Name the primary EC-01…EC-07 category. When an upstream warrant or Programme VII artefact applies, also name it (for example EC-01 ← EIP-002 observation class; EC-03 ← workflow completion evidence ID). Unpublished payload names are not constitutional evidence.

### ECEQ-02 — Which constitutional contract authorised consumption?

Name the primary RC-01…RC-07 contract(s). Cross-cutting consumption names all bound contracts (for example RC-02 + RC-05 + RC-07). “Table was readable” is not a constitutional contract.

### ECEQ-03 — Which constitutional provenance was preserved?

Distinguish:

- constitutional producer identity;
- authorising corpus path(s);
- claim class / evidence classification as published;
- succession / continuity references (EIP-005);
- EIP-001 writer identity when mutation history is material.

Never present storage keys, cache hits, broker metadata, or Twin estimates as provenance of understanding unless published law permits that classification.

### ECEQ-04 — Which constitutional outputs relied on the evidence?

Name only published output classes that depended on the consumed evidence: workflow advances / events, authority dispositions, recommendation artefacts / sets, EST/CST postures, Twin succession under EIP-001, audit / execution records, or explicit refuse/defer/escalate outcomes.

### ECEQ-05 — Which constitutional boundaries were maintained?

Confirm the hard stops in `EVIDENCE_BOUNDARIES.md` that were checked — especially non-invention, non-alteration of meaning, non-reclassification, non-fabrication of provenance, and non-bypass of constitutional evidence requirements.

## 4. Explanation Components

| ID | Component | Obligation |
|----|-----------|------------|
| **ECEC-01** | Evidence identity | Named EC-01…EC-07 (+ upstream warrant / artefact ID when applicable) |
| **ECEC-02** | Contract identity | Named RC-01…RC-07 binding(s) |
| **ECEC-03** | Authorising corpus refs | Documented constitutional producers |
| **ECEC-04** | Provenance record | Producer, claim class, succession / continuity refs preserved |
| **ECEC-05** | Integrity note | Confirmation that evidence was intact as published |
| **ECEC-06** | Output reliance catalogue | Which published artefacts / dispositions / records depended on it |
| **ECEC-07** | Boundary preservation record | Confirmation that forbidden acts did not occur |
| **ECEC-08** | Determinism note | Disposition reproducibility from published inputs |
| **ECEC-09** | Refusal / deferral honesty | When no lawful consumption existed, say so |
| **ECEC-10** | Continuity note | Prior lawful history not erased (EIP-005) |
| **ECEC-11** | Non-claim honesty | Explicit refusal of mastery / pass / meaning-rewrite / evidence-invention overclaim |
| **ECEC-12** | Audience projection | Student-plain vs developer/auditor vocabulary over one truth |

Components are **constitutional content obligations**, not database columns, API fields, storage headers, or UI widgets. Persistence and rendering are out of scope for this milestone.

## 5. Audience Rules

| Audience | May hear | Must not hear as educational law |
|----------|----------|----------------------------------|
| **Student** | What warrant supported the next step, why it was allowed, where it came from in plain educational language, and what limits apply | Internal EC/RC IDs as theatre; storage traces; optimiser scores as “proof you are ready” |
| **Developer / auditor** | Full ECEQ-01…05 answers, corpus paths, EC/RC IDs, provenance refs, boundary checks, determinism notes | Product success metrics, cache hits, or ack counts substituted for constitutional refs |

Student and developer traces must describe the **same constitutional truth**. Vocabulary may differ; facts may not.

## 6. Layering with Upstream Explainability

| Layer | Corpus job | Evidence-consumption speech role |
|-------|------------|----------------------------------|
| EIP-002 Educational Evidence meaning | What observational warrants of understanding are | Consume classifications; never rewrite |
| Programme VI coach / planner explainability | Why educational guidance is warranted | Consume; do not rewrite |
| Programme VII workflow / completion explainability | How orchestration flowed / what completion evidence held | Narrate EC-03 consumption under RC-03 |
| Programme VII authority explainability | Why a component was permitted to decide | Narrate EC-04 consumption under RC-04 |
| Programme VII recommendation explainability | Why a tip / set is speakable | Narrate EC-05 consumption under RC-05 |
| Programme VII state explainability | Why context is live / how it succeeded | Narrate EC-06 consumption under RC-06 |
| Programme VIII contract explainability (WS1 / MS001) | Which runtime contract executed under which law | Compose with; do not replace |
| Programme VIII event / completion explainability | Which event / execution cycle applied | Compose with when stimuli or completion referenced consumed evidence |
| **Programme VIII evidence consumption explainability (WS2 / MS001)** | **Which constitutional evidence was consumed under which contract with which provenance** | **This document** |

A complete material journey may carry every layer that applied. Evidence speech without upstream warrant is hollow. Upstream warrant without EC/RC identity and provenance invites silent reimplementation drift.
