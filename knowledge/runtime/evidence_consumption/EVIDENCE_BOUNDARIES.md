> **Runtime may consume published constitutional evidence,  
> validate evidence integrity,  
> reference evidence provenance,  
> and pass evidence to authorised constitutional processes.  
> Runtime must never invent evidence,  
> alter evidence meaning,  
> reclassify evidence,  
> fabricate provenance,  
> or bypass constitutional evidence requirements.**

## 1. Purpose

Runtime that silently becomes a second evidence authority — inventing warrants in readers, altering meaning because a payload looked suggestive, reclassifying coverage as mastery, forging provenance for smoother UX, or bypassing evidence requirements for demos — destroys student trust and educational integrity.

This document draws a bright line between **lawful evidence consumption** (Programme VIII / WS2 / MS001) and **constitutional evidence authorship** (Constitution / EIP / Programmes VI–VII / permitted writers).

---

## 2. Boundary Principles

1. **Consume, do not author.** Evidence consumption applies published warrants; it does not create them.
2. **Published evidence only.** Unpublished customs and infrastructure signals without EC mapping are hard stops.
3. **Published contracts only.** Consumption without RC binding is unlawful.
4. **Exactly as published.** Meaning and classification survive intact.
5. **Integrity first.** Altered or truncated warrants are refused, not “fixed” in runtime.
6. **Provenance required.** Origin and succession are not optional metadata.
7. **Authorised handoff only.** Evidence passes only to processes already permitted by published law.
8. **Meaning non-reinterpretation.** Programme VI questions and EIP-002 claim classes survive readers intact.
9. **No reclassification.** Coverage / time / confidence / engagement / orchestration close never become understanding or mastery in runtime.
10. **No provenance fabrication.** Missing origin is a stop, not a chance to invent a story.
11. **No bypass.** Product urgency never waives constitutional evidence requirements.
12. **Determinism.** Race-dependent evidence disposition is a defect.
13. **Explain the stop.** Students and developers should hear when consumption must refuse.
14. **No emergency exemption.** Load, deadlines, and demos never mint constitutional evidence power.
15. **Replaceability.** Storage topology never becomes evidence law.

## 3. What Runtime May Do (Lawful)

| Lawful action | Constitutional meaning |
|---------------|------------------------|
| **Consume published constitutional evidence** | Accept only EC-01…EC-07 instances with identifiable published producers |
| **Validate evidence integrity** | Confirm the warrant is intact, claim-class honest, and not silently altered |
| **Reference evidence provenance** | Cite producer, corpus path, succession / continuity refs, and authorising contract |
| **Pass evidence to authorised constitutional processes** | Hand off only under EIP-001 mutation rights and RC-01…RC-07 bindings |
| **Refuse unlawfully requested consumption** | Prefer honest stop / defer / escalate over improvisation |
| **Preserve claim-ladder honesty** | Keep coverage ≠ understanding ≠ mastery through consumption |
| **Remain deterministic** | Same published inputs → same disposition |
| **Remain replaceable** | Honour evidence law in any compliant implementation |
| **Explain consumption** | Answer evidence / contract / provenance / outputs / boundaries without rewriting meaning |

These actions **consume**. They do **not** publish a new Evidence Model, invent coach warrants, mint tips, author ownership maps, or invent EC types.

## 4. What Runtime Must NEVER Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Invent evidence** | EC catalogue is closed; invention is law invention | Refuse unpublished artefacts; propose corpus amendment |
| **Alter evidence meaning** | Producers own warrant meaning; runtime is executor | Consume exactly as published; escalate for corpus amendment |
| **Reclassify evidence** | EIP-002 / EIP-006 / Programme VII class owners own classification | Preserve published class; refuse soft-upgrades |
| **Fabricate provenance** | Provenance is constitutional attribution, not UX filler | Require published producer refs or refuse |
| **Bypass constitutional evidence requirements** | Evidence requirements are educational care, not optional polish | Prefer no-action / understatement over invented certainty |
| **Reinterpret educational meaning** | Programme VI owns coach / planner questions and envelopes | Consume published meaning; leave writers to permitted paths |
| **Transfer authority** | Programme VII WS2 owns ownership, permission, and conflict disposition | Apply Authority / Conflict corpora; refuse domain absorption |
| **Bypass constitutional workflows** | Programme VII WS1 owns orchestration | Require published workflow evidence / stages / transitions |
| **Generate unpublished recommendations** | Programme VII WS3 + Programme VI owners own tip warrant | Surface lawful artefacts or no-recommendation |
| **Invent educational state** | Programme VII WS4 owns EST/CST context law | Apply published postures / transitions only |
| **Modify constitutional specifications** | Constitution / EIP / Programmes VI–VIII are amended only under their governance | Change code to obey law, or propose a corpus amendment — never patch law in a reader |
| **Treat Twin / Adaptive / UI / storage noise as EC publishers** | They are consumers / delivery surfaces | Require published EC mapping or refuse |
| **Present scores / acks / latency / cache hits as constitutional warrant** | Operational proxies are not evidence law | Cite published corpora, EC, and RC |
| **Become irreplaceable by storage topology** | RCO-06 / ECO replaceability | Keep evidence law implementation-independent |

## 6. Boundary Checks (Pre-Consumption)

Before material constitutional evidence is consumed, processing requires affirmative answers:

| Check | Question |
|-------|----------|
| **ECB-01 Evidence class** | Is this a published EC-01…EC-07 category (not an unpublished custom)? |
| **ECB-02 Producer** | Which published corpus / permitted writer authored the evidence? |
| **ECB-03 Contract** | Which RC-01…RC-07 contract(s) authorise consumption? |
| **ECB-04 Integrity** | Is the evidence intact and claim-class honest as published? |
| **ECB-05 Provenance** | Are producer, succession, and corpus refs present and non-forged? |
| **ECB-06 Meaning** | Does consumption avoid reinterpreting Programme VI educational meaning? |
| **ECB-07 Classification** | Does consumption avoid reclassifying the warrant? |
| **ECB-08 Authority** | Does consumption avoid transferring ownership / inventing permission? |
| **ECB-09 Workflow** | If orchestration is involved, is WS1 law followed without bypass? |
| **ECB-10 Tip honesty** | If guidance would be surfaced, is recommendation evidence lawful (not unpublished)? |
| **ECB-11 State honesty** | If context is represented, is it a published EST/CST posture? |
| **ECB-12 Handoff** | Is the next process constitutionally authorised to receive this evidence? |
| **ECB-13 Spec immutability** | Does consumption avoid modifying constitutional specifications? |
| **ECB-14 Determinism / audit** | Is disposition reproducible; will records preserve evidence, contract, provenance, outputs, and boundaries? |

Any failed check → refuse / defer / escalate. Do not “best-effort” invent evidence law.
