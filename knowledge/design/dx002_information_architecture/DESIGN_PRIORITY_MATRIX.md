# Design Priority Matrix

**Programme:** DX-002

## Priority definitions

| Priority | Meaning |
|---|---|
| **P0** | Must redesign (structure/IA) before Beta |
| **P1** | Redesign during Alpha |
| **P2** | Improve later |
| **P3** | Already meets DX-001 intent closely enough |

*No screen is P3 on visual tokens yet — P3 means **information architecture / purpose clarity** is acceptable.*
