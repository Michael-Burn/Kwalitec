# Empty State Standards

**Programme:** DX-003  
**Status:** Binding  
**Release Candidate:** `RC-2026.07.29-01`  
**Tightens:** DX-001 empty-state beats (State + Why + Action → Reason + Next Action)

---

## Structure

Every empty state contains **exactly**:

```
Reason
    ↓
Next Action
```

Nothing else.

| Beat | Definition | Length |
|---|---|---|
| **Reason** | Factual why the surface is empty | ≤ one short sentence |
| **Next Action** | Exactly one Primary (or clear Secondary if Primary lives elsewhere) | Verb-led label |

Optional: a short object name in the heading (“No sessions yet”) — that is recognition, not a third essay.

---

## Forbidden in empty states

- Tips carousels  
- Secondary metrics / KPI ghosts  
- Marketing filler  
- Ontology teaching (“History is not Journal because…”)  
- Multiple CTAs of equal weight  
- Illustrations that require caption essays  
- “Welcome — get started by…”

---

## Patterns by surface

| Surface | Reason | Next Action |
|---|---|---|
| History (no sessions) | No sessions completed yet. | Return Home |
| Decision Journal (empty) | No guidance entries yet. | Return Home |
| Educational Timeline (empty) | No timeline events yet. | Return Home |
| Revision (none) | No revision suggested for today. | Return Home |
| Support queue (empty) | No submissions waiting. | — (or Return Overview) |
| Attention (empty) | Nothing needs intervention. | Open Subjects / Studio |
| Subjects (none) | No subjects yet. | Create Subject |
| Studio workspaces (none) | No workspaces yet. | Create Subject |
| Findings (none) | No open findings. | — |
| Choose Exam (none Ready) | No Ready subjects yet. | — (wait) / Contact support if Alpha |
| Search (no hits) | No matches. | Clear query |
| Session list filters | No sessions match. | Clear filters |

## Rewrite examples

| Current tendency | Target |
|---|---|
| “History shows what you practiced… educational meaning lives in Journal…” + Open Journal + Open Timeline | Reason: No sessions completed yet. Action: Return Home |
| “Upload documents to begin your curriculum journey with Kwalitec…” | Reason: No sources uploaded. Action: Upload Syllabus |
| “You’re all caught up — great work keeping the queue clear!” | Reason: No submissions waiting. |

---

## Relationship to Feedback

Empty is not Success. Do not celebrate emptiness. State Reason; offer Next Action; stop.
