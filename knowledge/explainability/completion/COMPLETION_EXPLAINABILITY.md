## 2. What Explainability Completion Explainability Is

**Constitutional Explainability Completion Explainability** is the constitutional obligation to narrate **fulfilment (or lawful refusal of fulfilment) of the required constitutional explainability lifecycle** — not to invent a second tutor voice from CI complete badges, and not to grade the student, remake decisions, amend constitutional law, freeze a stack, or create constitutional authority.

| Concept | Definition | Primary question |
|---------|------------|------------------|
| **Audit record explained** | Named completed constitutional audit record(s) consumed as explanation subjects | Which audit record was explained? |
| **Provenance validated** | Named reconstructable lineage identities bound to those audit records and explanations | Which provenance was validated? |
| **Fidelity validations completed** | Named fidelity dispositions under CEAL-05 / CEA-04 | Which fidelity validations were completed? |
| **Explanations published** | Named reconstructable published constitutional explanations | Which explanations were published? |
| **Boundaries intact** | Explicit confirmation that forbidden overclaims / executions / decisions / amendments / authority-creation did not occur | Which constitutional boundaries remained intact? |

Explainability Completion Explainability is:

- **fulfilment-centred** — it narrates why CEAC criteria hold (or why close is refused);
- **catalogue-bound** — every justification cites published CEA / CEAL / CEAC identities where applicable;
- **corpus-bound** — every justification cites published specifications, completed audit records, and named constitutional explanations;
- **non-executive** — explanation never becomes a back door to re-execute constitutional rules;
- **non-decisive** — explanation never remakes or silently replaces constitutional decisions;
- **non-auditing** — explanation never re-records or re-validates constitutional audits;
- **non-legislative** — explanation never becomes a back door to amend corpora;
- **non-authority-creating** — explanation never narrates completion as creation of constitutional authority;
- **EIP-faithful** — explanation never narrates completion as EIP reinterpretation or replacement;
- **quality-honest** — complete is never narrated as mastery, readiness, or educational quality;
- **technology-honest** — explanation never presents a stack preference as constitutional law;
- **audience-aware** — student speech and developer/auditor traces differ in vocabulary, not in truth;
- **layer-honest** — it does not replace Programme VI tip warrant speech, Programme VII ownership / workflow / state speech, EIP-002 evidence meaning speech, Programme VIII contract / evidence / validation speech, WS1–WS4 speech, WS5 / MS001 explainability speech, or WS5 / MS002 lifecycle speech;
- **transparency-aligned** — explanation components match CEAC reconstruction needs;
- **authority-honest** — explanations must not paper over authority inference or stack canonisation.

Explainability Completion Explainability is **not**:

- a rewrite of Constitution / EIP / Programme VI–IX / WS1 / WS2 / WS3 / WS4 / WS5 meaning;
- a quality report on learning, coaching, or exam readiness;
- a constitutional amendment instrument or authority-creation warrant;
- a silent decision-replacement, rule-re-execution, or audit-re-recording mechanism;
- a governance-finish report as constitutional law;
- a substitute for WS5 / MS001 explainability explainability or WS5 / MS002 lifecycle explainability (compose with; do not replace);
- a substitute for WS4 / MS003 audit completion explainability, WS3 / MS003 decision completion explainability, WS2 / MS003 execution completion explainability, or WS1 / MS003 context completion explainability (compose with; do not collapse);
- a rendering system, UI template, CI badge, explanation visualiser, or analytics dashboard;
- a claim that clear completion speech guarantees learning, a pass, conformity, constitutional amendment, or authority creation;
- a licence to present coverage, lint scores, ticket graphs, or pipeline greens as constitutional proof or educational quality.

## 3. Mandatory Explanation Questions

Every material completion judgement (affirm or refuse close) should answer all five questions:

### CEACQ-01 — Which audit record was explained?

Name the primary completed constitutional audit record identities (WS4 / MS003 CAAC-complete audit records) consumed as explanation subjects under the concern — or name which required completed audit records remain unavailable when refusing close. Never narrate invented, incomplete, or re-recorded audit records as lawful explanation subjects. “An audit happened somewhere” is not a constitutional audit-record identity.

### CEACQ-02 — Which provenance was validated?

Name the reconstructable provenance identities validated under CEAL-04 / CEA-03 — including completed-audit lineage, authority citations, and published corpus references required for the concern — or name which required provenance remains missing, truncated, forged, or invented when refusing close. Never narrate free-form logs or invented lineage as constitutional provenance.

### CEACQ-03 — Which fidelity validations were completed?

Name the fidelity dispositions under CEAL-05 / CEA-04 for candidate explanations — valid / invalid / refuse — including which fidelity expectations were applied — or name which required fidelity validations remain outstanding when refusing close. Never narrate CI greens, lint scores, or Twin confidence as fidelity validation.

### CEACQ-04 — Which explanations were published?

Name the published constitutional explanation identities under CEAL-06 / CEA-05 (or refuse-publish dispositions with reasons) — or name which required publications remain incomplete when refusing close. Never narrate ticket closures, badge glows, or pipeline exits as published constitutional explanations.

### CEACQ-05 — Which constitutional boundaries remained intact?

Name the boundary confirmations that close did **not** execute constitutional rules, produce constitutional decisions, reinterpret Educational Interpretation Principles, amend constitutional specifications, create constitutional authority, freeze a stack as law, or invent educational success / independent governance — or name which boundary would be breached if close were affirmed. Boundary silence is a defect for material completion speech.

## 5. Explainability Defects

The following are constitutionally defective completion explanations:

- “Explainability complete” with no named completed audit record.
- “Provenance validated” with no reconstructable lineage identity.
- “Fidelity validated” because CI was green.
- “Published” because a ticket closed or a badge glowed.
- Narrating completion as rule re-execution, decision remaking, audit re-recording, EIP reinterpretation, constitutional amendment, or authority creation.
- Collapsing audit completion, decision completion, execution completion, or context completion into explainability completion speech.
- Presenting stack / vendor / topology preference as the reason close was lawful.
- Refusing to answer any of CEACQ-01…CEACQ-05 for a material affirmed close.
