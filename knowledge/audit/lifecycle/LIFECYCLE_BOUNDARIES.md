## 1. Purpose

A lifecycle that silently becomes a second constitution — rewriting specs so stages “complete,” inventing educational meaning in “audit records,” licensing runtime behaviour under a closed seal, inventing completed decisions to force CAAL-03, re-executing constitutional rules under an audit badge, re-producing decisions under an audit badge, reinterpreting EIP mid-lifecycle, treating a preferred implementation as the new standard, mutating artefacts mid-lifecycle, creating constitutional authority, or freezing a stack as law — destroys student trust and educational integrity.

This document draws a bright line between **lawful constitutional audit lifecycle coordination** (Programme X / WS4 / MS002) and **constitutional authorship / educational judgement / runtime authorship / execution / decision production / audit-component authorship / independent governance authorship / artefact mutation / authority creation** (Constitution / EIP / Programmes VI–IX / WS1 / WS2 / WS3 / WS4 MS001 / permitted writers).

## 2. Boundary Principles

1. **Coordinate, do not legislate.** The lifecycle organises constitutional auditing; it does not create law.
2. **Published specifications only.** Unpublished customs and “main as law” are hard stops as standards.
3. **Published stages only.** Unpublished CAAL customs are unlawful.
4. **Published audit components only.** CAAL-02…CAAL-06 invoke CAA-01…CAA-06 only.
5. **Completed decisions only.** Lifecycles without identifiable completed constitutional decisions are theatre.
6. **Exactly as published.** Successful progress never rewrites specification meaning.
7. **No constitutional rule execution.** Recording audit information is not performing WS2 *execution*.
8. **No constitutional decision production.** Recording audit information is not performing WS3 *decision production*.
9. **No EIP reinterpretation.** Educational Interpretation Principles remain as published.
10. **Authority first.** Published corpora remain the sole constitutional standard; the lifecycle never creates authority.
11. **Implementation independence.** No stack, vendor, or reference implementation becomes law by proximity to closure.
12. **Closed ≠ quality.** Lifecycle closure never grades learning, mastery, readiness, or product success.
13. **Closed ≠ execution.** The lifecycle never re-executes constitutional rules or replaces WS2.
14. **Closed ≠ decision.** The lifecycle never re-produces constitutional decisions or replaces WS3.
15. **Published ≠ amendment.** Constitutional audit records never become constitutional law.
16. **No authority creation.** The lifecycle never creates constitutional authority.
17. **No redefinition.** Programme VI questions, EIP claim classes, WS1 / WS2 / WS3 meanings, and CAA component meanings survive coordination intact.
18. **No authority substitution.** A closed lifecycle never replaces the corpus for the next judgement.
19. **No artefact mutation.** Coordination never rewrites implementation artefacts to manufacture passable audit records.
20. **No bypass.** Product urgency never waives constitutional lifecycle requirements.
21. **Repeatability / accountability.** Race-dependent or private stage shortcuts are defects.
22. **Explain the stop.** Students, developers, and auditors should hear when the lifecycle must refuse progress or closure.
23. **No emergency exemption.** Deadlines and demos never mint constitutional amendment power or authority creation via lifecycle closure.
24. **Integrity before valid publication.** Invalid constructions must not be published as constitutionally valid.

## 3. What the Lifecycle May Do (Lawful)

| Lawful action | Constitutional meaning |
|---------------|------------------------|
| **Coordinate audit production** | Organise activities through CAAL-01…CAAL-07 |
| **Consume completed constitutional decisions** | Bind named WS3 / MS003 completed decisions without inventing or rewriting them |
| **Construct constitutional audit records** | At CAAL-03, assemble candidate records under CAA-02 |
| **Preserve provenance** | At CAAL-04, record reconstructable lineage under CAA-03 |
| **Validate audit integrity** | At CAAL-05, confirm constitutional integrity under CAA-04 |
| **Publish constitutional audit records** | At CAAL-06, publish valid records under CAA-05 for accountability / explainability |
| **Invoke published audit components** | Apply CAA-01…CAA-06 as published by WS4 / MS001 |
| **Refuse unlawful progress** | Prefer honest refuse / stop / escalate / invalid over improvisation |
| **Remain accountable and repeatable** | Same published inputs → same stage outcomes and dispositions |
| **Remain implementation-neutral** | Honour lifecycle law across lawful equivalent stacks |
| **Preserve constitutional fidelity** | Apply audit components exactly as published; never soft-amend |
| **Explain lifecycle progress** | Answer decisions / provenance / integrity / records / boundaries without rewriting meaning |
| **Propose corpus amendments upstream** | Recommend (not enact) amendments when law itself must change |

These actions **coordinate constitutional auditing**. They do **not** publish a new Constitution, invent coach warrants, mint tips, author ownership maps, invent CAA or CAAL types, invent CT links, author runtime behaviour, judge educational quality, execute constitutional rules, produce constitutional decisions, reinterpret EIP, amend specifications, create or replace constitutional authority, determine independent governance outside constitutional authority, or modify artefacts under coordination pretext.

## 4. What the Lifecycle Must NEVER Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Execute constitutional rules** | WS2 / CEE / CEEL / CEEC own rule execution | Consume completed decisions; never re-execute |
| **Produce constitutional decisions** | WS3 / CDA / CDAL / CDAC own decision production | Consume completed decisions; never re-produce |
| **Reinterpret constitutional meaning** | Programme VI / EIP / sibling corpora own meaning | Audit under published meaning; never redefine it |
| **Reinterpret Educational Interpretation Principles** | EIP is upstream law | Apply EIP as published; never rewrite claim classes |
| **Amend constitutional specifications** | Only corpus governance may amend law | Leave specs unchanged; propose amendment upstream or refuse |
| **Create constitutional authority** | Published corpora remain the standard after any closure | Keep artefacts as recognised subjects, never as next-cycle law |
| **Replace constitutional authority** | Lifecycle machinery never becomes the corpus | Keep closure as coordination end, not law replacement |
| **Invent completed constitutional decisions** | WS3 owns decision / completion | Consume completed decisions; refuse invented inputs |
| **Invent audit components** | WS4 / MS001 owns CAA-01…CAA-06 | Invoke published components only |
| **Invent lifecycle stages** | Only CAAL-01…CAAL-07 are lawful | Refuse unpublished stage customs |
| **Invent provenance** | Provenance must be reconstructable from published lineage | Record established lineage only; refuse invented links |
| **Modify implementation artefacts** | Coordination is not a mutation licence | Consume decisions and provenance as found; refuse when identity is insufficient |
| **Invent traceability** | CT owns lawful lineage | Preserve established relationships in records; refuse invented links |
| **Freeze a stack as law** | Implementation neutrality is mandatory | Honour equivalent lawful stacks; refuse stack canonisation |
| **Skip integrity validation** | CAAL-05 is mandatory before valid publication | Validate; refuse-publish when invalid |
| **Publish invalid constructions as valid** | Integrity is a constitutional precondition | Refuse-publish; escalate or stop |
| **Perform verification** | CV / CVL / CVC own evidence evaluation | Never re-author verification under an audit badge |
| **Determine compliance** | CCM / CCL / CCC own obligation status | Never narrate closure as a compliance determination |
| **Certify implementations** | CRT / CRTL / CRTC own recognition | Never narrate closure as certification |
| **Re-run WS1 preparation, WS2 execution, or WS3 decision production** | Preparation, execution, and decision are upstream | Consume completed decisions; refuse incomplete decision theatre |
| **Replace WS4 / MS001 audit architecture** | CAA defines components; CAAL sequences them | Invoke published CAA components; never rewrite CAA meaning |
| **Grade educational quality** | Educational Validation Framework / Programme VI own quality speech | Keep closure distinct from mastery / readiness |

## 6. Boundary Preservation Confirmations

Every material audit lifecycle must be able to confirm:

1. Completed constitutional decisions were consumed, not invented or re-produced.
2. Only published CAA / CAAL catalogues were applied.
3. Educational Interpretation Principles were not reinterpreted or replaced.
4. Constitutional specifications were not amended.
5. Constitutional authority was not created or replaced by lifecycle machinery.
6. Constitutional rules were not executed under audit pretence.
7. Implementation neutrality remained intact.
8. Invalid constructions were not published as valid.
9. Provenance remained reconstructable and non-forged.

These confirmations feed `LIFECYCLE_EXPLAINABILITY.md` (especially CAALEQ-05).
