## 1. Purpose

A lifecycle that silently becomes a second constitution — rewriting specs so stages “complete,” inventing educational meaning in “decisions,” licensing runtime behaviour under a closed seal, inventing completed compliance to force CRTL-03, performing verification or re-determining compliance under a certification badge, treating a preferred implementation as the new standard, mutating artefacts mid-lifecycle, or freezing a stack as law — destroys student trust and educational integrity.

This document draws a bright line between **lawful constitutional certification lifecycle coordination** (Programme IX / WS4 / MS002) and **constitutional authorship / educational judgement / runtime authorship / conformance meaning / lineage authorship / verification authorship / compliance authorship / certification-type authorship / artefact mutation / authority substitution** (Constitution / EIP / Programmes VI–VIII / WS1 / WS2 / WS3 / WS4 MS001 / permitted writers).

## 2. Boundary Principles

1. **Coordinate, do not legislate.** The lifecycle organises certification; it does not create law.
2. **Published specifications only.** Unpublished customs and “main as law” are hard stops as standards.
3. **Published stages only.** Unpublished CRTL customs are unlawful.
4. **Published certification types only.** CRTL-03 applies CRT-01…CRT-07 only.
5. **Completed compliance only.** Lifecycles without identifiable completed compliance are theatre.
6. **Validated prerequisites only.** Invented or skipped prerequisites are hard stops.
7. **Exactly as published.** Successful progress never rewrites specification meaning.
8. **Authority first.** Published corpora remain the sole constitutional standard.
9. **Implementation independence.** No stack, vendor, or reference implementation becomes law by proximity to closure.
10. **Closed ≠ quality.** Lifecycle closure never grades learning, mastery, readiness, or product success.
11. **Closed ≠ verified.** The lifecycle never performs verification or replaces WS2.
12. **Closed ≠ compliant again.** The lifecycle consumes completed compliance; it never re-determines CCM status or replaces WS3.
13. **Closed ≠ permanently conformant.** The lifecycle supports recognition honesty; it never replaces MS001 meaning or freezes conformity.
14. **No redefinition.** Programme VI questions, EIP claim classes, CC criteria, CT lineage meaning, CV verification meaning, CCM compliance meaning, and CRT type meaning survive coordination intact.
15. **No authority substitution.** A closed lifecycle never replaces the corpus for the next judgement.
16. **No artefact mutation.** Coordination never rewrites implementation artefacts to manufacture passable recognition.
17. **No bypass.** Product urgency never waives constitutional lifecycle requirements.
18. **Repeatability / consistency.** Race-dependent or private stage shortcuts are defects.
19. **Explain the stop.** Students, developers, and auditors should hear when the lifecycle must refuse progress or closure.
20. **No emergency exemption.** Deadlines and demos never mint constitutional amendment power or authority replacement via lifecycle closure.

## 3. What the Lifecycle May Do (Lawful)

| Lawful action | Constitutional meaning |
|---------------|------------------------|
| **Coordinate certification** | Organise activities through CRTL-01…CRTL-07 |
| **Consume completed compliance** | Bind named CCM determinations under lawful CCC completion (and supporting lineage / authority references) without inventing or rewriting them |
| **Validate certification prerequisites** | Confirm published prerequisites before assessment |
| **Consume constitutional specifications** | Use published Constitution / EIP / Programme VI / VII / VIII corpora as recognition standards |
| **Preserve established traceability in records** | Carry established CT-01…CT-07 relationships into certification records; never invent them |
| **Preserve conformance artefacts in records** | Reference identifiable WS1 / MS001 assessment records as supporting inputs without rewriting them |
| **Apply certification types** | At CRTL-03, apply published CRT-01…CRT-07 only |
| **Produce certification decisions** | Emit certified / not-certified / deferred / escalated under published criteria |
| **Preserve certification records** | Keep reconstructable trails of obligations, completed compliance, prerequisites, stages, decisions, and boundaries |
| **Publish certification artefacts** | Communicate decisions and records under published honesty rules |
| **Refuse unlawful progress** | Prefer honest refuse / defer / escalate / not-certified over improvisation |
| **Remain repeatable and consistent** | Same published inputs → same stage outcomes and dispositions |
| **Remain implementation-neutral** | Honour lifecycle law across lawful equivalent stacks |
| **Support constitutional recognition honesty** | Strengthen recognition honesty without replacing CC / CV / CCM meaning or becoming constitutional authority |
| **Explain lifecycle progress** | Answer completed compliance / prerequisites / stages / records / boundaries without rewriting meaning |
| **Propose corpus amendments upstream** | Recommend (not enact) amendments when law itself must change |

These actions **coordinate certification**. They do **not** publish a new Constitution, invent coach warrants, mint tips, author ownership maps, invent CRT or CRTL types, invent CT links, author runtime behaviour, judge educational quality, perform verification, re-determine compliance, or modify artefacts under coordination pretext.

## 4. What the Lifecycle Must NEVER Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Perform verification** | CV / CVL / CVC own evidence evaluation and verification completion | Never narrate closure as a verification re-run; never re-author CV findings |
| **Determine compliance** | CCM / CCL / CCC own obligation status and compliance completion | Consume completed compliance; never re-run determination under a certification badge |
| **Modify constitutional specifications** | Only corpus governance may amend law | Leave specs unchanged; propose amendment upstream or mark not-certified / refuse |
| **Replace constitutional authority** | Published corpora remain the standard after any closure | Keep artefacts as recognised subjects, never as next-cycle law |
| **Create constitutional law** | Decisions and stage progress are not legislation | Cite published law only; refuse unpublished standards |
| **Redefine constitutional / educational meaning** | Programme VI and sibling corpora own meaning | Recognise against published meaning; never redefine it |
| **Modify implementation artefacts** | Coordination is not a mutation licence | Consume completed compliance as found; refuse when identity is insufficient |
| **Invent completed compliance** | WS3 owns compliance determination and completion | Consume completed activities; refuse invented inputs |
| **Invent prerequisites** | Prerequisites are published law | Validate published prerequisites; refuse theatre |
| **Invent traceability** | CT owns lawful lineage | Preserve established relationships in records; refuse invented links |
| **Invent or rewrite verification findings** | CV owns verification meaning | Never perform verification; never amend findings to force certification |
| **Rewrite conformance findings** | CC owns conformity meaning | Preserve CC artefacts in records; never amend them to force certification |
| **Invent certification types** | CRT catalogue is closed under WS4 / MS001 | Apply CRT-01…CRT-07 only |
| **Invent lifecycle stages** | CRTL catalogue is closed under this corpus | Apply CRTL-01…CRTL-07 only |
| **Bypass lifecycle requirements** | Requirements are educational care, not optional polish | Prefer understatement / refuse over invented green |
| **Privilege a technology as constitutional** | Implementation neutrality | Coordinate recognition, not Flask / SQLAlchemy / REST / OpenAPI fashion |
| **Determine educational quality** | No CRTL stage is a quality rubric | Keep coordination speech distinct from quality speech |
| **Determine constitutional truth** | Constitution / EIP own truth | Obey published law; do not adjudicate truth in lifecycle machinery |
| **Transfer authority** | Programme VII WS2 owns ownership, permission, and conflict disposition | Apply Authority corpora; refuse domain absorption via stages |
| **Invent educational state** | Programme VII WS4 owns EST/CST context law | Assess against published postures only |
| **Generate unpublished recommendations** | Programme VII WS3 + Programme VI owners own tip warrant | Surface recognition findings, not new tips |
| **Treat Twin / Adaptive / UI / CI noise as constitutional producers** | They are subjects / delivery surfaces | Require published corpus mapping or refuse |
| **Present scores / coverage / acks / cache hits as constitutional satisfaction or closure** | Operational proxies are not lifecycle law | Cite published corpora, CRT types, and CRTL stages |
| **Become irreplaceable by coordination topology** | Replaceability | Keep lifecycle law implementation-independent |
| **Freeze stack authority via publication or closure** | Neutrality / authority preservation | Publish recognition; never make the stack the next standard |

## 6. Boundary Checks (Pre-Closure)

Before a material constitutional certification lifecycle is treated as closed, coordination requires affirmative answers:

| Check | Question |
|-------|----------|
| **CRTLB-01 Specification / obligation identity** | Are recognition standards published Constitution / EIP / Programme VI / VII / VIII obligations and specifications (not unpublished customs)? |
| **CRTLB-02 Stage class** | Are required CRTL-01…CRTL-07 stages being applied (not unpublished customs)? |
| **CRTLB-03 Certification class** | Are required CRT-01…CRT-07 types applied at CRTL-03 (not unpublished customs)? |
| **CRTLB-04 Completed compliance identity** | Which named completed compliance activities were consumed? |
| **CRTLB-05 Prerequisite identity** | Which certification prerequisites were satisfied (none invented or skipped)? |
| **CRTLB-06 Decision binding** | Which lifecycle stage produced the certification decision (especially CRTL-03 / CRTL-04)? |
| **CRTLB-07 Record identity** | Which certification records were preserved? |
| **CRTLB-08 Non-legislation** | Does the lifecycle avoid creating or modifying constitutional specifications? |
| **CRTLB-09 Non-redefinition** | Does the lifecycle avoid redefining Programme VI educational meaning or sibling constitutional meaning? |
| **CRTLB-10 Non-substitution** | Does the lifecycle avoid treating the implementation or lifecycle machinery as the next constitutional standard? |
| **CRTLB-11 Non-verification** | Is closure framed as certification coordination complete — not a verification re-run or substitute for WS2? |
| **CRTLB-12 Non-compliance-redetermination** | Is closure framed as coordination complete — not a second CCM determination or substitute for WS3? |
| **CRTLB-13 Non-conformance-replacement** | Is closure framed as recognition coordination complete — not certified conformity forever or a rewrite of CC meaning? |
| **CRTLB-14 Non-mutation** | Were implementation artefacts left unmodified by lifecycle coordination? |
| **CRTLB-15 Neutrality** | Does the lifecycle avoid privileging a language, framework, protocol, or CI vendor as law? |
| **CRTLB-16 Closure ≠ quality** | Is the outcome framed as lifecycle coordination / recognition — not educational quality? |
| **CRTLB-17 Spec immutability** | Are constitutional corpora left unchanged by the lifecycle act? |
| **CRTLB-18 Repeatability / audit** | Are stage outcomes reproducible; do explainability records preserve completed compliance, prerequisites, stages, decisions, records, and boundaries? |

Any failed check → refuse-close / deferred / escalated / not-certified as published. Do not “best-effort” invent lifecycle law, invent completed compliance, soft-amend specifications, perform verification, re-determine compliance, mutate artefacts, or replace constitutional authority in situ.

## 8. Closing Statement
