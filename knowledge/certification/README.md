## Purpose

This folder defines **the permanent constitutional recognition that an implementation has satisfied published constitutional obligations based on completed compliance activities**.

It answers *what certification must optimise*, *which recognised certification categories exist*, *what certification may and must never do*, and *how certification is constitutionally explained* — without implementing Runtime A, testing frameworks, CI/CD, creating constitutional law, modifying constitutional specifications, redefining constitutional meaning, replacing constitutional authority, performing verification, or performing compliance.

It does **not** implement Runtime A, test runners, CI/CD pipelines, GitHub Actions, Python, Flask, SQLAlchemy, REST, OpenAPI, infrastructure, or application services.

> **Constitutional certification formally recognises constitutional satisfaction from completed compliance activities.  
> It never becomes constitutional law itself.  
> It never creates, modifies, or redefines constitutional specifications.  
> It never performs verification or compliance.  
> It never replaces constitutional authority.**

## Architectural requirement

Constitutional certification formally recognises **constitutional satisfaction**.

| Lawful | Unlawful |
|--------|----------|
| Recognise completed compliance | Modify constitutional specifications |
| Preserve certification records | Create constitutional law via recognitions |
| Preserve audit continuity | Redefine constitutional / educational meaning |
| Preserve constitutional authority and implementation neutrality | Replace compliance or verification |
| Preserve governance integrity, explainability, auditability, and repeatability | Substitute certification for constitutional authority |
| Explain obligations / completed compliance / category / authority / boundaries | Elevate certification machinery into a constitutional producer |
| Refuse recognition when compliance is incomplete or unsatisfied | Equate certification with educational quality, permanent conformity, or frozen stack law |

**Certification formally recognises constitutional satisfaction. It never creates, modifies, or supersedes constitutional law.**

## How to use this corpus

1. Confirm the published constitutional obligations under recognition exist — refuse certification theatre against unpublished customs.
2. Confirm identifiable completed compliance activities (determinations + lawful completion) are available as inputs — refuse invented compliance or incomplete lifecycle theatre.
3. Read `CONSTITUTIONAL_CERTIFICATION_MODEL.md` for stack position and integrity rules.
4. Optimise under `CERTIFICATION_OBJECTIVES.md`.
5. Classify under `CERTIFICATION_TYPES.md` (CRT-01…CRT-07 only).
6. Enforce hard stops under `CERTIFICATION_BOUNDARIES.md`.
7. Require explainability contracts from `CERTIFICATION_EXPLAINABILITY.md` before student-, developer-, or auditor-facing certification narration.
8. Do not implement certification machinery that contradicts this corpus without amending it first.
