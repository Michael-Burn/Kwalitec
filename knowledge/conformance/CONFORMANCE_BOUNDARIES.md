## 1. Purpose

Assessment that silently becomes a second constitution — rewriting specs so code passes, inventing educational meaning in “findings,” licensing runtime behaviour under a green badge, or treating a preferred implementation as the new standard — destroys student trust and educational integrity.

This document draws a bright line between **lawful constitutional conformance** (Programme IX / WS1 / MS001) and **constitutional authorship / educational judgement / runtime authorship** (Constitution / EIP / Programmes VI–VIII / permitted writers).

---

## 2. Boundary Principles

1. **Evaluate, do not legislate.** Conformance measures fidelity; it does not create law.
2. **Published specifications only.** Unpublished customs and “main as law” are hard stops as standards.
3. **Published conformance types only.** Unpublished CC customs are unlawful.
4. **Named artefacts only.** Assessments without identifiable implementation subjects are theatre.
5. **Exactly as published.** Successful conformity never rewrites specification meaning.
6. **Authority first.** Published corpora remain the sole constitutional standard.
7. **Implementation independence.** No stack, vendor, or reference implementation becomes law by proximity.
8. **Conformity ≠ quality.** Conformance never grades learning, mastery, readiness, or product success.
9. **No reinterpretation.** Programme VI questions and EIP claim classes survive assessment intact.
10. **No behaviour authorship.** Findings do not licence new runtime, API, or UI behaviour.
11. **No authority substitution.** A conformant artefact never replaces the corpus for the next judgement.
12. **No bypass.** Product urgency never waives constitutional conformance requirements.
13. **Repeatability.** Race-dependent dispositions are a defect.
14. **Explain the stop.** Students, developers, and auditors should hear when assessment must refuse conformity.
15. **No emergency exemption.** Deadlines and demos never mint constitutional amendment power via findings.

## 3. What Conformance May Do (Lawful)

| Lawful action | Constitutional meaning |
|---------------|------------------------|
| **Evaluate implementations** | Apply CC-01…CC-07 to named artefacts against published specifications |
| **Reference constitutional specifications** | Cite Constitution / EIP / Programme VI / VII / VIII corpora as the exclusive evaluation standard |
| **Produce conformance findings** | Emit conformant / non-conformant / deferred / escalated under published criteria |
| **Preserve audit records** | Keep reconstructable trails of specs, artefacts, criteria, findings, and boundaries |
| **Refuse unlawful conformity claims** | Prefer honest non-conformant / deferred / escalated over improvisation |
| **Compose required types** | Apply published CC conjunctions without collapsing failed checks |
| **Remain repeatable** | Same published inputs → same disposition |
| **Remain implementation-neutral** | Honour conformance law across lawful equivalent stacks |
| **Explain conformance** | Answer specs / artefacts / criteria / findings / boundaries without rewriting meaning |
| **Propose corpus amendments upstream** | Recommend (not enact) amendments when law itself must change |

These actions **evaluate fidelity**. They do **not** publish a new Constitution, invent coach warrants, mint tips, author ownership maps, invent CC types, author runtime behaviour, or judge educational quality.

---

## 4. What Conformance Must NEVER Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Modify constitutional specifications** | Only corpus governance may amend law | Leave specs unchanged; propose amendment upstream or mark non-conformant |
| **Create constitutional law** | Findings are not legislation | Cite published law only; refuse unpublished standards |
| **Create educational meaning** | Programme VI owns coach / planner questions | Evaluate fidelity to published meaning; never invent it |
| **Reinterpret educational meaning** | Meaning owners own claim classes and warrants | Confirm published meaning; never rewrite it in findings |
| **Author runtime behaviour** | Programme VIII + permitted writers own execution law | Evaluate whether behaviour obeys published law; do not mint behaviour |
| **Substitute constitutional authority** | Published corpora remain the standard after any finding | Keep artefacts as assessed subjects, never as next-cycle law |
| **Bypass constitutional conformance requirements** | Requirements are educational care, not optional polish | Prefer understatement / non-conformant over invented green |
| **Privilege a technology as constitutional** | Implementation neutrality | Evaluate obligations, not Flask / SQLAlchemy / REST / OpenAPI fashion |
| **Determine educational quality** | No CC is a quality rubric | Keep conformity speech distinct from quality speech |
| **Determine constitutional truth** | Constitution / EIP own truth | Obey published law; do not adjudicate truth in assessment machinery |
| **Transfer authority** | Programme VII WS2 owns ownership, permission, and conflict disposition | Apply Authority corpora; refuse domain absorption via findings |
| **Invent educational state** | Programme VII WS4 owns EST/CST context law | Evaluate against published postures only |
| **Generate unpublished recommendations** | Programme VII WS3 + Programme VI owners own tip warrant | Surface fidelity findings, not new tips |
| **Treat Twin / Adaptive / UI / CI noise as constitutional producers** | They are subjects / delivery surfaces | Require published corpus mapping or refuse |
| **Present scores / coverage / acks / cache hits as constitutional adherence** | Operational proxies are not conformance law | Cite published corpora and CC types |
| **Become irreplaceable by assessment topology** | Replaceability | Keep conformance law implementation-independent |

## 6. Boundary Checks (Pre-Finding)

Before material constitutional conformance is treated as established, assessment requires affirmative answers:

| Check | Question |
|-------|----------|
| **CCB-01 Specification identity** | Are evaluation standards published Constitution / EIP / Programme VI / VII / VIII specifications (not unpublished customs)? |
| **CCB-02 Conformance class** | Are required CC-01…CC-07 types being applied (not unpublished customs)? |
| **CCB-03 Artefact identity** | Which named implementation artefacts are under assessment? |
| **CCB-04 Criteria identity** | Which published criteria from those specifications / this catalogue apply? |
| **CCB-05 Non-legislation** | Does the assessment avoid creating or modifying constitutional specifications? |
| **CCB-06 Non-reinterpretation** | Does the assessment avoid reinterpreting Programme VI educational meaning? |
| **CCB-07 Non-authorship** | Does the assessment avoid authoring runtime behaviour, tips, state, or ownership? |
| **CCB-08 Non-substitution** | Does the assessment avoid treating the implementation as the next constitutional standard? |
| **CCB-09 Neutrality** | Does the assessment avoid privileging a language, framework, protocol, or CI vendor as law? |
| **CCB-10 Conformity ≠ quality** | Is the outcome framed as fidelity — not educational quality / truth? |
| **CCB-11 Spec immutability** | Are constitutional corpora left unchanged by the assessment act? |
| **CCB-12 Repeatability / audit** | Is disposition reproducible; will CC-07 / explainability records preserve specs, artefacts, criteria, findings, and boundaries? |

Any failed check → non-conformant / deferred / escalated. Do not “best-effort” invent conformance law or soft-amend specifications in situ.

## 8. Closing Statement

> **Constitutional conformance is powerful only as a faithful evaluation of implementation against published law.  
> The moment it modifies specifications, creates educational meaning, authors runtime behaviour, or substitutes an implementation for constitutional authority — or pretends conformity is educational quality — it has left constitutional education and entered product fiction.**
