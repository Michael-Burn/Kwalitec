## 1. Purpose

An engine that silently becomes a second constitution — inventing meaning under the label “execution,” replacing EIP in “notes,” minting compliance as “outcomes,” certifying implementations because rules ran, or amending specifications so a demo can finish — destroys student trust and educational integrity.

This document draws a bright line between **lawful constitutional execution** (Programme X / WS2 / MS001) and **constitutional legislation / independent interpretation / governance determination** (Constitution / EIP / Programmes VI–IX / permitted writers).

---

## 2. Boundary Principles

1. **Execute, do not legislate.** The engine applies published rules; it does not author them.
2. **Completed context only.** Incomplete or unpublished preparation is a hard stop.
3. **Published rules only.** Unpublished customs and “main as law” are hard stops as rule sources.
4. **Published components only.** Unpublished CEE customs are unlawful.
5. **Exactly as published.** Successful execution never rewrites specification meaning.
6. **Authority first.** Published corpora remain the sole constitutional standard.
7. **EIP intact.** Educational Interpretation Principles are never replaced by engine prose.
8. **Implementation independence.** No stack, vendor, or reference implementation becomes law by proximity.
9. **Outcomes ≠ governance.** Execution outcomes never determine compliance or certify implementations.
10. **No independent interpretation.** Applying published rules is not inventing new constitutional meaning.
11. **No governance authorship.** Collecting outcomes is not minting CC / CV / CCM / CRT / CEG dispositions.
12. **No authority substitution.** A published outcome never replaces the corpus for the next act.
13. **No bypass.** Product urgency never waives required engine components or completed-context prerequisites.
14. **Determinism and repeatability.** Race-dependent or operator-dependent execution is a defect.
15. **Explain the stop.** Students, developers, and auditors should hear when execution must refuse or escalate.
16. **No emergency exemption.** Deadlines and demos never mint constitutional amendment power via the engine.
17. **Constraints survive.** Hard limits may be evaluated; they may not be waived by engine prose.
18. **Downstream honesty.** Downstream decision architecture consumes outcomes; it does not inherit legislative power from the engine.

## 3. What the Engine May Do (Lawful)

| Lawful action | Constitutional meaning |
|---------------|------------------------|
| **Consume completed execution contexts** | Begin only when WS1 / MS003 preparation fulfilment is confirmed |
| **Execute constitutional rules** | Apply published rules identified in the completed context via CEE-01 / CEE-02 |
| **Evaluate constitutional constraints** | Assess hard limits via CEE-03 without waiving them |
| **Produce execution outcomes** | Collect and publish reconstructable outcomes via CEE-04 / CEE-07 for downstream decision architecture |
| **Manage execution state** | Record speakable engine progress via CEE-05 (not educational or governance state) |
| **Coordinate exceptions** | Stop, escalate, or record via CEE-06 when lawful execution cannot continue |
| **Preserve constitutional authority** | Keep Constitution / EIP / Programmes VI–IX / WS1 as the standard |
| **Preserve implementation neutrality** | Honour engine law across lawful equivalent stacks |
| **Preserve determinism and repeatability** | Same completed context + same published rules → same disposition |
| **Explain execution** | Answer rules / constraints / outcomes / state / boundaries without rewriting meaning |
| **Refuse unlawful runs** | Prefer honest stop over improvisation |
| **Propose corpus amendments upstream** | Recommend (not enact) amendments when law itself must change before a concern can be executed |

## 4. What the Engine Must Never Do (Unlawful)

| Unlawful action | Why it is forbidden |
|-----------------|---------------------|
| **Interpret constitutional law independently** | Independent interpretation invents meaning; EIP and published corpora own meaning |
| **Redefine constitutional meaning** | Soft redefinition is legislation disguised as execution |
| **Amend constitutional specifications** | Specifications are never modified under engine pretext |
| **Replace Educational Interpretation Principles** | EIP remains intact; engine prose never substitutes new principles |
| **Determine governance outcomes** | Conformance, verification, compliance, certification, and evolution remain Programme IX |
| **Determine compliance** | CCM (and related) determinations remain Programme IX responsibilities |
| **Perform verification as engine law-making** | CV (and related) evaluation remains Programme IX; engine may apply published rules that *reference* verification artefacts as information, never re-author findings |
| **Certify implementations** | CRT (and related) recognition remains Programme IX responsibilities |
| **Evaluate conformance as law-making** | CC findings may be *referenced* as information; they are not re-run or elevated into new law by the engine |
| **Create constitutional authority** | Engine machinery never becomes the constitutional standard |
| **Replace constitutional authority** | Published corpora remain exclusive owners of meaning |
| **Complete or invent execution context** | Context preparation belongs to WS1; the engine consumes completed context only |
| **Mint recommendations or invent educational state** | Programme VI / VII and EIP-001 remain owners |
| **Freeze a stack as law** | Runtime A / Twin / Adaptive / CI proximity never becomes authority |
| **Waive constraints** | Demo urgency never suspends hard stops |
| **Silent exception swallowing** | Unrecorded improvisation destroys explainability and fidelity |
| **Present outcomes as educational quality** | Execution ≠ mastery, readiness, or coaching quality |

## 6. Hard Stops (Non-Negotiable)

The following are immediate constitutional defects. Prefer refuse / exception coordination (CEE-06) over continuation:

1. No completed resolved execution context (WS1 / MS003 not fulfilled).
2. Dispatch of unpublished rules or tribal customs.
3. Soft amendment of constitutional specifications mid-run.
4. Replacement or rewrite of EIP principles mid-run.
5. Minting of compliance, certification, verification, or conformance dispositions as engine outcomes.
6. Constraint waiver for demo, deadline, or preferred stack.
7. Non-deterministic or non-repeatable material disposition without honest exception recording.
8. Publication that presents execution outcomes as constitutional law or governance seals.
9. Elevation of Runtime A / Twin / Adaptive / CI into constitutional authority.
10. Off-catalogue engine steps presented as CEE components.
