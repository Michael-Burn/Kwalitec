## 1. Purpose

Kwalitec coaches students preparing for demanding professional examinations (especially IFoA syllabi such as CM1/CS1 and peers).

An expert IFoA tutor does not only *name* where the student is educationally — the tutor can also *say why* that focus is live, and *how* it lawfully arrived there from prior context. After MS001 has published EST postures and MS002 has published CST succession law, the platform still needs one constitutional explanation question answered consistently:

> **“Why is the learner currently in this constitutional educational context, and how did that context lawfully evolve?”**

That answer must cover initial context, single transitions, multi-step progression, and workflow-referenced succession — without inventing educational meaning, implying mastery or success, transferring authority, creating recommendations, executing workflows, or publishing undeclared rules.

This document records that tutor posture so every future Educational State Engine subsystem has a single educational reference for *how educational state is explained*.

> **Educational State Explainability describes constitutional reasoning about contextual representation and lawful succession.  
> It does not redefine educational meaning, transfer authority, execute workflows, or create recommendations.**

## 2. What Educational State Explainability Is

**Educational State Explainability** is the constitutional contract for narrating **why a named EST posture is currently live**, **how that posture lawfully succeeded from prior context (if it did)**, and **which published constitutional facts support that narration**.

| Concept | Definition | Primary question |
|---------|------------|------------------|
| **Current EST state** | Live primary constitutional context posture (and parallel-read siblings if any) | Where are we now as context? |
| **Preceding contextual states** | Prior EST postures in the lawful succession chain | Where were we before? |
| **CST references** | Named transition types that authorised succession steps | How did context move? |
| **Supporting contextual evidence** | Plan class, Programme VI warrants, WS1 progression facts, WS2 dispositions, continuity holds | What warrants the live posture / move? |
| **Published rules applied** | MS001 entry/exit, CST catalogue, conditions, SB/STB checks | Which constitutional law was applied? |
| **Workflow / authority references** | Optional orchestration or ownership speech consumed as *context*, not as ownership rewrite | What coordination or permission situates this focus? |
| **Continuity record** | Explicit preservation that prior context was not erased (EIP-005) | Did we forget where we were? |
| **Non-claim honesty** | Explicit refusal of mastery / success / completion / tip / ownership overclaim | What must this never mean? |

Educational State Explainability is:

- **constitutional** — it cites published EST/CST law, not product preference;
- **context-centred** — its core job is *why this focus / how it evolved*, not *why this tip is educationally good* (Programme VI owns that);
- **progression-aware** — initial posture and succession share one explanation contract;
- **audience-aware** — student speech and developer/auditor traces differ in vocabulary, not in underlying truth;
- **layer-honest** — it frames context and succession; it does not replace coach meaning, workflow narration, permission speech, or tip packaging;
- **non-inventive** — it never creates EST/CST types, evaluative meanings, owners, or tips;
- **continuity-preserving** — succession speech never erases prior lawful context.

Educational State Explainability is **not**:

- a second Educational State Model;
- a second Educational State Transition Framework;
- a rewrite of Programme VI educational meaning;
- a workflow stage sequencer or completion engine;
- an authority or recommendation engine;
- a rendering, UI, template, or analytics system;
- a claim that a clear explanation guarantees student success or mastery.

## 3. Educational Purpose

Educational State Explainability exists so that:

1. **Live context is speakable** — students and developers can hear which constitutional focus is live.
2. **Progression is traceable** — lawful succession is narrated without amnesia or mode flicker.
3. **Warrants stay honest** — context warrants are distinguished from understanding Evidence.
4. **Continuity stays dignified** — holding, waiting, and refuse/remain are clear care, not product emptiness or student failure.
5. **Layers stay distinct** — meaning, ownership, orchestration, tips, and context remain separable in speech.
6. **Evaluative overclaim is refused** — focus and succession never sound like mastery, pass certainty, or workflow completion.

## 5. Five Educational State Explanation Questions (Binding)

Every material educational state explanation must answer these five questions.

### ESEQ-01 — What is the current constitutional educational context?

Name the live primary EST posture (and any parallel-read siblings) in audience-appropriate language. Record that Article IV meaning-bearing states were not aliased as EST-xx.

### ESEQ-02 — Why does this context exist now?

Cite entry warrants, initiating educational events / dispositions / continuity bases, and prior exit when succession required it. For refuse/remain, explain why focus did *not* change.

### ESEQ-03 — How did this context lawfully evolve?

Name preceding EST postures and CST references for material succession steps — or explicit `initial` / `none` when the posture is the first speakable context in the window. Preserve continuity of prior context (EIP-005).

### ESEQ-04 — What constitutional evidence and published rules support it?

Distinguish **context warrants** from EIP-002 Educational Evidence of understanding. Cite published EST entry/exit, CST catalogue, condition families, and SB/STB checks. Never present scores or implementation details as constitutional proof.

### ESEQ-05 — What workflows, authority paths, or recommendations reference it?

List observing WS1 / WS2 / WS3 consumers when material — or explicit none. Ensure consumers are narrated as *observers / references*, never as owners of context meaning, tip sources invented by EST labels, or transferred authority.

All five ESEQs are mandatory for material educational-state narrations. Omitting ESEQ-03 when succession occurred (or when an auditor would expect a progression chain) is an architectural defect. Omitting non-claim honesty under ESEQ-04 / ESEQ-05 is always an architectural defect.

**Consistency with MS001 / MS002:**

| MS003 | Maps to |
|-------|---------|
| ESEQ-01 | ESQ-01 |
| ESEQ-02 | ESQ-02 (+ STQ-01 when a move just occurred) |
| ESEQ-03 | STQ-01 / STQ-04 progression & continuity (generalised) |
| ESEQ-04 | ESQ-03 + STQ-02 + STQ-03 |
| ESEQ-05 | ESQ-04 (+ optional workflow / authority / tip consumers) |

MS003 does not replace ESQ or STQ documents; it binds a unified explanation contract that must remain consistent with both.
