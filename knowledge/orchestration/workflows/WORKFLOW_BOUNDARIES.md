## 1. Purpose

Orchestration that silently becomes a second tutor — rewriting plans, inventing tips, or reinterpreting evidence — destroys constitutional layering and student trust.

This document draws a bright line between **lawful coordination** (Programme VII) and **educational meaning / mutation authority** (Programme VI + EIP).

---

## 2. Boundary Principles

1. **Coordinate, do not educate by substitute.** Workflows route; Programme VI answers.
2. **Preserve coach authority.** Daily, Learning, Recovery, Revision, and Exam meanings are not workflow property.
3. **Plan non-mutation.** Canonical Study Plan remains Master Planner / Scheduling contract.
4. **Evidence non-reinterpretation.** Evidence Model and permitted writers own observational truth.
5. **No independent recommendations.** Every material tip must trace to an invoked Programme VI authority.
6. **State Matrix supremacy.** Orchestration never gains mutation rights by renaming itself.
7. **Smallest sufficient coordination.** Prefer handoff over absorbing a sibling’s job.
8. **Explicit refusal.** When a requested flow would violate boundaries, refuse and explain.
9. **Determinism over cleverness.** Do not invent discretionary overrides that cannot be audited.
10. **Explain the limit.** Students and developers should hear when orchestration stops and another authority must act.

## 3. What Educational Workflows May Do (Lawful)

| Lawful action | Educational meaning |
|---------------|---------------------|
| **Recognise and classify events** | Map stimuli to WE-xx classes without deciding |
| **Open, continue, supersede, conclude workflows** | Manage orchestration lifecycle |
| **Select primary Programme VI authority** | Name whose educational question is live |
| **Assemble lawful inputs** | Gather plan, profile, evidence, history, sibling meanings as *inputs* |
| **Invoke Programme VI reasoning** | Call the owning constitutional model’s decision posture |
| **Sequence stages** | Move S0→S7 with conflict checks |
| **Prevent conflicting primary actions** | Enforce single primary decider |
| **Hand off between authorities** | Named transfer when the living question changes |
| **Refuse or escalate** | Honest no-recommendation or structural pathway |
| **Explain orchestration** | Event → participants → authority preservation → outcome |

These actions **coordinate**. They do **not** publish a new Study Plan, mint mastery, reinterpret evidence, or replace any coach.

## 4. What Educational Workflows Must NOT Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Redefine coach authority** | Programme VI owns coach meaning | Invoke the coach’s model; do not rewrite its question |
| **Modify the Canonical Study Plan** | Plan is Master Planner / Scheduling educational contract | Escalate via WE-08 / Master Planner pathways |
| **Reinterpret Educational Evidence** | Evidence Model + permitted writers own observational truth | Consume evidence as classified; never re-label coverage as understanding |
| **Introduce educational recommendations independently** | Recommendations require Programme VI warrant | Invoke primary authority at S3; surface *its* artefact at S5 |
| **Absorb Master Planner strategy / profile / scheduling** | Long-horizon design is Programme VI MS002–MS006 | Hand off structural questions |
| **Override Learning Mode topic authority by orchestration fiat** | EL-009 / Daily Coach / Constitution | Respect mode; escalate disclosed mode change only when constitutionally authorised |
| **Mint Estimated Knowledge / Mastery from workflow completion** | EIP-006 / Twin / Evidence authorities | Leave estimates to permitted writers |
| **Punitive catch-up via “workflow efficiency”** | Recovery boundaries forbid overload theatre | Recovery Coach restorative meaning only |
| **Exam theatre from calendar alone** | Exam Coach warrant rules | Evaluate WE-06 under Exam Coach model |
| **Silent merge of conflicting coaches** | WO-05 / single primary | Supersede or hand off explicitly |
| **Erase educational history on conclude** | EIP-005 Continuity | Conclude orchestration state only |
| **Bypass State Authority Matrix** | EIP-001 | Readers assemble; writers remain listed |

## 6. Boundary Tests (Pass / Fail)

Use these tests before accepting any proposed orchestration behaviour:

| # | Test question | Pass means |
|---|---------------|------------|
| B1 | Does every material recommendation cite an invoked Programme VI authority? | Yes |
| B2 | Does any stage mutate Canonical Study Plan educational intent? | Must be No |
| B3 | Does any stage reinterpret evidence or mint mastery from flow completion? | Must be No |
| B4 | Is there at most one primary educational decider? | Yes |
| B5 | Are coach meanings left intact (only sequenced)? | Yes |
| B6 | Is refusal/escalation available when envelopes break? | Yes |
| B7 | Can S6 explain start, participants, authority preservation, and outcome? | Yes |

Any **Fail** ⇒ educationally unlawful under this milestone.
