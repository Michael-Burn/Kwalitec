> **Educational state may represent constitutional context,  
> support orchestration,  
> support recommendation assembly,  
> and support explainability.  
> It must not create recommendations,  
> redefine educational evidence,  
> transfer authority,  
> replace workflows,  
> or execute educational actions.**

---

## 1. Purpose

Educational state that silently becomes a second tutor — inventing tips, rewriting evidence, transferring ownership, replacing workflows, or executing actions — destroys constitutional layering and student trust.

Educational state that is misread as success, mastery, or workflow completion destroys claim honesty (EIP-003 / EIP-006).

This document draws a bright line between **lawful context representation** (Programme VII Workstream 4) and **educational meaning / ownership / orchestration / recommendations / mutation** (Programme VI + WS1 + WS2 + WS3 + EIP).

---

## 2. Boundary Principles

1. **Represent, do not create.** State names context; it does not mint educational meaning or tips.
2. **Observe, do not execute.** State labels never run workflows or educational actions.
3. **Support, do not replace.** Orchestration and assembly may consume context; state never becomes Workflow or Recommendation Engines.
4. **Preserve ownership.** Naming Recovery Context never transfers Recovery Coach ownership — and never absorbs it into State Engine.
5. **Evidence non-redefinition.** Context warrants ≠ EIP-002 Educational Evidence of understanding.
6. **Article IV supremacy for meaning-bearing states.** EST types never redefine or mutate Study Progress, Evidence, Mission, or estimates.
7. **Published types only.** Undocumented modes are a hard stop.
8. **Non-success / non-mastery / non-completion.** Evaluative readings are forbidden interpretations, not features.
9. **Plan non-mutation.** Canonical Study Plan remains Master Planner / Scheduling contract.
10. **Explain the limit.** Students and developers should hear when context speech stops and another authority must act.

---

## 3. What Educational State May Do (Lawful)

| Lawful action | Educational meaning |
|---------------|---------------------|
| **Represent constitutional context** | Name the live EST-xx posture when entry conditions hold |
| **Support orchestration** | Provide observable context inputs to WS1 event recognition, authority selection, and conclusion |
| **Support recommendation assembly** | Serve as referenceable context for WS3 artefacts and sets |
| **Support explainability** | Make current context, warrant, supporting context evidence, and consumers speakable |
| **Preserve continuity** | Hold EST-12 or narrate succession without erasing history |
| **Refuse invented modes** | Prefer Continuity Holding / Absent Plan / Escalation Await over fabricated focus |
| **Distinguish Article IV objects** | Situate speech that mentions Study Progress / Evidence without becoming those states |

These actions **represent and support**. They do **not** publish tips, rewrite evidence, transfer domains, replace workflows, or execute study actions.

---

## 4. What Educational State Must NOT Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Create recommendations** | WS3 owns recommendation artefacts; Programme VI owns meaning | Reference context for assembly; leave tip creation to rightful owners |
| **Redefine educational evidence** | EIP-002 + permitted writers own observational truth | Cite context warrants; never relabel coverage/time/confidence as understanding |
| **Transfer authority** | WS2 owns the ownership map | Observe owners; never move domains via EST labels |
| **Replace workflows** | WS1 owns stages, transitions, and completion | Supply context to workflows; do not invent stage order or completion |
| **Execute educational actions** | State is representational, not an actor | Leave missions, sessions, plan writes, and estimates to their owners |
| **Claim educational success** | Success is not a constitutional context meaning | Narrate focus honestly; refuse success theatre |
| **Claim learner mastery** | EIP-006 / Twin / Evidence authorities | Leave mastery / knowledge estimates to lawful writers |
| **Claim workflow completion** | WS1 Completion Model | Leave orchestration fulfilment to completion law |
| **Mutate Article IV states** | EIP-001 Permitted Writers | Context change never writes Study Progress / Evidence / estimates |
| **Modify the Canonical Study Plan** | Master Planner / Scheduling | Escalate structural questions; do not “state” a new plan |
| **Invent undocumented modes** | Catalogue closure | Amend `STATE_TYPES.md` first — or refuse |
| **Silent dual-primary theatre** | Single primary context principle | One primary EST; siblings as parallel-read only |
| **Use engagement optimisers as context law** | Product metrics ≠ constitutional warrants | Keep metrics out of EST entry conditions |
| **Erase educational history via mode refresh** | EIP-005 Continuity | Succeed context; do not delete learner history |

## 5. Boundary IDs (Hard Stops)

| ID | Prohibition |
|----|-------------|
| **SB-01** | Create educational recommendations from state labels alone |
| **SB-02** | Redefine or reinterpret Educational Evidence under a state-engine label |
| **SB-03** | Transfer, absorb, or invent Authority Model domains via EST types |
| **SB-04** | Replace workflow stages, transitions, or completion with state-machine fiat |
| **SB-05** | Execute educational actions (start mission, write plan, pack calendar, mutate estimates) |
| **SB-06** | Interpret any EST type as educational success |
| **SB-07** | Interpret any EST type as learner mastery / Estimated Mastery |
| **SB-08** | Interpret any EST type as workflow completion |
| **SB-09** | Mutate Article IV educational states by context succession |
| **SB-10** | Publish undocumented context modes as constitutional educational state |

## 9. Binding Rule

If a proposed Educational State behaviour would require creating recommendations, redefining evidence, transferring authority, replacing workflows, executing actions, or reading EST labels as success / mastery / completion — **refuse**. Amend the rightful constitutional corpus first if the law must change. Educational state never gains power by renaming itself “the state engine.”
