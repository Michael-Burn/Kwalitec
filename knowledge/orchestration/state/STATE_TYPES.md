## 1. Purpose

An expert tutor recognises distinct educational situations: no plan yet, designing the journey, focusing on today, sitting a session, reflecting, tracking learning over time, recovering after disruption, revising known material, preparing for the exam, waiting while concurrent tips are dispositioned, awaiting a structural change, or simply holding continuity until the next live question.

These EST types bind Educational State Engine vocabulary so context remains auditable and non-evaluative.

---

## 2. Catalogue Principles

1. **Published only.** Only EST-01…EST-12 are constitutional educational states under this Model.
2. **One primary.** At most one EST type is *primary* student-facing context at a time, unless a documented parallel-read pattern applies.
3. **Meaning non-redefinition.** Entry/exit cite Programme VI and WS1/WS2 facts; they never rewrite coach questions.
4. **Non-success / non-mastery / non-completion.** Every type carries prohibited interpretations that block evaluative overclaim.
5. **Observers consume.** Listed observing components may read context; they do not gain mutation or tip-creation rights from observation.
6. **Warrants are contextual, not Article IV evidence rewrites.** Plan class, disruption signals, and orchestration facts may warrant context without becoming EIP-002 Educational Evidence of understanding.
7. **Amend to extend.** New types require amending this catalogue first.

## 4. State Definitions

### EST-01 — Absent Plan Context

| Aspect | Definition |
|--------|------------|
| **Constitutional meaning** | Constitutional educational context in which **no Active-class Canonical Study Plan** is available as the binding preparation contract. The learner is not under day-coach or coach-posture focus until structural planning lawfully establishes a plan. |
| **Entry conditions** | No Active-class Canonical Study Plan exists for the learner’s study context; or the prior Active plan has been lawfully ended/archived such that no Active contract remains. |
| **Exit conditions** | An Active-class Canonical Study Plan is lawfully published / activated under Master Planner / Scheduling authority; primary context then succeeds to EST-02 (if structural work continues) or EST-03 / EST-12 as warrants dictate. |
| **Observing components** | Workflow Engine (WS1); Master Planner pathways; Authority Model (plan-related domains); Recommendation surfaces (may refuse day tips); Continuity / onboarding narration |
| **Prohibited interpretations** | Not “student failure”; not lack of mastery; not workflow completion; not licence for independent Programme VII tips; not Study Progress erasure; not Exam Context by calendar alone |

---

### EST-02 — Structural Planning Context

| Aspect | Definition |
|--------|------------|
| **Constitutional meaning** | Constitutional educational context in which **Master Planner / structural design, reschedule, or replan** is the live educational focus — establishing or adjusting the Canonical Study Plan contract. |
| **Entry conditions** | Structural educational question is primary (initial plan design, lawful reschedule/replan, or escalation that requires plan authority); Master Planner (or Scheduling under plan authority) is the invited primary owner. |
| **Exit conditions** | Structural question is concluded (plan published/updated/refused under plan law) and primary focus hands off; or supersession to another primary warrant (e.g. recovery) under WS1 conflict / supersede law. |
| **Observing components** | Workflow Engine; Master Planner; Scheduling consumers; Authority Model (AD planning domain); Recommendation Engine (structural handoff speech only) |
| **Prohibited interpretations** | Not day-coaching by another name; not rewriting plan via recommendation packaging; not mastery minting from wizard completion; not “planning done ⇒ student understands syllabus”; not silent absorption of coach domains |

---

### EST-03 — Day Priority Context

| Aspect | Definition |
|--------|------------|
| **Constitutional meaning** | Constitutional educational context in which the **Daily Coach question** — what is most educationally valuable *today* under the Active Canonical Study Plan — is the constitutive focus. |
| **Entry conditions** | Active-class Canonical Study Plan present; day-level educational question is primary; Daily Coach is the invited primary owner; no superseding recovery / exam / structural primary warrant under WS1 law. |
| **Exit conditions** | Day question concluded, deferred, or superseded; session/reflection nested contexts may open as primary while day warrant remains parent; or handoff to EST-06…EST-09 / EST-02 / EST-11 when those warrants lead. |
| **Observing components** | Workflow Engine; Daily Coach; Session / Reflection participants; Recommendation Assembly; Authority Model (Daily Coach domain) |
| **Prohibited interpretations** | Not “today’s mission completed ⇒ mastery”; not Study Progress auto-complete; not recovery/revision/exam meaning; not plan rewrite; not workflow completion; not educational success |

---

### EST-04 — Session Context

| Aspect | Definition |
|--------|------------|
| **Constitutional meaning** | Constitutional educational context in which an **authorised learning sitting** is under way — executing (not inventing) the day’s or otherwise authorised study commitment in one sitting. |
| **Entry conditions** | Lawful session start under Daily Coach (or other authorised) warrant; Active plan context supports the sitting; session anatomy is live. |
| **Exit conditions** | Session ends (complete, abandon, or interrupt under published session law); typically succeeds to EST-05 when reflection is warranted, or returns to EST-03 / EST-12. |
| **Observing components** | Workflow Engine; Daily Coach / Session participants; Evidence recorders (as Article IV writers — orthogonal); Recommendation surfaces ( ordinarily defer primary tips mid-sitting unless published exception) |
| **Prohibited interpretations** | Not mastery from time-on-task; not Educational Evidence of understanding from elapsed time alone; not workflow completion of the whole educational journey; not licence to invent tips mid-session; not plan mutation |

---

### EST-05 — Reflection Context

| Aspect | Definition |
|--------|------------|
| **Constitutional meaning** | Constitutional educational context in which **post-sitting reflection / loop-closure** is the live focus — making sense of the sitting for later coaching without minting mastery from reflection theatre. |
| **Entry conditions** | Session has lawfully ended or reflection is otherwise warranted under session / Daily Coach law; reflection question is primary. |
| **Exit conditions** | Reflection concludes or is deferred; context returns to EST-03 / EST-12 or hands to EST-06…EST-09 when reflection surfaces a superseding warrant. |
| **Observing components** | Workflow Engine; Daily Coach / Reflection participants; Learning Coach (as consumer of reflection meaning); Evidence pipeline (when observations are lawfully recorded) |
| **Prohibited interpretations** | Not Estimated Mastery from self-confidence alone; not Study Progress write by reflection UI alone; not educational success certificate; not independent Programme VII recommendation engine; not erasure of prior session context history |

---

### EST-06 — Learning Progression Context

| Aspect | Definition |
|--------|------------|
| **Constitutional meaning** | Constitutional educational context in which the **Learning Coach question** — whether the student is genuinely learning over time, why not, and what learning response is warranted — is constitutive. |
| **Entry conditions** | Longitudinal progression, obstacle, or intervention question is primary under Learning Coach warrant; Active plan ordinarily present; not collapsed into day-only coaching. |
| **Exit conditions** | Learning Coach question concludes, defers, or hands off; day / recovery / revision / exam / structural contexts may succeed when their warrants become primary. |
| **Observing components** | Workflow Engine; Learning Coach; Daily Coach (sibling input); Recommendation Engine; Authority Model (Learning Coach domain) |
| **Prohibited interpretations** | Not redefinition of Estimated Knowledge / Mastery; not “intervention recommended ⇒ mastery gap proven beyond Evidence law”; not Daily Coach absorption; not workflow completion; not educational success |

---

### EST-07 — Recovery Context

| Aspect | Definition |
|--------|------------|
| **Constitutional meaning** | Constitutional educational context in which the **Recovery Coach question** — how the student should recover educationally after meaningful disruption — is constitutive. |
| **Entry conditions** | Meaningful disruption warrant is primary under Recovery Coach law; recovery — not mere revision theatre — is the live restorative focus. |
| **Exit conditions** | Recovery concludes, defers, or hands off under Recovery Completion / pathway law; ordinary day priority or other warrants may resume; Continuity Holding may follow. |
| **Observing components** | Workflow Engine; Recovery Coach; Daily / Revision / Exam as non-primary siblings when lawful; Recommendation Engine; Authority Model (Recovery domain) |
| **Prohibited interpretations** | Not “in recovery ⇒ student failed”; not mastery loss declared by context label alone; not silent plan rewrite; not revision substitute for recovery honesty; not workflow completion; not educational success when recovery context ends |

---

### EST-08 — Revision Context

| Aspect | Definition |
|--------|------------|
| **Constitutional meaning** | Constitutional educational context in which the **Revision Coach question** — what previously learned material should be revised now, and why — is constitutive. |
| **Entry conditions** | Revision warrant is primary under Revision Coach law; consolidating *previously learned* material is the live focus (not first learning disguised as revision). |
| **Exit conditions** | Revision concludes, defers, or hands off under Revision Completion / strategy law; other primary warrants may succeed. |
| **Observing components** | Workflow Engine; Revision Coach; Daily / Learning as sibling inputs; Recommendation Engine; Authority Model (Revision domain) |
| **Prohibited interpretations** | Not first-learning substitute; not mastery from revision checklist alone; not recovery by another name; not Study Progress auto-complete; not educational success; not workflow completion |

---

### EST-09 — Examination Context

| Aspect | Definition |
|--------|------------|
| **Constitutional meaning** | Constitutional educational context in which the **Exam Coach question** — how the learner should prepare for and approach the examination — is constitutive. |
| **Entry conditions** | Examination-facing preparation warrant is primary under Exam Coach law; not calendar proximity alone without constitutional warrant. |
| **Exit conditions** | Exam-facing question concludes, defers, or hands off under Exam Completion / strategy law; other primary warrants may succeed. |
| **Observing components** | Workflow Engine; Exam Coach; Daily / Revision / Recovery as sibling inputs when lawful; Recommendation Engine; Authority Model (Exam domain) |
| **Prohibited interpretations** | Not “exam mode from calendar alone”; not pass prediction; not mastery certificate; not plan rewrite by deadline anxiety; not educational success; not workflow completion of preparation journey |

---

### EST-10 — Conflict Disposition Context

| Aspect | Definition |
|--------|------------|
| **Constitutional meaning** | Constitutional educational context in which **multiple constitutionally valid recommendations coexist** and Conflict Resolution (WS2 / MS002) disposition is awaited or freshly applied — context that concurrency is live, not a new coach meaning. |
| **Entry conditions** | Concurrent valid recommendation set recognised under Conflict Resolution law; disposition pending or just recorded for narration; primary acted-upon tip not yet communicated as settled student focus, or disposition speech is the live coordination focus. |
| **Exit conditions** | Lawful RO disposition applied and primary educational focus context (EST-03…EST-09 / EST-02 / EST-11 / EST-12) resumes; or concurrency clears. |
| **Observing components** | Conflict Resolution Framework; Workflow Engine; Authority Decision Explainability; Recommendation Assembly; Authority Model |
| **Prohibited interpretations** | Not ownership transfer; not ranking inventing a mega-coach; not Educational Evidence rewrite; not “conflict ⇒ student error”; not mastery claim; not workflow completion |

---

### EST-11 — Escalation Await Context

| Aspect | Definition |
|--------|------------|
| **Constitutional meaning** | Constitutional educational context in which **orchestration awaits structural escalation or ownership resolution** — honest parking when no Programme VI coach envelope can lawfully answer within bounds. |
| **Entry conditions** | Workflow authorises escalate / await outcome; structural or ownership question exceeds current coach envelope; tip invention is refused. |
| **Exit conditions** | Escalation target concludes (often via EST-02 or rightful owner), refuse remains, or a new primary warrant lawfully supersedes. |
| **Observing components** | Workflow Engine (Completion / Transitions); Master Planner pathways; Authority Model; Recommendation surfaces (honest deferral / no-recommendation) |
| **Prohibited interpretations** | Not product outage theatre as educational meaning; not licence for independent Programme VII tips while awaiting; not student failure; not mastery; not workflow completion of the educational concern |

---

### EST-12 — Continuity Holding Context

| Aspect | Definition |
|--------|------------|
| **Constitutional meaning** | Constitutional educational context in which an **Active-class Canonical Study Plan exists**, yet **no primary educational question is live** — continuity is preserved until the next lawful warrant. |
| **Entry conditions** | Active plan present; no primary day / learning / recovery / revision / exam / structural / conflict / escalation warrant currently constitutive; or prior primary context has exited without an immediate successor warrant. |
| **Exit conditions** | A classified educational event / warrant makes another EST type primary; or plan becomes absent (EST-01). |
| **Observing components** | Workflow Engine (idle / resume recognition); Continuity Standard consumers; Recommendation surfaces (may prefer no tip); Analytics (observational only) |
| **Prohibited interpretations** | Not student inactivity-as-failure; not mastery plateau claim; not “holding ⇒ workflow completed”; not erasure of prior educational history; not invented motivational tip as substitute for context honesty |

## 5. Parallel-Read Pattern (Non-Primary)

Sibling contexts may be **observed as read-only inputs** to a primary EST type without becoming a second primary:

| Pattern | Lawful example | Unlawful example |
|---------|----------------|------------------|
| Day primary + revision signal as input | EST-03 primary; Revision Coach artefact consumed read-only | Silent merge into “revise today” mega-context without warrant |
| Recovery primary + day plan as constraint | EST-07 primary; Canonical Study Plan consumed, not rewritten | Day Coach absorbing recovery ownership |
| Exam primary + revision list as input | EST-09 primary; revision priorities as inputs | Calendar forcing EST-09 without Exam Coach warrant |

Parallel-read never creates dual-primary student focus theatre.

---

## 7. Binding Summary

Only **EST-01…EST-12** are recognised constitutional educational states under Programme VII Workstream 4 / MS001. Each answers a context question with published entry, exit, observers, and prohibited interpretations. None redefine Programme VI educational meaning, and none may be read as educational success, learner mastery, or workflow completion.
