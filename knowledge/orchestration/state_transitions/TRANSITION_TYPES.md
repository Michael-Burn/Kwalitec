## 1. Purpose

An expert tutor recognises distinct *changes of focus*: opening a sitting under today’s priority, returning from reflection, entering recovery after disruption, leaving recovery for ordinary day focus, waiting while concurrent tips are dispositioned, holding continuity when no question is live, or acknowledging that no Study Plan is active.

These CST types bind Educational State Engine vocabulary so contextual succession remains auditable and independent of educational meaning, workflow execution, and authority ownership.

---

## 2. Catalogue Principles

1. **Representation only.** A transition updates EST context; it does not answer a coach question, run a workflow, transfer ownership, or mint a tip.
2. **Published only.** Only CST-01…CST-13 are constitutional contextual transitions under this Framework.
3. **EST-faithful.** Origin and destination respect MS001 EST-01…EST-12 and parallel-read patterns.
4. **Meaning non-redefinition.** Purpose cites Programme VI and WS1/WS2 *facts*; it never rewrites coach questions.
5. **Non-success / non-mastery / non-completion.** Every type carries prohibited interpretations that block evaluative and executory overclaim.
6. **Deterministic classification.** The same origin + same lawful situation maps to the same CST kind.
7. **Absence is speakable.** “No transition warranted” (remain in current primary) is lawful when conditions fail (CST-13).
8. **Amend to extend.** New types require amending this catalogue first; new EST destinations require amending MS001 first.

## 4. Transition Type Definitions

### CST-01 — Warranted primary succession

| Aspect | Definition |
|--------|------------|
| **Originating contextual state** | Any primary EST-xx whose MS001 exit conditions are satisfied (or documented supersede path applies) |
| **Destination contextual state** | Any distinct primary EST-yy whose MS001 entry conditions are satisfied |
| **Constitutional purpose** | Name the general lawful act of updating primary constitutional context when prior exit and successor entry warrants both hold — the default succession class when a more specialised CST does not apply |
| **Prohibited interpretations** | Not educational success; not learner mastery; not workflow completion; not authority transfer; not recommendation creation; not Programme VI meaning rewrite; not Article IV mutation; not licence to invent undocumented EST types |

**Typical examples (illustrative, not exhaustive):** EST-06 → EST-03; EST-08 → EST-12; EST-02 → EST-03 when structural work concludes and day warrant leads.

---

### CST-02 — Nested context open

| Aspect | Definition |
|--------|------------|
| **Originating contextual state** | Typically **EST-03** Day Priority Context (or other authorised parent warrant that lawfully nests a sitting) |
| **Destination contextual state** | **EST-04** Session Context, or **EST-05** Reflection Context when reflection opens as primary without a concurrent session |
| **Constitutional purpose** | Represent that an authorised sitting or reflection has become the constitutive educational focus *nested under* an ongoing day (or otherwise authorised) parent warrant — without claiming the day’s educational question is finished |
| **Prohibited interpretations** | Not “session started ⇒ mastery”; not “reflection opened ⇒ understanding proven”; not workflow completion of the educational journey; not tip invention mid-sitting; not plan mutation; not Daily Coach ownership transfer to State Engine |

---

### CST-03 — Nested context return

| Aspect | Definition |
|--------|------------|
| **Originating contextual state** | **EST-04** Session Context and/or **EST-05** Reflection Context |
| **Destination contextual state** | **EST-03** Day Priority Context, **EST-12** Continuity Holding Context, or another primary EST when a superseding warrant leads |
| **Constitutional purpose** | Represent lawful return from nested sitting / reflection focus to the parent educational question or to honest holding — preserving that a sitting occurred without claiming success |
| **Prohibited interpretations** | Not “session ended ⇒ mission mastered”; not “reflection done ⇒ Estimated Mastery”; not Study Progress write; not workflow completion certificate; not erasure of session / reflection context history |

---

### CST-04 — Absent-plan enter

| Aspect | Definition |
|--------|------------|
| **Originating contextual state** | Any primary EST that depended on an Active-class Canonical Study Plan, or Continuity Holding under a plan that has ended |
| **Destination contextual state** | **EST-01** Absent Plan Context |
| **Constitutional purpose** | Represent honestly that no Active-class Canonical Study Plan remains as the binding preparation contract — so day-coach and coach-posture focus wait on structural planning |
| **Prohibited interpretations** | Not student failure; not lack of mastery; not workflow completion; not licence for independent Programme VII tips; not Study Progress erasure; not Exam Context by calendar alone |

---

### CST-05 — Plan-contract succession

| Aspect | Definition |
|--------|------------|
| **Originating contextual state** | **EST-01** Absent Plan Context |
| **Destination contextual state** | **EST-02** Structural Planning Context (if structural work continues), **EST-03** Day Priority Context, or **EST-12** Continuity Holding Context — as warrants dictate |
| **Constitutional purpose** | Represent that an Active-class Canonical Study Plan has been lawfully published / activated and primary context may leave absence for structural, day, or holding posture |
| **Prohibited interpretations** | Not “plan published ⇒ student understands syllabus”; not mastery minting from wizard completion; not day-coaching by another name while structural work is still primary; not silent absorption of coach domains; not workflow completion of preparation |

---

### CST-06 — Structural focus open / close

| Aspect | Definition |
|--------|------------|
| **Originating contextual state** | **Open:** any primary EST superseded by structural warrant (often EST-03, EST-11, EST-12, EST-01). **Close:** **EST-02** Structural Planning Context |
| **Destination contextual state** | **Open:** **EST-02**. **Close:** EST-03 / EST-07 / EST-11 / EST-12 / EST-01 as successor warrants dictate |
| **Constitutional purpose** | Represent when Master Planner / structural design, reschedule, or replan is (or ceases to be) the live educational focus — without the State Engine rewriting the Canonical Study Plan |
| **Prohibited interpretations** | Not plan mutation by CST label; not day-coaching substitute; not mastery from structural UI completion; not ownership transfer of AD planning domain to State Engine; not educational success |

---

### CST-07 — Coach-focus succession

| Aspect | Definition |
|--------|------------|
| **Originating contextual state** | Primary among **EST-03**, **EST-06**, **EST-07**, **EST-08**, **EST-09** |
| **Destination contextual state** | A different primary among **EST-03**, **EST-06**, **EST-07**, **EST-08**, **EST-09** |
| **Constitutional purpose** | Represent change of constitutive Programme VI coach question (today / learning progression / recovery / revision / examination) when warrants change primary focus — without blending coaches or inventing mega-context |
| **Prohibited interpretations** | Not “left recovery ⇒ recovery succeeded”; not “entered exam context ⇒ pass prediction”; not revision as first-learning disguise; not mastery gap proven beyond Evidence law; not authority transfer among coach domains; not tip creation; not workflow execution |

**Typical examples:** EST-03 → EST-07 on disruption warrant; EST-07 → EST-03 when recovery concludes and day warrant resumes; EST-03 → EST-08 when revision warrant becomes primary; EST-08 → EST-09 when exam-facing warrant becomes primary.

---

### CST-08 — Conflict-await enter

| Aspect | Definition |
|--------|------------|
| **Originating contextual state** | Typically a coach-focus or structural primary (EST-02…EST-09) where concurrent valid recommendations become constitutive for coordination narration |
| **Destination contextual state** | **EST-10** Conflict Disposition Context |
| **Constitutional purpose** | Represent that multiple constitutionally valid recommendations coexist and Conflict Resolution disposition is awaited or freshly the live coordination focus — context that concurrency is live, not a new coach meaning |
| **Prohibited interpretations** | Not ownership transfer; not ranking inventing a mega-coach; not Educational Evidence rewrite; not “conflict ⇒ student error”; not mastery claim; not workflow completion; not tip invention by State Engine |

---

### CST-09 — Conflict-await exit

| Aspect | Definition |
|--------|------------|
| **Originating contextual state** | **EST-10** Conflict Disposition Context |
| **Destination contextual state** | Resumed primary among EST-02…EST-09, EST-11, or EST-12 as disposition and warrants dictate |
| **Constitutional purpose** | Represent that lawful RO disposition has been applied (or concurrency cleared) and ordinary educational focus context may resume — without the State Engine performing disposition |
| **Prohibited interpretations** | Not “conflict resolved by state transition”; not State Engine ranking; not tip creation; not mastery; not educational success; not authority absorption |

---

### CST-10 — Escalation-await enter

| Aspect | Definition |
|--------|------------|
| **Originating contextual state** | Any primary EST where orchestration authorises escalate / await and no Programme VI coach envelope can lawfully answer within bounds |
| **Destination contextual state** | **EST-11** Escalation Await Context |
| **Constitutional purpose** | Represent honest parking while structural escalation or ownership resolution is awaited — without inventing tips to fill the wait |
| **Prohibited interpretations** | Not product outage theatre as educational meaning; not licence for independent Programme VII tips while awaiting; not student failure; not mastery; not workflow completion of the educational concern; not silent plan rewrite |

---

### CST-11 — Escalation-await exit

| Aspect | Definition |
|--------|------------|
| **Originating contextual state** | **EST-11** Escalation Await Context |
| **Destination contextual state** | Often **EST-02** (structural), or rightful coach primary / EST-12 / EST-01 when warrants dictate |
| **Constitutional purpose** | Represent that escalation target has concluded, refuse remains speakable, or a new primary warrant lawfully supersedes — updating context only |
| **Prohibited interpretations** | Not “await ended ⇒ educational success”; not tip minting; not ownership transfer via CST; not workflow execution by State Engine; not mastery |

---

### CST-12 — Continuity hold enter / exit

| Aspect | Definition |
|--------|------------|
| **Originating contextual state** | **Enter:** any primary EST whose warrant has exited without an immediate successor primary. **Exit:** **EST-12** Continuity Holding Context |
| **Destination contextual state** | **Enter:** **EST-12**. **Exit:** any warranted primary EST-01…EST-11 |
| **Constitutional purpose** | Represent lawful Continuity Holding when an Active plan exists but no primary educational question is live — or lawful exit when a classified warrant makes another EST primary — preserving continuity as care, not emptiness |
| **Prohibited interpretations** | Not student inactivity-as-failure; not mastery plateau; not “holding ⇒ workflow completed”; not erasure of prior educational history; not invented motivational tip as substitute for context honesty |

---

### CST-13 — Refuse / remain

| Aspect | Definition |
|--------|------------|
| **Originating contextual state** | Current primary EST-xx (unchanged) |
| **Destination contextual state** | Same primary EST-xx (no succession) |
| **Constitutional purpose** | Record constitutionally that proposed contextual succession is **not** warranted — conditions failed, EST entry/exit unmet, or boundary hard stop applies — so product pressure cannot invent a successor focus |
| **Prohibited interpretations** | Not a silent “soft transition”; not student failure; not mastery claim; not licence to invent undocumented modes; not workflow stuck-as-educational-meaning |

## 5. Parallel-Read Updates (Non-Transition of Primary)

Updating **parallel-read** sibling observations without changing the primary EST is **not** a separate CST catalogue entry. It is governed by MS001 parallel-read patterns and must:

- leave primary EST unchanged;
- never create dual-primary student focus theatre;
- never be narrated as CST-01…CST-12 succession;
- remain explainable as “additional input observed,” not “focus changed.”

If a sibling warrant becomes *primary*, classify under CST-01 or CST-07 (or specialised CST-08…CST-12) — never as a silent merge.

---

## 6. Relationship to Workflow Transitions (Non-Identity)

| CST concern | WT concern |
|-------------|------------|
| Updates EST context representation | Moves WS1 stages / postures |
| May *reference* lawful WT progression or completion as condition evidence | May *observe* EST context when coordinating |
| Never executes WT-xx | Never invents EST types |

A single educational situation may involve **both** a WT move and a CST move. They remain distinct constitutional acts with distinct IDs, conditions, and explainability chains.

---

## 7. Binding Summary

Only **CST-01…CST-13** are recognised constitutional educational state transition types under Programme VII Workstream 4 / MS002. Each names originating and destination contextual states (or refuse/remain), a constitutional purpose limited to representation, and prohibited interpretations that block success, mastery, workflow completion, authority transfer, tip creation, meaning rewrite, and workflow execution. None redefine Programme VI educational meaning.
