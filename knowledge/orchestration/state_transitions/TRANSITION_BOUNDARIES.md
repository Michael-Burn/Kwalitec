> **Educational state transitions may  
> update constitutional context,  
> reference workflow completion where appropriate,  
> and preserve contextual continuity.  
> They must not  
> redefine educational meaning,  
> imply learner success or mastery,  
> modify authority ownership,  
> create recommendations,  
> or execute educational workflows.**

---

## 1. Purpose

A contextual transition that quietly becomes a tutor — rewriting meaning, minting tips, transferring ownership, running workflows, or implying mastery “because focus changed” — destroys constitutional layering and student trust.

This document draws a bright line between **lawful context representation updates** (Programme VII Workstream 4 / MS002) and **educational meaning / ownership / orchestration execution / recommendations / mutation** (Programme VI + WS1 + WS2 + WS3 + EIP).

---

## 2. Boundary Principles

1. **Update representation, do not educate by substitute.** Transitions change EST posture; Programme VI answers educational questions.
2. **Reference flow, do not execute flow.** Lawful WS1 progression / completion may be cited; CST never runs WT stages.
3. **Preserve ownership.** Naming a new primary EST never transfers Recovery, Daily, Exam, or plan domains.
4. **Preserve meaning.** Succession never redefines coach questions or Article IV objects.
5. **No success / mastery theatre.** Evaluative readings are forbidden interpretations, not features.
6. **No tip minting.** Recommendations remain WS3 / Programme VI.
7. **Continuity over amnesia.** Prior context remains speakable (EIP-005).
8. **MS001 boundaries inherited.** SB-01…SB-10 remain binding during every transition.
9. **Conditions over convenience.** Failed conditions ⇒ CST-13 remain / refuse — not force-succession.
10. **Explain the limit.** Students and developers should hear when context speech stops and another authority must act.

---

## 3. What Educational State Transitions May Do (Lawful)

| Lawful action | Educational meaning |
|---------------|---------------------|
| **Update constitutional context** | Change primary (or parallel-read) EST-xx when CST conditions hold |
| **Reference workflow progression / completion** | Cite published WS1 facts as *permitting evidence* without executing them |
| **Preserve contextual continuity** | Succeed context without erasing prior focus history; prefer honest holding |
| **Refuse invented succession** | Apply CST-13 when warrants fail |
| **Support explainability** | Make why, warrants, published rules, and continuity speakable |
| **Distinguish Article IV objects** | Situate speech that mentions Study Progress / Evidence without becoming those states |
| **Observe authority / disposition facts** | Consume WS2 ownership and RO disposition as condition inputs without performing them |

These actions **update and narrate context representation**. They do **not** publish tips, rewrite evidence, transfer domains, redefine coach meaning, or execute study / workflow actions.

---

## 4. What Educational State Transitions Must NOT Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Redefine educational meaning** | Programme VI owns coach / planner questions | Cite Programme VI warrants; never rewrite them via CST |
| **Imply learner success** | Success is not a contextual succession meaning | Narrate focus change honestly; refuse success theatre |
| **Imply learner mastery** | EIP-006 / Twin / Evidence authorities | Leave mastery / knowledge estimates to lawful writers |
| **Modify authority ownership** | WS2 owns the ownership map | Observe owners; never move domains via CST labels |
| **Create recommendations** | WS3 owns recommendation artefacts; Programme VI owns meaning | Reference post-transition context for assembly; leave tip creation to rightful owners |
| **Execute educational workflows** | WS1 owns stages, transitions, and completion | Reference lawful progression / completion; do not advance WT stages |
| **Claim workflow completion** | WS1 Completion Model | Cite completion facts only as condition evidence; do not *be* completion |
| **Mutate Article IV states** | EIP-001 Permitted Writers | Context succession never writes Study Progress / Evidence / estimates |
| **Modify the Canonical Study Plan** | Master Planner / Scheduling | Escalate structural questions; do not “transition” a new plan |
| **Redefine Educational Evidence** | EIP-002 + permitted writers | Cite context warrants; never relabel coverage/time/confidence as understanding |
| **Invent undocumented EST or CST types** | Catalogue closure | Amend MS001 / this Framework first — or refuse (CST-13) |
| **Silent dual-primary theatre** | Single primary context principle | One primary EST; siblings as parallel-read only |
| **Erase educational history via mode refresh** | EIP-005 Continuity | Succeed context; do not delete learner history |
| **Replace workflow transitions** | WS1 MS002 supremacy for WT-xx | Keep CST and WT as distinct acts |

## 5. Boundary IDs (Hard Stops)

| ID | Prohibition |
|----|-------------|
| **STB-01** | Redefine Programme VI educational meaning via contextual succession |
| **STB-02** | Interpret any CST as educational success |
| **STB-03** | Interpret any CST as learner mastery / Estimated Mastery |
| **STB-04** | Modify, transfer, absorb, or invent Authority Model domains via CST |
| **STB-05** | Create, rank, or assemble educational recommendations from succession |
| **STB-06** | Execute educational workflows, advance WT stages, or run educational actions via CST |
| **STB-07** | Interpret any CST as workflow completion (even when completion is cited as condition evidence) |
| **STB-08** | Mutate Article IV educational states or the Canonical Study Plan by succession |
| **STB-09** | Redefine or reinterpret Educational Evidence under a transition label |
| **STB-10** | Publish undocumented EST/CST types or force succession when conditions fail |

MS001 **SB-01…SB-10** remain concurrently binding. STB-xx specialises succession-time hard stops; they do not weaken SB-xx.

## 9. Binding Rule

If a proposed Educational State Transition behaviour would require redefining educational meaning, implying success or mastery, modifying authority ownership, creating recommendations, executing workflows, or reading CST labels as workflow completion — **refuse** (CST-13). Amend the rightful constitutional corpus first if the law must change. Contextual transitions never gain power by renaming themselves “the state engine.”
