## Authority

This document is the constitutional overview of the **Recommendation Assembly Framework** for Kwalitec.

It is subordinate to the Educational Constitution, specialised Programme VI educational models, Programme VII Workstreams 1–2, and the Educational Recommendation Model (WS3 / MS001). It governs **how constitutionally valid educational recommendations are organised into a coherent recommendation set**. It does not authorise implementation shortcuts that contradict the Constitution, and it does not invent educational meaning, alter ownership, resolve conflicts, or execute workflows.

Authority order for recommendation assembly:

> Constitution defines educational truth and curriculum primacy.  
> Knowledge & Mastery defines coverage ≠ understanding ≠ mastery.  
> Evidence Model defines what may warrant educational claims.  
> Continuity Standard preserves rightful educational history.  
> State Authority Matrix defines who may mutate educational states.  
> Programme VI (Master Planner and coaches) defines educational reasoning and may emit authorised guidance.  
> Programme VII Workstream 1 defines how that reasoning is orchestrated across components.  
> Programme VII Workstream 2 defines who owns decisions, how valid recommendations compete for action, and how permission is explained.  
> Educational Recommendation Model (WS3 / MS001) defines what a constitutional educational recommendation is.  
> **This Recommendation Assembly Framework (Programme VII / Workstream 3 / MS002) defines how lawful recommendations are assembled into a coherent recommendation set.**  
> Downstream Runtime A, product surfaces, and narration must consume this assembly law — never invent tips, re-rank conflicts, or silently merge meanings while packaging a set.

## 1. Purpose

Kwalitec coaches students preparing for demanding professional examinations (especially IFoA syllabi such as CM1/CS1 and peers).

An expert IFoA tutor does not invent a new tip when several lawful pieces of advice already exist. After Programme VI has defined *what each educational question means*, after Workstream 1 has defined *how reasoning flows*, after Workstream 2 has defined *who owns decisions and how concurrent valid guidance is dispositioned*, and after Workstream 3 / MS001 has defined *what a constitutional recommendation is*, the tutor still needs one organisation answer:

> **“How are constitutionally valid recommendations combined into a single coherent educational recommendation set?”**

That answer must organise lawful recommendations, preserve ownership and provenance, maintain internal consistency, and remain explainable — without creating educational meaning, altering constitutional authority, resolving conflicts already governed by Workstream 2, or executing workflows.

This document records that tutor posture so every future Educational Recommendation Engine subsystem has a single educational reference for *how recommendation sets are assembled and are not*.

> **The Recommendation Assembly Framework describes organisation of lawful recommendations.  
> It does not create educational meaning, alter ownership, resolve conflicts, or implement Runtime A.**

## 2. What Recommendation Assembly Is

**Recommendation assembly** is the constitutional act by which Kwalitec **organises one or more already-valid constitutional educational recommendations** into a **coherent recommendation set** — carrying contributing sources, ownership references, workflow context, conflict disposition references, and supporting evidence references — without inventing tips, rewriting ownership, redefining meaning, re-resolving conflicts, or performing orchestration.

| Concept | Definition | Primary question |
|---------|------------|------------------|
| **Recommendation set** | The organised collection of lawful recommendation artefacts presented as one coherent educational package | What belongs together? |
| **Constituent recommendation** | A single constitutional educational recommendation satisfying WS3 / MS001 | Which artefacts are inputs? |
| **Assembly** | Organisation of constituents under published components and boundaries | How are they combined? |
| **Provenance preservation** | Faithful retention of each constituent’s sources, owner, evidence, and constitutional refs | Did packaging erase history? |
| **Internal consistency** | Set-level honesty: no dual primary without disposition, no silent contradiction of RO outcomes, no orphan constituents | Does the set cohere? |
| **Assembly validity** | Satisfaction of objectives, components, boundaries, and explainability in this corpus | Is this a lawful set or unlawful packaging? |

Recommendation assembly is:

- **organisational** — it arranges already-authorised artefacts;
- **ownership-preserving** — each constituent keeps its constitutional owner;
- **provenance-preserving** — sources and constitutional references survive packaging;
- **meaning-preserving** — Programme VI educational meanings are unchanged by organisation itself;
- **disposition-respecting** — Conflict Resolution outcomes are referenced, never re-decided;
- **non-executing** — assembly does not run workflows, write states, or pack calendars;
- **non-inventing** — assembly does not mint tips, scores, or mega-coach compromises;
- **explainable** — students and developers can see why recommendations appear together and how provenance was preserved;
- **honest about emptiness** — an empty or single-member set remains lawful when only that many valid artefacts exist.

Recommendation assembly is **not**:

- a second Daily Coach, Learning Coach, Recovery Coach, Revision Coach, Exam Coach, or Master Planner;
- reinterpretation of Educational Evidence under an “assembled tip” label;
- transfer or absorption of constitutional ownership;
- Conflict Resolution, ranking, or scoring among competing tips;
- workflow execution, stage advancement, or Authority Model amendment;
- a UI feed, notification batch, API schema, or analytics event;
- a claim that viewing the set guarantees learning or a pass.

## 3. Binding Distinction: Assembly vs Neighbours

| Layer | Educational / coordination job | Unlawful collapse |
|-------|--------------------------------|-------------------|
| **Programme VI meaning** | What a recommendation *means* and why it is warranted | Letting assembly rewrite coach meaning |
| **Authority ownership (WS2 / MS001)** | Who may *decide* a class | Letting assembly transfer or invent owners |
| **Workflow orchestration (WS1)** | How owners are *invited and sequenced* | Letting assembly invent stages or tips |
| **Conflict resolution (WS2 / MS002)** | Which *valid* recommendation is *acted upon* when several coexist | Letting assembly re-resolve or rank winners |
| **Single recommendation artefact (WS3 / MS001)** | What one constitutional tip *is* | Treating incomplete tips as set members |
| **Recommendation assembly (this Framework)** | How lawful tips form one *coherent set* | Treating set packaging as meaning creation or conflict law |
| **State mutation (EIP-001)** | Who may *write* educational states | Treating assembly as write authority |
| **Product presentation** | How sets are *shown* | Letting UI invent set members or hide disposition |

**MS001 without MS002** risks clear single artefacts with no lawful story for multi-recommendation packaging.  
**MS002 without MS001** risks packaging tips that are not yet constitutional artefacts.  
**MS002 without WS2 / MS002** risks organising concurrent tips without lawful disposition — inviting silent dual primary.  
All are required; none replaces Programme VI meaning.

## 4. Educational Purpose

The Recommendation Assembly Framework exists so that:

1. **Lawful recommendations can appear together** — the student receives a coherent set rather than scattered fragments or an invented mega-tip.
2. **Ownership survives packaging** — organising tips never silently absorbs a sibling domain under “the recommendation set.”
3. **Provenance survives packaging** — each constituent’s sources, evidence, and constitutional references remain reconstructable.
4. **Consistency remains honest** — acted-upon vs deferred / queued / superseded members are organised without contradiction of Conflict Resolution.
5. **Explainability scales to the set** — why recommendations appear together, how they relate, which sources contributed, and how provenance was preserved remain answerable.
6. **Product pressure cannot invent law** — ranking scores, engagement batches, and UI convenience never become assembly authority.

The Recommendation Assembly Framework is educationally responsible for:

The Recommendation Assembly Framework must **not**:

- redefine Programme VI educational meaning or coach questions;
- invent workflow stages, transition conditions, or completion criteria;
- amend Authority Model domains or Conflict Resolution CT/RP/RO catalogues by fiat;
- grant or invent EIP-001 mutation rights;
- implement ranking, scoring, personalisation mathematics, or Runtime A services;
- select Educational Strategy, pack calendars, or mint mastery from set packaging;
- absorb ownership of Educational Evidence, Estimated Knowledge, or Estimated Mastery under an “assembly engine” label;
- treat Version 2 Adaptive / Twin / Mission authorities as replacements for Programme VI / VII assembly law;
- silently merge competing coach meanings into a third mega-recommendation without a published constitutional merge pathway (WS2 / MS002 RO-03);
- re-resolve concurrency already dispositioned by Conflict Resolution.

## 8. Integrity Rules

1. **Organise, do not create.** Assembly arranges authorised recommendations; it does not invent educational meaning.
2. **Constituents first.** Only WS3 / MS001-complete artefacts may enter a set as recommendations.
3. **Ownership intact.** Packaging never transfers, invents, or absorbs constitutional owners.
4. **Provenance intact.** Each constituent’s sources, evidence honesty, and constitutional refs remain reconstructable.
5. **Disposition untouched.** When concurrency exists, disposition remains WS2 / MS002; assembly references RO outcomes — it does not invent ranking.
6. **Consistency over convenience.** A set must not present dual primary or mute material deferred siblings.
7. **Context is not meaning.** Workflow, authority, and conflict references situate the set; they do not replace Programme VI reasoning.
8. **Structure before speech.** Incomplete sets must not be presented as constitutional recommendation sets.
9. **Boundaries over packaging.** Product pressure to “batch more tips” never overrides `ASSEMBLY_BOUNDARIES.md`.
10. **Explain or refuse.** Material sets must satisfy `ASSEMBLY_EXPLAINABILITY.md` or must not ship as constitutional.
11. **Amend before invent.** Missing objective, component, or lawful input → amend this corpus (or Programme VI / VII siblings) — do not invent in Runtime A.

## 12. Closing

Recommendation assembly is how Kwalitec *organises* lawful tutor guidance into coherent sets — not how it *invents* a tutor, *re-ranks* coaches, or *resolves* conflicts.

When a set would lack lawful constituents, **refuse or show an honest empty/single set**.  
When packaging would need rewriting ownership or meaning to “make the set work,” **amend the owning corpora** — do not assemble by reinterpretation.  
When concurrency arises, **apply Conflict Resolution first** — then assemble dispositioned artefacts.  
When the set is complete and lawful, **organise and explain**.

> **Assembly organises constitutional recommendations.  
> It never creates educational meaning.**
