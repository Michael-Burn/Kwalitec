## 1. Purpose

Assembly that silently becomes a second tutor — inventing tips, absorbing ownership, redefining meaning, re-resolving conflicts, or skipping orchestration — destroys constitutional layering and student trust.

This document draws a bright line between **lawful organisation** (Programme VII Workstream 3 / MS002) and **educational meaning / ownership / conflict disposition / orchestration / mutation / single-artefact law** (Programme VI + WS1 + WS2 + EIP + WS3 / MS001).

---

## 2. Boundary Principles

1. **Organise, do not create.** Assembly arranges authorised recommendations; it does not mint educational meaning or tips.
2. **Preserve ownership.** Constitutional owners remain owners; packaging never transfers domains.
3. **Preserve provenance.** Sources, evidence honesty, and constitutional references survive the set.
4. **Meaning non-redefinition.** Programme VI educational questions and meanings are unchanged by organisation.
5. **No conflict re-resolution.** Concurrent valid tips are dispositioned by WS2 / MS002 — not by assembly ranking.
6. **No workflow bypass.** Student-facing primary sets follow lawful orchestration / authority invitation; assembly does not skip stages by fiat.
7. **Constituents first.** Incomplete MS001 artefacts are not set members.
8. **Plan non-mutation.** Canonical Study Plan remains Master Planner / Scheduling contract.
9. **State Matrix supremacy.** Assembly never gains mutation rights by renaming itself.
10. **Explain the limit.** Students and developers should hear when set packaging stops and another authority must act.

---

## 3. What Assembly May Do (Lawful)

| Lawful action | Educational meaning |
|---------------|---------------------|
| **Organise recommendations** | Collect and structure WS3 / MS001-complete artefacts into a coherent set (including empty / single-member sets) |
| **Reference constitutional context** | Attach workflow, authority, and conflict-disposition references that situate the set |
| **Preserve provenance** | Retain and index sources, ownership, evidence, and constitutional refs for each constituent |
| **Maintain set consistency** | Reflect RO dispositions honestly; prevent dual-primary theatre |
| **Support learner orientation** | Clarify how members relate (primary vs waiting) without coercion |
| **Refuse invented members** | Prefer empty / incomplete packaging refusal over fabricated tips |
| **Explain the set** | Answer why together / relations / sources / provenance (`ASSEMBLY_EXPLAINABILITY.md`) |

These actions **organise**. They do **not** publish a new Study Plan, mint mastery, reinterpret evidence, execute workflows, resolve conflicts, or replace any coach.

---

## 4. What Assembly Must NOT Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Invent recommendations** | Programme VI owns coach / planner meaning; MS001 owns artefact completeness | Admit only complete constituents; refuse empty invention |
| **Alter recommendation ownership** | Authority Model owns the ownership map | Index owners; never absorb sibling domains under a set owner |
| **Redefine educational meaning** | Programme VI owns educational questions | Organise artefacts as authored; do not rewrite guidance while packaging |
| **Resolve conflicts already governed by WS2** | Conflict Resolution owns disposition among valid peers | Reference RO outcomes; do not score or re-arbitrate |
| **Bypass constitutional workflows** | WS1 owns lawful coordination | Require workflow context for primary student-facing sets; escalate via workflow law |
| **Bypass authority checks** | WS2 owns who may decide | Refuse sets whose members lack lawful owners / permission |
| **Reinterpret Educational Evidence** | Evidence Model + permitted writers own observational truth | Consume evidence as classified; keep claim ladder honest |
| **Modify the Canonical Study Plan** | Plan is Master Planner / Scheduling contract | Escalate structural questions; do not “assemble a new plan” |
| **Silent merge of conflicting coaches** | Meaning preservation + conflict law | Disposition via RO-01…RO-06; merge only via published RO-03 |
| **Execute workflows or mutate states** | Assembly is organisational packaging | Leave execution/mutation to their owners |
| **Use ranking / scoring as educational law** | Product metrics ≠ constitutional disposition | Keep ranking engines out of provenance and out of RO replacement |
| **Claim certainty no constituent claimed** | EIP-003 honesty | Mirror Programme VI / evidence limits |
| **Erase educational history via set refresh** | EIP-005 Continuity | Replace packaging, not learner history |
| **Relax MS001 artefact law** | Constituents must remain constitutional | Incomplete tips stay out of RAC-01 |

## 6. Boundary Tests (Pass / Fail)

| ID | Test | Pass | Fail |
|----|------|------|------|
| **RAB-01** | Non-invention | Set members are MS001-complete (or explicit empty set) | Invents tips / filler members for layout |
| **RAB-02** | Ownership integrity | Each constituent owner matches Authority Model; set index does not absorb | Recommendation Engine / UI claimed as set owner |
| **RAB-03** | Meaning fidelity | Constituent ERC-01 meanings unchanged by packaging | Guidance rewritten to “fit the set” |
| **RAB-04** | Conflict non-resolution | Concurrent tips dispositioned via RO-xx; assembly only references | Ranking / silent average / re-arbitration without RO-03 |
| **RAB-05** | Provenance fidelity | RAC-02 / RAC-06 reconstructable; no undocumented sources | Heuristic / A/B / engagement score as sole provenance |
| **RAB-06** | Structure completeness | S1–S7 satisfied (`ASSEMBLY_COMPONENTS.md`) | Naked tip list shipped as constitutional set |
| **RAB-07** | Workflow non-bypass | Orchestrated primary sets carry RAC-04 | Set shown by skipping invitation / authority stages |
| **RAB-08** | Consistency | No dual primary; dispositions honest | Hidden deferred sibling or contradictory primaries |
| **RAB-09** | Plan non-mutation | Works inside Canonical Study Plan | Assembles plan rewrite as packaging convenience |
| **RAB-10** | Non-execution | Organisation only | Assembly “service” mutates Study Progress / Evidence |
| **RAB-11** | Explainability | RAQ questions answerable | Motivational batch copy without set provenance |

Any **Fail** makes the set educationally unlawful — even if engagement metrics improve.

## 8. Closing

Boundaries keep assembly as organisation, not as a shadow tutor or shadow conflict engine.

When packaging would be easier by inventing members, rewriting ownership, redefining meaning, re-resolving conflicts, or skipping orchestration — **stop**.  
Refuse, escalate, or amend the owning constitutional corpora first.

> **Organise recommendations. Preserve provenance. Never invent educational meaning.**
