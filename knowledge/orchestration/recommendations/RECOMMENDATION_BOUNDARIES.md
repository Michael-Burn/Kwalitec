## 1. Purpose

Recommendations that silently become a second tutor — inventing tips, absorbing ownership, reinterpreting evidence, or skipping orchestration — destroy constitutional layering and student trust.

This document draws a bright line between **lawful communication** (Programme VII Workstream 3) and **educational meaning / ownership / orchestration / mutation authority** (Programme VI + WS1 + WS2 + EIP).

---

## 2. Boundary Principles

1. **Communicate, do not create.** Recommendations surface authorised guidance; they do not mint educational meaning.
2. **Preserve ownership.** Constitutional owners remain owners; packaging never transfers domains.
3. **Evidence non-reinterpretation.** Evidence Model and permitted writers own observational truth.
4. **Documented sources only.** Undocumented provenance is a hard stop (`RECOMMENDATION_SOURCES.md`).
5. **Structure before speech.** Incomplete artefacts must not ship as constitutional recommendations.
6. **No workflow bypass.** Student-facing primary guidance follows lawful orchestration / authority invitation; recommendations do not skip stages by fiat.
7. **No conflict shortcut.** Concurrent valid tips are dispositioned by WS2 / MS002 — not by recommendation ranking.
8. **Plan non-mutation.** Canonical Study Plan remains Master Planner / Scheduling contract.
9. **State Matrix supremacy.** Recommendations never gain mutation rights by renaming themselves.
10. **Explain the limit.** Students and developers should hear when recommendation speech stops and another authority must act.

## 3. What Recommendations May Do (Lawful)

| Lawful action | Educational meaning |
|---------------|---------------------|
| **Communicate constitutional outcomes** | Surface Programme VI guidance, refuse, handoff, or escalate postures as speakable recommendations |
| **Aggregate lawful educational outputs** | Compose ERS/ERC components into one structured artefact without rewriting meanings |
| **Reference authority context** | Name owner, permission, refusal, and delegation bounds from WS2 |
| **Reference workflow context** | Situate guidance with event / participation / outcome class from WS1 |
| **Reference conflict disposition** | Communicate RO-xx outcomes when concurrency was resolved |
| **Support learner decision-making** | Clarify next step, limits, and when to wait — without coercion |
| **Refuse invented tips** | Prefer no-recommendation when warrants fail |
| **Explain the recommendation** | Answer why / contributors / owner / evidence / validity |

These actions **communicate**. They do **not** publish a new Study Plan, mint mastery, reinterpret evidence, execute workflows, or replace any coach.

---

## 4. What Recommendations Must NOT Do

| Forbidden action | Why | Lawful alternative |
|------------------|-----|--------------------|
| **Invent educational meaning** | Programme VI owns coach / planner meaning | Invoke and surface the owning artefact; refuse if none |
| **Alter ownership** | Authority Model owns the ownership map | Name the owner; never absorb sibling domains |
| **Reinterpret Educational Evidence** | Evidence Model + permitted writers own observational truth | Consume evidence as classified; keep claim ladder honest |
| **Bypass constitutional workflows** | WS1 owns lawful coordination | Require orchestration context for primary student-facing guidance; escalate via workflow law |
| **Bypass authority checks** | WS2 owns who may decide | Refuse tips that lack a lawful owner / permission |
| **Invent conflict ranking** | WS2 / MS002 owns disposition among valid peers | Apply RO outcomes; do not score coaches |
| **Modify the Canonical Study Plan** | Plan is Master Planner / Scheduling contract | Escalate structural questions; do not “recommend a new plan” by packaging |
| **Mint Estimated Knowledge / Mastery** | EIP-006 / Twin / Evidence authorities | Leave estimates to permitted writers; speak honestly |
| **Silent merge of conflicting coaches** | Meaning preservation + conflict law | Disposition via RO-01…RO-06; merge only via published RO-03 |
| **Execute workflows or mutate states** | Recommendations are communicative artefacts | Leave execution/mutation to their owners |
| **Use engagement optimisers as educational law** | Product metrics ≠ constitutional sources | Keep metrics out of provenance |
| **Claim certainty the artefact did not claim** | EIP-003 honesty | Mirror Programme VI / evidence limits |
| **Erase educational history via tip refresh** | EIP-005 Continuity | Replace speech, not learner history |

## 6. Boundary Tests (Pass / Fail)

| ID | Test | Pass | Fail |
|----|------|------|------|
| **RB-01** | Meaning creation | Surfaces an existing Programme VI artefact (or lawful refuse) | Invents a tip with no ERS-01 warrant |
| **RB-02** | Ownership integrity | Owner matches Authority Model domain | Recommendation Engine / UI claimed as owner |
| **RB-03** | Evidence honesty | Claim types match EIP-002 / EIP-006 | Coverage spoken as mastery |
| **RB-04** | Source closure | All provenance in ERS catalogue | Undocumented heuristic / A/B winner as sole source |
| **RB-05** | Structure completeness | C1–C7 satisfied (`RECOMMENDATION_STRUCTURE.md`) | Naked slogan shipped as coach advice |
| **RB-06** | Workflow non-bypass | Orchestrated primary guidance carries ERC-04 | Tip shown by skipping invitation / authority stages |
| **RB-07** | Conflict non-shortcut | Concurrent tips dispositioned via RO-xx | Ranking / silent average without RO-03 |
| **RB-08** | Plan non-mutation | Works inside Canonical Study Plan | Recommends plan rewrite as packaging convenience |
| **RB-09** | Non-execution | Communication only | Recommendation “service” mutates Study Progress / Evidence |
| **RB-10** | Explainability | ERQ questions answerable | Motivational copy without provenance |

Any **Fail** makes the tip educationally unlawful — even if engagement metrics improve.

## 8. Closing

Boundaries keep recommendations as speech, not as a shadow tutor.

When packaging would be easier by inventing meaning, rewriting ownership, or skipping orchestration — **stop**.  
Refuse, escalate, or amend the owning constitutional corpora first.

> **Communicate constitutional outcomes. Never invent educational meaning.**
