## 1. Purpose

Without a closed source catalogue, product surfaces invent provenance: A/B winners, proximity heuristics, or “the model said so.” This document names every class of input that may lawfully contribute to a constitutional recommendation.

Sources **contribute**. They do not automatically create a recommendation. Assembly still requires structure (`RECOMMENDATION_STRUCTURE.md`), boundaries (`RECOMMENDATION_BOUNDARIES.md`), and — when concurrency arises — Conflict Resolution disposition.

## 2. Source Catalogue

| ID | Source class | Role in a recommendation |
|----|--------------|--------------------------|
| **ERS-01** | Programme VI coach / planner outputs | Primary educational guidance meaning |
| **ERS-02** | Workflow Engine context | Orchestration situating (event, stages, participation, outcome class) |
| **ERS-03** | Authority Engine decisions | Constitutional owner, permission, refusal, delegation facts |
| **ERS-04** | Conflict Resolution outcomes | Acted-upon / deferred / superseded / queued / merged / rejected disposition |
| **ERS-05** | Educational Evidence (EIP-002) | Observational warrants supporting claims |
| **ERS-06** | Canonical Study Plan & Profile inputs | Binding preparation contract and diagnostic context (consumed, not rewritten) |
| **ERS-07** | Constitutional reference corpus | Document IDs and principles that establish validity |

## 3. ERS-01 — Programme VI Coach / Planner Outputs

**Definition.** Authorised educational artefacts produced under Programme VI constitutional models — Master Planner, Daily Coach, Learning Coach, Recovery Coach, Revision Coach, Exam Coach (and their specialised session / reflection / obstacle / intervention corpora where those models emit guidance).

| Property | Requirement |
|----------|-------------|
| Role | **Primary meaning source** for educational guidance |
| May supply | Today’s priority, learning response, recovery warrant, revision emphasis, exam approach, structural / plan guidance |
| Must not | Be rewritten, averaged, or silently merged across coaches by the recommendation layer |
| Owner | Remains the Programme VI component named by the Authority Model |

**Tutor rationale.** Recommendations speak coach and planner meaning; they do not replace it.

**Examples of lawful contribution:**

- Daily Coach artefact: “Most valuable today is topic X under Learning Mode Y.”
- Recovery Coach artefact: “Restore continuity with a sustainable return sitting.”
- Master Planner handoff: “Envelope change requires plan adjustment.”

**Unlawful:**

- A tip authored only by a recommendation service with no Programme VI artefact.
- A blended tip that invents a compromise meaning no coach warranted.

## 4. ERS-02 — Workflow Engine Context

**Definition.** Orchestration facts published by Programme VII Workstream 1 — initiating / continuing event class, warrant, primary authority selection, stage path, handoff / refuse / escalate outcome class, and completion status of orchestration duties.

| Property | Requirement |
|----------|-------------|
| Role | **Context source** — situates why guidance is live now |
| May supply | Event reason, participation set, stage outcomes, handoff targets, no-op / refuse / escalate classes |
| Must not | Substitute for Programme VI educational meaning or invent independent tips |
| Owner | Workflow Engine owns orchestration facts; coaches own educational answers |

**Tutor rationale.** Students deserve to know that guidance shifted because of a return to study, a disruption, or exam proximity — without orchestration pretending to be the tutor.

---

## 5. ERS-03 — Authority Engine Decisions

**Definition.** Ownership and permission artefacts from Programme VII Workstream 2 / MS001 (and permission narration facts consistent with WS2 / MS003) — who owns the decision, whether a component was permitted, refusals, and bounded delegation warrants.

| Property | Requirement |
|----------|-------------|
| Role | **Ownership source** — names the accountable constitutional owner |
| May supply | Owner identity, domain justification, refusal of non-owners, delegation bounds |
| Must not | Invent ownership, transfer domains, or absorb coach meaning under an “authority tip” |
| Owner | Authority Model owns the ownership map; recommendations consume it |

**Tutor rationale.** Every tip must answer “who owns this?” without product proximity inventing an owner.

---

## 6. ERS-04 — Conflict Resolution Outcomes

**Definition.** Disposition artefacts from Programme VII Workstream 2 / MS002 — RO-01…RO-06 (and any future RO-xx) applying when multiple constitutionally valid recommendations compete for action.

| Property | Requirement |
|----------|-------------|
| Role | **Disposition source** — which valid tip is primary *now*, and what happened to siblings |
| May supply | Acted-upon designation, defer / supersede / queue / merge / reject-as-unlawful records |
| Must not | Rewrite Programme VI meaning, transfer ownership, or invent ranking scores as constitutional law |
| Owner | Conflict Resolution Framework owns disposition law; recommendations communicate its outcomes |

**Tutor rationale.** When several good pieces of advice arrive at once, the recommendation artefact must reflect the lawful acted-upon outcome — not invent a fourth tip.

---

## 7. ERS-05 — Educational Evidence (EIP-002)

**Definition.** Observational Educational Evidence and permitted estimate inputs under EIP-002 / EIP-006 / Twin estimate paths — consumed as warrants, never redefined by the recommendation layer.

| Property | Requirement |
|----------|-------------|
| Role | **Evidence source** — supports educational claims honestly |
| May supply | Observations, classified evidence types, estimate inputs with claim-type honesty |
| Must not | Re-label coverage as understanding/mastery; invent evidence; mute contradictory observations |
| Owner | Evidence Model and permitted writers; recommendations consume |

**Tutor rationale.** Tips without honest evidence become theatre. Tips that overclaim from thin evidence become unlawful speech.

---

## 8. ERS-06 — Canonical Study Plan & Profile Inputs

**Definition.** The Canonical Study Plan (Master Planner / Scheduling educational contract) and Student Educational Profile diagnostic context — binding inputs that recommendations work *inside*, never rewrite.

| Property | Requirement |
|----------|-------------|
| Role | **Contract / diagnostic source** |
| May supply | Plan commitments, mode envelopes, diagnostic “where the student is now” as inputs |
| Must not | Modify, invalidate, or silently rewrite plan or profile via recommendation packaging |
| Owner | Master Planner / Scheduling for plan; Profile owned per Programme VI / EIP maps |

---

## 9. ERS-07 — Constitutional Reference Corpus

**Definition.** Explicit references to governing educational documents and principles that establish why the recommendation is constitutionally valid (Constitution, Logic Registry entries, EIP standards, Programme VI models, Programme VII corpora).

| Property | Requirement |
|----------|-------------|
| Role | **Validity source** — audit trail of applicable law |
| May supply | Document paths, principle IDs (e.g. ERO, ERS, ERC, EL-008), boundary citations |
| Must not | Cite unpublished “internal policy,” marketing briefs, or undocumented heuristics as constitutional law |
| Audience | Primarily developer / auditor; student speech may omit IDs while remaining faithful |

## 10. Source Composition Rules

1. **ERS-01 is mandatory for material educational guidance.** A tip that tells the student what to study, revise, recover, or exam-prepare without ERS-01 is unlawful — unless the communicated outcome is explicitly refuse / escalate / no-recommendation under WS1/WS2 law (still requiring ERS-02/ERS-03 as applicable).
2. **ERS-03 is mandatory for every material recommendation.** Owner must be named.
3. **ERS-05 is mandatory when the guidance asserts observational or estimate-backed claims.** Thin or absent evidence must be spoken as limits, not invented as certainty.
4. **ERS-02 is required when the recommendation is an orchestrated outcome** (normal Programme VII path). Standalone Programme VI artefacts consumed outside orchestration still need lawful invitation rules before becoming student-facing primary guidance.
5. **ERS-04 is required when concurrency was dispositioned.** Acted-upon speech must not hide sibling dispositions that affect the student’s understanding of why this tip leads.
6. **ERS-06 must be respected, not mutated.** Working “under the plan” is source consumption; rewriting the plan is forbidden.
7. **ERS-07 must be reconstructable for auditors** even when student copy is plain-language only.

## 11. Explicitly Unlawful Sources

The following must **never** originate or solely justify a constitutional educational recommendation:

| Unlawful source | Why |
|-----------------|-----|
| Undocumented heuristics or “common sense” tips | No constitutional provenance |
| Engagement / growth / monetisation optimisers | Product metrics ≠ educational meaning |
| Undocumented A/B or ranking winners | Not constitutional law; may not invent meaning |
| UI layout proximity (“nearest card”) | Presentation ≠ ownership |
| Version 2 Adaptive / Twin / Mission labels as tutor substitutes | Infrastructure authorities do not replace Programme VI / VII recommendation law |
| Silent average of conflicting coach tips | Merge only via published RO-03 pathway |
| Fabricated evidence or invented mastery | Violates EIP-002 / EIP-006 |
| Workflow stage completion alone as learning success | Orchestration fulfilment ≠ educational recommendation warrant |
| Founder / marketing copy as educational authority | Non-constitutional speech |

## 12. Source Trace Minimum

Every material constitutional recommendation must be able to answer:

| Question | Source class |
|----------|--------------|
| What guidance is being communicated? | ERS-01 (or explicit refuse / no-recommendation posture) |
| Who owns it? | ERS-03 |
| What evidence supports claims? | ERS-05 (or explicit thin-evidence limit) |
| Under what orchestration? | ERS-02 (when orchestrated) |
| If peers competed, what disposition applies? | ERS-04 (when concurrency arose) |
| Under which plan / diagnostic envelope? | ERS-06 |
| Which constitutional law makes it valid? | ERS-07 |

Failure of this trace makes the tip **not** a constitutional recommendation — regardless of UI polish.

---

## 13. Closing

Recommendations inherit authority from their sources. They never invent a source by packaging.

When provenance is missing, **refuse**.  
When a new source class seems necessary, **amend this catalogue first**.  
When sources conflict for action, **apply Conflict Resolution** — do not invent an undocumented blend.

> **No undocumented source. No invented tip.**
