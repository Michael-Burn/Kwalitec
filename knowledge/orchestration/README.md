# Orchestration

**Programme:** VII — Educational Workflow Engine / Educational Authority Engine / Educational Recommendation Engine / Educational State Engine  

Permanent specifications for **how educational decisions flow between constitutional educational components**, **which component owns which educational decisions**, **what a constitutional educational recommendation is**, **how lawful recommendations are assembled into coherent recommendation sets**, **how assembled recommendation sets are explained**, **what constitutional educational state (context) may exist**, **when constitutional educational context may lawfully transition**, and **how constitutional educational context and contextual progression are explained**.

Orchestration coordinates Programme VI educational reasoning. Authority catalogues decision ownership. Recommendations communicate lawful guidance. Assembly organises lawful recommendations into sets. Set explainability narrates packaging without inventing tips. Educational state represents constitutional educational context without claiming success, mastery, or workflow completion. Contextual state transitions update that representation without redefining meaning, transferring authority, creating tips, or executing workflows. Educational state explainability narrates live context and lawful succession without inventing meaning, mastery, tips, or ownership. None redefine educational meaning, Canonical Study Plan contracts, or Educational Evidence.
